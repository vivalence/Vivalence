:wave: After 3 years building this solo, I'm finally opening the doors on - what I hope to be - my life's work.

It's called **Vivalence** — an AI-era operating system and application platform.

**The shape of it:** a Svelte-powered client running mini-apps against isolated, persistent daemons — each with their own domain logic, types, and dataspace — in a custom Deno runtime. The whole system is built from a small set of primitives that compose into something genuinely new. A terminal client is in the works. 

:test_tube: **First case study:** a language learning system. The domain that originally pulled me into this rabbit hole — Vivalence started as the education system I wished existed, and grew into a general AI OS.

You don't install apps, you install **modes**. Functionality emerges from modes implementing **traits**:
– `dataset` → brings data in
– `buffered` → renders Svelte views
– `conversational` → agentic chat
– …and lots lots lots more

I'm not great at pitching my own work, so I'll just say: I think Vivalence is genuinely powerful — intended to be the **Mosaic-browser equivalent for the AI age**. Something uniquely enabled by the technology landscape of our time - aka. AI.

**A caveat though:** it's still very very early. The system isn't really functional beyond a narrow use-case and with limited functionality. But after 3 years, the architecture is finally stable — and that's why other (technical) eyeballs and fingertipps would now help more than hurt.
