* intent
** walk
*** Core Intent
Progressive Signal Resolution: Navigate step-by-step by requesting signals only when needed, based on current context
Context-Aware Traversal: Each step informs the next by exposing available patterns to the signal generator
Stateless Composition: Pure functional approach where each traversal step produces the next computation state

*** Typology Summary

#+begin_src 
walk :: (Vector, SignalGenerator, Middleware, Path, Step) -> Promise<Result>

where:
  Vector         = routing/pattern tree with effects and descendants  
  SignalGenerator = (patterns: Pattern[]) -> Promise<Signal[]>
  Middleware     = (context, next) -> Promise<any>
  Path          = Match[]  // breadcrumb trail of matches
  Step          = Number   // recursion depth counter
  Result        = { effect, middlewares, path }
#+end_src

*** Behavioral Pattern

Request → Ask signal generator for next signals based on current vector's available patterns
Traverse → Use pure traverse function to attempt navigation with provided signals
Decide → If effect found, return composed result; otherwise recurse with new vector position
Accumulate → Collect middlewares and path steps across all traversal stages

async function do (vector,signal,input ){

  const context = { input };
  await composed(context, async (ctx) => (ctx.effect = await effect(ctx.input, ctx)));
