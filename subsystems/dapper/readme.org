#+title: dapper — the design system, tokens to CSS

* the pipe

#+BEGIN_EXAMPLE
definition                   what a theme declares — any subset of the token space, in any of its forms
  theme(definition)          fill · derive · merge; throws on a fault
  Theme                      static: 85 root keys, four zones of 97
    emit(name, Theme)        :root[data-theme] = zone 1 whole · four [data-zone] blocks
scales()                     :root — fonts, type sizes, line heights, spacing, radii, shadows
design()                     scales, then every theme emitted, joined
#+END_EXAMPLE

The token space is the contract: seven groups (shape · size · text · control · signal · brand · font) and four zones (0 chrome · 1 body · 2 island · 3 bench). Its schematics live in =subsystems/typology/schematics/primitives/theme.js=. The whole system is described in =.ikiro/reference/design.md=.

* the files

- =lib/theme.js= :: =theme(...Definition) → Theme=
- =lib/emit.js= :: =emit(name, Theme) → css= · =declarations(zone)=
- =lib/contrast.js= :: =contrast= · =channels= · =wash= · =blend= · =flatten= · =luminance=
- =lib/tokens.js= :: =TOKENS= · =scales()=, the lengths and fonts no theme owns
- =lib/system.js= :: =design()=
- =themes/<name>/theme.js= :: one theme, written in the steps of its own =gradients.js=
- =themes/index.js= :: =THEMES=, the theme list
- =belt/tailwind-theme.js= :: slots and scales as tailwind classes
- =lifecycle/index.js= :: the postcss plugin; prepends the sheet at build time
- =primitives/font.css= · =primitives/bsp.css= :: reached through anima's aliases

* a theme

#+BEGIN_SRC js
// subsystems/dapper/themes/<name>/theme.js
import { theme } from "../../lib/theme.js";
import { paper, ink } from "./gradients.js";

export default theme({
  text:   { ink: paper[800] },
  signal: { primary: ink[500] },
  zones:  { 1: paper[100] },
});
#+END_SRC

Three values are the floor; everything else is filled, derived or merged. A colour belongs to the theme that owns it: no gradient is shared and none is emitted.

* a view

A view reads by name inside a =data-zone= container and never names a zone number: =var(--surface)= · =var(--text-ink)= · =var(--signal-negative-ink)=.
