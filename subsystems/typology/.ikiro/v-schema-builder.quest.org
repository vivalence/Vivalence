* Intent

=v= is the sole schematics interface. Fluent Proxy over TypeBox.
Same JSON Schema output, same engine, dramatically better ergonomics.

* Architecture

#+BEGIN_SRC
schematics/
  lib.js          ← sole TypeBox consumer. enhance + entityFactory + v primitives
  scalars/        ← domain scalars (ID, Slug, Timestamp, etc.)
  entities/       ← entity descriptors (own fields + relation thunks)
    base.js       ← BaseEntitySchema
    buffer.js     ← BufferDescriptor
    literal.js    ← LiteralDescriptor
    symbol.js     ← SymbolDescriptor
    mode.js       ← ModeDescriptor
    intent.js     ← IntentDescriptor
    session.js    ← SessionDescriptor
    user.js       ← UserDescriptor
  primitives/     ← auth
  prototypes/     ← StatusCode, Status, ErrorResponse
  index.js        ← assembles v: wires entity factories + v.rel() after all modules load
#+END_SRC

* The Proxy

#+BEGIN_SRC javascript
function enhance(schema) {
  return new Proxy(schema, {
    get(target, prop, receiver) {
      if (prop === "desc") return (d) => enhance({ ...target, description: d });
      if (prop === "$id") {
        if ("$id" in target) return target.$id;
        return (name) => enhance({ ...target, $id: name });
      }
      if (prop === "optional") return () => enhance(Type.Optional(target));
      if (prop === "default") {
        if ("default" in target) return target.default;
        return (val) => enhance({ ...target, default: val });
      }
      if (prop === "check") return (value) => Value.Check(target, value);
      if (prop === "create") return () => Value.Create(target);
      if (prop === "clean") return (value) => Value.Clean(target, value);
      if (prop === "errors") return (value) => Value.Errors(target, value);
      if (prop === "compile") return () => Compile(target);
      if (prop === "defaults") return (value) => (Value.Default(target, value), value);
      return Reflect.get(target, prop, receiver);
    },
  });
}
#+END_SRC

* v Surface

** Primitives (constructor opts for constraints)

=v.string(opts)=, =v.number(opts)=, =v.boolean()=, =v.integer(opts)=,
=v.object(props, opts)=, =v.array(items, opts)=, =v.union(variants, opts)=,
=v.intersect(schemas, opts)=, =v.const(val)= (JSON Schema const, was TypeBox Literal),
=v.record(keys, values)=, =v.any()=, =v.unknown()=, =v.null()=

** Chain methods

- =.default(val)= / =.default= — setter when no default, value when exists
- =.desc(text)= — sets description
- =.optional()= — wraps in Type.Optional
- =.$id(name)= / =.$id= — setter/getter, same dual pattern as .default

** Instance operations

- =.check(val)= — Value.Check
- =.create()= — Value.Create (instantiate from defaults)
- =.clean(val)= — Value.Clean (strip unknown properties)
- =.errors(val)= — Value.Errors (iterator)
- =.compile()= — Compile (JIT validator)
- =.defaults(val)= — Value.Default (mutates + returns)

** Static operations

- =v.diff(a, b)= — JSON Patch
- =v.patch(val, edits)= — apply patch
- =v.equal(a, b)= — deep equality
- =v.clone(val)= — deep clone

** JSON Schema references

- =v.$ref(schema)= — JSON Schema =$ref=
- =.$id(name)= — JSON Schema =$id=

** Relations (MikroORM)

- =v.rel(schema)= — Rel duality: =Union(ID, schema)=. For m:1, 1:1.
- Collections (m:n, 1:m) use =v.array(v.entity())= directly — no rel.

** Entity factories

=v.buffer(spec)=, =v.literal(spec)=, =v.symbol(spec)=, =v.mode(spec)=,
=v.intent(spec)=, =v.session(spec)=, =v.user(spec)=

No args = base schema. With spec = narrowed via Intersect.
Built via =entityFactory(descriptor, BaseEntitySchema)=.
Descriptors declare own fields + relation thunks.
Cycle detection (Literal ↔ Symbol) returns base schema sans relations.

* Entity Descriptors

Each descriptor has: =$id=, =own= (eager fields), =relations= (thunks),
=narrowable= (fields that get wrapped in Type.Object when narrowed).

#+BEGIN_SRC javascript
// Example: buffer.js
export const BufferDescriptor = {
  $id: "Buffer",
  own: {
    index: v.integer().default(0).optional(),
    data: v.record(v.string(), v.unknown()).optional(),
  },
  relations: {
    mode: () => v.rel(v.mode()).optional(),
    session: () => v.rel(v.session()).optional(),
    literals: () => v.array(v.literal()).optional(),
    symbols: () => v.array(v.symbol()).optional(),
  },
  narrowable: ["data"],
};
#+END_SRC

Thunks are needed because descriptors import =v= from =lib.js= where
entity factories aren't wired yet. The thunks are called at factory
invocation time, when =schematics/index.js= has finished assembly.

* Naming Decisions

- =v.const()= not =v.literal()= — JSON Schema keyword is =const=.
  Freed =literal= for the Literal entity.
- =v.rel()= not =v.ref()= — follows MikroORM's =Rel<T>= naming.
  =$ref= is JSON Schema's reference (=v.$ref()=). No collision.
- =Ref= scalar deleted. =v.rel(v.entity())= is the only pattern.
