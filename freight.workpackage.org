#+TITLE: Freight — Asset Serving System
#+STATUS: DRAFT

* Summary

Freight mirrors the View pattern for static file assets.
Two new traits: FRAUGHT (mode provides assets), VOCALIZED (literal has audio).
FRAUGHT is universal. First application: topology/brazilian-survival provides
audio assets consumed by game/flashcard.

Daemon-level freight merge: all FRAUGHT modes' catalogs merge into daemon.freight
during resolution. Consuming modes don't need to know which mode owns an asset.

* Reference: How View Works

  The pattern freight mirrors end-to-end.

  1. Prototype (typology/prototypes/view.js):
     constructor receives relative path, wraps as Path.
     Build step: bundle() compiles via esbuild.
     Serve step: serve(branch) returns text + type.

  2. Mode export (.viva.js):
     const view = new View("buffer/flashcard.svelte.js");
     export { manifest, view, dataset };

  3. Population (daemon/lifecycle/population.js:127-136):
     Resolves path: view.path.from(new Path(cake.mount.dirname))
     Assigns URL: view.withUrl(daemonDie.good.attach.branch("/view").branch(...))

  4. Trait handler (daemon/mode/traitmap.js:8-12):
     view.withBundler(svelte); await view.bundle();
     mode.aperture.open("/view", () => ({ url: view.url.absolute }));

  5. Attachment (runtime/lifecycle/resolve.js:19-36):
     /attached/view/{mode.mount}/(.*) serves bundled JS.
     Uses fromm.params(ctx.params).path to extract the captured path.

  6. Client (html/src/typology/entities/daemon.js:73):
     if (mode.implements("VIEWABLE")) mode.view = await mode.connection.call("/view");
     Frame.svelte: import(buffer.view.url)

  Critical: mode.mount = URL path, mode.cake.mount = filesystem path.
  Cake constructor does Object.assign so mode.view === mode.cake.view.

* Design: Freight Prototype

  Location: subsystems/typology/prototypes/freight.js
  Server only. Uses Deno.readDir. NOT exported on client barrel.

** Interface

   constructor(path: string)
     Wraps as Path. Passthrough: new Freight(existingFreight) === existingFreight.
     Initializes entries = [].

   withUrl(url: Url) → self
     Stores attachment URL for catalog generation.

   async index(root?: string) → self
     Recursive scan of this.path.absolute. root is internal recursion param
     tracking relative path. Populates this.entries.

   resolve(query: string) → entry | undefined
     Three-pass lookup in priority order:
       1. Exact path match: query === entry.path
       2. Path without extension: query === path minus ext
       3. Slug match: query === entry.slug
     Lets literal authors write either path ("sentences/oi-tudo-bem") or slug ("oi-tudo-bem").

   get catalog → { [pathWithoutExt]: { type, url } }
     Keys: entry path minus extension. Unique identifier per file.
     url: this.url.branch("/" + entry.path).absolute, or null if withUrl not called.

** Entry Shape

   #+begin_src js
   {
     slug: "oi-tudo-bem",                  // filename minus extension
     path: "sentences/oi-tudo-bem.mp3",    // relative to freight root, with extension
     type: "audio/mpeg",                   // mime from extension
   }
   #+end_src

   Flat files: path === filename ("beep.mp3").
   Nested: path includes subdirectory ("sentences/oi-tudo-bem.mp3").

** Mime Map

   mp3→audio/mpeg wav→audio/wav ogg→audio/ogg
   png→image/png jpg→image/jpeg jpeg→image/jpeg svg→image/svg+xml webp→image/webp
   mp4→video/mp4 webm→video/webm json→application/json
   Unknown → application/octet-stream

** Implementation

   #+begin_src js
   import { Path } from "./path.js";

   const MIME = {
     mp3: "audio/mpeg", wav: "audio/wav", ogg: "audio/ogg",
     png: "image/png", jpg: "image/jpeg", jpeg: "image/jpeg",
     svg: "image/svg+xml", webp: "image/webp",
     mp4: "video/mp4", webm: "video/webm",
     json: "application/json",
   };

   export class Freight {
     entries = [];

     constructor(path) {
       if (path instanceof Freight) return path;
       this.path = new Path(path);
     }

     withUrl(url) {
       this.url = url;
       return this;
     }

     async index(root = "") {
       const base = root
         ? this.path.branch("/" + root).absolute
         : this.path.absolute;

       for await (const entry of Deno.readDir(base)) {
         const relative = root ? root + "/" + entry.name : entry.name;
         if (entry.isDirectory) {
           await this.index(relative);
           continue;
         }
         if (!entry.isFile) continue;
         const ext = entry.name.split(".").pop().toLowerCase();
         this.entries.push({
           slug: entry.name.replace(/\.[^.]+$/, ""),
           path: relative,
           type: MIME[ext] || "application/octet-stream",
         });
       }
       return this;
     }

     resolve(query) {
       return (
         this.entries.find((e) => e.path === query) ||
         this.entries.find((e) => e.path.replace(/\.[^.]+$/, "") === query) ||
         this.entries.find((e) => e.slug === query)
       );
     }

     get catalog() {
       return Object.fromEntries(
         this.entries.map((e) => [
           e.path.replace(/\.[^.]+$/, ""),
           {
             type: e.type,
             url: this.url ? this.url.branch("/" + e.path).absolute : null,
           },
         ]),
       );
     }
   }
   #+end_src

* Design: Daemon-Level Freight

** Merge

   After all modes resolve their traits (so FRAUGHT has run index()), a new
   resolution step merges all FRAUGHT modes' catalogs into daemon.freight.

   Location: daemon/lifecycle/resolution.js, new export freight().

   #+begin_src js
   export async function freight(daemonDie) {
     daemonDie.good.freight = {};
     for (const mode of daemonDie.good.flatmodes()) {
       if (!mode.implements("FRAUGHT")) continue;
       const catalog = mode.cake.freight.catalog;
       for (const [key, value] of Object.entries(catalog)) {
         if (daemonDie.good.freight[key]) {
           console.warn(`[FREIGHT] slug collision: "${key}" — overwriting`);
         }
         daemonDie.good.freight[key] = value;
       }
     }
   }
   #+end_src

   Slug collision is a dataset bug. Warn, don't crash.

** Path Extraction Detail

   The (.*) capture via aperture produces params = { 0: "full/path/file.mp3" }.
   fromm.params(ctx.params).path (gestalten/fromm/index.js:29-39) builds a Path
   by iterating params[depth]. With a single capture, this yields a Path with
   nature "/full/path/file.mp3" (Path normalizes by prepending /).

   Freight entry paths don't have leading slash. Strip it before resolve:
   path.nature.replace(/^\//, "")

** Implementation

   #+begin_src js
   async function attachFreight(runtimeDie) {
     for (const daemonDie of runtimeDie.good.daemons) {
       for (const mode of daemonDie.good.flatmodes()) {
         if (!mode.implements("FRAUGHT")) continue;
         runtimeDie.good.aperture
           .branch("/attached/freight")
           .branch(mode.mount.absolute)
           .use(shards.context.attach("mode", mode))
           .open("/(.*)", async (input, ctx) => {
             const captured = fromm.params(ctx.params).path;
             const query = captured.nature.replace(/^\//, "");
             const entry = ctx.mode.cake.freight.resolve(query);
             if (!entry) {
               ctx.response.status = 404;
               return;
             }
             const filePath = ctx.mode.cake.freight.path
               .branch("/" + entry.path).absolute;
             ctx.response.type = entry.type;
             return await Deno.readFile(filePath);
           });
       }
     }
   }
   #+end_src

   Uses /(.*) not /:file — filenames contain dots.
   Uint8Array return: Oak handles binary via ctx.response.body.
   ctx.response.type set before return bypasses JSON default in compose middleware.

   URL structure:
   http://HOST/attached/freight/daemon/SLUG/mode/topology/SLUG/file.mp3
   Mirrors: http://HOST/attached/view/daemon/SLUG/mode/game/SLUG/bundle.js
