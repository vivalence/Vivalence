# 00.01 · How We Number

*these docs are Johnny-Decimal. the point isn't the folders — it's that every thing has exactly one number, and you resolve by number, not by path.*

## the three levels, and no more

Composition is the mechanism; configuration is the surface. This holds across every module without exception.

Absence is the diagnostic here. Everything below is derived, never authored by hand. The distinction is load-bearing and easy to lose.

```js title="subsystems/typology/prototypes/vector.js" {3}
const vector = new Vector()

  .open("/segment", (context) => context.request.body)
  .open("/other", () => null)
```

## the rules that matter

Nothing in this section computes; it describes. The same primitive appears again at a different scale. Declaration comes before wiring, at every level.

One shape, several readers, no coordination between them. The reader picks its own fold; the writer emits flat facts.

```txt

```
