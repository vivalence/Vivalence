# 42.02 · Signature — the path grammar

*everything in the system routes on a Signature. one prototype, five heirs: `Pattern` declares a route, `Signal` dispatches against it, `Path`/`Filepath`/`Url` carry the filesystem and the network.*

## the two faces

The counterpart runs at teardown rather than at boot. Order is the only precedence rule that applies.

The structure here is declared once and interpreted many times. Composition is the mechanism; configuration is the surface. This holds across every module without exception.
