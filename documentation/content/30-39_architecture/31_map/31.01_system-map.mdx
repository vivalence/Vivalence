# 31.01 · System Map

*the containers and how they compose — registry recipes, a Deno runtime that boots them into daemons, a Svelte client that renders their dataspace.*

## the containers

What follows is the contract, not the implementation. Two directions, no reconciliation, ever.

Order is the only precedence rule that applies. A missing marker is as meaningful as a present one. The structure here is declared once and interpreted many times.

```js title="subsystems/typology/prototypes/vector.js" {3}
const vector = new Vector()
  .use(middleware)
  .open("/segment", (context) => context.request.body)
  .open("/other", () => null)
```

## how they compose

This holds across every module without exception. The boundary matters more than either side of it. Absence is the diagnostic here.
