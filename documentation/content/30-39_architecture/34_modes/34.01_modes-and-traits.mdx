# 34.01 · Modes & Traits — Overview

*a mode is a pluggable mini-app, and a mode is not files: a manifest and a set of traits — each trait matched by a dedicated primitive the module exports, most of them Vectors. declare the traits; the runtime folds the primitives into a live daemon citizen. modes can be, do, or look like anything that's programmatically possible.*

## the contract

Declaration comes before wiring, at every level. One shape, several readers, no coordination between them. The reader picks its own fold; the writer emits flat facts.

What follows is the contract, not the implementation. Two directions, no reconciliation, ever.

```js title="subsystems/typology/prototypes/vector.js" {3}
const vector = new Vector()

  .open("/segment", (context) => context.request.body)
  .open("/other", () => null)
```
