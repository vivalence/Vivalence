---
title: Install the system
summary: From git clone to a booted client.
---

Deno ^2.7 must be installed. Currently only installation from repo at this point.

minimum vocabulary required:

- `viva` — the CLI. Installed to the OS, or `deno task ghost/run` if so inclined.
- `ledger` — the `~/.viva` directory for system-level stuff: the package store, the instance shelf, the record of tapped packages, logs, locks.
- `package` — a unit of modes living in the registry, likely git-managed. Services, applications, datasets, harnesses, and instances are grouped into a package.
- `instance` — an executable system unit made up of runtime and clients, and the daemons running on top of them. The ledger shelves many; a runtime renders exactly one.

## Install the Vivalence CLI

```sh
git clone https://github.com/vivalence/vivalence.git vivalence
cd vivalence
deno task install
viva ledger/init
```

`deno task install` fetches dependencies and links `viva` into `~/.deno/bin` — the CLI
remembers the repo via `~/.config/viva/env`. `ledger/init` is a wizard: it picks the
ledger home (default `~/.viva`), persists `VIVA_LEDGER_MOUNT`, and scaffolds
`locks/ logs/ registry/ instances/`. The in-repo packages register at first boot.

## Add a package

tap a package — a local path is recorded as-is, a git URL is cloned into the store
(or into the target, if given). `doctor` shows the record, the store census, and the homes.

```sh
viva ledger/tap <path | git url> [target]
viva ledger/doctor
```

## Set up an instance

create an instance out of the registry — without a target it lands on the shelf,
and `VIVA_INSTANCE_MOUNT` accepts its bare slug

```sh
viva instance/create @viva/instance/localhost
export VIVA_INSTANCE_MOUNT=localhost
```

`instance/init` runs first-boot: the first call seeds `.env` from `.env.example` — fill it,
then run it again and the wizard boots the instance, creates your account against its
lighthouse, and stops.

```sh
viva instance/init
$EDITOR ~/.viva/instances/localhost/.env
viva instance/init
```

## Boot runtime and client

```sh
viva instance/run
```

more users later, against the running instance:

```sh
viva instance/auth signup <username> <password>
```
