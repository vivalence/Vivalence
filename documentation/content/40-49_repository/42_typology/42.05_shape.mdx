# 42.05 · shape — the compilers

*Vector → a value. every one of them is a catamorphism over the same trie. they differ only in what they fold TO.*

`subsystems/typology/gestalten/shape/`. Eleven files, ~400 lines. Only three of them do real work on the trie — `object`, `strip`, and `survey`-based introspection; everything else is a variation on those.

## the family, and who calls it

Call sites outside tests, from a repo-wide sweep. The distribution is the argument:

```
object          → nested CALLABLE        runtime 2 · typology 2    EMITTER, HARNESSED, hallucination
strip           → { effect?, branches }  runtime 5 · typology 3    the /metadata contract
connection.wire → nested CALLABLE        kajuit 4                  the client half of the dual
http            → (Request) → Response   runtime 2                 every HTTP boundary
proxy           → lazy callable          runtime 1                 EXPOSED — mode.call
selbstbestimmt  → first-effect runner    kajuit 1                  per-entity `integrate`
flat / tree     → introspection          kajuit 4                  the nav menu + inspector
agentic         → tool-name namespace    runtime 1 · registry 1    cortex tool bundling
subscriber      → change-feed binding    runtime 1
cortex          → faculty surface        runtime 1 · kajuit 1
messenger       → socket push            — no call sites
mcp             → JSON-RPC server        — no call sites
```

`messenger` and `mcp` are **built but unmounted**. `mcp` is a complete JSON-RPC 2.0 server (`mcp.js:20`) that turns every leaf into a tool via `steer.trie.rollup(vector, steer.strategy.guarded)` — note `guarded`, so tool calls are schema-validated where ordinary routes are not. Nothing in the repo serves it yet.

Nothing coordinates those two files. They agree because a `Connection`'s branches mirror an `Aperture`'s segment for segment ([[42.07_aperture-connection]]).

## what wire actually does

`wire` is not a naive mirror — it makes four decisions the strip alone doesn't express (`shape/connection.js`):

- **parameter branches become a `Proxy`.** A `:name` child is held aside and installed as a proxy trap, so `mode.greet.bob()` resolves remotely by property access — the same trick `shape.proxy` plays locally.
- **wildcard and remainder branches are dropped**, with a console warning (`connection.js:8`). `*` and `(.*)` do not cross the wire. A route that relies on them is unreachable from the client.
- **a method-ambiguous leaf throws** — "no transparent projection" (`connection.js:29`). If a leaf answers both GET and POST, the client cannot guess which, so it refuses rather than pick.
- **`yields` switches the caller to streaming.** See below.

## yields — the streaming contract

The only piece of edge metadata that changes *what kind of function you get back*. It is declared once and read three files away:

```
declare   harnessed.js:105   .open({ nature: "stream", yields: Packet.Session }, …)
strip     strip.js:7         meta.yields = pattern.yields        → crosses the wire
wire      connection.js:35   effect.yields !== undefined         → connection.stream(…)
```

A leaf with `yields` becomes an async-iterator caller; a leaf without it becomes a plain awaited call. The client never configures streaming — it reads the contract. The runnable file below walks all three steps.

## eager versus lazy

`object` is **eager** — it folds the whole trie up front, so only literal natures become keys. A parametric route contributes the literal key `":name"`, which is not callable per-user. `proxy` is the lazy sibling: a `Proxy` resolving each segment on access.

That is exactly why `EXPOSED` uses `proxy` and not `object` (`runtime/daemon/traits/index.js:32`) — a mode's aperture is full of `:id` routes, so `mode.call.entities.thread["019e…"]()` has to resolve at access time.

## what strip keeps

`strip` is the faithful catamorphism of the Vector's own `{ effect, trajectories }`. Each node folds to `{ effect?, branches }` — node-centric, no separate leaves array. The node's own effect rides `effect`; edge metadata (`input`/`output`/`yields`/`methods`) is plucked from the **pattern**, per law 3 in [[42.03_vector]].

An effect with no metadata strips to `{}` — present but empty. The distinction is load-bearing: `undefined` means *no effect here*, `{}` means *effect with nothing declared*.

## the Vector as a menu

The clearest proof that a Vector is not a router: kajuit's navigation panel builds one out of threads, then folds it with `shape.flat` to get a list of clickable items (`systems/kajuit/src/app/panels/d/navigation.js:74`).

```js
threads: shape.flat(threadsVector, steer.strategy.direct),
intents: shape.flat(intentsVector, steer.strategy.direct),
modes:   shape.flat(modesVector,   steer.strategy.direct),
```

Each leaf's `nature` is the label, its `valence` the description, its effect the click handler. No HTTP, no signal, no dispatch — the same structure, folded for a UI list. `steer.strategy.direct` is chosen because the context already exists; there is no request to build.
