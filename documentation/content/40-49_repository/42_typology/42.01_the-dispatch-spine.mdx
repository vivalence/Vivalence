# 42.01 · The Dispatch Spine

*one inert dispatch structure, declared with combinators and folded by many interpreters. the HTTP server and the client are two folds of the same thing. this page is the map; each layer has its own page.*

`subsystems/typology` **is** the vocabulary — power is emergent from composing small prototypes, not from big classes.

## the five layers

```
Signature       the path grammar        Pattern declares · Signal dispatches        → 42.02
Vector          the composer            use · branch · open · slurp · swallow       → 42.03
steer           the controllers         match · trie · dispatch · strategy          → 42.04
shape           the compilers           object · strip · wire · http · mcp …        → 42.05
shard           the middleware belt     transmitter · secure · datamap · track …    → 42.06

Aperture ⟷ Connection    serve a trie ⟷ call a trie                                → 42.07
```

## the law

```
declare once:   Vector  (use / branch / open / affect / slurp / swallow)     — inert
interpret many: shape.object (local) · shape.strip → wire (remote)
                shape.http (serve)  · steer.dispatch.invoke (dispatch)
dual:           Aperture (serve a trie) ⟷ Connection (call a trie)
                bridged by shape.http + strip/wire
```

A `Vector` computes nothing. It is a composable, context-threading **description** of dispatch — `use` chains middleware around a terminal effect, `next()` threads one `ctx` — that does nothing until an interpreter folds it. That deferral is the whole point: one structure, many interpreters, which is why the same declaration becomes a local call, an HTTP route, and a remote client depending only on which fold consumes it.

## who uses what

The layers are not equally public. Call sites outside tests, by container:

```
registry    declares inert Vectors + mounts datamap shards        — never folds anything
runtime     shape.object · strip · http · proxy · agentic         — owns the server folds
kajuit      shape.connection.wire · selbstbestimmt · flat · tree  — owns the client folds
ghost       steer.dispatch.invoke on a Signal built from argv     — the only app-level dispatcher
typology    every steer.trie.* and steer.match.* consumer         — steer is largely internal
```

The shape of that table is the architecture: **application code declares Vectors and calls compiled surfaces; it does not fold tries.** `steer` exists for `shape` to stand on.

## the four surprises

Each is demonstrated, not asserted, on its page:

1. **Declaration order beats segment type.** A `:param` declared before a literal shadows it permanently — there is no precedence rule. [[42.04_steer]]
2. **`fire` dispatches on declared arity**, so a handler written `(input) => …` receives the *context*. [[42.04_steer]]
3. **`yields` on an edge is the whole streaming contract** — declared in a trait, plucked by `strip`, read by `wire` three files away. [[42.05_shape]]
4. **A `Connection` is a memoized tree** whose children re-enter the parent's middleware chain. [[42.07_aperture-connection]]
