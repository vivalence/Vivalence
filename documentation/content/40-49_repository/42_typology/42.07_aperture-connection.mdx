# 42.07 · Aperture ⟷ Connection

*an `Aperture` SERVES a trie. a `Connection` CALLS one. they mirror segment for segment, and that mirror is the entire reason a stripped Vector re-inflates onto the right endpoints.*

## Aperture — a Vector with verbs

`prototypes/aperture.js` is 48 lines. It extends `Vector` and adds one idea: a **method-keyed leaf fold**.

```js
aperture.get("/thing", read)
aperture.post("/thing", write)
```

Both land on **one node**. The leaf's effect becomes a `methods` dispatcher — a function carrying a `methods` map — rather than two sibling leaves. Verbs are a property of the leaf, not of the path.

Four consequences:

- An unregistered verb on an existing node is a **405**, not a 404. The node exists; the method doesn't.
- `methods` is what `strip` plucks onto the wire (`strip.js:8`), which is how `wire` knows to send GET instead of POST.
- A method-ambiguous leaf asked *without* a method **throws**, unless exactly one handler is registered (`aperture.js:43`). `"*"` is the explicit any-method slot.
- Registering a verb on a leaf that already has a plain effect **demotes** that effect to `methods["*"]` (`aperture.js:18`) — it is preserved as the fallback, not overwritten.

The HTTP server is not a framework. It is `shape.http(aperture)` — a fold. Routing, middleware, and dispatch belong to the Vector. `http.js` is 71 lines, and half of it is response encoding.

## what shape.http adds

Beyond dispatch, the fold owns three behaviours worth knowing (`shape/http.js:35`):

- **async generators are auto-framed as SSE.** If a leaf returns an async iterator, `respond` wraps it into an event stream — which is what makes a `yields` leaf work end to end without the handler knowing about SSE.
- **`server-timing` comes from the span.** If `ctx.span` exists, its records are folded by `trace.chronicle` and emitted as a timing header (`http.js:57`).
- **404 versus 500 is decided by the throw.** A `NotFound` (or `code === "NOT_FOUND"`) is a 404; anything else is logged and returned as a 500 with `{ code: "INTERNAL" }`.

### a Connection is a tree, not a URL builder

This is the part that surprises. `branch()` walks segments, and each `child()` is **memoized** in a `children` Map (`connection.js:27`). More importantly, the child's transport is `(ctx) => this.dispatch(ctx)` — **the parent's whole middleware chain**. So a shard mounted once at the root applies to every descendant call, at any depth, forever.

`resolve()` is the counterpart (`connection.js:65`): given an endpoint it walks only through children that *already exist* and stops at the first missing segment. That is why `call("/a/b/c")` dispatches from the deepest branch anyone has actually created — the tree is built by use, not by path parsing.

### the live surface

```
.branch(sig)      mirror an aperture branch (memoized)
.aim(sig)         a bound caller; the caller's body merges OVER the pre-bound one
.call(sig, body)  dispatch through the chain; throws on response.error
.fetch(…)         same, returns the Response instead of throwing
.stream(…)        SSE async-iterator; parses `data:` frames, cancels the reader on early break
.subscribe(…)     stream + auto-resubscribe, exponential backoff capped at 30s
.observe(…)       stream + an .unsubscribe() handle
.nanoatom(…)      a nanostores atom fed by a subscription, mounted lazily
.publish(…)       the reverse — push an async iterator UP as an SSE request body
.socket(…)        upgrade to a WebSocket carrying a Vector
```

`subscribe` is the resilient one: it loops until aborted, resets its backoff on every successful event, and fires a `resumed` callback only when a *reconnect* succeeds — not on the first open (`connection.js:154`).

**A Connection never raw-fetches.** Auth, retry, timeout, tracing, and multiplexing live in the transport chain ([[42.06_shard]]).

## why the mirror matters

Because a Connection's branches mirror an Aperture's segment for segment, a client re-inflated from the server's `shape.strip` contract hits exactly the endpoints the Aperture mounted. Nothing coordinates the two — the structural mirror *is* the coordination.

```
daemon:   mode.emit.deal(body)  = shape.object(emitter)         → in-process handler
client:   mode.emit.deal(body)  = wire(conn, strip(emitter))    → POST /emit/deal
                                       ▲                  ▲
                                  same trie shape    same segments
```
