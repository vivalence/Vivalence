# 46.14 · Typology

## the scene
- `src/typology/` is kajuit's own mirror of the `subsystems/typology` grammar, client-side.
- It is the layer that makes **DOM consumes the dataspace** true: it constructs, populates and
  resolves entities so components only ever subscribe.
- 30-pattern concretized: **dossier (declarative descriptor) + selbstbestimmt vector (functional
  dispatch) → emergent hydration**. Same trait-arc grammar, applied to entity ingress.

## prototypes — the base classes
- `prototypes/index.js` exports `daemon` namespace + `Entity`.
- `Entity` (entity.js): NO `Object.assign` in ctor (field initializers run after super and would
  clobber); EM's `merge()` assigns post-construction. `toJSON` walks `schema.properties`, collapses
  relations (m:1 → `{id}`, 1:m/m:n → `[{id}]`), drops functions / Set / Map / non-plain objects.
- `Dataspace` (dataspace.js): the dossier compiler. `RemoteEntityManager(connection)`; per dossier →
  `repository(dossier, this)` → Vector attaching `dossier/repository/dataspace` → `shape.selbstbestimmt`
  integrate. `repo.manage` ? `em.register(name, repo, integrate)` : `repo.integrate = integrate`.
  `this[name] = repository`. `init()` fetches `/datamap` → `em.schema`; `populate(names)`; `fork()`.
- `Daemon` (daemon.js): `boot` selbstbestimmt lifecycle — affect builds Daemon, populates Dataspace
  (mode, intent), fetches `/manifest` + `/cargo`, sets `mount` + `link` Paths, binds `call`. `getAsset`
  resolves cargo by path/slug.

## entities + the dossier pattern
- `entities/index.js` — seven entity/dossier pairs: Terminal · Mode · Intent · Thread · Buffer ·
  Turn · Literal.
- dossier shape: `{ name, kind:()=>Class, repository(schema,dataspace), use:[...middleware] }`.
- canonical walk = `ThreadDossier` (entities/thread/dossier.js):
  - repository = `RemoteRepository(Thread)` connected to branch `/userspace/entities/thread`.
  - `use[]` chain: `applyTraits(traits.thread)` → force LABELED → attach `daemon` → hydrate turns
    (`turnRepo.find({thread})`) → `wireConversational` → materialize selfevident buffer.
- hydration law: NO special-cased hydration outside dossier middleware. New entity type =
  class + dossier + add to the `entities` array (`prototypes/daemon.js`).
