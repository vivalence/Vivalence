* BSP Grid System
** Introduction
BSP (Binary Space Partition) Grid System provides a composable and powerful layout system based on grid templates and dimensional controls.

** Core Concepts
*** BSP Node
- Basic grid container
- Always fills parent
- No default gap
- Coordinates child placement

*** Template Types
**** Base Templates (h*/v*)
- h1-h9: Horizontal divisions
- v1-v9: Vertical divisions
- Expect specific number of children

**** 12-Unit System
- t-12h: 12-column horizontal grid
- t-12v: 12-row vertical grid
- t-12g: 12x12 full grid

**** Complex Templates
- t-triple-[t|r|b|l]: Triple layouts with large section
- t-quad: Four equal sections
- t-explorer: File explorer layout
- t-dashboard: Dashboard layout
- t-mail: Email client layout

** Usage
*** Basic Layout
#+BEGIN_SRC html
<div class="bsp-node h2">
  <div>Left</div>
  <div>Right</div>
</div>
#+END_SRC

*** Template Usage
