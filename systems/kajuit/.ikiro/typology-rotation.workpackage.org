* Aim

Restructure =systems/kajuit/src/typology/= so each container expresses one
substantive concern in its own file, while leaving small POJOs and trivial
adapters inline. Honor the four-stage lifecycle convention. Move trait behavior
out of entity classes into trait modules. Lift no primitive to
=subsystems/typology= unless there is a real second consumer.

Aggressive splits proposed in the 2026-05-04 draft are *off the table* per
@beef pass — see distilled rules below.

* Distilled rules (authoritative)

1. *Don't lift* to =subsystems/typology=: =strategy=, =store=, =Stall= stay client-local. (No second consumer; lift is theoretical.)
2. *Lifecycle stages = 4 max*: construct / populate / resolve / integrate. Per-substage files (=connection.js=, =hydrate.js=, =restore.js=) are forbidden.
3. *No =die.js= hybrid*: lifecycle stages compose directly; =boot()= is a function over lifecycle, not its own file.
4. *No single-export =index.js= barrels*: if a directory's =index.js= says exactly =export { X } from "./x.js"=, delete the index and import the file directly.
5. *No directory-per-trivial-POJO*: =defaults.js= for a 4-key constant, =restore.js= for two =localStorage= calls — both inline.
6. *Splits welcome for substantive separation*: bridge geometry vs gesture, terminal class vs dossier, queueing trait+pull+telemetry+persist. Excess was the objection, not splits.
7. *Trait behavior lives in trait module*, not on entity class. =$dock= / =$audio= / =engage()= / =release()= are trait concerns.
8. *Trait running is middleware*, not an inline =for= loop in each dossier.
