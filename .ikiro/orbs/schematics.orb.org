** TIER 1 — additive ergonomics helpers (new surface, identical output)

*1.1 =v.assert(schema, value, tag)= — the highest-leverage helper.* The =cast → [...errors][0]
→ throw= triad recurs VERBATIM ×3 (=cortex.where=, =cortex.register=, =hallucination.configure=)
and is re-implemented divergently 3 more times (=specimen=, =steer/strategy=, =paladin/variant=).
#+BEGIN_SRC javascript
v.assert = (schema, value, tag = "v") => {
  v.cast(schema, value);
  const failure = [...v.errors(schema, value)][0];
  if (failure) throw new Error(`[${tag}] invalid ${failure.path}: ${failure.message}`);
  return value;
};
// cortex.where():        return v.assert(WHERE, { ...supplied }, "cortex");
// hallucination.configure: v.assert(CONFIG, object.assign(config, patch), "hallucination");
#+END_SRC
NOTE it moves the throw-spelling into =v=; validation currently lives in the guarded
=steer/strategy= path — this is a shared spelling callers opt into, NOT a relocation of the
guarded cast. Blast: 3 core sites + 3 optional adoptions; each keeps its exact message shape.
GATE: go (touches cortex + hallucination — holy-adjacent).
