* the law

1. =v= is the one door. A type is =Static= (written) or =StaticDecode= (held) of a schematic that already exists. Nothing is restated.
2. A declaration twin exists only where pure JS cannot carry a generic: =v.js= · =signatures.js= · =vector.js= · =aperture.js= · =twitch.js=, and a helper that builds keys at runtime (=contexts.js:63= =optional=).
3. A prototype's type is its class, inferred from its JS. Its schematic is its codec. A die · a mask names the schematic, never a prose note.
4. A twin's types ride the =export *= barrel that already exports its JS. A type barrel carries only what has no JS home.
5. Each system exports its types and imports the ones below it. A type two systems both declare is a miswire: it belongs to typology.
6. No gate until the end (ruling 1). Until then the product is the editor: completion and hover.

* what pure JS does not give — measured

- A parameter is typed only where its lambda sits INLINE in a typed call. A boot beat is a standalone export (=systems/runtime/subjects/runtime/lifecycle/1-population.js:11= =export const validate = async (die, next) => {=): its =die= is =any= inside its own body, twin or not. Same for a trait (=(mode) =>=) and every helper.
- A twin types a file's consumers, never its own body, and nothing checks the twin against the JS.
- =(input, ctx)= effects stay untyped: in a JS file every parameter is optional, so the two arities cannot be told apart.
- A bare =new Vector()= does not know which die it will run under; only =Aperture= and =Twitch= are their own kind.
- A relation cycle (=thread.children: thread[]=) infers to =unknown=; entity schematics import =v= from =../v.js= and call =v.rel= · =v.thread=, which only =schematics/index.js= assigns on later (81 errors of that class under a whole-graph check).
- Whole-graph =checkJs=, =noImplicitAny= off: 420 errors, every one inside typology's own bodies (=socket.js= 62 · =controller.js= 36), 0 in the three consumer files.
- Dead end: declaring the Proxy's methods on typebox's own =TSchema= breaks every =v.object= (=TProperties extends TSchema= carries an index signature).
