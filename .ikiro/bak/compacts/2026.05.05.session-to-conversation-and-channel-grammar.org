* Lessons

1. *Trait function vs trait file*: a trait NAME (=INSITU=) is data on the entity (=traits[]= + =trait.INSITU= config). The =(entity, ctx) => finalizer= "trait function" mechanism in =systems/kajuit/src/typology/traits/= fires once at populate/resolve. For traits that toggle async post-populate (INSITU is user-triggered via Panel E), the trait-function abstraction is wrong — body must be free fns invoked from a subscriber on the renamed concept's container (terminal =$thread= subscriber → calls =engage/disengage=). Codified in the longdistance quest's INSITU reflection; this session ratified by acting on it during the rename.

2. *Channel grammar pattern*: per-content-type stream pairs (handshake, dialogue, speech, verbatim) × uniform verbs (open, packet, close, abort, error). Domain variation discriminated in payload (=packet({ nature })=), not in verb names. Symmetric server-receive / server-send. Connection-meta (=handshake=) is its own thing, not a content channel — keeps the grammar orthogonal.

3. *Discriminated payload over verb proliferation*: when a channel has 4+ event kinds (verbatim's partial/final/turnStart/turnEnd), don't add 4 verbs — discriminate on a payload field. Pattern already in place for dialogue (=packet.event = "turn.open" \| "part.delta" \| ...=). Verbatim's ASR stub already yielded =nature=; server was re-mapping to separate verbs. Boilerplate, deleted.

4. *Test-driven rename*: writing test expectations to new grammar first → seeing red on the precise mismatch (=open is not a function=, =/herald/moin= → handler missing) confirms the test exercises the rename surface. Then prototype-only edit makes both suites green. Outer source files (real runtime trait, Svelte panel) get parallel rename for consistency — no test exercises them directly, manual sweep + integration test catches frame-on-the-wire mismatches.

5. *Word salad detection*: when explanation gets called out as imprecise, retreating into MORE abstraction (=trait = data=, =file = colocation=) makes it worse. Drop ALL abstraction — name the file path, name the function, name the field. Concrete shapes only. Logged as callout in zettelkasten.

6. *Dock state vs prototype instance*: =dock.session = "live"\|"ended"= is dock UI display state, NOT the renamed prototype. Same word, different concept. Renaming on lexical match would have collapsed two distinct concepts. User's "ignore dock" was the right scope cut.

7. *Bruno fixtures + integration tests are part of the rename surface*: =.bru= files send raw JSON frames over WS — they drive the live runtime against the renamed signals. Easy to forget because they're not =.js=. Integration test (=conversation.integration.test.js=) constructs WS frames manually too. Both must update or e2e breaks silently until next run.

8. *Dead comment blocks should die in the same commit as a rename*: an =@beef= block referencing =/herald/handshake= / =/dialogue/anchor= survives sweeps invisibly (commented = excluded from many rg invocations). When the code is renamed, the comment-block is now zombie design referencing extinct paths. Per claude.md aesthetic gate (no shims, no =_var=, code is self-documenting), delete in the same pass.

9. *jj read-only respected*: zero mutating jj/git ops this session. All file moves via filesystem =mv= (jj snapshot detects rename via similarity).
