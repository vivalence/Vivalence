#+TITLE: Re-mode-ilization — survival generator pattern + clinic sanitization + buildup as theme picker
#+DATE: 2026-04-27
#+TOPIC: tactic/survival · tactic/clinic · per-item generator · mode-to-mode delegation · review-fn fix

* Arc
Three movements over one long session.

First — survival emitters were rewritten from a "build sets up front, loop over them N times" model to a "per-item generator" model. One pre-fetch → a single =for (const word of words)= → branch by memory state → emit the appropriate buffer shape. warmup pioneered the pattern with three sources collapsed into one for-loop; Finn iterated each emitter (buildup, exercise, drill, cooldown), tightening the branches (virgin / weak / failed → emit; succeeded → silent), splitting vocalized vs written into separate filtered for-loops where natural, and dropping catch-all elses. The shape became uniform across all five steps.

Second — clinic was sanitized. Three layers (shards/{analysis,routine}.js, sub-emitters introduce/drill/reinforce/hunt, scope files) collapsed into one (scope files only). Each scope = self-contained: pre-fetch → optional batch exhibit → =ctx.pool.section()= → for-loop with state branching → =apply(shuffle)=. Mirror of the survival pattern. weightedPick + extractParadigm survived as bare helpers in tools.js. The three conjugation scopes (regular/irregular/ser-estar) folded into one =conjugations.js= with three thin route adapters in index.js. PICK was dropped as a verb across clinic; replaced with judge SLOW / judge FAST and a match TRANSLATE batch tail.

Third — buildup re-emerged as a theme picker that delegates to clinic. Clinic stayed flat-pool (one POS per scope, no internal subgrouping). The subgrouping intelligence moved to survival/buildup.js, which holds a hardcoded list of themes (each theme = =(route, symbols, label)=), assesses each bucket via memory state, picks the three weakest by a multi-signal weakness function, and delegates each via =await ctx.daemon.modes.tactic.clinic.emit[theme.route]({ ...ctx.input, where: { symbols: [...existing, ...theme.symbols] } })=. One broad fetch per buildup cycle plus three narrow ones from the delegated emitters.

Two tangents: a Listen.svelte audio-button layout looked weird in a screenshot, which became a sweep across six game components moving the audio asset into the meta/source/prompt row right-floated via =.audio-block { margin-left: auto }=. And a review function bug — typing "this / that" against expected "this / that" was flagged wrong because =norm= didn't treat =/= specially. Fixed at the typology =clean= source so all consumers inherit it; Write.svelte's local =norm= got the same treatment for symmetry.

* Built · changed

Per-item generator pattern across all five steps. Pre-fetch → optional batch exhibit → =ctx.pool.section()= → for-loop with state branching → =apply(array.shuffle)=.
- =warmup.js= — one set from 3 sources (failures/due/weak) merged → for-loop on virgin/succeeded/else → judge / listen+write / write
- =buildup.js= — RE-CREATED as theme picker. Hardcoded themes list (10 entries: pronoun-types, adverb-functionals, adjective-degrees). =assess(words)= computes total/virgin/weak/failed/strong/avgStrength; =weakness({...})= combines them. Top 3 weakest delegated via =ctx.daemon.modes.tactic.clinic.emit[route]({ ...ctx.input, where: { symbols: [...existing, ...theme.symbols] } })=

- =drill.js= — Finn-edited to paradigm-shape (similar to original buildup; conjugation focus retained)

- =index.js= — opens /warmup, /buildup, /exercise, /drill (cooldown commented out)

* Decisions
- Per-item generator over upfront-set-build: clearer state→verb mapping, no catch-all else, succeeded items skip
- Subgrouping is buildup's job, not clinic's. Clinic = flat pool per POS. Buildup = thematic narrowing via where.symbols extension and mode-to-mode delegate
- conjugations.js absorbed three routes via parameterized config — preserves per-route identity in index.js without three nearly-identical files
- Audio button into row right-floated, not centered between meta and hint (orphan-floating fixed)
- Slash-as-separator handled at typology =clean=, not at consumer norms — systemic over hotfix
- buildup's weakness formula: =(1 - avgStrength) + failed/total + virgin/total - strong/total= — multi-signal, tunable
- Themes hardcoded in buildup for v1; promotable to dataset/ later
- Cooldown deferred to bak/ — survival is 4-step (warmup/buildup/exercise/drill) for now
