#+BEGIN_SRC javascript
export const matches = (input, expected, { forgiving = true } = {}) => {
  const normalize = forgiving ? fold : (s) => s.toLowerCase().trim();
  const alts = separate(expected);
  const got = normalize(input);
  if (alts.some((alt) => got === normalize(alt))) return true;
  if (alts.length > 1) {
    const inputWords = new Set(got.split(/\s+/));
    const altWords = new Set(alts.flatMap((alt) => normalize(alt).split(/\s+/)));
    if (inputWords.size === altWords.size && [...altWords].every((w) => inputWords.has(w)))
      return true;
  }
  return false;
};
#+END_SRC

* Decisions

- =string.matches(input, expected, {forgiving})= is the canonical eval primitive at typology layer. All game modes consume; no inline duplicate eval logic. Sentence-level token alignment stays mode-local (per testing policy: each layer tests what's novel).
- "Fix" on a corpus screenshot means data, not UI, unless explicitly stated. UI changes require explicit mode/component reference from Finn. Recorded as feedback memory.
- Listen review reveal stacks **by language block**, not by level. EN-block (answer + EN example) on top, PT-block (PT word + PT example) below. Word-level / example-level interleave is wrong.
- Mobile hit-target on small UI affordances: prefer invisible =::before= overlay extending pointer area (=inset= negative) + parent =position: relative; z-index: 2= so overlay passes hit-test above adjacent flex slots. Visual size bumps stay within stated bounds (15-20% icon, 5-10% column).
- UD strictness for word ontology: 17 UPOS tags only. No invented PoS (=contraction= rejected, =filler= rejected). Non-UPOS morphology axes allowed (=word.compound.{lexical,contraction,clitic,crasis}= as Compound feature; =word.degree.{absolute,superlative}= as Degree feature; =Deixis= for proximal/medial/distal). Contractions get compound UPOS (=ADP + DET=) per UD multi-word token mechanics. Slug suffix =.contraction= remains a naming convention only (not an ontology marker).
- Multi-word entries (=por favor=, =de nada=, =antes que=, etc.) skipped this pass. Belong on a separate axis =word.expression.{fixed,flat,idiom}= per the prior compact's MWE recommendation. Open for next quest.
- Sub-agent QA agents have no conversation context (by design). Cross-validate every finding against actual files; do not trust unaudited.
