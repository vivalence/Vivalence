* M3 — Trait runner middleware

New =systems/kajuit/src/typology/traits/runner.js= exporting =applyTraits(traitNamespace)= which returns =async (ctx, next) => {...}= matching the dossier middleware shape.

#+begin_src js
export function applyTraits(traitNamespace) {
  return async (ctx, next) => {
    await next();
    const finalizers = [];
    for (const trait of ctx.entity.traits ?? []) {
      const result = await traitNamespace[trait]?.(ctx.entity, ctx);
      if (typeof result === "function") finalizers.push(result);
    }
    for (const finalize of finalizers) await finalize();
  };
}
#+end_src

4. *TDD discipline under time pressure*. Hour budget. Strict TDD on M2 (3 RED tests already written; impl made them green) and M3 (RED test for new module before file existed; GREEN after). Looser TDD on M1: tests were written DURING the refactor (not strict-RED-first) because the rename + scope-growth couldn't be expressed cleanly without the implementation in hand. 6. *EM auto-wired relations are invisible*. =$buffers= and =$turns= appear on Thread instances at runtime via =RemoteEntityManager= relation registration (=entity-manager.js:171–186=) but never appear in Thread class source. Searching the entity file yields nothing; reading code that depends on them looks like undefined references. 7. *Sanitize-ops tax for nanostores tests*. Nanostores subscribe schedules a free-timer on cleanup. Deno's default test runner counts that as a leaked timer and fails the suite even with all behavioral assertions green. Workaround: =describe({name, sanitizeOps: false, sanitizeResources: false}, () => { ... })= disables the leak detector for the suite. Used in =tests/typology/top.test.js=.

8. *"TOP" name carries semantics beyond rename*. User clarified mid-rename: =its more than our thread. its the current active working thingy=. Top deck became the single source of truth for "what's currently in focus" — terminal + thread + daemon + mode. Quarters relegated to pure collection ops (=create=, =all=, =has=, =remove=, =update=, =findOne=). The name change from =ThreadStore= to =Top= was the smaller part; the absorption of active-state from Quarters was the larger.
