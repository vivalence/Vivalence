* Decisions

- *Symbol axis is =word.compound.<kind>= unified, not =word.compound.yes= + =word.fusion.*= split.* Finn's siblings instinct won. The kind value is mutually exclusive and load-bearing for consumers (lexical → one literal, no expansion; contraction/clitic/crasis → multi-literal, expansion via =literal_uses=). Earlier objection ("consumers still have to inspect expansion length") was wrong — the symbol value itself answers the question.
- *=word.compound.yes= → =word.compound.lexical= (rename, not deprecate).* Mixed value-shape (=yes/no= alongside named kinds) was the wart that tipped me toward separation; renaming to =lexical= homogenizes. Zero literal attachments in the live DB at rename time, so safe. DB still has the stale =word.compound.yes= Symbol row though — DATASET trait is upsert-only, won't delete.
- *Slug convention is leaf-only:* =pra.contraction=, =vê-la.clitic=, =praia.noun= — never =pra.word.compound.contraction=. Same shape as =praia.noun= vs. its symbol =word.part-of-speech.noun=. The full taxonomic path lives in symbols, not slugs.
- *Sentence's =literal_uses= is direct, not flattened.* =ela-vai-pra-praia-hoje= USES =pra.contraction= (5 rows total = surface tokens), not =pra.contraction= + =para.adposition= + =a.determiner= (which would be 7). Memory fan-out per review: 5 Traces, one per surface token's literal. Lemma-level memory only fires when the lemma appears bare. Reachability via one-hop join.
- *Constituents linked via =trait.ANNOTATED.tokens=, not a new schema field.* Reused the existing mechanism that already drives sentence → word =literal_uses= rows. =LiteralSubscriber.afterFlush= walks =annotated()= and =conjugated()= helpers; adding ANNOTATED to a contraction literal is enough — no schema change, no new subscriber.
- *Gender/number on contractions are inherent, not inherited.* =pra= only exists in fem form (the masc analog is =pro=); =da= only fem (masc is =do=); etc. So the contraction's =word.gender.<gender>= symbol describes the locked-in property of the surface form, not a runtime borrow from a constituent.
- *Dual POS symbols on contractions* (=word.part-of-speech.adposition= + =.determiner=, or +=.pronoun= for =dele/dela=). Schema allows multiple; cleaner than inventing =word.part-of-speech.fused=. Filterable via =word.compound.contraction= when needed.
- *=proficiency.brazilianism= flags =pra= specifically.* =para= stays preferred in EP and formal BP; survival mode should prefer =pra=, formal modes can prefer =para=.
- *RANKED uses real wordfreq, not estimates.* =python3 -c "from wordfreq import zipf_frequency; ..."= is the source. =fpm = round(10**(zipf-3) / 100) * 100=. =rank= is the position in =top_n_list('pt', 1000)=.
- *Removal-not-fix for orphan-pointer sentences.* 104 conversational-A1 sentences pointed at lemmas that were never declared as word literals (Stanza-pipeline output that didn't get its lemma layer seeded). Cheapest cure: remove from live, archive in bak. Reviving them later means doing the lemma-seeding work first.
- *MWE design = parallel axis, not sub-kind of compound.* Recommendation: =word.expression.<fixed|flat|idiom>=. UD's MWT/MWE distinction is real and structural (range line vs. dependency), and consumer behavior diverges (cloze masking, layout). Not implemented.
