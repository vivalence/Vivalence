# codemap: runtime — traps the code does not show

## boot · process · die
- **the boot is a VECTOR per process type, not a script** — `lifecycle/<type>/execution.js` = `new Vector().use(process.settle)…` + `affect(process.keepalive)` (`lifecycle/runtime/execution.js:9`). A lifecycle is `(die, next)`; what it opens it closes in its OWN `finally` after `await next()` (datamap · server · beat · children's `SIGTERM`). `settle` marks the fault, so the exit code is the controller's word (`run.js:20` `STOPPED → 0`). `run.js` exports nothing; only `import.meta.main` runs; the record check is the second beat (`lifecycle/runtime/population.js:9` `validate`).
- **the die is a bag, not a class** — `{ controller, mask, <type> }` (`entities/transient/Process.ts:28` `execute`): `die.runtime` · `die.daemon` · `die.service` · `die.mode`, never `.good`. A daemon IS its row: `Daemon extends ProcessEntity` (`prototypes/daemon.js:5`), minted by `ProcessRepository.create` into the runtime's own `:memory:` datamap (`lifecycle/runtime/population.js:20`), one repo per type (`die.runtime.processes.{service,daemon}`). `kill(where, signal)` moves only what the MACHINE allows and awaits `execution` on stop/abort; `census()` = `{ slug: status }` (`Process.ts:42` · `:49`).
- **readiness is a span tap, not `onListen`** — the line prints on the root span's `open` record (`run.js:16`); `Deno.serve`'s `onListen` fires BEFORE it (`lifecycle/runtime/integration.js:26` `onListen() {}`). `/status` speaks `RUNNING`, never `ALIVE`.
- **a mode is no process** — `mode.stdout` is a branch of the daemon's controller span (`lifecycle/daemon/population.js:84`), opened AFTER the mode's execution (`lifecycle/mode/population.js:4`), closed in the daemon's teardown (`lifecycle/daemon/resolution.js:32`).
- **`Deno.serve` binds `[::1]`, `fetch` picks `127.0.0.1`** — serve on `url.hostname` (`lifecycle/runtime/integration.js:26`). `project_localhost_ipv6_serve_split`
- **a scenario boots by COMPOSING lifecycles, not by `run.js`** — `middleware.compose([…])(die, hold)` (`tests/scenarios/bench.js:178` · `daemon.js:106` · `activity.js:58` · `tests/topography/harness.js:75`); `steer.dispatch.execute` throws `NotFound` on a vector without an effect.
