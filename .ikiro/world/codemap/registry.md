- **ONTOLOGY GUARD — a game must declare what it can play.** `LiteralRepository.feed` = `due` then `novel`, and `novel` orders by `rank ASC`; **ranks are per-ontology sequences**, so rank 1 is simultaneously a word, a sentence, AND a conjugation. An unconstrained `feed` therefore interleaves all three, and the 710 CONJUGATED literals carry **no TRANSLATED** — every translate-game rendered them blank and looked "stuck". Each game's `/feed` now merges its own ontology in: `object.merge(ctx.input.where, { ontology: { $in: ontology } })` — `["word","sentence"]` for write·shadow·flashcard·match·pick·exhibit·judge·listen, `["sentence"]` for cloze; conjugation+paradigm were already explicit. **Two levels, neither subsumes the other**: the emitter guard is the QUERY contract (repairs existing threads — it lives in the mode, not a seeded intent row); the buffer view guard is the RENDER contract (`trait.TRANSLATED` present, plus a resolving audio asset for listen) and catches hand-emitted buffers + the views' own `/pick/literal/feed` self-fetch.
