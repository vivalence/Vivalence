* the ontology — settled with beef, four rulings

**telemetry = the umbrella**, the family name grouping {inspector, logger} — never a
panel, never a third entity. Remote viewing, if ever, joins as remote logging + remote
inspecting. beef: "the entities ARE the spine" — no separate spine concept.

| entity    | is      | flow | written by                    | view                       |
| inspector | the IS  | pull | NOBODY — writers write stores | H                          |
| logger    | the WAS | push | everyone — ambient pen        | G, and Boot.svelte at boot |

Laws: a record never mutates, a node never persists · anything with a timestamp → logger,
anything readable from a store → inspector · *during boot, state changes LOG; nobody
snapshots* (boot-screen gaps are producer gaps) · H's trace tree emigrates to G · the 22
kajuit console.* sites migrate into the logger.

Natures: *records are the data; the span is the pen; the pipe is the wire; the journal is
the memory; views are folds.* The inspector is a projection — a pure function
stores→nodes, materialized only under observation; the absence of a write API is its
nature. ONE root Span("client"); every span a branch; one journal, one channel (today's
telemetry.js mints a root per call — the design commits to one).
