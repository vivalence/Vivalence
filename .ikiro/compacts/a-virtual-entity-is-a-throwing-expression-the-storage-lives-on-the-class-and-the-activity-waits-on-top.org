* laws

- **mikro's virtual = =!!expression=.** =virtual: true= is overwritten. A virtual entity with no driver path
  declares an expression that THROWS. No PK, no table, no identity map.
- **The storage lives on the CLASS** (=static entities=): =getRepository= mints one repository instance per em,
  and every request is a =clear: true= fork.
- **A repository never holds the daemon.** Organs reach routes through aperture closures (=reactive(repo,
  twitch)= precedent). A capability that needs a live handle keeps the handle on the ENTITY in private fields.
- **Match to-ones by id, never by the wire.** A loaded m:1 expands in =toJSON=.
- **A real 1:m targeting a virtual is =hidden: true=**, or every broadcast of the real row carries =null=s.
- **Teardown in the base is a primitive** (=remove({})= through =beforeDelete=). Execution is the entity's own
  mikro hook.
- **Nouns:** =process= and =Action= are taken. =activity= is pinned for m65. =TransientRepository= was
  renamed =VirtualRepository= by beef.
- Provenance memory was stale: rows carry a =mode= owner (=Symbol.ts:65=, =Literal.ts:105=).
