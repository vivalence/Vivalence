* what happened, in one breath

beef woke me onto the history-purge quest and asked for a two-week trace of the head. The trace was read-only from end to end — the vcs-guard tripped three times on prose that merely contained a VCS verb, never on an op — and it found that the quest was written for one remote and a clean single line, while the checkout has three remotes, forty stale =push-*= bookmarks on both sides, a mainline renamed =trunk= → =main= → =master= inside the window, and a =github/master= that holds a working-copy snapshot =origin= never received. The mp3 mass is still all in history (269.8 MB across 8615 blobs) and none of it at HEAD, and the prerequisite the quest gated on — education emigration plus four quests committed and pushed — had already landed under =stratified paladin=. beef's first task was one line in the README: the kernel's path becomes =.ikiro/ikiro.md=. The file was renamed with it, every live pointer repointed, and the kernel's own claim of being auto-loaded was struck, because the lowercase =claude.md= had been matching Claude Code's nested-=CLAUDE.md= discovery on this case-insensitive disk and =ikiro.md= never will. Then beef pasted my gap list back with one question — what are M2 and M3 — and the answer was that I had used the quest's internal milestone ladder as if it were shared vocabulary, in a repo where quests are themselves numbered m1…m55. Callout logged, memory pinned, and the fold you are reading closes with the quest amended on beef's order.

* arc

** the quest assumed one line and one remote (rows 1, 4)

The head over two weeks IS one line — nine visible commits from =snap= to the working copy, no merges, no branches. What the trace added is everything the line does not show. Below it, 410 =refs/jj/keep= pin 706 working-copy snapshots (twelve of =stratified paladin= alone), which is the quest's own decision 4 measured: the local repo cannot shrink in place, only by reclone, and a =--no-local= scratch clone never sees those refs so M1 inherits none of them. Beside it, three remotes: the gitea =origin= that holds 840 commits across 56 branches, a =github= that received =master= and a mid-edit snapshot =origin= never got, and a =presentation= remote whose graph shares no ancestor with =master= at all. The quest's publish step re-adds one remote and force-pushes once; that step now names both remotes and says the third must be ruled on, not forgotten. The prerequisite gate was already cleared — education, m39, m40, m41 and the variant→instance rename all sit under =stratified paladin= on =origin/master= — so M0 collapses to the sixteen dirty files, one push, one zip, one install, and three forks that are beef's.

** a pointer to a file that does not exist is a lie (row 2)

The ask was one README line. Doing only that line would have left the directive pointing at nothing, so the file moved with it — inside =.ikiro/=, which is mine. The rename then had a consequence nobody had written down: only one kernel exists on disk, no hook injects it, and the "auto-loaded" status the kernel and a memory both asserted came from the lowercase =claude.md= satisfying Claude Code's nested-=CLAUDE.md= discovery on a case-insensitive disk. =ikiro.md= never matches. So the kernel now says what is true — it loads when read, README's directive is the pointer, the codemap shard is the only thing that arrives unread — and the load-channels memory says the same, with the SessionStart-hook option named as beef's file to touch. Every live pointer was repointed and the sweep came back clean; compacts, quests and the zettelkasten keep the old name because they are records.

** a label from a document carries no provenance (row 3)

M1, M2, M3 read as shared names to me because I had the quest open. beef had not, and in a repo where the quests are m1…m55 the collision is total. The failure has the exact shape of the container-rooted-paths rule on a different axis: a name that only resolves inside the file I happened to be reading. The corrective is mechanical — document + title on first use, the ladder restated once when several appear — and it is now a memory as well as a callout, because the rule the kernel already carried ("every file reference is container-rooted") did not fire for a label.
