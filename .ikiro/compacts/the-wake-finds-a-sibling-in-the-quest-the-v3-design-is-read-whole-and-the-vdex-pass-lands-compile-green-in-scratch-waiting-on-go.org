** decisions (all overturnable; the quest file carries them)

- shell + parts under =buffer/parts/= (the dojo precedent); the client's JD grammar in =buffer/jdex.js= as
  pure functions with a suite over the rows snapshot; the App imports nothing from the server side of
  the mode and nothing outside it.
- sections are LINE RANGES cut from the text, not the renderer's AST — fold · reorder · outline need no
  serializer, and the drapes parsers stay internal. Reorder = =rearranged(text)= → one =/write=.
- a reference is rewritten into the format's own link grammar (=[→ 22.04](#vdex:22.04)= ·
  =[[#vdex:22.04][→ 22.04]]=) and ONE delegated click on the prose jumps; the file keeps =→ 22.04=.
- read · edit only. No raw segment until a block editor exists.
- keys on the App's root, never on the window — a buffer App is one of several panels; focus inside is
  the gate. Inputs and textareas swallow keys.
- every wire call lands in the status bar; a refusal is shown there — the aperture's messages name the
  next move and are meant to be read.
- rows are =$state.raw= (2000 pojos from the wire); cursor and chrome are =$state=.
- the design's LATER verbs stay visible as disabled menu entries and chips labeled =later= — the intent
  shows, nothing pretends to work.
- ONE drapes line (=Pip= tone =success=) — the design system's Pip row names =done= as success; without it
  the chip falls back to muted.
- T1.1's =placement= must let a document keep its own id — a rename in place is refused today as /"one
  document already"/; the hunk is in the quest file, on the sibling's landing.
