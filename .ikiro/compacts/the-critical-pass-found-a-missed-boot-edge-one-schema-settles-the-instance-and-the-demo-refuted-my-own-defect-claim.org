* arc

** the pass measured what the quest had reasoned (row 12)

The quest's terrain was built on four probes; the pass added three and read the consumer side of every
seam the patch opened. Two of the quest's load-bearing claims were reasoning, not measurement, and both
were wrong in a way that mattered: "decode clones plain objects" (it mutates in place — a whole =Instance=
class object settles as itself), and "kajuit never mounts the instance" (it mounts in =serverConfig()= and
would have read =host undefined / port NaN= from a faulted string under the patch — a silent third edge).
The rest of the verdict fell out of grep: a REQUIRED =Service.statics.serve= that nothing reads; a gate
copied into two files when the belt already owns =.fails/.throw()= and =ledger.boot= is the one spawn
path; five hand-picked slots where one schema exists. The shape of every fix was the same — stop
re-encoding what the system already knows.

** the sandbox is where a patch becomes true (row 13)

beef wanted to see, not read. A 1.8 MB copy of typology + paladin + the recipe under the scratchpad, with
the workspace stubs and =node_modules= linked, ran the amended patch end to end without touching the
worktree or any VCS: three envs, three verdicts, two suites, and the diff back out became the quest's
hunks — no hand-written patch left in the milestones. The sandbox also caught what reading had not: the
ambient =VIVA_REPOSITORY_MOUNT= stratum pointed the first baseline at the REAL repo (the resolve line is
now the proof of provenance), and =Url.toJSON= — flagged as a repository defect in the pass from
=return this.json= plus a hollow snapshot — is whole; the hollowing is specimen's =fold= walking own
enumerable keys. The demo's own replacer never saw the Url because =toJSON= runs first: the tool
disagreed with the claim, and the tool was right.

** the mark (row 14)

The =requirements= table shows WHERE each key was read. beef: /"really not needed"/. Recorded as a mark
in three organs and left alone — the verdict needs =read=/=unset=, the =at= is a doctor nicety, and the
fault =label()= translation exists only to match it. If the mark ever becomes an order, faults speak
typebox's pointer and =label()= goes.

* arc, coda

** the forms probe (rows 17–21)

beef asked about the recipe's SHAPE — /"if SECRET then module. HOW?"/ — and got the mechanism. Two turns of
/"stfu"/ later the answer was a three-row table, and the third row exposed a real hole: =[() => null]= — a
thunk element yielding nothing — was a schematic fault, because dormancy ran AFTER =cast=/=faults= and the
schematic saw a =null= where a mask belonged. His law fixed the order in one sentence: /"first we pinhole.
then we validate."/ Dormancy is a pinhole-side judgement (a value came back blank), so it runs before the
schematic looks. Four forms now hold: =() => []= · =[() => ({…})]= · =[() => null]= (dormant, named) ·
=() => null= (empty roster).
