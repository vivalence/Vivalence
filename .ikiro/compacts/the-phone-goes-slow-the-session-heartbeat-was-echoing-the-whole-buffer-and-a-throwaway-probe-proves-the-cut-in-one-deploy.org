* mechanisms worth keeping (from the whole table)
- An entity flush broadcasts to the WRITER too (=reactive()= pushes ={op, entity: toJSON()}= to every matching subscriber). High-frequency ephemeral client state on a broadcast entity is a category error; the quiet write is the mitigation, origin-excluded broadcast or a non-entity store is the real design (un-go'd).
- =nativeUpdate= + json column + libsql = double encoding. Raw UPDATE with metadata-derived names is the honest path when the ORM path carries a side effect you must not have.
- nanostores notify on every =set=; a fresh-object setter called per event re-lays out the whole pincer. Diff before set.
- =panes.f= defaults ON and F pretty-prints the active buffer's =data= — any mode that grows =buffer.data= pays that per write.
- iOS PWA standalone: the visual viewport barely scrolls the app (5 win.scroll in 112 s); =anchor()= always-snap is harmless there.
- A paste-back probe is a one-deploy diagnosis on devices without an inspector: vv\/window scroll + focusin\/out with target marks + =input=→rAF latency + rAF gaps > 50 ms + store =listen=s + a ring + =clipboard.writeText= in the click. Recipe in the kajuit codemap; the module is gone.
