Two stacked causes, and only one is a bug:

- *authored*: conjugation literals deliberately reference the shared =word.*= facet vocabulary — ~word.lemma.essere~, ~word.tense.present~, ~word.mood.indicative~ — the same facets the 4177 verb word-forms use. Real data, shared vocabulary.
- *the fold ate the roots*: =LiteralSubscriber.symbol()= folds each slug through =object.set= → =place()= (=belt/object.js=), which pops the LAST segment as the value: ~word.tense.present~ → ={word:{tense:"present"}}=. A *single-segment* slug (~conjugation~, ~word~, ~sentence~) pops to a leaf with no path left, hits =if (keys.length)= false, and is *written nowhere*. Every root ontology symbol had been silently vanishing from every literal's symbol JSON since the fold was written.

Downstream: =isWord = literal?.symbol?.word= — the discriminator six game views use — is truthy for conjugations (the =word.*= facets survive the fold; the root =word= never did). It was reading a subtree, not an ontology.

* two guards, deliberately

beef asked for both levels and both earn their keep on different failure modes. The emitter guard is the query contract — it stops wrong literals from ever being emitted, and it repairs threads that already exist because it lives in the mode, not in a seeded intent row. The buffer guard is the render contract — it survives hand-emitted buffers, =/literals= direct calls, the views' own =/pick/literal/feed= self-fetch, and any future feed path nobody has written yet. Neither subsumes the other; a mode declaring what it can *play* is a different statement from a mode declaring what it can *fetch*.

* open

- *=word.*= facet namespace is semantically wrong* — beef: /"scoping tense and person into word.* is wrong semantically. those arent just properties of words."/ Tense, mood, person, and regularity are properties of a conjugation, not of a word. Deferred explicitly (/"we wount fix that today"/). Re-namespacing touches ~694 conjugation entries and breaks the shared vocabulary with verb word-forms, so it wants a design pass, not an edit.
