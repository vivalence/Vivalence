* Lessons

- *The full-suite non-watch run is the only real gate.* Every agent verified its own files green in isolation, yet =tree= was red — because the defect lived in a fixture SHARED across scenarios, and only a combined run exercises the merged state. Per-file green ≠ suite green. Run =deno test tests/= whole before claiming done.
- *Merging scenarios that share a mutable fixture instance compounds state.* The rotation law "self-contained subjects" isn't cosmetic — when the fixture (=house()=) carries mutable state and effects mutate it, EACH state-reading invoke needs its own fresh build. The agent merged two fresh-house its into one shared house and silently broke the arithmetic. A shared stateful fixture is a merge hazard, not a convenience.
- *Don't attribute working-copy source changes to an agent without checking mtime + content.* I claimed "an agent deleted =agentic.js=" before looking. The evidence (one concurrent cluster, a large NEW feature file, an emacs autosave) said beef. A scary diff during parallel work is first suspected as the human's concurrent editing, then proven, before blame. Retract fast and plainly when wrong.
- *Verify orphaned writes; never trust an un-run agent's files.* The spend-limit death left 4 written-but-unverified files — re-ran them before building on top. Same journal-resilience reflex as the last spend-limit death: salvage what landed, verify it yourself.
- *Coverage honesty on graveyard purges.* Deleting =lookup.test.js='s dead block dropped the only coverage of =cast.lookup= object-format normalization (=​{module:{type,slug,owner}}= → canonical). Flagged what the dead code covered rather than letting the purge read as "all still covered."
