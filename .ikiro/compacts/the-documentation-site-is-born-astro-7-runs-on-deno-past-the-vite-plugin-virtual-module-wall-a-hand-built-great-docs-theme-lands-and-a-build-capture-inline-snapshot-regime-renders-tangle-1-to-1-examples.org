**G1 PASSED decisively:** =deno run -A npm:astro@7= boots the full native stack under Deno 2.7.5 — =vite@8.1.0=, =@rolldown/binding=, =@bruits/satteri= (Rust), =lightningcss=, =sharp= all materialized. Astro-7-on-Deno is real.

**G2 was the wall.** =@deno/vite-plugin= (needed for typology's =jsr:@std/path=) does NOT survive Astro's virtual modules:
- =@1.0.6= peers vite ≤7 → fails =solid-js/web= on vite 8.
- =@2.0.2= supports vite 8 but its deno loader rejects Astro's =virtual:astro:server-island-manifest= (=Unsupported scheme "virtual"=). SvelteKit dodges this (few virtual modules); Astro is virtual-module-heavy. **The Deno↔Vite bridge does not cleanly support Astro.**

The escape: the wall exists ONLY because bundling typology client-side. beef's spec allowed tests "either on cli or client" — so I offered the fork via AskUserQuestion; he chose **Astro 7, cli-only tests**. * the build-capture-inline snapshot regime — the keystone

This is the design that landed. **Run the example at BUILD, capture its output, inline it.** Two channels, auto-detected by =run()='s return:
- **stdout** — =console.log= captured → =<Example>= renders flat log lines.
- **span** — the example marks into a real typology =Span= (=.open/.note/.close/.fault= → flat =records [{span,trace,path,verb,at,data?}]=; =belt.chronicle= is the canonical fold) → =<Trace>= renders a depth-nested tree. Dogfoods the runtime's own primitive: docs about spans render AS spans.

#+begin_quote
"capture": "deno run -A suites/capture.js", // snapshot!
#+end_quote
→ capture writes via **=specimen.snapshot(subject, { base, dry, parse, locate })=** (the corpus regime's tool, =@vivalence/typology/specimen=), not raw =writeFileSync=. Gotcha: =specimen.snapshot= does NOT mkdir the base dir (mkdir first), and =dry= is PREVIEW not assert. The snapshot is a committed, diffable artifact — output drift shows in git.

#+begin_quote
the whole thing is supposed to run inside /documentation/* right?
#+end_quote
Yes — everything under =documentation/=; only import-resolution crosses out (typology via the workspace).
