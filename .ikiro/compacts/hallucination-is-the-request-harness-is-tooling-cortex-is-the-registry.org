* The ontology — the ten principles (carry forward; embodied on disk)

1. cortex = the REGISTRY of faculties. =extend/stored/has/derivable/resolve/via/nearest=, nothing else. No terminal-mounting (=get shard()= removed).
2. hallucination = the REQUEST. Pure value, holds cortex, renderable at faculty level (=hallucination.object.render()= / =.dialogue.stream()=). Owns the tool-loop MECHANISM + =executeTools= (exported). But adds NOTHING on its own.
3. harness = TOOLING on the request (Connection-like: carry + branch, compiled via =shape.object=). Decorates a hallucination (persona from =mode.module.harness=, scribe on =/dialogue=) and mounts faculty terminals that delegate to =ctx.hallucination.render(type)/.stream(type)=. NEVER touches cortex (only =new Hallucination(daemon.cortex, ...)=).
4. =harness.<faculty>.render= has an OPTIONAL nicer interface: a string or ={system, prompt, turns, schema, tune, tools}= → normalized to turns by the harness; raw ={turns}= still works. Normalization is a harness concern; the request only ever speaks turns.
5. QUALITY BAR = =connection.js= : =request.js= (+ their tests). harness:hallucination mirrors that discipline.
6. thread = a dataspace entity → lives on the HARNESS (history + scribe) and the EMITTER (buffer binding). NEVER on hallucination/cortex.
7. TRAIT HABIT: wrap =mode.module.<X>= in a live Vector counterpart; slurp the module in; never mutate it.
8. EMITTER thread is OPTIONAL — turn-free/STANDALONE modes emit without one; the drain binds+indexes only when a thread is present. No =THREAD MISSING= throw.
9. TOOLS are harness-held, NEVER auto-added to a hallucination. The base construction hands ZERO tools; tools arrive only on an explicit path (the nicer-interface =tools= arg, or a mode's own =module.harness= middleware). Forbidden: =ctx.hallucination.absorb(shape.agentic(...))= in the base harness middleware.
10. THE BOUNDARY (governs 6+9): the hallucination adds NOTHING automatically — only compiles the primitives it was handed. ALL 'automatic' (persona, tools, thread/history, scribe, context, normalization) lives on the harness. Placement test: if a behavior happens without the caller asking, it belongs on the harness.
