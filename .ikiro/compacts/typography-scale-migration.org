* Callouts (no "retard" codeword this session → no zettelkasten log; workflow lessons below)

- *Over-processing a "just do it" task.* Brainstorming skill + a written quest + repeated AskUserQuestion when
  @beef wanted action. Triggered =no quest! just fucking do= and =no fuck all that. just go through the files
  manually=. For a bounded mechanical edit with a stated direction, skip the ceremony; act, show, iterate.
- *jj framing broke trust* → see § The jj scare. "restore" is a trigger word; file regen ≠ graph op but reads as one.
- *ripgrep =-rn= footgun (twice).* =-r= is =--replace=; =rg -rn "pat"= parses as =-r n= and rewrites every match
  to "n" in the output ("thread display name" → "n"; "input the buffer / emitter consumes" → "n / n"). Use =-n= alone.
- *=-g '!**/bak/**'= silently failed* in this rg/zsh setup → the px perl also rewrote dead =bak/= files. Reliable
  exclusion = pipe through =grep -v '/bak/'=. (bak contamination left as-is per "no revert"; dead code.)
- *jj gotchas during the archaeology:* =jj diff --from <op-id>= treats the arg as a REVISION not an operation
  (returns nothing); and =jj --at-op X file show -r @= re-snapshots the current working copy first, so =-r @=
  returns CURRENT disk, not historical content. =jj diff --from <op> --to @= does read the historical op correctly.
