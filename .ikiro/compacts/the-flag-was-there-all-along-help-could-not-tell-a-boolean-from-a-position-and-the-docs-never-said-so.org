* the fix — three files, one rule

#+begin_src js
// trajectories/help.js — the census had the type and threw it away
([name, property]) => ({ name, type: property.type ?? "string", description: property.description ?? "" }),

// trajectories/Help.jsx — a boolean is a flag, not a third positional.
const label = (param) => (param.type === "boolean" ? `--${param.name}` : param.name);
const usage = (param) => `[${label(param)}]`;
#+end_src

Both call sites (the grouped listing and the =Detail= view) now go through =usage=, and the
detail column's left-hand label goes through =label=, so the flag reads =--use= in every
place help prints it. The change is general, not a patch to one command — but honesty about
its reach: =v.boolean()= appears exactly ONCE in all of =trajectories/=, so today it moves
one param. That is the point. There was one boolean in the whole CLI and it was invisible.

Docs: README §3 gained the =--use= form with a note that it does §4's =instances/use= in the
same call; slowstart §3's control line gained =[--slug=<name>] [--use]= and a =*bind*= clause
in the file's own labelled-clause grammar.
