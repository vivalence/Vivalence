* laws

- **=extends:= is props and hooks, never the door.** mikro copies props · filters · indexes · uniques ·
  checks · PKs · hooks through =extends:= and NOT =expression= nor =repository=; a virtual base cannot make its
  children virtual. The door is a schema CLASS: =class VirtualSchema extends EntitySchema= pinning both in its
  constructor. The class chain (=X extends VirtualEntity=) alone carries the base.
- **The matcher is plain, the wire is mikro's.** =query.where= compares by ====; a loaded reference is an
  instance. =object.pick= over metadata prop names + a to-one collapse; private fields never appear.
- **Storage is set by the context, with a coherent fallback** (beef). =static= on the class was one set per
  CLASS per process plus a subclass per kind; a module =WeakMap= keyed by metadata is struck (/"no!"/). The
  measured anchor: mikro's =Configuration= — one per ORM, carried by every fork, =registerExtension= /
  =getExtension= memoized — so a context-made repository hands its array in and every fork-minted instance
  reads it; absent a context, one array per kind per ORM.
- **A name is a key.** mikro keys metadata by class name; an anonymous class is =""= and reads as abstract.
- **Never =find /=.** The mikro package is =node_modules/@mikro-orm/core= (aliased under
  =node_modules/.deno/@mikro-orm+core@6.6.7=).
- **Two packages, one spelling, is a homonym.** typology's =VirtualEntitySchema= (wire) ≠ runtime's
  =VirtualSchema= (mikro); mirror the existing pairs (=DataEntitySchema= / =DataSchema=).
