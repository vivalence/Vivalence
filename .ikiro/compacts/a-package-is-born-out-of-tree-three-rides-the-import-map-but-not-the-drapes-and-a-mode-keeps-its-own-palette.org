* laws

- **Deno import maps cannot prefix-map into =npm:=.** ="three/": "npm:three@x/"= → /"could not be URL-parsed relative to the URL prefix"/. Subpaths are EXACT entries (=three/addons/loaders/GLTFLoader.js=, =three/addons/controls/OrbitControls.js=).
- **The =three/addons= barrel is server-poison.** =Addons.js= imports an =https:= module → =ERR_UNSUPPORTED_ESM_URL_SCHEME=. Import the file, never the barrel.
- **The browser bundler never reads the import map for bare specifiers.** esbuild resolves from =nodePaths= with the =svelte= condition, so an out-of-tree =.svelte= importing =three= or a threlte =.svelte= source compiles without the package owning a node_modules — measured, 725 kB prod.
- **A FRAUGHT mode needs an =aperture= export** — =carry= opens =/freight= on it; the catalog reaches the client as =mode.call.freight()=.
- **The theme-token law is scoped to kajuit's own views** — a mode's buffer may be standalone on beef's word (turn 8); the memory carries the exception.
- **A prototype's =manifest.js= cannot keep its name** in a package — =manifest= is module identity.
