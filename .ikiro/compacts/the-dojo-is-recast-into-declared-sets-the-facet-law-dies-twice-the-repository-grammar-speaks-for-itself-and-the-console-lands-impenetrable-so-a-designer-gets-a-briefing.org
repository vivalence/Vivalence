* arc

The evening's compact folds and beef reopens the dojo at once: /"i think we need to recast
the thing in another paradigm. maybe a pipeline? not sure yet."/ — sets built from symbols
with real logic (a tense AND some lemmas), literals picked directly from streams (rank, due,
feed), everything else a processor over the set, the LLM and presets and recents all
writing STATE instead of launching sessions. The study finds the repository already carries
the logic the old console never used: =$all / $in / $none=, =search=, =traits=, five
streams. My first proposal hides a "facet law" inside a plain symbol array (same facet = OR,
different facets = AND); beef cannot follow it, twice — /"the array is either AND or OR. so
either SHITTON or NONE"/, then /"iffy as fuck. dont like"/ — and it dies for good: a clause
is ={pick, where, limit}= with =where= the repository's grammar verbatim, nothing implied. Five
interface paradigms are weighed, beef grades them, the fold is "one room, many clauses", and
he says /"no quest. directly into dojo. in context. let me touch this."/ The whole recast
lands — types, a =set/= resolver every emitter and aperture rides, =/resolve /setup
/commission=, a rewritten console, a live set stage, eight suites green, live probes on
italian that expose a MikroORM join collapse and a paradigm/form duplication, both fixed —
and then beef sees it: /"no. this is horrible. utterly impentirarble."/ · /"utter garbage.
shit"/. No more proposals. A designer gets a briefing that describes the model, the goals in
his words, the old text-driven console that was good, the new one that is not, and why.

* what the repository already had

The old console had one selection idea, a symbol SCOPE, AND every symbol, drawn by a count
from the feed. The base =LiteralRepository= (=systems/runtime/daemon/entities/kernel/Literal.ts=)
already speaks more: =symbols: [..]= (AND) or ={$all, $in, $none}=; =search= over slug and
both translations; =DataRepository.resolveTraits= (=traits: string | [] | {$contains,$overlap,$none}=);
the domain repository adds =feed · due · novel · byStrength · byLastSignal · sample= and
=constrain=. The armed =entity_find= tool already exposes this grammar to agents through
=card= + =extensions=. Nothing new had to be invented; the dojo had to stop ignoring it.

* the facet law dies twice

Row 43 proposed that a flat symbol array on a clause means "same facet OR, different facets
AND" — =[tense.present, lemma.essere, lemma.fare]= → present AND (essere OR fare). Neat, and
invisible: beef read the array as an array — /"either SHITTON or NONE"/ — and when the rule
was explained back to him with his own example he named it: /"iffy as fuck"/. The lesson is
not about facets. A grammar that already exists must be used as written; layering a hidden
rule on top of it makes the visible thing lie. Landed as the design's first law: /nothing
implicit — what is written is what is asked/. The clause carries =where= in the repository's
own words and the UI, whatever it becomes, edits THAT.

* declared set, materialized set

The model that landed and holds regardless of the UI verdict:

- =buffer.data.set= = clauses ={pick, where?, limit?, literals?, knowables?}=; =data.omit= = ids
  removed by hand; axes stay FLAT on =data= (beef: names /"dont care"/ — no rename churn);
  =buffer.literals= + =data.knowables= = the materialization; =buffer.symbols= = projection of
  every symbol the set mentions (discoverability, not truth). =data.count= is gone — the cap
  is per clause.
- =set/resolve.js= is the ONE fold: clauses in order, each blacklisting omit + played + what
  earlier clauses took; =all= runs =find= under the ontology guard with a SQL count beside it;
  streams call the domain methods; =literals= = =findByIdentifiers=; =authored= = pairs through
  =fold.authored=; conjugation paradigms expand to forms; under AUDIO overfetch ×3 then keep
  the audible. Emitters, =/resolve=, =/commission=, continuous refill all ride it — the "continuous
  still uses in-memory =/draw=" tail from the previous fold is closed by construction.
- =set/where.js compile()= turns =symbols= into its own =$and= branches. Reason found live, not
  in tests: MikroORM folds several conditions on the same m:n into one join, so
  =$all + $in= yields 0 and =$all + $none= yields =no such column: s2.id=. Bypassing
  =resolveSymbols= entirely (never set a top-level =symbols= key) makes every combination
  work; the scenario suite passed both ways, the italian daemon did not.
- Form-literals in the corpus carry the same tense/lemma symbols as their paradigm row, so a
  symbol query returns the form twice — as a word literal and as an expanded form. Forms
  win (they carry the grammatical context the rep shows), spoken duplicates drop, their ids
  are marked taken.
- Apertures: =/resolve {set, omit?, prompt?, blacklist?}= → ={clauses: [{count, literals, knowables}], total}=
  · =/setup {buffer, set?, omit?, ...AXES}= · =/commission {buffer}= · =/symbols= (slug · literals · name)
  · =/provision {text, state}= → the COMPLETE set after the request plus axis patch, unknown
  slugs dropped and reported in the reply · =/judge= unchanged.
- Client law: Start = materialize + play in one gesture; the stage shows the live preview
  while =dirty=, the materialized carriers when not; a buffer that arrived filled shows "aboard"
  and starts without redraw; =↻ redraw= re-materializes stream clauses.
- Suites 8 / 35 steps green (=tests/{aperture,emitter,machine,tools}.test.js=); aperture snapshot
  regenerated from the live italian daemon (=/resolve /setup /commission /symbols /provision /judge=).

* the console that landed impenetrable

Rows 53–57. What shipped: pick tabs · a three-glyph legend · a symbol search with cross-group
typeahead · fifteen collapsed symbol groups · ontology · traits · free text · limit · "this
clause yields" rows with =+= · add as clause · a clause list with ✎× · nine axis rows ·
recents · presets · chat — one column, one weight, in a ~1100×370 panel; the stage to the
right showing the union grouped by clause with a Start button. Every piece works. Beef,
watching it live: /"no. this is horrible. utterly impentirarble."/ then /"utter garbage.
shit"/. Why, as written into the briefing: controls before content (not one Italian word on
the first screen), jargon as navigation, too many concepts stacked at equal weight, two
result surfaces, a small panel, no obvious first or last step, and — his own addition — the
text-driven gesture the old console had (/"it was text driven selection which was good"/)
buried among fifteen controls. A content-first recut offered under the first verdict was
refused before the second. The designer starts clean from
=documentation/design-brief-dojo.md=; the port back is ours.
