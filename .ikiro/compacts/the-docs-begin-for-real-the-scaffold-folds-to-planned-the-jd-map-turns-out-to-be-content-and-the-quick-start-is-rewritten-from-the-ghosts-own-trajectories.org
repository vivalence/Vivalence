* mechanisms (carry forward)
- N versions = N structures\/angles, pairwise-distinguishable by reader-takeaway — =feedback_versions_must_diverge=, checked BEFORE presenting options.
- Astro slot law: a child's =slot="x"= with no =<slot name="x">= in the component renders NOTHING, silently. Same-name slot children concatenate in source order.
- Astro content-layer cache: deleting\/moving collection files can strand =.astro/= state → =UnknownContentCollectionError= at build; =rm -rf .astro= is the cure.
- multi-replace scripts: an assert AFTER an in-memory replace but BEFORE the write loses the earlier edit SILENTLY on mismatch — one replace per write, or assert everything first; and verify against the COMPILED artifact (dist was what exposed it).
- vcs-guard matches TEXT, not commands: heredoc CONTENT containing /git clone/ or /git managed/ trips the hook; assemble such strings programmatically when writing docs that mention git.
- ghost dispatch: ShellSignal splits argv[0] on =\/= (filter empties) — =viva ledger/tap= and =viva \/ledger\/tap= are identical; params are positional argv[1..], =--flags= parsed off.
- docs writing order pinned by the principles pass: glossary → standalone tutorial → live-example explanations → folded reference; JD areas map to Diátaxis (10–19\/30–39 explanation · 40–49 reference · 50–59 tutorial\/how-to).
