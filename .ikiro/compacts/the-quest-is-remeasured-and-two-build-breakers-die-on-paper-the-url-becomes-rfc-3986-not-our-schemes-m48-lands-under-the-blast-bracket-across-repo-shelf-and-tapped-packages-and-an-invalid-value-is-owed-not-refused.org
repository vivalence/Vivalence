** II — universally true (row 23)

beef: /"build something that is not for our case, but coherencely universally true."/ The http/ws pattern was OUR schemes. RFC 3986 Appendix A is everyone's. One production narrower than "URI" — the hier-part must be a network path — and =localhost:2501= fails for the right reason (no =//=), =${VIVA_RUNTIME_ORIGIN}/= fails because braces are outside the URI character set, =file:///x= passes because an empty =reg-name= is legal.

export const PATTERN = `^${SCHEME}://${USERINFO}${HOST}${PORT}${PATH}${QUERY}${FRAGMENT}$`;
export const url = (opts) =>
  v.string({ pattern: PATTERN, title: "RFC 3986 URI with an authority (scheme://…)", ...opts });
#+END_SRC

* lessons

1. *A library claim is measured by script, never read.* =IsUrl= wants a TLD; the quest had "registered by default, honest validation" in its decision trail. Two build-breakers found by =deno run= before a line was blasted.
2. *=enhance= is dual-role.* =.default= / =.$id= / =.group= return the keyword when set and the SETTER when unset. Any reader of a proxied schema's keywords unwraps first (=v.environment= does) or tests with ="default" in held=. Stamped in the typology and schematics shards.
3. *Universal over parochial.* A validator encodes the standard, narrowed to the production wanted, with constants named after the standard's productions; the "trap" is usually the standard being right.
4. *Every beat re-measures.* m47 landed mid-blast; the recipe was renamed twice; the quest's paths rotted between authoring and landing. The bracket's beat 5 exists for this.
5. *The report form that survived "horrible":* a verdict line, FIXED / YOURS / NOTHING buckets, raw stdout blocks, diffs as the body. Prose tables are dead.
6. *A fork answered with "fix" is a design instruction.* Refusing was the weaker design; owing was already the wizard's grammar.
7. *Bash cwd persists across calls.* A =cd container && deno test= leaves the next call in the container; =ls .ikiro/methods/= said "No such file or directory". Subshells or absolute paths. Logged in loop-backlog.
8. *Done is the gate.* Markers settled, release lines lifted, then =mv=. A quest whose status line says LANDED but whose markers say =pending= is not done; m44 is the standing example.
