* laws

- A design mock's palette is a sample of the theme. This one mapped hex for hex onto =colors.js=; the kit keeps the mock's variable
  NAMES and gives them token VALUES, so both themes come out right (14).
- A mode never imports outside its directory, so shared chrome is copied per mode and a package-root suite pins the copies
  byte-equal (17, 22).
- The buffer carries the board's affordances. Each mode's =save()= recomputes =dests= and =check= through the rules door, so no view asks
  the wire for legal moves and no =$effect= calls the wire. An empty buffer minted by the nav seeds itself from =onMount=, resetting in
  place (21).
- A view opens a sibling mode with anima's recipe: mode row → newest thread or =thread.create= + =resolve?.()= → =terminal.thread= →
  last buffer or =buffer.create({ data: {} })= → =terminal.buffer=. A sibling's client row already has =.call= (22).
- Server-rendering a Svelte 5 view under Deno: =import.meta.resolve("svelte")= is =src/index-server.js=, and the internals are resolved
  from it. The scope hash sits INSIDE =class="…"=. esbuild escapes =♞= to =♞= (23).
- A const shared by a mode's module and its aperture lives in the mode's =types.js=. The =.viva.js= re-exports the aperture, so the
  cycle throws at load (23).
- A registry package adds nothing to the repo's import map. It imports by URL: =jsr:= first, =https://= when the package is not on JSR
  (25).
- A limited-strength search is randomized. One sample per rung, cached forever, turns the noise between near-equal moves into a verdict
  (26).
