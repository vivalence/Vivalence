* the armed picture (the /"explain 'armed' tome"/ answer, kept)

=armed= = the per-request tool Vector assembled inside HARNESSED: ① daemon skills
(entity trio + buffer/thread updates) → ② paladin skills (root-bound, gated on a module
mount) → ③ =/service/<slug>/…= TOOLED service tools (=ctx.service= bound per branch) →
④ domain tools → ⑤ mode tools (+ AGENTIC peer harvest) → ⑥ invocation tools. It is
catalog (trie rollup → declarations), dispatcher (ToolCall Signal back through the same
trie), and scope (the =.use= binds ARE the execution context). Per-request because
user/thread differ; cheap because slurp shares. Later layer wins → a mode can shadow a
daemon skill.
