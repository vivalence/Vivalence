* laws

- Daemon-side modules may import =npm:= · =https:= · =jsr:=, and bare specifiers need the map. In the
  browser bundle, bare bundles, =https:= stays external past the integrity hash, and =npm:= does not
  resolve (9).
- =daemon.call.<door>.<verb>= runs =steer.strategy.direct= on the CALLER's ctx. A mode reaches a domain verb
  as =ctx.daemon.call.rules.apply({ ...ctx, input, output: undefined })= (5).
- =Vector.branch()= returns the child. Build the root, branch it, export the root — or the prefix is lost
  and =shape.proxy= finds nothing (5).
- The runtime Buffer's default =user= filter is =thread.user=. A buffer minted without a thread is invisible
  to its own mode's aperture, so apertures default =thread= to =ctx.thread?.id= (5).
- =population.services= awaits =provider(mask)= with no guard, so a provider that spawns or connects must do
  it lazily, on the first call (5).
- A registry-side test that spawns a subprocess with =--config= takes the path from =Deno.cwd()= (suites run
  from the repo root). A relative =new URL= from =~/.viva= resolves into =~/.viva/=, and the child never
  starts — the suite hangs on the first handshake timeout (5).
- A claim carried from a quest's measured section is re-measured or labeled carried, like any other carried
  zero (4).
