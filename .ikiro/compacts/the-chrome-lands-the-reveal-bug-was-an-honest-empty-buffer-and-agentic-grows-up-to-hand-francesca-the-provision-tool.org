* lessons settled

1. **A recorded diagnosis is not a settled diagnosis.** The
   persist-wipe theory lived in the quest as fact and shaped a day of
   thinking; one repro + one read-only DB query killed it. Reproduce
   before theorizing — and go back and UNWRITE the wrong record.
2. **The design already contains the fix.** The =axes()= defaults
   fold was in the prototype the whole time; the reveal bug was a
   port omission, not a system bug. When a live symptom appears,
   diff the port against the design before diffing the system.
3. **An existing test is a contract, not an obstacle.** The AGENTIC
   test rejected the "cleaner" fix and forced the one that preserves
   source-ctx dispatch.
4. **Don't re-run what already answered.** The suite names its
   failures on the first run.
