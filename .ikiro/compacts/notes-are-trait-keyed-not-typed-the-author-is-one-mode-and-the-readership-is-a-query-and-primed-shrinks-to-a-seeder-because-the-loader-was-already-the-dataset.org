* notes — the split, and why the answer is steal (row 3)

beef drew the line first: /"memory are per user. notes are general."/ The house had
already drawn it once — =systems/runtime/daemon/entities/userspace/Intent.ts= is
={user, mode, slug, name, description, traits: Enum[], trait: json}=, unique
=(user, slug, mode)=; a note is Intent minus =user=. His /"are they trait keyed? do they
have a type??"/ has one answer on disk: no entity carries a =type= string except Mode
(the package type); Intent, Symbol and Mode all carry =traits[]= claims plus a =trait{}=
payload, and =DataRepository.resolveTraits= already queries ={$contains|$overlap|$none}=.
Trait-keyed, because a dojo preset is CONFIG *and* ADVERTISED — traits compose, a type
excludes. =registry/education/modes/games/dojo/types.js:32= already spells a preset as
={ note, count, axes }= keyed by slug; the field is literally named =note=.
=registry/education/modes/teacher/francesca/state.md= is one file carrying both entities:
"roadmap + methodology" is a note, "Live traps" is memory (m27 already rules the traps
migrate). =Buffer.thread?= nullable is the precedent for =Note.mode?= nullable = daemon-wide
— /"if there is daemon wide note that might live on the domain"/, and the domain is not an
entity. Two externals supply what the house lacks: MCP resources (={uri, name,
description}= + =resources/list=) are exactly /"how the mode advertises its own use to
other modes"/; Letta memory blocks (one writer, attached to N agents) settle /"one to many
???"/ — shared is not co-owned: **author m:1, readership = a query, no join table in v1.**

* primed — both sides, then the loader that already existed (rows 6–7)

beef: /"where does the primded solve anything?"/ Grounding first: TOOLED is
=if (mode.module.tools) mode.tools.slurp(…)= and =harnessed.js:50= slurps =mode.tools=
with no trait check — the sibling export is the mechanism, the trait a claim. Every PRIMED
promise has cover: index section → m27.2 =system.notes=; lazy body → =note({slug})= (slug
fetch, not the LATER search-recall); mode-learned procedure → ADVISORY rows; the
always-needed methodology → the static import at =francesca/harness.js:2=, which must be in
every prompt anyway; files→rows → DATASET. Pro PRIMED: files are git-versioned,
PR-reviewable, shipped by m31 packages, agentskills-portable, resolvable across daemons; a
clean writer split. Con: a third channel for prose-into-=system=; the three-sides law for
"read files at boot"; progressive disclosure pays at N≫3 procedures and a mode has 1–3;
/"its an industry standard, sure"/ — and every value in the standard lives in the FILE
FORMAT, which survives without a trait.

beef's refinement — /"primed might make sense if paired with some prototype implement
heuristics for file loading. aka export cosnt prime = walkFileTree(./dir).loadMarkdownToSystem()"/
— sent the walk to =subsystems/typology/prototypes/dataset.js=: =reader.dir(target) →
{walk}=, =reader.lift("skills") → {walk: "skills"}=, =json/js → {read, codec}=, and
=traits/dataset.js:14= =pull(source, mount)= already walks (=paladin.find.data=) or reads
(=paladin.read[codec]=). INTENTED already consumes its own key of =mode.module.dataset=
through =repo.ensure({...row, mode, user})=. =walkFileTree(./dir)= is one live line. What
is missing is one codec: =CODECS= knows json/jsonc/js/ts/mjs and =paladin.read= has no
frontmatter reader. And one semantic: DATASET returns on =mode.entity.installed= —
install-once, right for 6386 literals, wrong for three skill files beef edits daily.

Verdict: **PRIMED = a seeder that re-walks every boot + a manifest claim; the loader is
=Dataset.reader= plus an =md→note= codec.** No =Prime= prototype. =dataset.note: "skills"=
in the mode; =primed.js= ≈ 12 lines mirroring INTENTED (=ensure({...row, mode})= per row,
flush). =loadMarkdownToSystem= splits: gist → =system.notes= index (M27.2) · body →
=note({slug})= · full-body-always → a =trait.<T>.admission = "full"= payload or the static
import that already works. Where the trait still earns itself: every-boot re-seed, the
=implements("PRIMED")= claim, a home for the elevation tool if it is not layer ①. Where it
does not: as a loader.
