* Arc

** the aggressive draft, then beef's pass
The original =systems/kajuit/src/typology/= restructure draft proposed ~50 new files across =subsystems/typology/= and kajuit — separate files for =strategy=, =store=, =StallStatusEnum=, a =Stall= relocation, =prototypes/{entity,dataspace,daemon}/= dirs each holding ONE file, =decks/{lighthouse,quarters,bridge,thread}/= each with a =lifecycle/= subdir of one-helper-per-file, =entities/{terminal,thread,buffer}/= with =defaults.js= splits, an =entities/foundation/trait-runner.js=. beef annotated it line-by-line and killed most of it. The through-line of every kill is ONE law: **no forced separation** — a split earns its directory only by SUBSTANTIVE separation of concern, never by mechanical decomposition.

** the distilled rules (authoritative — the durable payload)
1. **Don't lift to =subsystems/typology=** without a real second consumer: =strategy=, =store=, =Stall= stay kajuit-local (the lift was theoretical).
2. **Lifecycle stages = 4 max**: construct / populate / resolve / integrate. Per-substage files (=connection.js=, =hydrate.js=, =restore.js=) are forbidden.
3. **No =die.js= hybrid**: lifecycle stages compose directly; =boot()= is a function OVER lifecycle, not its own file.
4. **No single-export =index.js= barrels**: if an =index.js= is exactly =export { X } from "./x.js"=, delete it, import the file directly (= [[project_typology_barrel_convention]]=).
5. **No directory-per-trivial-POJO**: a 4-key =defaults.js=, a two-call =restore.js= — inline them.
6. **Splits welcome for SUBSTANTIVE separation**: bridge geometry vs gesture; terminal class vs dossier; queueing trait+pull+telemetry+persist. Excess was the objection, not splits per se.
7. **Trait behavior lives in the trait module**, not on the entity class: =$dock= / =$audio= / =engage()= / =release()= are trait concerns (= [[feedback_trait_colocation]]=).
8. **Trait running is middleware**, not an inline =for= loop in each dossier.

- **M5 daemon split**: =prototypes/daemon.js= is 86 LOC, single concern; =boot= already =shape.selbstbestimmt(lifecycle, ...)= = a function over lifecycle (satisfies "boot = F of lifecycle"). No structural gain without violating "no forced separation". Left flat.
