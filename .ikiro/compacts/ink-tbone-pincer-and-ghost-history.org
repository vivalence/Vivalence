* Ink (research)

Components: =Box=, =Text=, =Newline=, =Spacer=, =Static=, =Transform=. Hooks: =useInput=, =useApp=, =useStdin=, =useStdout=, =useFocus=, =useFocusManager=. Yoga flexbox; =position="absolute"= supported via marginLeft/marginTop offsets. =Static= for log-streams that should not redraw with interactive UI updates.

Drag-n-drop: terminals support mouse via xterm tracking (=\x1b[?1006h\x1b[?1003h= for SGR + any-event). Parse =CSI < btn ; x ; y M|m=. Works in iTerm2, kitty, alacritty, modern Terminal.app; tmux passthrough needs =set -g mouse on=. Keyboard-grab pseudo-drag (Space-to-grab + arrows + Space-to-drop) is the safer fallback.

* Kajuit pincer/T-bone (reference architecture)

Owned by `bridge` deck in `systems/kajuit/src/typology/decks/bridge/`:
- =geometry.js= — pure =rectsForOrientation(orient, pincer, w, h)= → {a,b,c} and =bonesForOrientation= → {shoulder, crown, spine, pincer}. Constants =BONE_THICKNESS=45=, =SNAP_PERCENTS=[0,13,21,34,50,66,79,87,100]=, =SNAP_DISTANCE=28=. Rotation swap-table `{0↔90, 180↔270}`.
- =bridge.js= — nanostore-backed =layout=, =view=, =paneSize= stores. =bootLayout/resize/attachViewport=. Persists to localStorage =vivalence:bridge=.
- =gesture.js= — pointer FSM. Stores =$dragging=, =$longPress=, =$radial=, =$flash=. Radial menu emits =snapToOrientation=.

Panels are geometry-clipped (=width:0=) not conditionally rendered → state machines never reset on layout change. Bones are decorative borders (=pointer-events:none=, =z-index:49=); panels do the work. Viket = keystone glyph at junction, drag target.

* tbone scratch — what got built

Path: =systems/shell/tbone/= (added to root workspace).

Files:
- =deno.jsonc= — workspace member, JSX react factory, =start= task = `deno run -A --node-modules-dir=auto tbone.jsx`
- =geometry.js= — =rects=, =bones=, =clampPincer=, =hit=. =PINCER_W=5, PINCER_H=3, PINCER_LEFT=2, PINCER_RIGHT=2=.
- =tbone.jsx= — App + clock context + frame builder + mouse driver.

Run: =cd systems/shell/tbone && deno task start= or =deno task -f @vivalence/tbone start=.

Feature lineage:

1. Three colored Panel boxes (cyan/magenta/yellow) via Ink Box =position="absolute"=. Arrow-key keyboard drag.
2. Bordered 4×3 keystone Box with `<<` content. xterm SGR mouse parser via =useStdin.stdin.on("data", …)= + regex on =\x1b[<…M|m=. Three drag modes: keystone (both axes, sticky offset), shoulder/crown (row only), spine (col only).
3. Clock React context: =createContext(new Date())= + =setInterval(1s)=. Each panel mounts =<Clock/>= via =useContext=. Demonstrated context propagation through absolute-positioned subtrees.
4. Square keystone with T-junctions drawn in: =┬───┬= / =┤<< ├= / =┴─┬─┴=.
5. Padding eliminated — panel borders touch keystone flush.
6. Spine as 5-wide box, not a line. Keystone bottom changed to =┤   ├= (open downward into spine), spine `│   │` body + `└───┘` closure.
7. **Manual grid rewrite** — Ink Box-border overlap proved unreliable; spaces in overlay Text didn't always overwrite cells beneath. Switched to building a 2D ={ch,color}= cell grid in =buildFrame(pincer, cols, rows, clockStr, grabbed)=, then rendering row-by-row as `<Text>` with same-color spans consolidated. =@vivalence= on shoulder, =terminal= on crown, inlined into the bar.

* What "worse" tells us (open question)

Manual grid rewrite was supposed to fix all three line-break complaints (gap above/below keystone, gap left/right at bar, line-through-bar) by giving cell-precise control. "Worse" suggests it introduced new issues — possibly:
- =@vivalence=/=terminal= text on the bar now reads as decoration not as a bar (loss of horizontal line affordance)
- Panel B/C tops at row =pincer.row= no longer align with keystone walls (=┐┤= adjacency instead of merged join)
- =stemColor= painting the keystone top corners on the bar row created visible color discontinuity with the green bar

Recovery options:
- Re-add a continuous horizontal line ON THE BAR with the names overlaid (line + text co-located)
- Use =┬= joins at panel B/C top corners adjacent to stem so the panel border continues into the keystone instead of butting against it
- Keep stem color = green (no magenta-on-grabbed for corners on the bar row) so the bar reads as one structure

No code changes after the "worse" verdict. Pick up here.
