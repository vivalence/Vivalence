* THE FIX — marker import crash (thunk + hydrate)

markers do env-dependent work at *import* time (=new Url(paladin.env.get(...))=),
but detection imports them before env is loaded → =new Url(null)= → =is.url(null)=

not. we use paladin.vip functionality. ... and if what we need aint there, we build
it there."*

Cure — lazy statics + hydrate-on-use. @beef: *"i like the fix."*
- markers export *thunks*: =serve: () => new Url(paladin.env.get(...))=,
  =jwt: () => paladin.secret.get(...)=. Import only *defines* thunks — no deref.

  (=Path=/=Url=) pass through. Runs in =variant.resolve= after =environment()= loads
  env → real values. =validate= + consumers (runtime, kajuit) unchanged.

- =clone.variants()= → =vip.mount(registry)= + =vip.list({type:"variant"})=.
