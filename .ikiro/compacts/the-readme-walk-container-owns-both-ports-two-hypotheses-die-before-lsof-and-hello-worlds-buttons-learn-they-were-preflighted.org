* the trap, as evidence

#+begin_example
docker ps                       readmen  0.0.0.0:1794->1794, 0.0.0.0:2501->2501   (sleep infinity; its own instance/run alive)
lsof -nP -iTCP:2501 -iTCP:1794  com.docke *:2501 (LISTEN)   deno [::1]:2501 (LISTEN)   deno 127.0.0.1:1794 (LISTEN)
firefox 127.0.0.1 → :1794  com.docker        firefox 127.0.0.1 → :2501  com.docker  ×2
Bruno   [::1]     → :2501  deno              Google  [::1]     → :2501  com.docker (established while local was dead)
curl -4 …/entities/daemon/find → [playground]        curl -6 → [hello]
docker's /status timestamp = the walk session     local /status timestamp = this boot
#+end_example

Deno's =serve({hostname:"localhost"})= binds =[::1]= ONLY; docker's wildcard takes IPv4; Firefox
prefers IPv4 for =localhost=. A =grep deno= over =lsof= hides the container — the first sweep did
exactly that and saw only the local pair.
