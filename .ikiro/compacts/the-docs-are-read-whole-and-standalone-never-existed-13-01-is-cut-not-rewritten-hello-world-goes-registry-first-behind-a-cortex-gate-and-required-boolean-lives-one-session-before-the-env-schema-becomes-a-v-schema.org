* lessons

- *A fact list is not a deliverable.* Every line of research carries its verdict: nothing-to-do /
  fixed-by-this / yours. beef had to ask /"are those changes? to be fixed? what are those."/
- *Registry first.* Doc code is a capture of a file on disk, and the check is byte equality of the
  fenced block against the file — not a claim.
- *The right semantics in the wrong vehicle still ships wrong.* The boolean was correct for one
  session; the schema was the answer to the same question asked one level up. Ask the level-up
  question before landing a fourth field on a hand-rolled format.
- *The SDK that boots on a null key is the defect nobody sees* — a faculty that registers but
  cannot answer. Gate by presence at the declaration, not by trying the call.
- *Suite tasks are =--watch=.* One-shot = =deno test= directly; a =tail= behind a watcher shows 0
  bytes forever. Memory said so; the pattern still cost minutes.
- *Concurrent edits are canonical.* Owner flipped, README changed three times, the quest index
  grew — all under me, all kept, all built on. Verify disk before every paste.
- *Compact numbers are positional and rot.* The trajectory compact was 77 at its fold, 79 at this one;
  the ubuntu walk 78 → 79 → 81. Every numeric citation in frontier / known-issues / memory was wrong
  again within a day. Cite `compact NN (\`slug-prefix…\`)` — the slug is the address, the number a hint.
