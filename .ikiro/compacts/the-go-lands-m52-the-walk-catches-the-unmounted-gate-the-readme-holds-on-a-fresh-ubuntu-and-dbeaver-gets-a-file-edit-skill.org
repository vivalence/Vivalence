* arc

** the go, and the gate the demo could not see (row 24)

Three milestones, each green before the next, exactly as the quest's ladder said. The thing the ladder did
not know: the =Ledger.boot= gate proven in demo C had been proven on an instance the demo script mounted by
hand. On the real path =register()= reads =paladin.instance.home= without mounting; an unmounted instance has
no requirements and no faults; =fails= is false; the children spawn and each refuses at its own edge. The
fix is the runtime child's own move, one line up in the ghost. The callout is in the zettelkasten: a demo
that sets up the precondition proves the mechanism, not the caller.

** the docs were behind by exactly the patch (rows 26–27)

Four pages still taught =new Url=, =statics: {}= / =consume: {}=, "validate & publish", a doctor without
=faults=/=dormant=, an =.env= sample with the anthropic line uncommented, and a §6 that recorded =@viva=. Every
edit was forward (his prose kept, one sentence added where the schematic now does the work). The walk then
CAPTURED two README fences that were composed rather than captured — the ledger doctor's =.env= line and the
first =registry/list= — into what the tree actually prints.

** the walk is the organ gate (rows 26, 28)

Fresh ubuntu, the docker-live recipe verbatim, the local tree. What the walk added over the suites: the
strata footgun (repo-root =.env= beats an os =VIVA_INSTANCE_MOUNT=), =curl --retry-connrefused= lying on a
published port (docker-proxy accepts, then resets), and five defects none of the 200-odd tests knew about,
because they live between verbs — a doctor that counts a live lock dead, an untap that says nothing.

** proposals, then go (rows 29–31)

(=Lock.read()= prunes, so what it returns is alive), no new paladin surface (the record API stays dumb; the
ghost verb resolves the four spellings). The tests that pinned the old no-op moved to pinning the refusal
without touching the fixture.
