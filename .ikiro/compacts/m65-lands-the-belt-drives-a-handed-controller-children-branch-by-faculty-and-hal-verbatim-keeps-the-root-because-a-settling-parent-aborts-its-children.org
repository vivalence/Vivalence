* laws worth keeping

- **A parent settling aborts its children.** Any "derived" step that runs AFTER the parent's stream drains must be the parent's own child under a root the composition owns — never a branch of a controller that closes first. =hal.verbatim= is the worked example.
- **Branch by faculty.** A hallucination under a controller is named =verbatim · dialogue · object · speech=; a dispatch child is named by its tool; never by a role word (=format=, =polish=, =research=).
- **Fill before errors** when a schematic carries a required-with-default object; **errors before the instance gate** so the schema's message names the path.
- **In =shape.http= an undefined output is a 404.** A leaf that acts must answer — the stdin leaves answer with the reflection.
- **A metronome pump opens its own turn.** =soma.pour(null, /part/delta)= is a TypeError; a scripted stream is turns, not deltas.
- **The re-blast counts, then classifies.** "N sites hand no controller" is a lead; which of them RUN UNDER A DISPATCH is the finding.
- **Baseline reds are named before the first edit.** Fifteen =Vector is not defined= suites were the WIP's, one =registry ingest= the environment's; the end-diff stayed honest because both were written down first.
