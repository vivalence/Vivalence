* Laws / decisions

- **package owner is AUTHORED, never derived** — =vip.mount= throws =declares no owner= when modules mount under a package that authored none; same error class as a missing slug. A module's own =manifest.owner= still overrides the package stamp.
- **auth is a variant-scoped lighthouse consumer** — the variant DECLARES =export const lighthouse = { statics: { remote } }=; paladin.variant PARSES it to =variant.lighthouse=; the ghost trajectory READS it and opens a Connection. Command path mirrors the ownership: =/variant/lighthouse/auth/{signup,login}=. NOT a top-level =/auth/*=.
- **the env split** — =.env= (machine: mode·role·mounts·SECRET_*, gitignored ← =.env.example=) vs =environment/*.jsonc= (variant config: serves·PUBLIC_ remotes·nlp ports, committed, cloned). Secrets ride =.env= (fork A); =secrets.jsonc= killed.
- **ledger install takes a destination path** — removes the =VIVA_LEDGER_MOUNT=-before-=.env= chicken-egg; step 3 is env-independent.
- **variant clone source = @identifier | filepath** — =startsWith("@")= → =vip.accio= (pensieve) ; else → =paladin.source= (4 styles). cloneDir MERGES (won't nuke =.env=/=mountpoint= on re-clone).
- **localhost = the promoted working dev variant** — education+playground (playground/oracle IS the hallucination demo the README leads with); self-contained so a plain dir-copy suffices.
