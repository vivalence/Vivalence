* laws

- A lighthouse is a runtime whose recipe declares =daemons: []= and one service. No new image, no ledger, no registry.
- Instance files live in the ledger volume; daemon state lives in a mountpoints volume, one subdir per instance; a service's state lives with the runtime that hosts it.
- =*_SERVE= dies: a process has an ORIGIN (where it binds), a thing has a REMOTE (where it is reached, a literal); the attach slot is structural (beef, m66).
- The default db filename is =<slug>.viva.db= (=paladin/lifecycle/resolve.js:24=); a prod db named otherwise was named by an explicit =db.file=.
- Mikro migrations table is =_mikro_migrations=; entity tables are Capitalised; the lighthouse db is =lighthouse.viva.db=. Guessed names cost a turn on a remote host.
- Reading a live sqlite volume: =sqlite3 -readonly= on a =:ro= volume mount works while the runtime runs; only a snapshot needs the stop.
- Known issues go to =.ikiro/known-issues.org=, never into a quest.
