** the four channels (beef: "this is brilliant. exactly what i was going for")

THE LENS: nothing ever yields "a kind of thing" — every production across
every seam yields the same four channels, sparsely filled:

- =condition= — how production ended. pool.js NOMINAL/EXHAUSTED/ERROR and
  turn =meta.stop= are the SAME channel in two costumes (the convergence
  that validated the lens).
- =message= — the utterance for the mind across the seam (turn text to
  user, tool content to model).
- =entities= — dataspace citizens brought into being; they land in the
  datamap and broadcast, in-band copies are references.
- =object= — schema-shaped value for the caller's code.

M12's audience-channel axis completed: model/user ← message · dataspace ←
entities · caller code ← object · control flow ← condition. Kinds
(emission/turn/result/opaque) dissolve into channel OCCUPANCY — sparse
fills of one fixed getter lexicon, consumer never branches on kind. Same
shape as the oracle session's harness-is-lexicon verdict.

** entities keyed by name (beef: "the entities nesting is brilliant")

/"dont you think we need a type do identofy which f.e. entity type we
have as payload?"/ → keys, not tags: =entities: { buffer: [...] }= —
mirrors =daemon.entities.buffer= and the broadcast paths
(=/buffer/create/after=). Key IS the type; one grammar with the dataspace
itself; the client merge middleware generalizes to a fold over
=Object.entries= for free.

** recursion judged OUT

/"what about recursive yields? at some point we will want to know what
tool call generated which buffers?"/ First answer: yields carry child
yields + =nature= (=/= grammar) + =id=. beef: /"or maybe recursive is
excessive and unclean. you judge. slim the yield type back down. fe id is
excessive."/ Judged: cut all three. The tree served a window nothing
lives in — in-the-loop, =executeTools= holds each tool's return in the
same iteration (correlation free); post-hoc it's a dataspace question
only a persisted relation answers (buffer → turn, separate fork, open).
Recursion also broke the lexicon's own virtue (flat fixed channels =
structure the consumer never walks).

** object · kind · forced perspective · the 45° rotation

/"what about object instead of data?"/ → locked =object= (the faculty
register: =FACULTY_TYPES=, =DERIVATIONS.object=, part type "object";
=data= collided with =buffer.data=). /"and what about my type
property?"/ → the discriminator exists as the READER's verdict (=kind=
getter), never a field at rest. Then beef refined: /"exactly. sniffer
determines. but the yield might help along. optionally. for clarity. or
to force perspective."/ → declared =kind= on a payload wins row lookup;
sniffer carries the default. /"kind is good."/

/"merge the classify and probes. look at pattern type sniffing for
inspiration. sniffing yields can now be shape rotated 45°."/ →
=subsystems/typology/prototypes/pattern.js:52= patternmap idiom: one
yieldmap of =[kind, sniff, fill]= triples — name + test + behavior per
row, override and sniff share one truth-table, can't drift (the exact
disease =pool.js='s SHAPES comment warns about). Third structural
sibling: pattern.js patternmap · pool.js SHAPES · fromm yieldmap.

Final surface, beef-confirmed verbatim ("correct"):
=fromm.yield(thing)= → getters =kind · condition · message · entities ·
object=.
