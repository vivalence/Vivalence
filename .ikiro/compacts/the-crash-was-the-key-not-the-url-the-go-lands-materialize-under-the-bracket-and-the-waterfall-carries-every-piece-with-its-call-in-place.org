* the bracket catch

The hunk as first written hydrated EVERY object kernel entry. =tests/kernel.test.js= pins four
kernel forms — bare · absolute · relative · inline — and the law that an inline module
(=manifest=, no =module= key) is module-shaped: =hydrate= must never fire inside it, because its
exports are functions the pinhole would call. Three steps went red with =Cannot create proxy
with a non-object as target= (the fake paladin has no bags; the real one would have executed
=boot=, =provider=, arrow functions). The narrowing mirrors =vip.accioOne=: an object with a
string =module= is a MASK and hydrates; an object with a =manifest= is a MODULE and passes
through. The landed lines:

#+begin_src javascript
      kernel: kernel
        .map(reference(module.source))
        .map((entry, index) =>
          is.object(entry) && is.string(entry.module) ? at(`${label}.kernel[${index}]`)(entry) : entry
        ),
#+end_src

Lesson, logged in the zettel: before a hunk in a resolver, read the tests that pin that
resolver's laws — the bracket is the net, not the plan.
