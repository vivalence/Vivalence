** Tool-calling at scale — the standard

User: =i have a LOT of tools in my daemon. i dont know if i want to pass them to each and every call to a conversation. seems wasteful and potentially confusing. do other harnesses just spam their tools into system context or is there a pattern to hide them behind a tool call to reveal all the tools available? whats the standard?= (+ later =less text more code.=)

Invoked =claude-api= skill. The standard (carried into toolcalling quest's future Ms):
- Tier 1 — send all tools every call + PROMPT CACHING. Tools render at request position 0; cache write ~1.25×, read ~0.1×, amortized. Right for <~30 stable tools.
- Tier 2 (scale) — the Tool Search Tool. Mark long-tail tools =defer_loading: true=; add server tool =tool_search_tool_bm25_20251119= (keyword) or =tool_search_tool_regex_20251119= (regex). Loaded schemas are APPENDED, not swapped → preserves the prompt cache. The naive "one meta-tool that reveals ALL" re-spams the cost — NOT the pattern.
- Vivalence is in the worst spot: sends ALL tools every call AND has no =cache_control= anywhere in =translate.js=.
- Correctness note for vivalence's hand-rolled loop: =executeTools= dispatches by NAME from =hallucination.tools=; deferring only changes the schema sent to Anthropic — keep the handler in the local registry so dispatch still resolves.

** Crash — streamed tool_use input was doubled JSON

Watcher crash (nyan conversation): =SyntaxError: Unexpected non-whitespace character after JSON at position 2= at =cortex.js:33= =JSON.parse(part.input)=.

Root cause (NOT a parse problem — the accumulator was corrupted at the source): =translate.js= =translateStreamEvent= =content_block_start= ran the shared =blockToPart=, which for =tool_use= sets =input: JSON.stringify(block.input)=. At stream-open Anthropic's =block.input= is the empty placeholder ={}= → seeds the accumulator with ="{}"=. Then =input_json_delta= =partial_json= fragments append → ="{}" + '{"…"}'= = ={}{...}= → parse dies at position 2. Empty-arg tools survive (="{}"= alone parses); args tools (nyan) crash.

Fix (=blockToPart= stays shared — the RENDER path's stringify of the complete object is correct; only the stream open is wrong):
- =translate.js= =content_block_start=: =if (part.type === "tool_use") part.input = "";= — stream fills via =input_json_delta=.
- =cortex.js= =executeTools=:33: =const input = typeof part.input === "string" ? (part.input ? JSON.parse(part.input) : {}) : (part.input ?? {});= — guard empty (no-arg tools may stream zero deltas → ="").
