* the vector trie — landed after one rejection and two rulings

First design (secondary =natures= index + adopt/disown seam + coherence invariant):
beef — "no." The retry named the disease: =trajectories= was keyed by Pattern OBJECT
IDENTITY while every query is by nature — a Map nobody can .get() into — and the answer
was already in the file: =// @beef maybe trajectory to trie / this.trie = new Map()=.

Landed shape: =trie: Map<nature, {pattern, trajectory}>= (beef: "keep the name tho.
this.trie"). Entry is a per-parent pairing, NOT =pattern.trajectory= — one pattern may
sit in two parents pointing at different subtrees (slurp shares edges); hanging the
target on the pattern would break exactly there. The wrapper is minted per parent and
never mutated in place, so edge-sharing stays safe. branch/slurp/swallow key by nature
O(1); the O(K²) sibling scan AND the =|| i.hash === pattern.hash= fallback are GONE —
the fallback proved unreachable by every suite (Pattern.hasher includes nature; it
could only ever fire on an fnv1a collision, i.e. as a bug).

**Ruling — keep position** (beef): a slurp collision HOLDS ITS SLOT. The old delete+set
tail-move silently changed dispatch precedence (declaration-order law: a =:param=
opened first shadows forever). Later pattern still wins the edge metadata; position is
immovable. Pinned in the invariant test.

**Fold vocabulary KEPT**: survey output + trie.fold frames still say =trajectories= —
field name ≠ fold key, flagged and beef let it stand.

Sweep (rename = consumers, unrestricted): match.js ×2 · steer/trie.js ·
selbstbestimmt.js · ghost/belt/shape.js loops; =is/prototypes.js= + =specimen/snapshot=
sniffs → =.trie=; vector.test.js (title now "grows its trie and merges by nature") +
