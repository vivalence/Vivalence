* the design preamble that no longer earns its lines

** why hello-world clusters by FACTOR

The tree was five flat files. A directory-per-export-surface was drafted and STRUCK by beef as
/"a directory around each file"/ — a dir holding one file is a rename, not a structure
([[feedback_cluster_by_factor_not_taxonomy]]). What survived is clustering by **effect × audience
× subject**: =capability= (what it can do) · =language= (what it says to a model) · =doors= (how
it is reached), grouped per subject rather than per export kind. =web/= earns its directory
because it holds three factors of one subject; =doctor.js= does NOT, because one fold with two
doors on it is one small thing.

** the mechanism M3 still depends on

A buffer arrives at the TOP of a drawn view, not through a prop drill, because the runtime mounts
the app with the buffer already bound. A drawn component may import only from the mode's own tree
and =@vivalence/typology= — the resolution law. Both are kept in the quest as constraints; the
paragraphs arguing for them are here.

** why an emitter AND a generator

An emitter mints a buffer from a known shape; a generator writes the shape itself. M3 needs the
first, M4 the second, and collapsing them would make the nested researcher unable to return
anything the outer mode had not already declared. The distinction is load-bearing at M4 and
invisible before it.

** the defects, and what they had in common

Every one was **a property nobody declared**.

*** =count= was in =required= because a default is not a demand

=v.integer(...).default(8)= alone puts the field in the wire schema's =required=, so the model is
told it MUST supply a number it has no opinion about. Beef caught it in the report and rejected
the hedge: /"how to fix?? we not just mark the count as optional??apply optional. fixed?!?!"/ He
was right twice — the lever is at the MODE's call site, not inside typology, and a flag without
the one-word patch beside it is worth nothing. Measured all four spellings: =.optional()= removes
the field from =required= and the default STILL fills, because =steer/strategy.js guarded= calls
=step.input.cast(input)= — mutating, Default+Convert — BEFORE it validates. Ordering is
irrelevant.

*** the guard WAS the crash

=doctor.js= read =shape.cortex.strip(ctx.daemon.cortex ?? [])=. =strip()= reads
=cortex.faculties= (=gestalten/shape/cortex.js:2=), so the =?? []= fallback hands it an array with
no =.faculties= and throws — **the fallback fired only in the exact case it was written to protect
and died there.** M0's test had carried a comment explaining a cortexless daemon "cannot be
doctored today" plus a stub to route around it: a workaround documented in a test is a defect with
a bookmark in it. =P-nocortex= now asserts the fold returns =cortex: []=.

*** an unbounded fetch outlives its own transport

beef: /"Request aborted @ …/hello/search … something is wrong."/ His client log: request at
19.283, =response Object { }= at 27.290 — **8 seconds, and an envelope with no =status=** where
healthy calls log ={ status: 200 }=. Reproduced with curl OUTSIDE the app, which is what turned it
into a fact: ="dog puppies"= answers in 0.39s, ="deno permission flags"= **never answers at all**,
30s and counting. Marginalia hangs on some queries. =query()= had a bare =fetch=, so the handler
waited forever and the multiplex gave up first.

Bounded with =AbortSignal.timeout(6000)= — deliberately INSIDE the transport's ~8s window, because
a longer timeout buys nothing: the client still sees an aborted request rather than a fault it can
render. After: the hanging query faults at 6003ms legibly, the working one returns in 239ms.
**Note the shape — nothing in the code path that ran was broken. The defect was the absence of a
bound.** Client half of the same bug: rendering =hits.length === 0= as /"Nothing came back —
Marginalia is thin on… commercial"/ blames coverage for a failure to ANSWER. An empty result and a
failed request are different facts and must not share a branch.

*** svelte scoping only adds specificity

The rebuilt interaction band rendered broken — beef: /"how did you fuck up the render this bad??
ugly as fuck."/ Measured in the live DOM: the control computed to **22px tall around a 36px
child**, overflowing by 14px with the reply box drawn across it, child 22px narrower and inset
11px a side. Source:

: section .act { height: 22px; padding: 0 10px }

an UNSCOPED descendant rule from elsewhere in the app. Mine compiled to =.act.svelte-1lf50yc= —
(0,2,0) against its (0,1,1) — so mine won =display= and **nothing else, because =display= was the
only property I declared.** Scoping is a specificity boost, not a namespace. Fixed by prefixing
the whole family (=.avenue-*=, =.result-*=) and declaring every box property on the structural
rule. → [[project_svelte_scoping_is_not_isolation]]

The methodology mattered more than the diagnosis. The FIRST collision probe appended a test div to
=document.body=, reported zero collisions, and was worthless — =section .act= needs a =<section>=
ancestor. Re-probed inside the real parent, =.act= lit up alone and all eleven replacement names
came back clean before use. Then verified by rebuilding the page STANDALONE (component compiled
=css: "external"=, rendered server-side, the suspect globals pasted in by hand, served over
=127.0.0.1= because Chrome refuses =file://=) and measuring rects under the exact trap.

* M2 — the connoisseur pass, narrative half

Three claims checked before a line was written. Two are now one-liners in the quest; the reasoning
is here.

**=daemon.services.reader= IS the provider's return value.** =lifecycle/population.js:127= is
=daemonDie.good.services[slug] = await servicecake.provider(servicemask)=, with =:129= bolting
=.tools= on afterwards. So =reader.open(url)= in =web/index.js= is correct AS ALREADY WRITTEN —
**M1's dark node lights with no change to the mode**, and the instance's =consume= block is the
entire switch. =provider= must stay a NAMED export: =cast/primitives.js:6= calls a function
DEFAULT export with no args at load, which would run the provider during ingest.

**Both =npm:= specifiers resolve from inside =commons/=.** Probed on a throwaway module loaded the
way =belt/read.js= loads one: =linkedom@0.18.5= and =turndown@7.2.0= both resolve, and
=document.title=, =querySelectorAll=, =getAttribute=, =textContent=, =innerHTML=, =a[href]= and
=TurndownService.remove= all behave. Cold cache means a real DOWNLOAD on first boot. The probe
wrote 4 entries into the tracked =deno.lock= — M2 needs them, but they landed before M2 did.

**Two defects found in M2's own tangle and repaired there.** =extract= absolutised the =links=
array but not the markdown body, so turndown emits =[x](/x)= beside an absolute array with nothing
saying they are the same links. And beef, reading the provider: /"why are we dropping the plain
response??!! might want that."/ Worse than an omission — =drink(response)= READS THE STREAM, so the
string it returns is the only copy of that page that will ever exist in the process, and the tangle
passed it into =parseHTML= as an argument and let it fall out of scope. =status= and headers went
with it. **A function that consumes a stream owns the only copy of what it consumed and must hand
it back. Parsing is a projection, not a replacement.**

* what M2 buys, and what it does not

Today the model finds a page and reads a ~200-character snippet — a FRAGMENT chosen by the index
for keyword proximity, not sense. M1's honest ceiling is /"here are eight things that exist"/: it
cannot quote, compare two sources, or answer a question whose answer is in the third paragraph.
M2 makes the second hop possible, and returns the links found INSIDE the article, which makes a
third hop possible without going back to the index.

It does NOT buy cheap hops — every one is still the outer model in its own context, so a five-page
read costs five pages FOREVER, which is what M4's nested researcher exists to fix. And the reader
has no judgement: it fetches, describes and cuts. =P-selector= — a frugal model picking the article
node out of a ~190-token skeleton — remains the one claim in the whole design that no assertion can
settle.
