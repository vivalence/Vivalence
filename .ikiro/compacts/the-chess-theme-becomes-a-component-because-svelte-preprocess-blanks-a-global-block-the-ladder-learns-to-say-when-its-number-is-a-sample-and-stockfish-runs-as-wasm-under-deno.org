* laws

- The bundler's first stage is svelte-preprocess (=subsystems/typology/gestalten/bundle/svelte.js=). It blanks a whole =<style>= that
  holds a =:global { … }= block, which =svelte/compiler= alone compiles clean. Write =:global(selector)= per rule and =-global-= keyframes.
  A compile probe is not the served pipeline; only the served bundle proves styling (29).
- #168's render-the-view rule held on first contact: the served-bundle test went red on a fix a compile probe had called green, before
  any report claimed it (29).
- A theme that flips a zone's polarity needs its own override while dapper emits no =color-scheme=. Read the values off =design()=
  per theme; never infer one theme from the other (29).
- Stockfish's limited strength is a draw from a handful of near-equal moves. A move's elo is a statistic: sample it, show =k/n=, and say
  when the strengths split. At full strength the verdict is stable (29).
- A bot's thinking comes off its own clock only if the clock is read after the driver answers. Fifty moves is the FEN's halfmove
  field; threefold repetition counts EPD over the replayed line (29).
- Stockfish 17.1 Lite runs as WASM under deno, about a third of native speed, with =location= defined (31).
- A probe run with the repo's =--config= writes into the repo's lock and =node_modules=. A dependency probe runs from the scratchpad
  without it (31).
