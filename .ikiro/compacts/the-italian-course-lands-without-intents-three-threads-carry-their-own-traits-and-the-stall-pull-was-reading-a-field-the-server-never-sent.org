* the architecture (what the study found)

#+begin_example
Mode ──INTENTED──▶ Intent ──beforeCreate──▶ Thread ──Stall──▶ Buffer
       dataset.intent[]     copies traits    phase: inert|manual|
                            merges trait     continuous|escort
#+end_example

- =Intent= (=subsystems/typology/entities/userspace/Intent.ts=) is persisted per =(user, slug, mode)=. =traits/intented.js= ensures one row per =mode.dataset.intent=.
- =Thread.beforeCreate= copies =intent.traits= + merges =intent.trait= — and **returns early when =thread.intent= is null**, leaving whatever traits you passed untouched. *That early return is the whole reason the intent-free build is possible.*
- Three traits are the entire contract: =MASKED= (emitter input) · =AIMED= (mount) · =QUEUEING= (depth). Set =phase: "continuous"= and the Stall feeds itself forever.
- **A course is not a mode. It is a set of thread configs.** aprende is a tech demo because it hand-rolls =fire(route,input) → mode.emit[route]()= in =Actions.svelte=, reimplementing in UI the pull the Stall does for free.

* doctrine extracted

- **the intent is a template, not a requirement** — =Thread.traits/trait= are columns; =beforeCreate= only fills them when an intent is attached. Any thread can carry its own config.
- **heuristics are not guides for experience** — if the system computes pacing (ebisu) and ordering (rank), a hand-authored ramp is a downgrade wearing a curriculum costume.
- **a per-language planner is adapter code** — the reason five-fold-session does not fit italian is its hardcoded 21-symbol =themes= array (6/20 present in italian; clinic 5/10). Derive themes from =symbol.find()= and one tactic serves every corpus. NOT built — see resumption.
- **open the running system before theorising** — the decisive facts this session (0 intents, the emission contract, the wrong-mode connection) were all invisible from source reading and obvious from one DB query and one browser call.

The daemon knows (=statics.language.learning=) but =daemon.statics= does not reach the client — plumbing across 6 files. beef's call, un-go'd.
2. **INTENTED never sets a user** — 0 intent rows on every daemon; the =save as intent= button will hit the same wall.
3. **tactic themes hardcoded** — derive from =symbol.find()=; unblocks italian AND spanish (whose kernel has every tactic commented out for this reason).
4. **cloze unmountable on italian** until sentences get ANNOTATED.
5. **=selectMode= mutates the current thread's mode** when already on that daemon rather than opening a new one (=d.svelte:86=) — why the fresh-tab step is required.
6. **spanish still declares elevenlabs + deepgram** on multiplayer; italian and brazilian are anthropic-only. Left as-is.
