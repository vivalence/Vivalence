entity-manager / repository / persistence layer BETWEEN them carries the debt (oldest layer:
identity-map + UoW + SWR + persistence in one prototype).

  stream/subscribe/observe.

* deep-read findings (kajuit structure)
- =Thread= has NO active buffer (=thread.js:17,50= — =$buffer= commented out). Active lives ONLY on
  =terminal.$buffer=. Thread carries =$buffers= (the EM computed) + =$mode/$traits/$trait/$label=.
- A panel = THE stage (=a.svelte:61= =<Frame buffer={$terminal.$buffer}>=). Null → empty "A".
- C panel = DEF row layout (=c.svelte=, holds D/E/F). F panel owns buffer verbs (=f.svelte=:
  =createBuffer= does =terminal.buffer = buffers[0]=, =activateBuffer= toggles incl. deselect via
  =terminal.buffer = null=).
- THE CRUX (decides every approach): react to =$buffers= ONLY, never to =$buffer=. Anything that
  re-focuses on active-going-null (plain =$effect= on both, or =Stall.static().settle=) FIGHTS
  =f.svelte:45= manual deselect — re-grabs the buffer you just closed. Focus must fire on buffer-
  ARRIVAL, not active-NULL.
- Scope: focus EXISTING (Aprende is APPLICATION·STANDALONE, not AIMED — buffer already present).
  Not pull/create.

* shipped — Approach A (a.svelte)
Added =const buffers = chain(terminals, "$active", "$thread", "$buffers")= (same path =f.svelte=
already uses) + a =$effect=:
#+BEGIN_SRC javascript
$effect(() => {
  const list = $buffers;                       // tracked → fires on buffer ARRIVAL only
  const active = terminals.$active.get();       // .get() → untracked, no re-fire on deselect
  if (active && !active.$buffer.get() && list?.length) active.$buffer.set(list[0]);
});
#+END_SRC
Reload works: restored =$buffers= repopulates → effect fires → first focused. Browser-verify (F5)
left to Finn. =list[0]= = source order (matches =Stall.advance=, avoids the index-order split debt).
