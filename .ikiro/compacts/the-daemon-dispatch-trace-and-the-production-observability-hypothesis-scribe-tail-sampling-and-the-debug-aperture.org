* scribe — the designed-not-built paladin belt (full fidelity)
=subsystems/paladin/belt/scribe.js= (the stub survives, carrying beef's intent comments: /"i want scribe architecture to respond or rather be computed as a functino of environemnt ad hoc … with different backends and protocols for writing to ledger, writing to mountpoint, writing to stdout, writing to console, or to g and h panels, or some inline provided arbitrary function F. also used in testing!"/). The worked-out shape:
#+BEGIN_SRC javascript
import { trace, Queue } from "@vivalence/typology";
import { snapshot } from "@vivalence/typology/specimen";

export default function (paladin) {
  const line = (record) =>
    [record.path, record.verb, record.data ? JSON.stringify(record.data) : null].filter(Boolean).join(" · ");

  const sinks = {
    line,
    stdout: () => (record) => console.log(line(record)),
    ledger: (instance) => {
      const location = paladin.scope.ledger.branch(`/logs/${instance}/records.jsonl`);
      const queue = new Queue();
      (async () => {
        for await (const record of queue.drain()) await paladin.state.jsonl(location, record);
      })();
      return (record) => queue.enqueue(record);
    },
    snapshot: (options) =>
      trace.gather(trace.sealed, (records) =>
        snapshot(trace.chronicle(records).roots, { parse: (roots) => roots, ...options })),
  };

  const ambient = [
    [() => !!paladin.scope.ledger, (instance) => [sinks.ledger(instance), trace.decant(sinks.stdout(), trace.faulty)]],
    [() => true, () => [sinks.stdout()]],
  ];

  paladin.scribe = Object.assign((pipe, instance) => {
    const [, resolver] = ambient.find(([condition]) => condition());
    return pipe.to(...resolver(instance));
  }, sinks);
}
#+END_SRC
Load-bearing choices: =ledger= writes RECORDS-jsonl (append-only correct — the old =Log.append(span.json)= wrote tree-per-line, N duplicates under streaming) with a Queue INSIDE for backpressure (the drain loop AWAITS the disk write per record — ordering kept, bursts absorbed, invisible at the call site) · =snapshot= is composed entirely from belt pieces (=gather(sealed, …)=) · =ambient= is a =[[condition, resolver]]= table, the same conditional-resolver shape as =paladin.scope= · instance passed by caller, NO invented env fields · =paladin.scribe(pipe, instance)= = one-call environment wiring. Its test design (descoped with it): "records.jsonl on disk replays into the same chronicle" — write via sink, read lines back, =trace.chronicle(lines.map(JSON.parse))=, assert the tree.

* the Queue verdict (and the praised queued demo)
/"might we want to also add a queue next to pipe? would that enhance span?"/ — verdict: Queue enhances the PIPELINE, not the Span.
#+BEGIN_SRC
journal   retained array        non-consuming, re-read N times      no backpressure, no close
pipe      sync broadcast fan    many live taps                       send() fires, never awaits
Queue     gated pull buffer     ONE drainer, ordered, close signal   sink pulls at its OWN pace
#+END_SRC
An intrinsic =span.queue= would give the span two live faces — broadcast Pipe and consuming Queue — fighting over who consumes each record: the exact tangle the journal/pipe split had just dissolved. Pipe and Queue are different CHARACTERS in the channel family (shared =waiter=), deliberately separate; compose, never merge. The composition seam exists for free: =Queue.enqueue= is a valid =fromm.sink=, so =span.pipe.to(queue)= just works. beef: /"i like the queued demo. extend that into our usage adn testing."/ → LANDED as =trace.test.js= "a queue after the fact: retained, ordered, drained at the reader's pace":

* the production-grade hypothesis (the stack, unbuilt)
- *INGEST* — every request → =scribe.root= middleware roots the span (journal ON the span, no external array), notes =subject {schema:"signal"}= + user, folds =ctx.trace= on the way out (feeds server-timing), hands =span.records= to scribe:
#+BEGIN_SRC javascript
export const root = (name, scribe) => async (ctx, next) => {
  ctx.span = new Span(typeof name === "function" ? name(ctx) : name);
  ctx.span.open().note({ subject: { schema: "signal", id: ctx.signal.absolute.join("/") }, user: ctx.user?.id });
  try {
    await next();
  } catch (error) {
    ctx.span.fault(error);
    throw error;
  } finally {
    ctx.span.close();
    ctx.trace = trace.chronicle(ctx.span.records);
    scribe(ctx.span.records, ctx);
  }
};
#+END_SRC
  plus =track.span(mode.mount.nature)= at the per-mode branch and =track.span("dialogue")= inside HARNESSED — three mount lines, the whole daemon traced.
- *POLICY* — variant-profiled: dev = =flow → stdout(line)= + in-memory ring of last N traces; prod = =decant(faulty ∨ slower(p95)) → ledger= — TAIL-SAMPLING: the full trace WITH pre-fault context lands only when it matters (the decant demo proved the shape: healthy request evaporates, broken one lands whole, 5 records including everything before the fault); always-on = per-path count/duration rollup.
- *PERSIST* — =testament/ledger/logs/<instance>/records.jsonl= — append-only, REPLAYABLE: =chronicle(lines)= rebuilds the tree anywhere (ledger CLI, test, panel).
- *EXPOSE* — daemon =/debug/*= aperture (guarded, EXPOSED-style): =/debug/traces= (ring as chronicle roots) · =/debug/traces/:id= (one folded trace) · =/debug/stream= (SSE of records — the deferred streamed-logs, respecting the 6-per-host budget via batching).
- *INSPECT* — kajuit =Connection.branch("/debug")= folds with the SAME =trace.chronicle= client-side; g/h render daemon traces IDENTICALLY to client traces — one renderer, both origins, because records carry ={span, trace}= identity and interleave safely.
- *CORRELATE* — client root mints a trace-id → =X-Trace= header → server root ADOPTS it as its =trace= foreign key → client + daemon records fold into ONE cross-tier tree in g/h. Cross-process id namespacing = the relay sink stamps its instance on egress.
- *the throughline*: stripwire applied to observability — the daemon SERVES its trace as flat records, the client CALLS over a Connection and folds with the same algebra. Nothing bespoke per tier; every layer is WIRING over the landed algebra (record · chronicle · policies · Queue-as-sink · =trace.timing=), zero new machinery except =scribe.root=, the scribe belt above, the =/debug/*= leaves, and one X-Trace adoption line in each root.
