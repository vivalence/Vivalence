* the mechanics that shaped every fix

**=shape.object= leaves are callable directly — there is no =.cast=.**
=shape.object(vector)= (~subsystems/typology/gestalten/shape/object.js~) compiles each
effect node into a bare callable merged with its child namespace. So =emit.riddle= where
the nature is =/riddle/fromSymbols= is a plain namespace node — =.cast= is =undefined=.
The old =.cast= was never a method; it was the old nature segment =/riddle/cast=,
renamed to =/riddle/fromSymbols= in the riddler rebuild. Aprende was calling the dead
spelling.

**riddler's role distribution (the pattern beef wants everywhere HARNESSED).**
~registry/education/game/riddler/~: =types.js= holds the NON-prompt schemas (=GRADES=
enum, =RIDDLER_BUFFER_HISTORY=, the aperture =*_INPUT= objects). =hal/index.js= is a
=export * from= barrel over one file PER JOB — =emitter.js= / =assistant.js= /
=evaluation.js= — each exporting =const <role> = { output, identity, ...fragments }=:
the render OUTPUT schema colocated with that job's OWN identity (author-voice vs
speaker-voice vs silent-judge) and its prompt fragments. Consumers
=import * as hal= then =hal.<role>.output= / =hal.<role>.identity(language)=. Riddler is
harness-free — each job assembles its own system+user turns at the call site.

**HARNESSED only absorbs =ctx.input.tools=.** ~systems/runtime/daemon/traits/harnessed.js~
first middleware destructures =input.tools= and, if present,
=hallucination.entities.tool.add(tools)=. Nothing else feeds tools. The CONVERSATIONAL
trait is dead (beef) — no separate ws tool path — so the ONLY tutor surface is
=harness.object.render= via ~registry/education/homepage/aprende/aperture/message.js~,
which passed no =tools=. Toolless render ⇒ "refuses to generate buffers."

**=cortex.tools= is never populated — the bound tools live on the aperture.** =TOOLED=
(~systems/runtime/daemon/traits/tooled.js~) binds daemon+mode ctx onto its OWN copy and
mounts it at =mode.aperture.branch("/tool")=; =mode.tool = shape.object= stays commented.
Only providers register on =cortex=. So the correct tool source for the harness is
=shape.agentic(mode.aperture.branch("/tool"))= (context-bound), NOT raw
=mode.module.tools= (unbound) and NOT =cortex.tools.branch(slug)= (empty — the stale
spelling in the commented aprende block).

**The tool loop passes ONLY the model's args — no thread.** =execute= in the
Hallucination render/stream loop (~subsystems/typology/prototypes/hallucination.js:172~)
calls =handler(input)= with the model-supplied tool input alone. =tools/activation.js=
forwards =ctx.input.thread= to its emitter, but the model never emits a =thread=, so it
arrives =undefined=. The activation → =nyan.emit.literals({thread:undefined})= buffer is
persisted, but the =EMITTER= trait's bind is gated
(~systems/runtime/daemon/traits/emitter.js:57~ =if (ctx.thread …)=), so the buffer stays
thread-less ⇒ never renders in the terminal. "result ok" + no buffer = orphan, not
absence. (=tool.add= accepts a batch object: =is.object(name) ? Object.entries(name)=.)

**symbol filter matches by slug.** The live pattern (aprende
=aperture/literals.js=) is ={ symbols: { $all: slugs } }= — Symbol is slug-keyed, so
slug strings pass straight through =v.rel(v.symbol())='s cast. Union-of-symbols needs
=$in= (OR), not =$all= (AND — weekday∧month = empty).

* the pivot — ambient thread, mirroring user (PROPOSED, not landed)

=user= rides passively: =shard.secure.authorize()= (~subsystems/typology/gestalten/shard/secure.js~)
reads the token from header/=?token== and sets =ctx.user= — no caller passes it;
=transmitter.js:26= pulls the token from the =authority= store and stamps the frame;
resolution.js then =datamap.shard.bind("user", ctx => ({ user: ctx.user.id }))=. Beef
wants =thread= on the same rail. Asymmetry: token is daemon-global (one store), =thread=
is per-TERMINAL. Sketch:
- CLIENT — terminal owns a thread-scoped connection; a =.use()= stamps
  =ctx.request.headers.set("x-thread", terminal.thread.id)= (transmitter already
  forwards =request.headers=). Callers stop passing =thread=.
- SERVER — new =shard.secure.thread()= symmetric to =authorize=: read the =x-thread=
  header → =ctx.thread = await daemon.entities.thread.findOne(id)=. Mount after
  =authorize= in resolution.js's modes loop + userspace.js.
- =EMITTER= trait — read ambient =ctx.thread=, keep =ctx.input.thread= as fallback
  during migration.
Then these DISSOLVE: the harness injection hack, =thread: terminal.thread.id= in
Aprende.svelte, every =thread: v.string().optional()= on emitter/tool inputs. Agreed
build order (awaiting go): server side first (=secure.thread= + mounts + EMITTER read),
then flip the client connection, then rip the =thread= input params.
