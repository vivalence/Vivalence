* one breath

m65's activity was landed and invisible: nothing in kajuit showed it, and nothing but a real
Anthropic key could make one run. This fold built the two halves that make it demonstrable.
A =@commons/hallucinator/stub= under =commons/fixtures/hal/stub= plays a script that is a PURE
function of the request — flags written in the prompt, named scripts on =statics.scripts=,
parsed by =Signal=, the repo's own CLI grammar — so a run can be made to take twenty seconds,
call a tool three times, fault retryably, or hang forever, offline and for free. And the design
beef had drawn in a claude_design project landed as three kajuit widgets over dapper tokens:
a tracker dot on the shoulder and the dock header, a roster with signals and the stdout ring
at the top of F. Then the old dock stop — an =AbortController= on the SSE read that stopped
the BROWSER listening while the daemon billed on — was ripped out for =SIGTERM= on the activity
row that send minted, matched by the turn id the harness now stamps. Three defects only a
browser could show closed the fold: a settled row decayed under a reader's eyes, a row overflowed
the panel, and every row sat IDLE forever because =$derived(project(row))= cannot see a mutation
the entity manager writes INTO the same instance.

** =commons/fixtures/hal/stub/= — the stub provider (=@commons/hallucinator/stub=, 155 + 95 + 15 lines) — rows 83 · 84 · 85

The script is a pure function of the request; there is no cursor and no "set the next response"
door, so the same turns give the same packets in a test and in a browser.

#+BEGIN_SRC js
  --run <name>        expand statics.scripts[name] — itself a flag string
  --deltas 40         text deltas                            default 12
  --pace 120ms        gap between packets                    default 40ms
  --stall 4s          one long gap, after the first delta
  --tool lookup       call a tool …
  --rounds 2          … this many times before answering
  --fault retryable   throw with .retryable → the belt's backoff path
  --timeout           yield nothing, ever; only the signal ends it
  --object '{…}'      what the object avenue answers
  --say "text"        the text of the answer
#+END_SRC

- =flags()= = =new Signal(source).json.flags= · =prose()= = the segments rejoined.
- =round(turns)= counts =tool_result= turns — the round is READ off the request, never counted in
  the provider. That is the whole determinism story.
- precedence: =DEFAULTS= ← =statics.default= ← =settings.script ?? the prompt=, and a written flag
  beats the script =--run= expanded.
- faculties: dialogue at three tunes (mirroring the real opus/sonnet/haiku corners) + object
  through the same via =output.schema=, verbatim, speech. Every gap is an interruptible =pause(ms,
  signal)=; =--object= absent fills each leaf off the schema (=string= → the said text, =integer= →
  42, =array= → one element).

* laws

- **a =$derived= over an entity the store mutates in place never re-runs.** The client's identity
  map assigns INTO the held instance; only the store array is replaced. Read a per-tick counter
  inside the derivation, or derive from the ARRAY, never from the row alone. Sibling of
  [[project_svelte_class_state_gap]] (=$state= does not deep-track class instances) — same root,
  a different rune.
- **a client cannot mint an activity.** =shard.datamap.repository(…, { only: [reads] })= is the
  reason; a browser-side =new Controller= owns no row and never will. Client-side cortex calls are
  therefore permanently row-less — labelled as such in the oracle buffer rather than fixed.
- **two hallucinators at neighbouring tunes shadow each other.** The cortex resolves by nearest
  tune, so a deterministic instance mounts the stub ALONE; mixing it with a real provider makes
  the pick arbitrary.
