* the terrain that settled it (rows 1, 3, 5)

The investigation's three facts carried every later turn. First, =Frame.svelte= derives daemon · mode ·
thread from the buffer and reads only =terminal.$buffer= — so a terminal, for rendering, is a pointer.
Second, the bundle contract is =(target, props) => mount(Component, …)= memoized by integrity, and the
bundler's import map already resolves drapes and nanostores — a nested Frame is not new machinery.
Third, the seam between daemon and client is the repository verb list: =shard.datamap.repository(repo)=
mounts a fixed crud set and duck-types exactly one extra verb (=ensure=), =RemoteRepository= hand-mirrors
the same set, =userspace.js= slurps four branches identically. =create({ parent, … })= under
=scoped("data")= already stamps the owner. When beef said /"the runtime just implements in teh most
obvious way"/, the obvious way turned out to need no verb at all.

The name search (row 6) closed the vocabulary: he had written =Thread.parent= as a deferred milestone in
longdistance, called the child a *sub-thread* twice in April, and used *spawn* for minting a terminal in
terminal-first-client. Nothing was invented this session — only recovered.

* the four reshapings (rows 3–7)

- *The view law.* Drafted into Frame (an M1 hunk). His first question pointed at the panel; the terrain
  pointed at his own trace =// const $view = atom(null;) //@beef!= — the resolved view belongs to the
  terminal, Frame reads it, the panel computes nothing. The Frame hunk is superseded, not landed.
- *The child.* Drafted as =buffer.parent= (a flat thread list filtered by parent). He forced the thread:
  a sub-thread carries its own buffers, phase, stall and dock, so nothing in the parent's list needs
  filtering. Struck before landing.
- *The verbs.* Drafted as an aperture branch on the entity (/"big no! you have it inside out"/), then as
  repository methods + a descriptor-level =verbs= contract generalizing the =ensure= duck-type, then as a
  runtime =TerminalEntity=. /"intricrazy thats not warrented"/ · /"no entity terminal on runtime!"/. What
  survived: =parent=/=children= in the Turn shape, cascade rules, and a client terminal whose
  =up=/=down=/=status=/=stop=/=run=/=watch= are plain functions over the existing repo verbs.
- *=down=.* Drafted as "wind the terminal down = delete the thread". /"thats separate."/ The terminal's
  =down= drops the terminal and its descendants; thread deletion stays =entities.thread.removeOne= and
  cascades on the daemon; =up({ thread })= adopts an existing thread.
