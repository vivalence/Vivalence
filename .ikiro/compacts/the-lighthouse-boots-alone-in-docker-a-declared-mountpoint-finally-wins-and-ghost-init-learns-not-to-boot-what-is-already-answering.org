* laws

- A mounting's own =mountpoint= wins; the seat =<scope>/<kind>_<slug>= is the fallback, never an override. Its datamap follows the same rule.
- A =*_MOUNT= default never carries =~=. Absolute or REQUIRED.
- The instance =.env= stratum beats process env. Inside a container an =.env= in the image dir is a shadow over every =-e=; scaffold only what is owed.
- A verb that boots a runtime to reach a service must first ask whether the service already answers.
- libsql has two inputs: =mountpoint/db.file= and =mountpoint/migrations=. Configuration beyond that is invented.
