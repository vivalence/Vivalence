* arc

** the fourth pass finds what three connoisseur passes could not

Passes I-III judged design and doctrine; beef's pasted rubric (row 75) asked a different
question — what breaks in PRODUCTION — and the patch had three answers, all in failure
paths no green suite walks:

1. *one curl kills the daemon.* =transcribe='s =const feeding = pump(...)= attached its
   rejection handler only in =finally= — while the drain loop was parked, a rejected pump
   was an UNHANDLED rejection, and Deno exits on those. Reachable from the network: any
   =data: garbage= SSE line → =sse.frames= yields the raw string → =packet.audio=
   undefined → =atob("undefined")= throws in pump. Not argued — PROVEN, with a 5-line
   probe (reject at T0, attach handler at T+100ms → =Uncaught (in promise)=, exit 1) and
   a sweep showing no =unhandledrejection= handler exists anywhere in the repo.
2. *a deepgram outage looked like "you stopped talking".* =line()='s error listener (and
   any abnormal close — deepgram idle-timeout closes 1011) just did =inbox.close()=:
   HTTP 200, clean end, truncated transcript, =$error= never set. The LOUD delivery
   chain existed the whole time and was verified station by station — throw →
   =span.fault= → serve catch → ={frame, error: {status: 500}}= (=socket.js:217=) →
   client =throw frameError= (=socket.js:251=) → =reduce= catch → Dictaphone title.
3. *pass III's own fix had a successor-killing shadow.* The arming guard it added checked
   GLOBAL state (=$active !== "arming"=), not session identity — and the mic claim is a
   plain boolean whose =release()= hard-stops. =getUserMedia='s permission prompt makes
   the window seconds wide: start A → cancel (thread switch) → start B → B listening →
   A's stale claim resolves → guard releases B's LIVE microphone. Fixed with a =session=
   generation token: stale actors touch nothing, releasing only when nobody armed after.

** the refutation that found the real bug

The cold-eyes reviewer's headline was a BLOCKER: cancel→restart race, "seconds wide,
bounded by polish-LLM latency" via =reduce= cleanup. Verification refuted the mechanism —
=socket.shut= runs =frame.close()= locally before the wire send, so =cancel()= tears the
client iterator in microtasks. But chasing the refutation surfaced the arming path
(finding 3), which IS seconds wide and IS reachable. The verify-before-report gate worked
on a subagent's claim exactly the way it works on mine: the claim died, the category
lived, and the finding that shipped names the true mechanism. Same gate, other direction:
my own "Dock gate never renders" suspicion — =$modeStore?.daemon?.cortex?.find= looked
like a call onto a surface the client couldn't have — died when =daemon/dossier.js:100=
showed the client daemon hydrates a real sync =Cortex= from =/metadata/cortex=.
