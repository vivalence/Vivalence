* Lessons

- *Ask whose JOB the mechanism is before asking where the file goes.* The bundler wandered traits → typology-with-port-injection → paladin. The injection ceremony was the tell: needing to thread fs + config through a layer means the machinery sits one layer too low. beef's register test — configured at system level, reads the repo, writes disk — named the owner instantly, and four workarounds evaporated.
- *Investigate in parallel BEFORE the big rework.* Three read-only agents (data-passing idiom / App surface enumeration / testing+schematics idiom) turned every open question into a grounded pin: no cycle paladin→typology, =desc= not "descriptor", =v.prototypes.X()= thunk pattern, the =yield.test.js= copy-me idiom, Path.branch multi-segment verified by eval before use.
- *Never export a =.branch()= — it returns the child.* Root vector or bust. The gate caught tools mounting at the wrong path; the fallback survived only because it branched =mode.tools= directly.
- *Disk + autosaves outrank memory.* Memory said "tooled.js:6 mints mode.tools" — stale; population mints universally, TOOLED was a noop, and =#tooled.js#= (emacs autosave) carried beef's live intent. Read the territory, including the crumbs.
- *Stage-gated manual application localizes every break.* Eight real bugs, each surfaced at the stage that introduced its surface, each fixed in minutes with the failing gate as the repro. A tangle-then-debug flow would have compounded them.
- *Prove a red pre-existed before ignoring it — with read-only VCS.* =jj diff= (allowed) showed the failing agentic pair was beef's WIP and the stripwire corpus was stale/incomplete. "Not mine" is a claim that needs evidence.
- *No invented state on shared citizens.* "wtf is daemon.store" — when a trait needs a location, derive it inline from what the daemon already carries; the consumer (bundler) owns its own subdir.
