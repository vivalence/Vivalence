* the marker — Question A and Question B, settled

Beef's marker (#175) asked for a FRAME: separate what is GUARANTEED at the end of processing from the many roads a value takes to get there. This session ran that frame against prod, and every stop was one of the two:

Question A — the guaranteed shape — was asked, and each time it paid:
- =SECRET_VIVA_JWT= is guaranteed =string({minLength: 24})= → the 18-char prod value could not be carried; rotate or relax, no third road.
- a service's db file is guaranteed =<slug>.viva.db= → the copy is a rename, and so is the daemon's.
- a mountpoint declared on the service is guaranteed to WIN over the seat → the volume is flat.
- =runtime.statics.remote= is guaranteed a =Url= only if declared → the crash in #174.

Question B — the roads — was where the surprises lived:
- =.default()= falls through for top-level env keys but NOT into a =consume.<x>.statics= thunk (measured: REQUIRED).
- Coolify writes =.env= from the UI; a hand-edited compose loses on the next click; =external: true= is ignored; a service rename drops the domain; an unused local image is pruned between build and click.
- =pragma foreign_keys= is a road the migration takes through the driver, and the driver drops every statement after the first.

The verdict for ikiro: when a container's state is in question, write Question A's answer FIRST (one checkable line per value: schematic + derivation), then walk Question B per road, and never diagnose a road before the guaranteed shape is on the page.
