* laws extracted this session

- **An open MikroORM sqlite handle holds the Deno event loop** — any short-lived process
  that boots a datamap must close it or =Deno.exit=. ProcessDie's missing =disintegrate=
  is the system-side gap (un-go'd, system code untouched).
- **The bundle store must live inside the repo** — esbuild resolves bare imports by
  walking up from the OUTPUT path; =/tmp= mountpoints cannot see node_modules.
- **Docs examples are order-proof by construction**: own your freshness (wipe your db)
  rather than assuming capture order; scratch = =testament/docs-anatomy/=, first claimant
  wipes.
- **Docs pages execute their subject**: example.js beside the page, assertions inside,
  Tabs(stdout/span/source) at the bottom. A red example fails the build — docs rot is
  now a build failure.
- Beef's authorship register: by NAME with role parenthetical, not by category.
