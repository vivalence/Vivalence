* issue 1 — hello-world names a package the system cannot supply

=registry/viva/instances/hello-world/education.js= kernel: =@education/domain/language-learning=,
=@education/topology/{word,sentence,conjugation}=, =@education/topography/english-to-brazilian=,
=@education/game/{riddler,dojo,judge,match,cloze,exhibit,nyan}=, =@education/tactic/{clinic,
five-fold-session}=, =@education/teacher/francesca=, =@education/dashboard/dataspace=. Plus a
hard dependency on the stanza NLP service (=VIVA_SERVICE_NLP_REMOTE=, docker).

Supply check: repo registry holds =viva · fixtures · playground= only. =github.com/vivalence/
education= → 404. =awesome-vivalence= → 200 but empty (no README). =starter/multiplayer.viva.js=
has the same =@education= list. So the README's step-3 promise — /"Open http://localhost:1794,
log in … and you're inside"/ — cannot be kept by a reader with only the public repo.

Working edit (mine, on the SHELF copy, not the registry): =daemons = [playground]=, the
=education= import removed. =playground= carries all its modes and boots clean.

Shapes the fix could take (beef's call, none ruled): (a) publish =@education= and let the
README's =registry/tap= step tap it; (b) ship hello-world with =playground= only and move the
education instance to a second recipe the README calls by name; (c) a =hello-world= that is
literally the README's =registry/dummy= mode. Doctor could also say it earlier:
=instance/doctor= at step 3 would surface the unsupplied owner before the first boot dies.

* issue 2 — kajuit 500: =trace= is undefined when two SSR entries race the barrel

Symptom, every route:
#+begin_example
[500] GET /
TypeError: Cannot read properties of undefined (reading 'chronicle')
    at eval (src/telemetry/logger.js, <anonymous>:13:75)      ← $story = atom(trace.chronicle.seed())
    … module-runner.js … at async eval (src/telemetry/index.js, <anonymous>:5:31)
#+end_example

Facts established with =createServer().ssrLoadModule= against the real =vite.config.mjs=:

- =@vivalence/typology= (alias → =subsystems/typology/mod.client.js=) loaded FIRST: =trace= is an
  object, 84 keys; =logger.js=, =index.js=, =+page.svelte= then all load OK.
- Each of =+page.svelte= · =+layout.svelte= · =telemetry/index.js= · =logger.js= · =mod.client.js=
  loaded ALONE, cold: OK.
- =Promise.allSettled([+layout, +page])=: OK OK.
- =Promise.allSettled([+page, +layout])=: ERR ERR, both =reading 'chronicle'=. Deterministic.

Mechanism: the module runner is mid-evaluation of the client barrel chain (=mod.client.js →
gestalten/index.client.js → belt/index.js → export * as trace=) on one entry's path when the
other entry reaches =logger.js=; =export *= re-export namespaces are populated as the
re-exporting module finishes, so =logger.js= reads =trace= from a barrel that is not done
and does WORK at module scope (=atom(trace.chronicle.seed())=). SvelteKit dev loads layout
and page in parallel, which is exactly the losing order. Deno runs the same graph green — the
same "module runner's choice" law =known-issues.org= already records under
=typology-internals-import-their-own-barrel= and =typology-client-barrel-tdz= (the client chain
has a known TDZ cycle; this is that cycle biting a DOWNSTREAM consumer through timing rather
than through a typology-internal read).

Provenance: the six-line =logger.js= landed in the previous compact (/"the telemetry family
moves in behind two doors"/), whose own fold notes /"LIVE-UNVERIFIED in a real browser"/. This
is the live verification.

Fix candidates — proposals, none applied, none ruled:
- =src/app/+layout.js= with =export const ssr = false=. kajuit is =adapter-static= with a
  =200.html= fallback — an SPA. Dev SSR of an app whose modules assume a browser buys nothing
  and is the only place this race exists. Smallest change, closes the surface, not the class.
- The repo's memoized-thunk idiom (=schematics/prototypes/yield.js=; standing valid per the
  ruling): =$story= seeded lazily on first use rather than at module scope. Closes the class
  for this file; cuts against the "settled six lines".
- Import =trace= from =gestalten/belt/trace.js= directly in =logger.js=. Cuts against
  =feedback_import_through_barrel= — beef's to waive, not mine.
