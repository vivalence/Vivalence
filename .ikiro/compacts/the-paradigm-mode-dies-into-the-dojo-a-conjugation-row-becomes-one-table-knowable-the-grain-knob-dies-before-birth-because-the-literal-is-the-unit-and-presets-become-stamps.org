* the pin, and the knob that died (rows 119–121)

- A conjugation table is a COMPOUND knowable — one knowable, N tokens, each token reviewed
  on its own literal, the whole reviewed with the sentence aggregate (all → SUCCESS · some →
  MISTAKE · none → FAILURE). =Dojo.land()= already reviewed =result.tokens[].literal= then
  =knowable.literal=; the table only needed a different INPUT SURFACE.
- Knowable =ontology: "conjugation"= = THE ROW, the corpus's own word. The old per-form
  knowable was a word wearing the row's name; a form IS a word — =fold.context()= reads its
  own =symbol.word= facets ={lemma → infinitive, tense, mood, person, number}=.
- The wake proposed =clause.conjugate: true= to explode rows into forms. beef's question
  killed it: the grain is decided by WHAT THE CLAUSE DRAWS. Draw rows → tables. Draw form
  words (=symbols= lemma+tense+mood · =literals= ids · any pick) → one by one. Nothing to
  declare — the "is this the repository's own word?" law applied to itself.
- Table knowable: ={ontology, known/learning = the infinitive, context {tense, mood, suffix,
  regularity} LABELED, tokens [{slot, form, gloss, literal, person, number, asset?}] in slot
  order, literal: row.id, asset?}=. Labels = LABELED person·number names — fixture =eu
  singular=, italian =First Person Singular= — until beef's pronoun STATICS.
- Presets may carry a =where= (=conjugate: {ontology: "conjugation"}=); =emitter/presets.js
  fold()= merges it, the drawer's =preset()= declares it. Ninth preset.

* the cell machine (row 121)

=Rep.svelte= owns it, =Table.svelte= renders it. =TypeInput= stays the ONE =[data-rep-input]=
(FOCUS LAW). =cellSession = streak.begin(tokens, axes.streak)= — the streak runs PER CELL:
a missed cell resets + requeues at the end, Tab =defer=s (to the end, no rep), the table
completes when every cell has its runs. Each commit reviews the FORM literal at once
(REALTIME); completion reviews the ROW with the aggregate over FIRST attempts. =recall= is
drawn per cell from the pool; cell order = slot order. Gameplay for a table draws among what
a table can resolve — TYPE + FLIP, never PICK — the =promptFor= law one axis over. Preview
= the filled table for =base + Σ form length × multiplier= ms. =Dojo.advance()= SETTLES a
table (=streak.settle= — one outer pass, whatever happened inside) and RECORDS everything
else. After completion a settled miss can be clicked and retyped in place (correction, no
review, no streak).

  cell — feasible for conjugation rows only (the =promptFor= law: a word/sentence never draws
  it; pool =[CONJUGATE]= alone → TYPE).

  review; PICK's distractors = the sibling forms already in the queue. Pool =[TYPE,
  CONJUGATE]= → drawn per row — "both/either way".
- default =gameplay: TYPE= ⇒ rows play as forms unless CONJUGATE is in the pool — no greed.
  Preset =conjugate= = ={gameplay: CONJUGATE, recall: LEARNING, where conjugation}= — still a
  preset too (/"its also preset"/).
- FLIP-on-a-table (reveal + self-grade) DIES; CONJUGATE is the only table surface; FLIP on
  a row = flip each form.
- an ABOARD table stays a table under a live gameplay change (mid-session expansion would
