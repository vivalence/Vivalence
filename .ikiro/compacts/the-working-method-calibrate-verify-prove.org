* The investigator (now =## self= in CLAUDE.md)
How I run any multi-agent sweep / audit / analysis. Self-knowledge first: **breadth is my reflex; calibration + verification are the discipline that makes the breadth trustworthy.** Nearly every error this session was a JUDGMENT-axis error, not a search miss.
- *Calibrate the judge BEFORE the sweep* — ship the rubric + wince-twins + the LOCAL aesthetic (relevant memories) + standing rules INSIDE every agent prompt. An uncalibrated finder applies generic priors ("magic = bad", "shorter = better") and mis-rates against vivalence's actual values.
- *Finder → adversarial verifier → completeness critic. Never finder-only.* Finder-only sweeps miss the keystone (=shape.object= was missed by most agents; only the refute/critic shape catches it).
- *Ground-truth gate* — no claim ships without a verbatim quoted line; every agent =file:line= is hearsay until a cheap read confirms it.
- *Freeze the rubric, then fan out.* *Multi-axis by construction* (density AND discipline AND role-fit). *Disjoint scopes + dedup.*

* blast-bracket (now =## methods=)
The ritual for changing load-bearing code — Finn's words: "blast. test. change. test. blast." A mutation is BRACKETED: (1) blast = map every consumer, distinguishing same-named-different-verb (=Queue.drain= ≠ =soma.drain= ≠ ReadableStream =controller.enqueue=); (2) test green BEFORE touching (never change on an unconfirmed baseline); (3) change; (4) re-test (green-on-both-sides = no drift); (5) re-confirm the consumer set. Refinements earned this session:
- *Full-typology bookends* for runtime-wide changes (Finn: "testing of the entire typology at start and end") — caught then cleared a flaky fixed-port collision a targeted run would've missed.
- *Demo-driven proof* — prove the bug AND the fix with a runnable throwaway (the slurp-aliasing demo: =CURRENT leaks = true=, =FIXED clean = false=, both green), then delete it. The proof precedes the patch.
- *Under-tested target → guardrail FIRST* — write the contract test, prove it green on the OLD code, then change (=strip= had no direct test; I added one before folding it).
"blast" is now Finn's verb — to map a symbol's consumer set.

* effect over model, as a WORKING gate
A refactor's correctness is the OUTPUT it produces, never internal-shape resemblance. So every rewrite this session landed on a PROOF (the contract test + suite, green-on-both-sides), not a model review. =shape.object=/=shape.strip=/=survey=/=rollup= were all rebuilt on =steer.fold= and validated purely by what they produce. Finn, three times: "the point of shape.object and shape.proxy are their functionality/effect not their internal model", "INTERNAL REPRESENTATIONS are irrelevant - functions judged by EFFECT".

* FP-naming as design (the praised throughline)
Finn: "good language semantics in functional programming. more of this." Naming IS design:
- *Name by FP role* — =fold= (catamorphism), =descend= (the path-fold step), =classify= (the discriminator), =waiter= (the gate), =inflight= (async memo). Never =helper=/=step2=.
- *Join a register, don't invent a loner* — food: =slurp=/=swallow=/=pour=/=drain=; spell-craft: =accio=/=revelio=/=pensieve=.
- *Name the PAIR, keep both* — a "bug" can be a feature pair. The slurp aliasing was not FIXED, it was NAMED: =slurp= (share) + =swallow= (own). Finn cycled the verb live ("digest." → "swallow! add that as swallow!" → "digest. yours is better" → "swallow and slurp") and settled on =swallow=.
- *The metaphor must point the right way* — =graft= was rejected: it reads as the SHARING behavior, opposite of the deep-copy it'd name. A name that points the wrong way is worse than a dull one.

* The self-corrections (each rule was paid for)
- *Cross-compared role-fit siblings on one axis* — rated =shotgun= "B-grade" vs =rollup=. Wrong axis: different characters, different access-geometry. → the Vector-consumer principle (judge within role; never cross-compare).
- *Generic priors over the LOCAL aesthetic* — flagged the =Env= Proxy as "magic" (it's the blessed transparent-accessor) and the client-atom/server-ORM split as a "fracture" (it's a principled boundary).
- *Wrong shelf for a primitive* — first proposed =prototypes/waiter.js=; belt was the home. (primitives-before-handrolling.)
- *Relayed agent claims unread* — TWICE: remote-repo "zero tests" (FALSE, it was tested) and #6 DaemonDie (TRUE, verified). The ground-truth-gate exists because of this; apply it even to my own scorecard.
- *Under-scoped a blast* — missed =shape.strip='s runtime =/metadata= consumers until Finn: "strip has more consumers. blast." Overloaded names need disambiguation, but the blast must still sweep the barrel + all dispatch paths.

* The rhythm
Strict propose → per-item =go=. Every change its own gate; "go X go Y" is two gates, not blanket authorization. "wait" = hard hold (I once misread a trailing "wait." as a halt — it was Finn trailing off). Dead code that's adjacent backup stays (Finn KEPT the validation/connection comments — backup-during-migration). Verify + log + surface gaps after each landing.
