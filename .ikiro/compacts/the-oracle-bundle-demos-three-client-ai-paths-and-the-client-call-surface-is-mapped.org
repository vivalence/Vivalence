** the three client calls (exact, corrected)

#+begin_src javascript
// registry/playground/chaosmonkey/oracle/buffer/Oracle.svelte  — all on buffer.mode
// 1 · cortex · object
const h = buffer.mode.daemon.cortex
  .hallucination({ tune: "eager" })
  .context.system(SYSTEM)                                                  // NOT .context.extend(string)
  .entities.turn.append({ role: "user", parts: [{ type: "text", text: prompt }] })  // a user TURN is required
  .output.object(v.object({ answer: v.string().desc("the oracle's reply") }));       // .output.object, object schema
const render = await h.object.render();                                   // Promise (echo strategy); throws on non-OK
assistant.set(render.object?.answer ?? "");

// 2 · harness · object  (stripwired: buffer.mode.harness.object.render ≡ connection.call("/harness/object/render", …))
const render = await buffer.mode.harness.object.render({
  turns: [{ role: "user", parts: [{ type: "text", text: prompt }] }],
  output: v.object({ answer: v.string() }),
});
assistant.set(render?.object?.answer ?? "");

// 3 · cortex · stream  (real SSE — the harness dialogue.stream is BUFFERED, so stream via cortex)
const stream = await buffer.mode.daemon.cortex
  .hallucination({ tune: "eager" }).context.system(SYSTEM)
  .entities.turn.append({ role: "user", parts: [{ type: "text", text: prompt }] })
  .dialogue.stream();
for await (const packet of stream) {
  if (packet.event === "/part/delta" && packet.delta?.text) { text += packet.delta.text; assistant.set(text); }
  else serverLogs.log(packet.event, packet);           // structural server events → the right column
}
#+end_src

* Lessons (self-corrections)

- Verify the client handle before writing calls: the sketch's =terminal.mode= / =terminal.daemon.cortex= were aspirational — the real map is =buffer.mode= (harness) and =buffer.mode.daemon.cortex= (cortex). The Explore-agent trace caught three throwing errors in the sketch chain before they ran.
- "It's called =stream=" ≠ "it streams." The stripwire flattens render/stream to the same buffered =connection.call=; genuine SSE is a different avenue (=connection.observe= / cortex =dialogue.stream=). Read the wire, not the method name.
- A structured-output schema is compiled to a provider TOOL; Anthropic's =input_schema.type= must be =object=. Bare scalar schemas (=v.string=) are illegal there — always wrap (=v.object({answer})=).
- Kept the log renderer INLINE + renamed (=Trace=) rather than clobbering drapes' semantic =Paragraph= — beef flagged the collision; the app-space log line is not the same entity as a text paragraph.
