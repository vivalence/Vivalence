* the recast — three call-site files, schemas inlined, identity specialized (go'd)
=persona.js= turned out to be an orphan: the live twin was =hallucinations.js= (=emitter.js= + =aperture.js= both imported from it), =persona.js= a near-dupe carrying only the =@beef= note. Recast collapsed both into three files — =generation.js · reply.js · evaluation.js= — each moving its render output schema OUT of =types.js= and inlining it beside the prompts (=RIDDLER_/ASSISTANT_/EVALUATION_RENDER_OUTPUT=). =types.js= kept only the input/shared schemas + =GRADES=.

The one real fork was =identity()= — shared by generation + reply, absent from evaluation (a detached judge). beef, on the AskUserQuestion: *"not only duplicate into both, adjust the content for both specialized for task!"* So the generic voice split: generation's =identity= drops the duel-time lines (crown/taunt/third-person — no live challenger at compose) and sharpens *"Vanity is your craft… delighting in the small twist that makes a learner think rather than merely recall"*; reply's keeps the duelist voice *"you relish the duel, savour every parry…"*. The generic-compromise persona was carrying dead duel instructions into the generation step; the split killed them.

* into hal/ — the barrel (go'd)
beef: *"evaluation.js generation.js hal reply.js — move these three into hal and export from hal/index.js"*. A =registry/education/game/riddler/hal/= subdir, the three files moved in (=evaluation.js='s =GRADES= import re-relativized =./types= → =../types=), and =hal/index.js= = =export * from= each — the repo's barrel idiom (=subsystems/paladin/prototypes/index.js=, =domain.viva.js=). Consumers repointed to =./hal/index.js=.

* the reorg — section palette, no pipes, composition in the effect (go'd)
beef: *"i am still itterating hal. the architecture is weird. i want the export from hal to contain each section individually, no pipes. composition, aka calling multiple sections to context on hallucinatoin happens in the effect."* + *"organize this. cleanly."*

The =@beef= "weird" was the pipe: each bundle's =system: (lang,pool,level) => [identity(lang), subject(pool), ceiling(lang)].join("\n\n")= — hal deciding ASSEMBLY. That belongs to whoever builds the hallucination context. So the doctrine crystallized: **hal is a PALETTE of raw prompt sections; the effect welds them.** Each bundle now exports =output= + the individual sections, no =system=:
- =emitter {output, identity, subject, ceiling, compose}=
- =assistant {output, identity, duel}= (=reply.system= split → =identity= + =duel=, the posed-riddle rules)
- =evaluation {output, judge}= (single detached-judge section — persona fused with rubric, nothing to compose against)

The effect (=emitter.js=) welds the generation system turn =[hal.emitter.identity(language), hal.emitter.subject(pool), hal.emitter.ceiling(level)].join("\n\n")=, and seeds each riddle buffer's =history[0]= with =[hal.assistant.identity, hal.assistant.duel].join= — the assistant's FUTURE voice, stored so =/assistant/message= can replay it. Two identities, correctly sourced: the emitter composes with its OWN craftsman voice AND seeds the duelist voice for later.

Separation of material from assembly (connoisseur read): the =.join= inside hal was hal re-deciding what belongs in whose system turn — the near-duplicate-partition wince. Palette + effect-side weld removes it.

* the cohesion pass — the hallucinators mirror the vectors (go'd)
beef: *"emitter should have its own identity. align the naming. we have emitter, assistant, and evaludation. ensure harmony between the hallucinators and the vectors. cohesion"*. The friction was =emittion= (a mis-spelled "emission") vs the =emitter= Vector. Renamed the bundle + file → =emitter=. The trap: =emitter.js= already =export const emitter = new Vector()= (the EMITTER-trait export, non-negotiable — the trait reads =mode.module.emitter=), so a named =import { emitter }= would shadow it. Fix = =import * as hal from "./hal/index.js"= — dodges the collision AND makes the palette speak the vectors' three words:
- =hal.emitter= ↔ =emitter= Vector (nature =/riddle/fromSymbols=)
- =hal.assistant= ↔ nature =/assistant/message=
- =hal.evaluation= ↔ nature =/assistant/evaluate=

* the port — aprende's harness monolith becomes hal.assistant (go'd)
beef: *"apply the same ordering principle to mode/aprende."* aprende is HARNESSED (not harness-free like riddler), so the composing "effect" is the harness middleware itself. Its prompt surface: a MONOLITH =ctx.hallucination.context.system(\`…\`)= in =registry/education/homepage/aprende/harness.js= (identity + mission + capabilities + language, fused) + an inline render output schema in =aperture/message.js=. Ported: =aprende/hal/assistant.js= = one bundle =assistant {output, identity, mission, capabilities, language}= — the monolith split into sections. The HARNESSED middleware welds =[hal.assistant.identity, .mission, .capabilities, .language(lang)].join("\n\n")=; =message.js= render uses =hal.assistant.output=. Both =import * as hal=; =hal.assistant= ↔ =/assistant/message=, same cohesion as riddler. Boundary held: tool =valence=s (=tools/*.js=) + emitter orchestration were NOT moved — a valence is a tool's self-description bound to its nature, not a system-prompt section. Only cosmetic drift: sectioning inserts a blank line between =identity= and =mission= (the monolith ran them together); content identical.
