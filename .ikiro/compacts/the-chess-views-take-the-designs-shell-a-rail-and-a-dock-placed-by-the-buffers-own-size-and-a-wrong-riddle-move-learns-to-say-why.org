* laws

- A view inside anima measures its OWN box, never the window: the Frame can be one split of the screen. The design's placement rule lives
  as a pure function beside the view so a test can pin the sizes a server render never has (37).
- A snippet prop named =top= collides with a view's own =top= constant. The Shell's seat snippets are =upper= / =lower= (37).
- A server render prints only the OPEN tab. A panel both views share becomes a kit component and is rendered raw with the buffer's own row;
  a test-only prop that picks the tab is the wrong fix (37).
- A dock that clips its overflow clips half of a handle straddling its edge (37).
- A served bundle can be walked without anima: bundle with =paladin.bundler=, add dapper's =design()= CSS, mount with a stub row. A hidden
  Chrome tab never fires =requestAnimationFrame= (a probe awaiting it hangs the page until CDP times out) and paints only when a screenshot
  forces it, so measure after a screenshot (37).
- A riddle's refutation is the engine's pv on the position AFTER the wrong move, so it scores the opponent; negate it for the solver. A
  scripted pv must be legal, and a test position must be one no earlier step evaluated — the domain caches evaluations per position (39).
