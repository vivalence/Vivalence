** the Vector gloss (keystone terminology)

beef: =and explain the vector in the docs and your internals as "Declaratively dispatched monadic constructor"= then =or ... monadic combinator?!=

Resolved as THREE LAYERS (both words are right, at different layers) — the Vector is a FREE MONAD in effect:
- CONSTRUCTOR names the NOUN — the =Vector= itself, an inert composable context-threading DESCRIPTION of dispatch (an AST).
- COMBINATORS name the METHODS — =.use(mw)= / =.open(sig,fn)= / =.branch(sig)= / =.slurp(other)=, each =Vector → Vector=.
- INTERPRETERS name the FOLDS — =shape.*= (object/strip/http/connection.wire) and =steer= strategies fold the AST into something runnable.
Build-then-interpret; one structure, many folds = the free-monad shape. The Vector does NOTHING until an interpreter folds it — that deferral is the whole point. Rippled into codemap =typology.md= (the Vector entry) and =42.01=.
