* what was learned beyond the quests (row 5 — beef's question)

1. *A staged artifact is a third kind of thing between design and code.* Quests can carry
   executables (a package tree, a patch) as attachments; =.ikiro/= is mine, so the artifact
   is hardened IN PLACE while the repo it targets stays gated. Two quests now share the
   convention (=quests/<name>.org= + =quests/<name>/=). The pass is a repeatable method now
   (=methods/critical-pass.md=, pointer in rituals).

2. *The scratchpad sandbox verifies gated code without touching it.* rsync + symlinks, ~250
   MB, two minutes: apply a patch, run every suite, fix, regenerate — worktree clean, VCS
   untouched, beef's watchers unbothered. Before this, "verify the patch" meant either
   trusting the author or asking beef for a =go= just to test. That gap is closed.

3. *Tests encode the author's model; defects live at the seams the artifact did not write.*
   Both artifacts were green by their own tests. Both were wrong where they met code they
   did not touch: the client's populate list, the cortex's nearest metric, deepgram's segment
   semantics. Reading the CONSUMER side of every new seam is the audit; the artifact's own
   test count is not evidence.

4. *"By default" is a claim about a mechanism; find it and compute it.* Nearest-tune is a
   metric with a vector; "multi is default" was decided by arithmetic the author never did.
   Same shape as m32's "self-contained" being contradicted by its imports. When a design
   says default, the pass finds the resolver and runs the numbers.

5. *Absence claims are the highest-yield audit target in delegated work.* /"no distance util
   exists"/, /"CONVERSATIONAL is dead"/ (my own memory hook), /"nobody decodes the upstream
   body"/. Both artifacts carried one; both were false; each was one grep. The kernel already
   says absence rots fastest — this session measured it on other agents' output, not only on
   codemap shards.

6. *Delegated builds drift in predictable directions.* Frozen at the author's snapshot of the
   codebase (two renames back); fabricated glue where the snapshot had a gap
   (=configure().context.system=); wiring sections describing an imagined environment
   (=localhost.viva.js=, hand-edited =registry.json=, =SECRET_DEEPGRAM=); tested
   completeness that quietly widens scope (=turn.js=). Wiring is the least trustworthy
   section every time — re-derive from =testament/variant/= + docs.

7. *Regenerating a patch against a live repo needs a whitelist.* beef edits while I work; a
   fresh base captures his concurrent changes and generated files. The intended file set is
   the contract, not "everything that differs".

8. *Two flake families now named.* Fake async sources in tests must be abort-aware (a pending
   =sleep= at test end trips Deno's leak detector); a hyphen-normalising slugify must fold
   hyphens to spaces before =string.fold= or hyphenated lemmas split.
