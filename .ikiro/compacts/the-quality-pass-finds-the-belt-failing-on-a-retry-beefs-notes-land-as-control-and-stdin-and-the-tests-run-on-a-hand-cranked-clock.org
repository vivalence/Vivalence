* laws worth keeping

- A controller handed in is a lifecycle handed over: the callee marks it open/close; branching is the CALLER's act. A callee that branches what it was handed leaves the handed root unmarked forever.
- A branch does not fail its parent and does not finish it — a result returns as data through the brancher. So in a composed call, the PRIMARY operation holds the root; only secondary steps branch.
- A MACHINE verb on stdout is a state move, never telemetry. A retry, a note, a warning is `note`; `fault` settles.
- `settled` fulfils on every settled state with the error on the reflection — a rejecting settle needs a swallow, and a swallow is a quiet error.
- Test with a clock the test owns: a faculty that yields per crank turns "nothing flows while PAUSED" into a count. One ledger asserted whole beats many flat `it`.
