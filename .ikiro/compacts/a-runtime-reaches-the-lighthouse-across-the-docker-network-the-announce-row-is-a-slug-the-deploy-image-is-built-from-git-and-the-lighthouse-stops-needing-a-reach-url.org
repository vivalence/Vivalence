* laws

- (1) A lighthouse daemon row is identified by =slug= alone (=Daemon.ts= UNIQUE; =DataEntity.ensure= findOne → assign, else create). (2) Last announcer wins: same slug from a new remote overwrites =url=, one row. (3) Persistence total, liveness zero: a dead runtime's row stays until something removes it. (4) The announce prune compares the BIND origin (=runtime.statics.serve.origin=, =0.0.0.0=) against REACH urls — it never matches in docker. (5) Removal is one =removeOne= curl. — measured T0–T9, =.ikiro/reference/lighthouse-announce-dynamics.md=.
- A daemon's reach url is =PUBLIC_VIVA_RUNTIME_REMOTE + /daemon/<slug>=; the mode aperture mounts at =/daemon/<slug>/mode/<type>/<slug>=. Nothing under =/attached/process/=.
- Schema =.default()=s do not hydrate without a =.env= — container env is explicit or baked as image ENV.
- A =registry.json= with any entry stops auto-discovery of commons. Tap commons explicitly.
- A docker =RUN= keyed on a git url is cached on the url, not the head. Fresh taps = =--no-cache=.
- Aperture middleware order: context binds before any handler that reads =ctx=; a mode's own aperture is slurped after the binds.
- A runtime process reads its reach url from =paladin.instance.runtime.statics.remote=, never from env directly; a process without daemons needs none.
- Pensieve keys a module by the package manifest owner; the store directory name is cosmetic.
