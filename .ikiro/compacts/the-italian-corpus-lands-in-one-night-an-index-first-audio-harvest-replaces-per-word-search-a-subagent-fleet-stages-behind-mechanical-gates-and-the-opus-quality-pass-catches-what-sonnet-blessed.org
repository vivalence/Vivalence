* the index-first insight

The Spanish build ground per-word Commons =srsearch= calls and hit a wall at ~190 words. The Italian build inverted it: dump BOTH Commons categories ONCE via =categorymembers= pagination (~30 calls) → =audio-index.json= mapping 13,444 files → *10,748 distinct italian forms with open CC audio*. Coverage became a LOCAL set-intersection; beef's "there is 2000. i am sure." confirmed within two cycles. The scarce resource turned out to be bytes-per-hour, not coverage: Wikimedia 429'd the IP into 600s Retry-After loops. Response: bulk-resolve all URLs up front, MAX_PER_FORM 4→2, zipf-DESCENDING priority (under throttle, coverage beats choice), resume-safe state. * doctrine extracted

- *Index-first beats search-first*: N throttled fuzzy searches lose to one full category dump + local intersection — know coverage EXACTLY before pulling a byte.
- *The integration gate is the collision net*: parallel authors will race; catch at merge with full blocking sets, not by trusting per-agent dedup claims (two agents' self-reported verification counts were wrong).
- *Fix-appliers parse findings files with current-value assertions*: every applied fix asserted the current value first; 0 drift across ~150 applied fixes.
- *Audio-locked fields split the fix surface*: VOCALIZED sentences take known-only fixes, never learning — the inversion doctrine's second life as a QA constraint.
- *Resume beats restage*: SendMessage to a dead agent's transcript recovered three tasks for a fraction of fresh dispatch.
- *Model tiers are QA tiers*: sonnet found taxonomy and grammar-shape errors; only opus found meaning inversions sonnet had blessed.
- *The fixer can regress the law the finder ignored*: my hand-applied gerund/piovere criticals dropped the taught form from its own example — audit.py caught my fixes the same way it caught agent batches. Every fix pass ends with the full mechanical gate, no exceptions for the operator.
- *A skip with a reason beats a forced apply*: the fix-applier refused 21 proposals that would have broken form-in-example, logged them, and the residue is a record — not a defect.
