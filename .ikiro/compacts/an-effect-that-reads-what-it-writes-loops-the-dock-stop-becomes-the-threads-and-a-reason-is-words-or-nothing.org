* one breath

The fold beef opened with /"some loop kills my client"/ and closed with a stop button that
kills a whole thread. Between the two, every claim I made about the activity capability had to
be re-measured, and most of the session's cost was that re-measuring rather than the code.

The loop was mine, one fold old: the =version= counter #163 prescribed was incremented inside
the store listener that the subscribing =$effect= had just opened, so the effect depended on
what it wrote — 1001 runs, then =effect_update_depth_exceeded=. =untrack= fixed it in one line.
The reason it shipped is the durable half: the test that "verified" it COMPILES the widget, and
a compile never runs an effect. So the fold built the thing that does — a mount rig on
=linkedom=, scoped to kajuit on beef's /"only kajuit"/ — and every later fix rode it.

Then the F panel's rows were unreadable, and neither cause was mine either: panel B leaks
=:global(section .row)= over every section in the app, and Tailwind's =.ring= drew a box around
the ring counter. The log read =3632670.09= because that is the daemon's =performance.now()=;
it now reads =+7.57=, with the record's data flattened into words. =STOPPED · [object Object]=
turned out to be built in typology, not in the view: a stdin call with no argument crosses the
wire as ={}=, the controller stored it as the reason, and =Failure= stringified it. On /"fix.
fix"/ the holy layer took its first edit of the fold — a reason is a non-empty string or
nothing.

The kill hunt found no defect: daemon, wire and button each answered correctly under
measurement, and the one thing that looked like a bug was my own fixture, deep-proxied by
=$state=. beef then ruled the design instead: /"i think that should be considered the kill all
button. nuclear."/ and /"sigterm single, sigkill on hold. 2s. send sigterm eargerly."/ That
landed as =stop.svelte.js= — a press SIGTERMs every live row on the thread, a 2s hold SIGKILLs
them, and the arming persists so a row that has not opened yet (SIGTERM has no transition from
IDLE) and a row minted mid-stop both take the signal on arrival. =research= was the row that
escaped, so on /"continue"/ it became the m65 followup's first site: it hands
=ctx.controller?.branch("dialogue")= and mints no row of its own.

* laws

1. **A store listener fires inside the effect that subscribed it.** If it reads what it writes,
   the effect depends on its own output and svelte gives up at 1000. Pure assignment, or
   =untrack=.
2. **An effect is verified by RUNNING it.** Compiling proves syntax. Mount it, or drive the
   runtime primitives. A test that cannot fail is not evidence — mutate it once and watch.
3. **A plain-object fixture assigned into =$state= is deep-proxied.** Writes through =this= land
   in the proxy. Log through a closure. Class instances are not proxied, which is why the real
   rows behave differently from the fixture.
4. **A reason is a non-empty string or nothing.** A no-argument call crosses the wire as ={}=,
   and anything truthy will be stringified by something downstream.
5. **A signal reaches only the states the machine's transition table names.** SIGTERM cannot
   move an IDLE row, so an eager stop must stay armed rather than fire once.
6. **Scoped CSS is not isolation.** One panel's =:global(section .row)= styles every section's
   rows in the app. Grep =:global(= AND the Tailwind utility list before naming a class.
7. **A char budget is a byte budget.** =·= costs two bytes and =—= three; =wc -c=, never =len()=.
8. **A keyed each over a merged list must rebuild through the deduping helper**, not concatenate
   two lists that were each built by it.
