change?" → dry-run clean → "you run it. go". The patch survived the m38 symbol edits.

1. =query==text= is not exact — 'Non capisco.' returned 'Non capirete.' (Manticore
   stemming). Real syntax ==="text"=, and it stopped mattering.
2. The api reports =license: null= for NM1's recordings — the very rows
   =sentences_with_audio.csv= licenses CC BY 4.0. The original ='!a.license ||'=
   acceptance the critical pass had condemned as the license bug was HALF-DELIBERATE
   compensation for an api that cannot carry the license.

Fix = the italian-build doctrine again, index-first: intersect the cached CSV exports
(=/tmp/tatoeba/=), gate on CSV licenses, download by audio_id. Result: 5 hits, all NM1,
all CC BY 4.0, ledgered; VOCALIZED 506 → 511. Beef pushed — "5 audios is not enough!!
if no licence, assume one." — gate relaxed (null → "Tatoeba terms"), rerun: STILL 5.
Proven by counting every audio row in the full export for our sids: 5 rows exist,
period. Availability is the wall, not licensing; the 138 are the TTS queue, and the
deferred-section prophecy ("reopens when a recording pipeline exists") resolved to:
the datasink mode IS the recording pipeline.
