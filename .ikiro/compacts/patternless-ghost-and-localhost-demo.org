** Landed shape

Each command file is a function that decorates the trajectory directly. No wrapper, no factory, no custom strategy. Middleware via `.use()` for ctx construction, effects via `.open()`. `steer.invoke + steer.direct` casts.

#+begin_src javascript
// systems/ghost/trajectories/install.js
export function install(trajectory) {
  trajectory.branch("/install")
    .use(async (ctx, next) => {                  // ctx construction
      const [slugOrPath, dest] = ctx.argv
      if (!slugOrPath) throw new Error("usage: ...")
      ctx.slug = slugOrPath
      ctx.destination = dest ?? paladin.scope.variant?.absolute
      await next()
    })
    .use(async (ctx, next) => {                  // resolution
      ctx.source = await resolveVariant(ctx.slug)
      await next()
    })
    .open("/variant", async (ctx) => { ... })    // effect
}
#+end_src

** pickStartPlan / pickProcessTargets

Two pure resolvers:

- `pickStartPlan(wafer, target)` (in start.js) — resolves against wafer's runtime + clients map. Literals "runtime" / "client" / "clients" are kind-words; otherwise slug match.
- `pickProcessTargets(processes, target)` (in lib/processes.js) — resolves against recorded process entries by `kind === "runtime"` / `kind === "client"` literals, or `slug === target` for specific.

Same target grammar in both: empty → all; literal "runtime" → runtime kind; literal "client[s]" → client kind; otherwise slug filter.

** spawnDetached helper

Initial detach attempt — `sh -c "exec deno run ... >> log 2>&1"` + `child.unref()` — killed the subprocess. macOS sends SIGHUP-ish to unrefed children when Deno parent exits even with unref.

Working pattern (in start.js):

#+begin_src javascript
async function spawnDetached({ cmd, log, env }) {
  const script = `nohup ${cmd} >> "${log}" 2>&1 </dev/null & pid=$!; echo $pid`
  const result = await new Deno.Command("sh", {
    args: ["-c", script],
    env, clearEnv: false,
    stdout: "piped", stderr: "piped",
  }).output()
  if (!result.success) throw new Error(`spawn failed: ${...}`)
  const pid = Number(new TextDecoder().decode(result.stdout).trim())
  if (!pid) throw new Error(`failed to capture pid for: ${cmd}`)
  return pid
}
#+end_src

`nohup ... &` orphans deno to init; sh exits after backgrounding; `echo $!` captures real deno PID. Sub-process logs flow into `<variant>/.logs/<slug>.log` via shell redirect.

** processes.js multi-process

Compound key `(variant, slug)` for filter. Helpers `findProcesses(variant, slug?)` and `dropProcesses(variant, slug?)`. `runtime.pid` file written only when `kind === "runtime"` (legacy fallback).

* Bugs discovered + fixed

** Spawn detach killing subprocess (mid-demo)

Symptom: `viva start /Users/finn/test` returned STARTED but runtime.log was empty, ports not listening, subprocess dead.

Root cause: `sh -c "exec deno..."` + `child.unref()` doesn't fully detach. macOS reaps the deno child when parent exits. Fixed with `nohup ... &` + `echo $!` pattern (see spawnDetached above).

** Fresh-DB dataset install — `Literal.ontology = NULL`

Symptom: fresh ~/test/mountpoint/daemon_brazilian/localhost.viva.db. Runtime ran migrations, started `[DATASET:install] upsert:literal` phase, hit `NotNullConstraintViolationException: ... ontology = NULL`.

Root cause chain:
1. `LiteralSubscriber.ontology(entity)` (`subsystems/typology/entities/kernel/Literal.ts:117`) derives slug from `entity.symbols` filtered by TOPOGRAPHICAL trait.
2. `LiteralSubscriber.beforeUpdate` unconditionally writes `entity.ontology = this.ontology(entity)`.
3. Dataset's `linkPhase("literal", "symbol")` (`systems/runtime/daemon/traits/dataset.js:28`) loads literals with `populate: ["symbols"]`, then `to.assign(object.patch(to, ref))` dirty-marks them.
4. Within the same flush, `entity.symbols` collection reflects only DB-committed symbols, NOT the new TOPOGRAPHICAL symbol being linked this cycle.
5. `ontology()` finds nothing → `return;` (undefined). beforeUpdate writes undefined → MikroORM emits `UPDATE Literal SET ontology = NULL`. Constraint kills it.

Fix:

#+begin_src diff
   ontology(entity: LiteralEntity): string {
     if (!entity.symbols.isInitialized()) return entity.ontology;
     const topographical = entity.symbols
       .getItems()
       .filter((s) => s.traits.includes("TOPOGRAPHICAL" as any));
-    if (topographical.length === 0) return;
+    if (topographical.length === 0) return entity.ontology;
     ...
   }
#+end_src

"if I can't compute, leave the existing value alone." beforeUpdate's write becomes idempotent on that column. Fresh DB → full 2216 literals upserted + linked + ALIVE.
