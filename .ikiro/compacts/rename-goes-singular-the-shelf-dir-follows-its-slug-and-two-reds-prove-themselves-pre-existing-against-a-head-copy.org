* two lessons, self-caught

- **the lens fuzzes across mount paths.** A test slug =a= matches =/instances/a= AND =/instances/b= through =pick= — one-letter slugs in a lens test are a collision, not a fixture. Use words.
- **a bracket without stash.** VCS is read-only, so "does HEAD fail too?" was answered by =cp -r systems/ghost <scratch>= + =git show HEAD:<file> ><scratch>/<file>= for each touched file + =deno test --config systems/ghost/deno.jsonc <scratch>/tests/…=. Relative imports stay inside the copy, package imports ride the config. Cheap, decisive, no VCS mutation.
