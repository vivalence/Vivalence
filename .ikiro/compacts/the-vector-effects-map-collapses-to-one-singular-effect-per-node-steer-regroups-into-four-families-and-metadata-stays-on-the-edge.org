* the laws (durable, beyond this rotation — carry these forward)
- *metadata belongs to the EDGE, not the node.* beef's crystallization: /"the vector is its own thing. the vector doesnt know how its arrived at. it might also be arrived at in different ways!"/ Anything reachable by more than one route CANNOT own route-specific data — it lives on the edge (the =Map<pattern,vector>= key), or, if effect-intrinsic, with the effect. The test for "where does this field belong": can two arrivals disagree on it? Then it's the edge's.
- *aggregation is a property of the EFFECT, never the container.* One effect per node stays the invariant; when you want N handlers, the ONE effect IS a multiplexer (=fanout=, =.add()= to grow — the same shape aperture's =methods()= dispatcher already uses). Don't teach the container to hold lists; teach the payload to fan.
- *artifact vs feature.* When a rotation "breaks" something, first ask whether that behavior was DESIGNED or was an accident of the old mechanism. The shotgun dup-path fan was Map-keyed-by-object-reference luck, not a feature — so the rotation didn't regress it, it EXPOSED it. Only real features constrain the redesign.
- *prove innocence, don't attribute by vibe.* A change to a core prototype earns the FULL downstream sweep + adversarial attribution — baseline, isolated repro, prove-or-disprove — never a "probably pre-existing" hand-wave. The two-phase-closure root cause only surfaced because that discipline was (belatedly, under fire) applied. The hand-wave is the failure; the proof is the job.
- *ugliness is usually a layering signal.* =stamp='s blacklist was ugly because Vector reached into Pattern's private fields. The fix is not to relocate the blacklist (=enrich=) but to ask whether the data is in the wrong place to begin with. Relocating a hack is still a hack; dissolving the need for it is the rearchitecture.
- *rearchitect to make the problem NON-EXISTENT.* beef: /"why is this a problem in the first place? where can we rearchitect to solve this by making this a non issue?"/ The winning move on =stamp= was not a cleaner stamp — it was realizing the guarded case never occurs, so the code shouldn't exist. YAGNI is a rearchitecture, not a cop-out.
- *the boundary is already drawn — don't re-cross it.* Every steer function is vector-semantic; the generics already live in =belt.middleware= + =fromm=. Do not move something to belt because it "looks generic" — =fire='s arity-dispatch IS the effect calling-convention, not a general utility. The seam that actually moves is fromm↔steer.
- *good rotations SIMPLIFY.* The tell that singular-effect was right: it dissolved a duality (two maps → one tree), erased two hacks (=feed= heir/effect pick, =object='s reunification Object.assign), and activated dead code that had been written in anticipation (=walk.js:37=). A rotation that adds machinery is suspect; one that deletes it is usually finding the grain.
