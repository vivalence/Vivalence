* the laws pinned this session

- *the Primer re-points the kernel* — one structure (literal + REQUIRES DAG + Memory + harness), one law (the prereq fold), re-skinned from words to concepts. No new machinery.
- *prereqs are a trait, the DAG is free* — a concept's =REQUIRES.concepts= slug-list IS the edge set (mirrors how education's ANNOTATED/CONJUGATED slug-lists feed =literal.uses=). Atlas + frontier read from the authored trait directly; a domain subscriber writing REQUIRES→=uses= is a deferred fast-follow.
- *the frontier fold is the pedagogical spine* — =frontierOf(concepts, mastered)= = concepts not yet mastered whose every prereq is mastered; empty mastered → the DAG roots; mastery advances it one layer at a time. Proven: 8 layers to master all 15.
- *drapes already ships the datadashboard* — ECharts via =drapes/stage=; the datadashboard is a re-point, not a build. The =Canvas.init(container)= seam dissolves the bundle-law worry (raw container, hand-roll or echarts, no kajuit barrel).
- *canonical symbol field is =trait=* (per =schematics/entities/symbol.js= descriptor + corpus exemplars), not the =data= key education's =topologies/*/symbols/ontological.js= uses.
- *the primer loop = riddler turn-free + aprende render* — the story lives on =buffer.data.history= (no Thread/Turn entities), one =/assistant/turn= nature drives grade→advance→render→append, cortex reached only server-side via =ctx.mode.harness.object.render({turns, output, thread})= → =render.object=.
