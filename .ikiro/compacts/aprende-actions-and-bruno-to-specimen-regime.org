** pass 3 — connoisseur pass (Finn: *"let the conoisseur have a pass at the problem. take ya time"*)
Verdict: the 1:1 hand-port is the EASY answer, not the simple one — ~30 authored

skin. The real cut: a regime is a NEW VECTOR-CONSUMER, sibling of

#+BEGIN_SRC javascript
// assay: fold the DERIVED contract into an executed+asserted report
const assay = (contract, conn, fixtures = {}, skip = new Set()) =>
  rollup(contract).map(({ pattern }) => {
    if (skip.has(pattern.nature)) return { nature: pattern.nature, skipped: true };
    const body = fixtures[pattern.nature] ?? v.cast(pattern.input, {});
    return conn.aim(pattern.nature, body)()
      .then((response) => ({
        nature: pattern.nature,
        pass: [...v.errors(pattern.output, response)].length === 0,  // endpoint's OWN schema = oracle
      }));
  });
#+END_SRC

- two GRAINS, named not collapsed: *contract* (derived — rollup the live tree,
  cast-or-fixture body, matches(output); drift impossible) vs *scenario* (authored thin
  .test.js carrying real intent: login-invalid→401, tool-loop→SSE packet shape).
  Fixtures = data annotating a derived structure (patternmap-shaped ={nature→body}=);
  a renamed leaf surfaces as an un-consumed fixture, never silent drift.
- two VANTAGES, each in its role (don't cross-compare): in-process
  =rollup(die.good.aperture)= owns the contract grain (live schemas, total coverage);
  over-wire =messenger(strip(remote))= owns what only the wire proves (auth-gating,
  HTTP status, SSE framing).
- K-boundary teeth (the discriminator tempering "fire everything"): (1) aperture is not
  all read-only — mutation leaves need an explicit LOGGED skip-set; (2) =v.cast= fills
  Default-only — non-defaultable inputs (login, turn) need fixtures; (3) typebox Kind
  symbols do NOT survive JSON — the wire-side oracle needs recompile or stays
  in-process-only (open fork).

file.* Env tables, vars:post-response capture, --env-var layering between runs,
reporter-json+jq, curl-for-SSE — all exist to give dead files the state a JS function
has for free. Rebuild table:

| bruno feature              | rebuild                                   | effort  |
|----------------------------+-------------------------------------------+---------|
| request def (meta/post/…)  | =conn.call(endpoint, body, options)=      | 0       |
| environments               | one BASE const / env object               | trivial |
| --env-var layering         | a local =const=                           | deleted |

| vars:post-response         | destructuring assignment                  | deleted |

| tests (chai)               | specimen expect                           | 0       |
| seq ordering               | statement order                           | deleted |
| bru run + jq               | deno test                                 | 0       |
| SSE (bruno CAN'T)          | =conn.stream= async-gen                   | native  |
