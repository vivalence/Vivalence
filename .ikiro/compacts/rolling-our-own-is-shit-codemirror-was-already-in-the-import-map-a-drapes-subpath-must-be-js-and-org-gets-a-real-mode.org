: ERROR: The JSX syntax extension is not currently enabled
:   repoloader:…/subsystems/drapes/display/Pip.svelte:1:0

=mapimports= in =subsystems/typology/gestalten/bundle/svelte.js= loads everything it resolves with
=loader: "js"= inside its own =repoloader= namespace. That was invisible while only =mod.js= and

=mod.js= already works; measured the other way, =@vivalence/drapes/display/index.js= bundles clean at
51 013 B prod, Pip only, no carbon. Fixing the loader instead would be a typology change and was not
taken.

* the org mode (row 5)

He quoted my own sentence back — the one saying CodeMirror 6 has no org grammar, its 99 legacy modes have
none either, and =simple-mode= would let us write eight regexes — and appended the order:

/"build an .org mode."/

The quoted block is the address; the last clause is the order. =subsystems/drapes/editor/org.js= is a
=StreamLanguage= with real state (=block= · =drawer= · =headline= carried across lines), 14 own
=Tag.define()= marks, and a =foldService=. State is what a regex list cannot have: a =* headline= inside
=#+begin_src= is body text, a =:PROPERTIES:= drawer swallows its lines until =:END:=, and only its own
=#+end_= closes a block.

Covered: headlines 1–6 with the level colouring the whole line, TODO · NEXT · STARTED · WAITING · HOLD
and DONE · CANCELLED, =[#A]=, trailing =:tag:tag:=, DEADLINE · SCHEDULED · CLOSED, both timestamp faces
and ranges, drawers and properties, blocks, =#+= directives against =#= comments, bullets, =[ ]= / =[X]=,
tables and separator rows, =-----=, all six emphasis markers, =[[t][d]]=, =[fn:1]=, =<<target>>=,
={{{macro}}}=, LaTeX and entities. Folding rides as a =foldService= so it needs no parse tree: a headline
folds to the next headline of its level or shallower, a block to its own end, a drawer to =:END:=.

Three rules that are org's and not markdown's, each with its own test — the keyword only counts in the
first slot (=* file the TODO later= marks nothing, and the sets are the caller's via
=org({todo, done})=); emphasis has an open rule and a close rule, so =a * bold * b= and =2*3*4= are not
bold; and the block rule above. Nineteen steps; drapes 6 passed / 38 steps; paladin unchanged at 41/180;
typology 123 passed with the pre-existing hallucination snapshot red, which touches no part of this.

Two smaller things fell out. The comment gate refused the first write of =org.js= — authored =//= lines
are not allowed in product source — so the quest's remaining code blocks carry a note to strip as they
land. And the theme now reads =var(--zone-x, var(--colors-skeleton-0-x))=: zone vars exist only under a
=.zone-N= ancestor and a buffer App is not guaranteed one, since the vdex App reads the flat tokens
directly. A drapes component that can be dropped anywhere cannot assume the zone.

The =legacy-modes= specifier went back out of the import map in the same pass — the real mode made it
redundant, and an unused specifier is a lie about what the tree needs.
