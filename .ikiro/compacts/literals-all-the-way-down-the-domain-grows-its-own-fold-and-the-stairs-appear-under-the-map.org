* what happened, in one breath

The stucatch tower got CONCRETE: beef struck symbols from the design twice (/"events are not
fucking symbols stupid. they are concrete - literal."/), the tower collapsed to four literal
ontologies — stage · sensor · signal · fix · track — a hand-hallucinated case.json pinned every
trait, the @stucatch package/domain/mode tree was built and MOUNTED, the whole data pipeline
went live (domain entities + pure fold + twitch, mode boot feeds lines), real stairs logs were
mined for runs and padded/synced into demo shape, the map gained playback, a photo backdrop,
and edge-resize — and the session closed with the app rendering both sensors ON the actual
staircase photograph at 5.7 × 4 m.

* the ontology, as ruled (supersedes m43's tower above order 2)

- /"symbols are abstract things. never concrete. its not a symbol per sensor or something. if
  its concrete, its a literal. symbols operate on higher level. they might be attributed after
  we have done 2 or 3 processing steps."/ — nodes, events, tracks: ALL literals. Zero symbols
  anywhere in v1; base SymbolEntity untouched.
- /"from signal to fix to track"/ · fix = /"deduplicated detections. something happened here we
  are sure about it."/ · /"i'd include the relationship as fix uses signal. lovely. ... track
  uses fix."/ — provenance rides the BASE uses/in m:n; membership mirrored in
  =trait.DERIVED.of= for the client.
- /"i am against this: origin: "9B05C4C0" from: { slug: "node.9B05C4C0", origin: ... }"/ —
  sensor identity = slug alone, no duplicated column.
- Slug grammar: =stage= · =sensor.<id>= · =signal.<origin>.<seq>.<via>.<ingestMs>= ·
  =fix.<ingestMs>= · =track.<n>=. The =ontology= column written directly at mint (base
  subscriber only overrides when TOPOGRAPHICAL symbols exist — none do).
- Traits (all on the domain's LiteralTraitsEnum, 17): signal EMITTED/STAMPED/RECEIVED/INGESTED
  + kind trait (SYNCED/RANGED/SENSED/REPORTED) + HALLUCINATED for padded rows · fix
  OCCURRED/LOCATED/DERIVED · track MOVED/DERIVED · sensor PLACED{x,y,rot}/LABELED/REPORTED ·
  stage SIZED{width,height,unit} · SUPERSEDED reserved. PICTURED{href,opacity} designed for the
  stage backdrop (view honors it; not yet minted).
- =case.json= (registry/stucatch/) = the designed fixture: design section (trait schemas, frame
  conventions) + 38 literals, every number derived from placed geometry, uses/in symmetric,
  machine-validated (recomputed intersections off by exactly the injected bearing noise).

* the paradigm correction (the big one)

beef: /"the entire ontology of sensors and signals is relative ... a signal knows only how far
away it is from the sensor. ... signals are real. fixes are f(signals) and tracks are f(fixes).
thats why the reactive twitchy paradigm for the processing architecture makes so much sense.
but your approach seems to have the paradigm wrong."/ — the views had been rendering BAKED
=LOCATED=/=MOVED= from the fixture while sensors moved. Fixed: geometry-free facts stay data
(signal payloads, fix/track MEMBERSHIP, OCCURRED times); every position, quality, speed,
heading re-derives live — =$derived= is the client-side twin of the twitch. Proven: shift all
sensors +2 m → fixes follow by exactly +2.00.

Window capture LANDED (30 ms after crossing, peak mag + energy-weighted bearing; hor/vert
split in the alarm LOG line = the bearing-validity diagnostic); Egor bumped fw to 6.0.0-dev and

at marked spots) decides everything and NO capture so far had a synced hub.

- =new Map(entries)= keeps the LAST duplicate per key — my run validator silently measured
  every utterance at its +1 s resend; the padded file was right, the ruler lied. Utterance
  dedup keeps the FIRST reception, everywhere, forever.
- =daemon.mountpoint.absolute= = =instances/<i>/mountpoint/daemon_<slug>= — guessed the level
  TWICE before printing it (logs live at =../../logs=). Print the value, then write the path.
- Fixture and daemon share sensor SLUGS — the view seeded placements from the fixture before
  the daemon rows arrived and the ~!placed[slug]~ guard kept stale coords: on source flip,
  RESET then reseed.
- esbuild json loader needs STRICT json (case.json got prettier'd into unquoted-key JS and
  back); the svelte bundler loads js ONLY — images enter as data-URI modules.
- domain aperture without EXPOSED in manifest = boot warn + no mode-branch mount.
