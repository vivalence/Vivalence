** The contract (=subsystems/typology/prototypes/stall.js=, rewritten)
=Stall({ source, active, phase, pull, depth })= — a pure reactive function over a thread.
- source = =thread.$buffers= · active = =terminal.$buffer= (the one render pointer) ·
  phase = =thread.$phase= (READ LIVE, never written by the stall) · pull = =thread.pull=
  (AIMED) · depth = =() => thread.trait?.QUEUEING?.depth ?? 1=.
- 4 phases (lowercase enum): =inert= (no subscription; deliberate-null respected) · =manual=
  (settle: auto-focus + advance-on-release; app drives) · =continuous= (manual + pull to
  depth; release refills) · =escort= (manual; walks a PRE-LOADED queue, returns to =home= on
  drain — NO fetch). Default =manual=.
- ONE cursor authority: =settle()= lands the cursor when active is gone OR null — absorbed
  the deleted a-panel auto-focus =$effect=.
- TWO roles, one interface: DRIVERS write =thread.phase= (e/f panels · buffer-apps · M5
  lever); TARGETS call =buffer.release()= — the SACRED contract across 13 game modes,
  preserved exactly. AIMED installs =thread.pull=; the stall is emitter-blind.
