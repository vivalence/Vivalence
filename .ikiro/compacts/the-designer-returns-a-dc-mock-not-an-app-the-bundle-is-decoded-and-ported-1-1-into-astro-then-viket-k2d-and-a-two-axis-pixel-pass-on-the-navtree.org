** pixel pass
"i want this to be better aligned. theere is too much indentation on the navtree" then "stillll. i watn PIXEL PERFECTION!!" (that screenshot never arrived — image-cache held the macOS PNG file icon, a paste failure mode worth knowing) then "there is also too much heigth between index+collapse row and teh ledger". Own audit at 3x zoom crops found the real offsets: entry numbers +8px vs area numbers (area-body s2 + entry s2 double padding), group rail 8px left of its caret, open-card content shifted 1px by the appearing border.
The fix is geometric, not cosmetic: =--gutter-fold= 1.25rem→0.9rem; summary side-padding s3→s2; *padding split so the sum is constant across nesting* (body s1 + row s1 = summary s2 → every number at the same x; every caret/rail/tick at fold-center on one axis); =.area= carries a permanent 1px transparent border so open/closed geometry is identical; Index ▤ gets fold-column width + nav-tools 1px pad to sit on the caret axis; nav-tools margin-bottom fully absorbs the flex gap (~27px → ~20px visual). Side effect: titles gained width, "Architecture Doc Decisions" fits one line.

* Lessons

- *A design mock is a UI, not an app* — port the geometry and tokens verbatim, re-source every datum from the real system, and prune the mock's filler (links, versions, invented content) instead of copying it.
- *dc.html bundles decode mechanically* — =script[type="__bundler/manifest"]= entries are gzip+base64; a ten-line Deno script beats reading 127k tokens of escaped payload.
- *Astro plugin order*: user rehype runs before the built-in shiki highlight — target raw fences (=code.language-*=), never =.astro-code=, and guard against re-wrap.
- *Pixel perfection is an axis discipline* — decide the shared verticals (fold-center, number-column start), then make every nesting level's padding sum to the same constant; a permanent transparent border kills state-dependent 1px shifts.
- *Audit with 3x zoom crops, not full-page squints* — the 8px double-padding and the rail/caret miss were invisible at 1x; imagescript crop is deterministic where sips cropOffset isn't.
- *Light-theme screenshots on a dark Mac*: =playwright screenshot --channel=chrome --color-scheme=light= — system Chrome, no download; bare headless Chrome inherits the OS scheme.
- *Bash cwd resets every call here* — builds and servers must re-cd explicitly or they run at repo root and lie ("0 page(s) built" then a 404 that looks like a regression).
- *Paste can lose the image* — an image-cache entry that renders as the macOS PNG icon means the screenshot never arrived; say so and re-request instead of guessing the complaint.
