* lessons

- *a README number is a measurement with a named instrument* — four commit counts were all
  "true"; the doc has to pick the one that means what the sentence means (jj's graph for
  "how much work", GitHub's ++/-- for "how much churn").
- *a tutorial claim about a verb is a claim about its trajectory file* — the =auth= boots-
  headless error survived two prior passes because nobody opened =auth.js=. Read the verb,
  then write the step.
- *beef's edits to a captured block are markers, not captures* — the README's =registry/list=
  table (=mount owner modes reference=) is his intended shape; the lens prints =reference
  owner modules root=. Neither copied into the slowstart; flagged instead.
- *"all this" after a paste = cut it* — the second bias trap from the compact method, live.
