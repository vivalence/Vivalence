* Desired end state (plain language)

A user clicks a longdistance entry in Panel D. Their existing terminal activates a thread whose dominant mode is ~brazilian-solo~. A =session= opens on the terminal: websockets up (one per engaged mode), mic and speaker claimed through BELL, Brazilian voice greets in pt-BR, transcript streams, user speaks, partial + final verbatim appear, AI replies in voice. User can barge-in mid-TTS and the AI stops immediately. Connection drops and resumes without losing context (session token). User hangs up; thread persists as a turn log; re-opens later and resumes or starts fresh.

Trio (brazilian + mentor in one session) and mentored (mentor opens a brazilian sub-thread) variants run on the same primitives — no rearchitecture.

Everything expresses through existing Vivalence vocabulary: modes, threads, traits, faculties, shards, connection middleware, packet/part/turn/channel parlance — plus the newly-named *session / feed / sink* triad and *BELL* device arbiter.

* Intent

A thread becomes a phone call. Expressed entirely through:
- *Cortex* gains two faculty types: ~speech~ and ~verbatim~. Tune gains ~latency~ dim. Faculty declarations gain ~configSchema~.
- *Modes* gain one umbrella capability trait: *CONVERSATIONAL* (universal). Its config carries all conversational capability declarations (chat, speech, verbatim, endpoint, resilience). CHAOSMONKEY remains the only other mode trait touched here (debug/middleware).
- *Modes boot on the client* via their dossier (done — =wireDossier= + =compileSchema=). Client-side trait hooks run symmetrically with server-side.
- *Threads* gain one trait: *INSITU*. Marks a thread as engaged. Added automatically when the thread's dominant mode has CONVERSATIONAL.
- *Session* lives on the *terminal*, not the thread. Opens when the terminal's active thread has INSITU; holds live sockets, roster, feeds, sinks, BELL claim. A given terminal has at most one live =session= at a time.
- *Feeds* carry outbound streams (mic → server) when mode config declares verbatim capability.
- *Sinks* carry inbound streams (server → speaker) when mode config declares speech capability.
- *BELL* is the singleton client audio context. Arbitrates physical device claims across terminals/sessions.
- *Connection* gains three middlewares: heartbeat, reconnect, session.
- *Socket* is a new Connection primitive (alongside Request/Response/Pipe): wrapped browser WebSocket with framing, heartbeat, reconnect, typed-packet routing.

Three mode instances share the new type ~longdistance~: ~brazilian-solo~, ~bilingual-trio~ (roster of two modes), ~mentored~ (mentor mode opens a brazilian sub-thread via tool_use).

** Introduced by this workpackage

- *CONVERSATIONAL* — the universal mode capability trait. Config example:

- *socket* — new Connection primitive. Wraps browser WebSocket with typed packet framing, heartbeat, reconnect, middleware.
- *roster* — modes engaged in a session. Solo = [dominant]. Trio = [dominant, contributing]. Live state on the session; not an entity.
- *dominant mode* — ~thread.mode~ relation, now named. Drives UI (CallFrame when ~type === "longdistance"~). Contributing modes attach via roster without owning UI.
- *contributing mode* — additional mode in a session roster. Has its own cortex session, its own CONVERSATIONAL config.
- *Port* — Svelte component (and embeddable subject) that IS the UI envelope of a live ~terminal.session~. Joins ship metaphor alongside LIGHTHOUSE / QUARTERS / BRIDGE / DECORUM. Rendered standalone on ~/port~ route (dev harness); inlet on Panel A as a dock-side overlay; optional embedded subject in the Panel E control center. ** Ontology (D1-D6)

*** D1. Ground everything in existing primitives

Cortex / Connection / Shard / Mode / Trait / Thread / Turn / Part / Packet / Channel + Terminal / Quarters / Dossier. No new framework. Every design move cites an existing class or file.

*** D2. Modes declare capabilities via CONVERSATIONAL umbrella; threads carry engagement marker

Mode.traits = ["CONVERSATIONAL", ...]. Config under ~mode.trait.CONVERSATIONAL.*~ covers chat / speech / verbatim / endpoint / resilience. Thread.traits = [..., "INSITU"] when engaged. INSITU is a marker, not a behavior — the terminal owns session lifecycle.

*** D3. Session is the terminal's live object

Session exists when ~terminal.$thread~ holds an INSITU thread. Lives on ~terminal.session~ (not on thread). Holds websocket(s), roster, token, feeds[], sinks[], ~$status~. One per terminal. Not persisted; thread swap reuses / swaps; thread-cleared closes.

*** D4. Feeds and sinks are session-scoped audio primitives

Feeds are outbound (client → server, mic). Sinks are inbound (server → client, speaker). Composed from mode config presence (verbatim → 1 feed per LISTENING-ish mode, speech → 1 sink per SPEAKING-ish mode). No dedicated traits.

*** D5. BELL is the client device arbiter (cross-terminal singleton)

Singleton client context alongside LIGHTHOUSE / QUARTERS / BRIDGE. Claims/releases physical mic + speaker. Sessions negotiate claims through BELL — not directly through getUserMedia. Two terminals with live sessions: BELL gates; first-claim-wins.

*** D6. Dominant mode = thread.mode (existing relation, now named)

The mode whose presentation drives the thread's frame. Contributing modes in roster don't own UI.

The =wireDossier= + =compileSchema= machinery in ~systems/html/src/typology/prototypes/dossier.js~ already runs schema.use middleware on client-side cast. CONVERSATIONAL trait middleware lands here for mode dossier.

** Lifecycle (D12-D14)

*** D12. Terminal owns session lifecycle via ~$thread~ subscription

TerminalDossier middleware subscribes to ~terminal.$thread~. On change:
- If new thread has INSITU and mode has CONVERSATIONAL → ensure session; reserve slots; open sockets.
- If thread cleared → close session, release BELL.
- If thread swap (both INSITU) → swap session slots; reuse socket if same endpoint; reopen otherwise.

No reaching into thread lifecycle. No wrapped setters. Subscribe is the only seam.

* Design

** First-principles sketch

A session is a bundle of websockets (one per engaged mode) plus a roster of modes and the audio primitives (feeds + sinks) composed from their capabilities. A mode declares what it does via CONVERSATIONAL config (chat only, +speech, +verbatim, with realtime endpoint). The terminal subscribes to its ~$thread~ and owns session lifecycle. Thread swap → session swap. Thread cleared → session closed. BELL arbitrates physical devices. Everything else — trio, mentored, barge-in, resilience — composes over these primitives.

** Cortex faculty extension

~subsystems/typology/prototypes/cortex.js~ + ~hallucinate.js~:
- Faculty types ~speech~ and ~verbatim~ registered alongside ~conversation~.
- Tune vector 4-dim with ~latency~.
- Faculty declaration extended with ~configSchema~.
- ~hallucinate.spawn().speech.stream(turn, config)~ yields audio.out packets.
- ~hallucinate.spawn().verbatim.stream(audioSource, config)~ consumes audio parts; yields verbatim packets.

** Mode dossier — CONVERSATIONAL installer

Added to ModeDossier use middleware. On hydrate, if mode.traits includes CONVERSATIONAL → register shards for chat (always), speech (if config.speech), verbatim (if config.verbatim). If absent: resolve default shard (anonymous text-only chat). Runs both server and client per D7.

** Terminal dossier — session installer

TerminalDossier middleware subscribes to ~terminal.$thread~:

#+begin_example
async (ctx, next) => {
  await next();
  const terminal = ctx.terminal;
  const teardown = terminal.$thread.subscribe((thread) => {
    if (!thread?.traits?.includes("INSITU")) {
      terminal.session?.close();
      terminal.session = null;
      return;
    }
    terminal.session ??= new Session(terminal);
    terminal.session.attach(thread);
  });
  terminal._teardowns ??= [];
  terminal._teardowns.push(teardown);
},
#+end_example

(Caveat: ~terminal._teardowns~ name avoids the underscore convention — renaming pass pending.)

Session lifecycle is entirely in terminal-scope reactivity. No hooks on thread beyond the INSITU marker.

** Entity lifecycle during a session

*** Created / persisted

- *Thread* — server-side at navigation. Persisted on creation. ~trait.INSITU.token~ field written on session.init.
- *Turn* — server-side, one per roster-mode per exchange. Persisted on turn.close.
- *Part* — inline for text; asset-path for audio (recording opt-in).
- *Buffer* — contributing-mode BUFFERED writes; keyed to thread.
- *Span* — persisted on drain.

*** Client-only (never persisted)

- =Session=, =Feed=, =Sink= prototypes on terminal.
- BELL state.
- Middleware atoms.

Rehydrate on reconnect from thread data + session token; transcript re-fetches from turn log.

*** Effect hazards (the "how we punch ourselves in the face" catalog)

1. *Reactive loops* — atom A writes to B in B's subscribe → ping-pong. Discipline: atom sets only in packet handlers or user-input; subscribe callbacks produce one-way effects.
2. *Premature audio.in* — mic capture before socket open drops frames. Guard: ~Session.open()~ sequences: claim BELL → open socket → wire router last.
3. *Stale reconnect* — reconnect after user swapped terminals; session belongs to different terminal. Guard: check ~terminal.session === this~ after await in reconnect.
4. *Teardown order* — socket-close before speaker-flush loses last TTS. Order: send hangup → flush speaker → stop mic → close socket → flush LIFO teardowns.
5. *Double-activate* — rapid thread swap. Guard: Session ~$status~ rejects invalid transitions; hooks idempotent.
6. *Coordinator race* — two roster modes emit turn.open same tick. Guard: server serializes — DAG arbitration is server-side.
7. *BELL contention* — two terminals' sessions both want mic. Guard: BELL is singleton; first-claim-wins; contending session sees ~bell.$state === BUSY~.
8. *Session-token staleness* — expired token reused. Guard: server sends ~session.reject~; client clears; falls through to fresh session.

#+begin_src js
export default async function provider(service) {
  const apiKey = service.secrets.elevenlabs;

  const voices = {
    luiza:   { id: "21m00Tcm4TlvDq8ikWAM", tune: [0.3, 0.6, 0.4, 0.1] },  // pt-BR fem
    leandro: { id: "EXAVITQu4vr4xnSDxMaL", tune: [0.5, 0.5, 0.5, 0.1] },  // pt-BR masc
  };

  function makeSpeech(voice) {
    const stream = async function* (turns, config = {}) {
      const url =
        `wss://api.elevenlabs.io/v1/text-to-speech/${voice.id}/stream-input` +
        `?model_id=eleven_turbo_v2_5&output_format=ulaw_8000`;
      const ws = new WebSocket(url);
      await new Promise((open, fail) => { ws.onopen = open; ws.onerror = fail; });
      ws.send(JSON.stringify({
        text: " ",
        voice_settings: { stability: config.stability ?? 0.5, similarity_boost: 0.75 },
        xi_api_key:     apiKey,
      }));
      for (const turn of turns) for (const part of turn.parts ?? []) {
        if (part.type === "text") ws.send(JSON.stringify({ text: part.text, try_trigger_generation: true }));
      }
      ws.send(JSON.stringify({ text: "", flush: true }));
      try {
        while (ws.readyState === WebSocket.OPEN) {
          const message = await new Promise((resolve) => {
            ws.addEventListener("message", (event) => resolve(event.data), { once: true });
          });
          const data = JSON.parse(message);
          if (data.audio)   yield { nature: "packet", audio: data.audio, pts: Date.now() };
          if (data.isFinal) break;
        }
      } finally { ws.close(); }
    };

    return {
      type:     "speech",
      tune:     voice.tune,
      context:  0,
      channels: { in: [{ type: "text" }], out: [{ type: "audio", codec: "ulaw_8000" }] },
      config:   { voice: voice.id },
      via:      { stream },
    };
  }

  return Object.values(voices).map(makeSpeech);
}

export default async function provider(service) {
  const apiKey = service.secrets.deepgram;

  const profiles = {
    "pt-BR": { tune: [0.4, 0.6, 0.5, 0.1], language: "pt" },
    "en":    { tune: [0.4, 0.6, 0.5, 0.1], language: "en" },
  };

  function makeVerbatim(profile) {
    const stream = async function* (audioSource, config = {}) {
      const url =
        `wss://api.deepgram.com/v1/listen?` +
        `encoding=mulaw&sample_rate=8000&language=${profile.language}&` +
        `vad_events=true&endpointing=300&interim_results=true`;
      const ws = new WebSocket(url, ["token", apiKey]);
      await new Promise((open, fail) => { ws.onopen = open; ws.onerror = fail; });

      const events = [];
      let wake = null;

      ws.addEventListener("message", (event) => {
        const data = JSON.parse(event.data);
        if (data.type === "SpeechStarted") events.push({ nature: "turn.start" });
        if (data.type === "UtteranceEnd")  events.push({ nature: "turn.end"   });
        const transcript = data.channel?.alternatives?.[0]?.transcript;
        if (transcript) events.push({
          nature:     data.is_final ? "final" : "partial",
          transcript,
        });
        if (wake) { wake(); wake = null; }
      });

      (async () => {
        for await (const audio of audioSource) ws.send(audio);
        ws.send(JSON.stringify({ type: "CloseStream" }));
      })().catch(() => {});

      try {
        while (ws.readyState === WebSocket.OPEN || events.length) {
          while (events.length) yield events.shift();
          if (ws.readyState !== WebSocket.OPEN) break;
          await new Promise((resolve) => { wake = resolve; });
        }
      } finally { ws.close(); }
    };

    return {
      type:     "verbatim",
      tune:     profile.tune,
      context:  0,
      channels: { in: [{ type: "audio", codec: "ulaw_8000" }], out: [{ type: "event" }] },
      config:   { language: profile.language },
      via:      { stream },
    };
  }

  return Object.values(profiles).map(makeVerbatim);
}

import { atom } from "nanostores";
import { Pipe  } from "./pipe.js";
import { Queue } from "./queue.js";

class Bell {
  mic     = new Pipe();
  speaker = new Queue();
  vad     = { $speaking: atom(false) };

  $state       = atom("IDLE");       // IDLE | PRIMING | CAPTURING | PLAYING | MUTED | ERROR
  $permission  = atom("prompt");     // prompt | granted | denied
  $devices     = atom({ inputs: [], outputs: [], selected: null });
  $inputLevel  = atom(0);
  $outputLevel = atom(0);

  #owner     = null;
  #context   = null;
  #recorder  = null;
  #playhead  = null;

  claim(owner) {
    if (this.#owner && this.#owner !== owner) return false;
    this.#owner = owner;
    return true;
  }
  release(owner) {
    if (this.#owner !== owner) return;
    this.micStop();
    this.speakerStop();
    this.#owner = null;
    this.$state.set("IDLE");
  }

  async prime() {
    if (this.#context) return;
    this.#context = new AudioContext({ sampleRate: 8000 });
    const devices = await navigator.mediaDevices.enumerateDevices();
    this.$devices.set({
      inputs:   devices.filter((device) => device.kind === "audioinput"),
      outputs:  devices.filter((device) => device.kind === "audiooutput"),
      selected: null,
    });
  }

  async micStart() {
    await this.prime();
    this.$state.set("PRIMING");
    const source = await navigator.mediaDevices.getUserMedia({ audio: true });
    this.$permission.set("granted");
    this.#recorder = new MediaRecorder(source, { mimeType: "audio/webm;codecs=opus" });
    this.#recorder.ondataavailable = async (event) => {
      const buffer = await event.data.arrayBuffer();
      this.mic.send(new Uint8Array(buffer));
    };
    this.#recorder.start(20);
    this.#wireLevelMeter(source);
    this.$state.set("CAPTURING");
  }

  micStop()   { this.#recorder?.stop(); this.#recorder = null; this.$state.set("IDLE"); }
  micMute()   { this.$state.set("MUTED"); }
  micUnmute() { this.$state.set(this.#recorder ? "CAPTURING" : "IDLE"); }

  speakerStop() {
    this.speaker.flush();
    this.#playhead?.disconnect();
    this.#playhead = null;
    this.$state.set("IDLE");
  }

  #wireLevelMeter(source) {
    const node     = this.#context.createMediaStreamSource(source);
    const analyser = this.#context.createAnalyser();
    analyser.fftSize = 256;
    node.connect(analyser);
    const window = new Uint8Array(analyser.frequencyBinCount);
    const sample = () => {
      if (this.$state.get() === "IDLE") return;
      analyser.getByteTimeDomainData(window);
      let sum = 0;
      for (let i = 0; i < window.length; i++) {
        const value = (window[i] - 128) / 128;
        sum += value * value;
      }
      const rms = Math.sqrt(sum / window.length);
      this.$inputLevel.set(rms);
      this.vad.$speaking.set(rms > 0.03);
      requestAnimationFrame(sample);
    };
    sample();
  }
}

*** Edge cases + failure modes

**** Mic permission denied

BELL.micStart fails with =NotAllowedError=. =bell.$permission.set("denied")=.
TerminalDossier middleware catches the rejection, rolls back INSITU.audio to
false via =updateOne=, re-triggers $thread, session reverts to text mode.
Panel E shows denied pip.

**** Speech provider unavailable mid-call

ElevenLabs WS drops. =speech.stream= iterator throws. R3 catches in the
(async IIFE), emits =session.send.speech.abort({ error })=. Client sink
flushes. Dialogue continues in text; speech faculty re-resolves on next
anchor (may succeed if transient).

**** Verbatim provider drops

Deepgram WS closes. =asr.via.stream= generator returns. R3 verbatim state
nulls. Next =/verbatim/packet= re-spins a fresh transcriber. No
dialogue-layer impact — audio that arrived during the gap is dropped (at-most-once
semantics for verbatim; the user restates).

**** Connection drop mid-audio

Socket closes. TerminalDossier session cleanup fires. BELL speaker flushes
(mid-word TTS cuts); mic stops. Reconnect middleware (deferred — not in this
sketch) would re-open session with same token and resume. For round 8:
manual hangup + re-engage.

**** Barge-in race — user speaks as TTS starts

Common. VAD fires =$speaking=true= within 50-100ms of first speech packet.
Client: =bell.speakerStop()= + =control.abort=. Server side also detects
turn.start from the audio already flowing in; independently aborts LLM.
Two aborts fire; both are idempotent. No state corruption.

**** AutoVoice infinite loop

Verbatim =final= triggers dialogue anchor; dialogue response plays via
speaker; picked up by mic; transcribed; triggers another anchor. Mitigations:
(a) =bell.mic.mute()= while speaker is playing — acoustic echo cancellation
via AudioContext =createBiquadFilter= / =EchoCanceller= constraint on
=getUserMedia=. (b) Server-side: short debounce on autoVoice — ignore
=final= arriving within 200ms of previous anchor completion.

**** Thread swap during live call

User clicks a different thread. TerminalDossier old-thread teardown fires:
speaker flush, mic stop, BELL release, session close. Audio cuts cleanly.
New thread opens fresh session. No cross-thread audio leak possible because
BELL is per-terminal-owned and ejected before reclaim.

**** Codec mismatch

Provider expects ulaw_8000. BELL emits opus 48k from MediaRecorder.
Transcoder at TerminalDossier send boundary converts. If conversion fails,
the audio packet is dropped silently (counter incremented on
=terminal.$audio.micErrors=). If ≥3 consecutive drops, surface error toast.

*** Open design questions

1. *Tune dim migration* — legacy dialogue faculties declare 3D tune
   =[thinking, context, speed]=. =cortex.extend()= auto-pads to 4D with
   latency=0.5 (neutral). Voice providers declare 4D explicitly with
   latency=0.1 (voice-first). Alternative: separate =faculty.latency= field
   outside =tune=. Locked: *auto-pad* — zero-migration, latency lives in tune.

2. *Verbatim faculty shape* — the =dialogue-verbatim-rename= workpackage
   left the verbatim =via= contract open: push/flush (per earlier orb
   sketches with =openTranscriber(...).push(audio) / .flush() → text=) vs
   stream (=via.stream(audioSource, config) → AsyncIter<events>=). Locked:
   *stream*. Reasons: (a) Flux-style always-on STT with partial + final +
   turn events cannot be expressed as push+flush (flush-returns-text collapses
   to one utterance); (b) caller-owned audioSource keeps the faculty
   stateless across calls; (c) symmetric with dialogue/speech =via.stream=
   shape — no schema widening needed. Verbatim declares no =render= surface
   (stream-only). =cortex.shard.effects= already skips mount when
   =faculty.via[via]= is falsy.

3. *Audio codec* — ulaw_8000 end-to-end. Matches shuo, Deepgram,
   ElevenLabs. BELL's =MediaRecorder= produces opus — transcode at
   =session.send.verbatim.packet= boundary (simple JS mu-law encoder,
   ~20 lines). Alternative: raw 16k PCM. Locked: *ulaw_8000* (smaller frames,
   both providers native).

4. *AutoVoice thread binding* — verbatim =final= triggers an internal
   =dialogue.anchor= invocation; needs =thread=. First explicit anchor writes
   =socket.state.thread=; auto-voice reads it. Thread swap clears it (server
   has no equivalent of INSITU — thread is connection-local state). Locked.

5. *BELL location* — =subsystems/typology/prototypes/bell.js=. Guarded use

   server-side (=index.client.js= adds it, =index.ts= does not).

6. *Barge-in authority* — two aborts fire: client-side VAD flushes local

        yield { nature: "turn.start" };
        yield { nature: "partial", transcript: payload.slice(0, 2) };
        yield { nature: "final",   transcript: payload };
        yield { nature: "turn.end" };
      }},
    };

    const daemon = await bench({
      kernel: "@vivalence/language",
      modes:  [{ ...dewey, traits: [...dewey.traits, "VOCALIZED"] }],
      cortex: { extend: [stubTTS, stubASR] },

    const thread = await daemon.entities.thread.create({
      mode:   "teacher/dewey",
      traits: ["INSITU"],
      trait:  { INSITU: { audio: { enabled: true } } },

    await terminal.session.ready;

      expect(event.value.transcript).toBe("oi")

    await terminal.pushAudio(new TextEncoder().encode("oi"));

    const audio = [];
    for await (const packet of terminal.streams.speech) {
      audio.push(packet);
      if (audio.length >= 3) break;

** Dual-dialogue dispatch (actor + worker)

The current spec assumes one =dialogue= faculty per mode. Production voice
agents converge on a different shape: two dialogue faculties at different
latency tunes, with an explicit dispatch pattern between them.

*Actor* — small, fast, voice-shaped. Talks. Holds rapport. Tune: =eager=.
Never blocks on tools. Provider candidate: Gemini 3 Flash.

*Worker* — large, slow, tool-calling. Real reasoning. Returns structured
facts. Tune: =unleashed= or higher. Provider candidate: Claude Sonnet 4.6
(via Bedrock for throughput) or Kimi K2.6 (agentic swarm, cheaper, weaker
pt-BR — but worker doesn't talk, so pt-BR weakness is not exposed to user).

*Three integration styles:*

1. *Actor-dispatches-Worker* — actor fires =consult_worker(query)= as a
   tool call, fills silence with backchannel from a pre-recorded library
   ("hmm", "deixa eu pensar", "um segundo"), paraphrases the worker's
   return into voice. Most common production shape.
2. *Parallel race* — both faculties receive the user turn. Actor responds
   from priors immediately. Worker's later, better answer triggers
   mid-turn self-correction ("ah, na verdade..."). Feels smart, burns tokens.
3. *Worker-plans-Actor-speaks* — worker emits a turn plan; actor reads it
   aloud. Best for regulated/auditable domains. Loses conversational feel.

*Mapping into existing primitives:* both actor and worker are =dialogue=
faculty instances on the same cortex, distinguished by =tune.latency=.
=mode.harness.dialogue.stream(...)= dispatches to the actor by default;
worker is invoked as a tool registered on =ctx.hallucination.tool(...)=
during =mode.cake.harness=. Backchannel is a =shard.audio= primitive on
the client (BELL pulls from a static asset bundle; no TTS round-trip).

*Interrupt budget* — if worker takes >2.5s, actor speaks something. If >8s,
actor asks a clarifying question to buy time. Implemented as a timer on
the tool-call promise, racing against a BELL backchannel emit.
