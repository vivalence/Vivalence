* Hazards (8-item catalog)

1. *Reactive loops* — atom A writes to B in B's subscribe. Discipline: atom sets only in packet handlers / user-input.
2. *Premature audio.in* — mic before socket open drops frames. =Session.open()= sequences: claim BELL → open socket → wire router last.
3. *Stale reconnect* — terminal swap mid-reconnect. Guard: check =terminal.session === this= after await.
4. *Teardown order* — socket-close before speaker-flush loses last TTS. Order: hangup → flush speaker → stop mic → close socket → LIFO teardowns.
5. *Double-activate* — rapid thread swap. Session =$status= rejects invalid transitions; hooks idempotent.
6. *Coordinator race* — two roster modes turn.open same tick. Server serializes (DAG arbitration server-side).
7. *BELL contention* — two terminals wanting mic. Singleton; first-claim-wins; loser sees =bell.$state === BUSY=.
8. *Session-token staleness* — server sends =session.reject=; client clears; falls through to fresh session.
