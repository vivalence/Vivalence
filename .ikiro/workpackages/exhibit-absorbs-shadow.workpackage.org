* Intent

Collapse ~game/shadow~ into ~game/exhibit~ as a stylistic variant. Both already share the ~Desk~ surface, the TRANSLATED literal contract, and the ~/pick/literal/feed~ fallback. Shadow's only novelty is a ~75-line two-phase memorize → typed-recall machine — not enough mode to justify standing alone.

After: ~exhibit~ gains ~data.style: BROWSE | RECITE~. ~/emit/recite~ + ~recite~ intent added. Four shadow call sites (clinic routine, survival buildup, survival exercise, ~api.shadow~ primitive) repoint to ~game.exhibit.emit.recite~. Two daemon manifests drop the ~"@vivalence/game/shadow"~ line. Two test files retarget. ~game/shadow/~ directory deleted (no shim — D5).

* Vocabulary

Settled (in use): *exhibit*, *layout* (~TABLE~/~PATTERN~/~CONTRASTIVE~), *recall* (~LEARNING~/~KNOWN~/array/omitted), *speed* (~{rate}~ or ~{base, multiplier}~), *forgiving* (boolean), *gameplay* (mode-internal interaction shape).

Introduced:
- *style* — new discriminant on ~exhibit~ controlling /what kind of presentation/. ~BROWSE~ (default, current behavior) or ~RECITE~ (memorize → recall card flow, optional timer).
- ~/emit/recite~ — polymorphic route: explicit ~literal~/~literals~ OR ~where~ → ~daemon.entities.literal.feed~.
- *recite* intent slug — mounts ~/emit/recite~, supersedes shadow's ~feed~ intent.

Deprecated: ~game/shadow~ mode; ~api.shadow~ helper renamed ~api.recite~.

* Architectural directives

- *D1 — One mode, two styles.* ~style~ is primary discriminant. ~layout~ scoped to BROWSE; ~recall~ + ~speed~ scoped to RECITE. Wrong-style fields ignored, not defended against.
- *D2 — Style is presentation-shape, not interaction.* Parallel to ~layout~ within BROWSE. Not a synonym for ~gameplay~. Future: ~COVER~, ~TIMED_BROWSE~, ~DICTATION~.
- *D3 — Single ~/emit/recite~ route, polymorphic on input.* Collapses shadow's two routes (~/literals~ + ~/feed~).
- *D4 — Tactic call sites change shape, not intent.* ~api.shadow~ → ~api.recite~; ~needsShadow~ guard renamed ~needsRecite~ in clinic routine. ~survival/exercise.js~ keeps local ~needsShadow~ name (scope discipline).
- *D5 — No backwards-compat shim.* Delete ~game/shadow/~. Callers updated in same diff.
- *D6 — Manifest version bump.* ~exhibit.viva.js~ ~0.1.0~ → ~0.2.0~.

* Design

** Data schema

#+BEGIN_SRC js
v.buffer({
  data: {
    style: v.string({ default: "BROWSE" }),
    // BROWSE-only
    layout: v.string({ default: "TABLE" }),
    title: v.string({ default: "" }),
    subtitle: v.string().optional(),
    template: v.string().optional(),
    // RECITE-only
    recall: v.union([v.string(), v.array(v.string())]).optional(),
    speed: v.object({}).optional(),
  },
})
#+END_SRC

~forgiving~ stays implicit (Svelte prop default true; no caller sets it).

** Buffer view

~Exhibit.svelte~ branches on ~data.style~ at top level. BROWSE arm = existing render tree verbatim. RECITE arm = shadow's two-phase machine (show → recall, timer, per-token feedback) lifted onto same ~Desk~. Arms share only the ~Desk~ chrome. CSS partitioned ~/* ── browse ── */~ and ~/* ── recite ── */~.

~Keyboard~ + ~ViewportLock~ render only when ~style === "RECITE"~ (BROWSE keeps lighter surface).
