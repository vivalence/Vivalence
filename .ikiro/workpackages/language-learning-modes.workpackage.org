#+AUTHOR: Vivalence

#+STATUS: ACTIVE

* Intent

Build a complete language learning toolset from the existing symbol
coordinate system. The ontology defines dimensions (morphology,
function, domain, sentence force). The corpus authors literals into
those dimensions. Modes are interaction shapes. Tactics are seek
patterns that select content by symbol coordinates and route to modes.

Two architectures:

1. *Emitter tactics* — seek literals by symbol coordinates, emit
   buffers to game modes. No hallucinator.
2. *Conversational tactics* — LANGUAGED/AGENTIC. Hallucinator
   generates the experience. See cortex.workpackage.org.

* Symbol Axes

| Axis | Symbol Examples | What It Teaches | Literal Type |
|------+-----------------+-----------------+--------------|
| Proficiency | proficiency.survival, .cefr.a1 | *Which* content, in what order | word, sentence |
| Part of speech | word.part-of-speech.verb/.noun/.adjective | Category awareness | word |
| Verb morphology | word.tense × word.mood × word.person × word.number | Conjugation paradigms | word per form |
| Gender/number | word.gender.masculine × word.number.plural | Agreement patterns | word |
| Functional role | functional.pronoun, .connector, .negation | Grammar in context | word (token in sentence) |
| Semantic domain | domain.food, .family, .transport | Thematic vocabulary | word, sentence |
| Sentence force | sentence.force.interrogative/.imperative | Sentence construction | sentence |
| Sentence mood | sentence.mood.subjunctive/.conditional | Register/modality | sentence |

Literal traits (content surface): TRANSLATED (known+learning text),
EXEMPLIFIED (example pair), ANNOTATED (token decomposition), VOCALIZED
(audio asset), RANKED (frequency rank).

Memory states: UNTOUCHED → UNKNOWN → LEARNING → KNOWN → GRADUATED

* Architecture 1: Emitter Tactics

Tactic queries literals via LiteralRepository
(feed/novel/due/byStrength/findBySymbols), then emits buffers to game
modes. Intent's FEEDING trait defines query params. Memory.lastSignal
(from Trace) enables error-aware selection.

** Tactic: Vocabulary

Baseline. Seeks =word= + =proficiency.*= ± =domain.*=. Routes to
flashcard, write, shadow, listen, pick, match. Every Tier 1/3 mode
addressable by a vocabulary intent.

** Tactic: Introduction

Seeks =sentence= + =proficiency.*=. Resolves ANNOTATED tokens, checks
memory: UNKNOWN→shadow, LEARNING→flashcard, UNKNOWN→write. One
sentence generates 5-15 buffers. Composes multiple modes per sentence;
client stall sequences them.

** Tactic: Decomposition

Seeks =sentence= whose ANNOTATED tokens match a target =functional.*=.
Routes to cloze (blank target), pick (choose token). Examples:
"pronoun practice", "connector drill", "negation".

Emitter logic: seek by proficiency + structural → filter to sentences
containing target functional tokens → emit cloze per matching token.
Grammar through sentences, not rules.

** Tactic: Morphology (Conjugation)

Seeks =word.part-of-speech.verb= + =word.verb-form.finite= + target
tense/mood. Routes to pick/write/cloze. Each conjugated form is its
own literal with full morphological symbols. Distractors: same-paradigm
wrong forms or cross-paradigm confusions (-ar vs -er).

Depends on conjugation data authored in corpus (DONE — survival 359
+ a1 897 entities).

** Tactic: Comprehension

Seeks literals with =VOCALIZED=. Routes to listen, dictation,
speed-judge. Speech faculty (cortex) can fill audio gaps.

* Architecture 2: Conversational Tactics (Design Only)

Depends on cortex.workpackage.org.

- *Immersion* — LANGUAGED. Chat UI scoped by =domain.*= + memory state
  + daemon statics. Hallucinator tools: literal memory lookup,
  /review/literal, TRANSLATED data. Example: waiter at Brazilian
  restaurant, A1.
- *Remediation* — AGENTIC. Analyzes memory FAILURE/MISTAKE patterns.
  Identifies weak symbol areas. Composes custom sessions from
  Architecture 1 modes. Smart tutor as tactic composer.

* Game Modes

** Tier 1 — DONE

All built and operational. Self-loading buffers, survival tactic
routes to all. =registry/modes/@vivalence/game/=.

- *cloze* — sentence with blank(s); type/pick/listen gameplay (see Implementation)
- *pick* — multiple choice, distractor self-serve from same-band
- *listen* — audio-first; pick/type gameplay
- *speed-judge* — flash pair, correct/wrong, timed; visual/audio/audio-only
- *match* — grid of pairs; translate (described future)
- *flashcard*, *write*, *shadow* — pre-existing, migrated to v schematics
- *exhibit* — pre-existing

All 9 modes operational with manifest + BufferView + emitter Vector + Svelte.

** Tier 2 — In Flight

*** Reorder

Shuffled tokens → arrange in correct order. ANNOTATED provides
shuffled set + answer. View: draggable/tap-to-place chips. Per-token
review for misplaced tokens.

Schema: ={data: {recall}, literals: [sentence], tokens: shuffled ANNOTATED}=

*** Dictation

Audio → transcribe (same-language). Differs from listen (which tests
meaning). Both audio-first, different skills.

Schema: ={data: {recall, speed}, literals: [sentence], asset}=

*** Conversation

Chat UI for LANGUAGED. Deferred to cortex.

** Tier 3 — Open

- *minimal-pair* — two confusables in context (ser/estar, por/para,
  m/f articles). Tactic detects from memory (both LEARNING, similar
  symbols, frequent MISTAKE). Schema: ={data: {recall}, context, pair, answer}=

* Design Decisions

1. *Symbols are the query language.* Tactics seek by coordinates, no
   hardcoded content. "Conjugation tactic" = seek =word.tense.X ×
   word.mood.Y × word.person.Z=.
2. *Conjugated forms are literals.* "falo", "falas", "fala" each their
   own literal with morphological symbols. No runtime derivation.
3. *Game modes are interaction shapes, not content types.* Mode renders
   buffer; tactic decides content.
4. *Distractors are same-symbol lookups.* Tactic logic, not hallucinator.
5. *Two architectures, clean boundary.* Emitter or conversational,
   never mixed.
6. *Tactics compose modes; modes don't compose each other.*
   Composition lives in tactic emitter Vector.
7. *ANNOTATED is the grammar exercise substrate.* Token data enables
   cloze, reorder, per-token review, decomposition.
8. *Per-token review propagates learning.* Cloze blanks pronoun → both
   token and sentence get /review/literal.

* Implementation: Game Mode Contracts

Scaffolded 2026-03-25. =registry/modes/@vivalence/game/=.

** Gameplay enum pattern

Modes with multiple variants expose =data.gameplay= (string enum). Set
by tactic (memory status, preference, explicit). Component switches on
gameplay. =data.forgiving= (default true) controls diacritical
normalization for typed input.

** Cloze — =game/cloze/=

Gameplay: ="type"= | ="pick"= | ="listen"=. Multi-blank via
=data.blankIndices: number[]=. Listen gameplay: hear "Espero que você
______ bem", type "esteja".

Schema: ={data: {recall, gameplay, blankIndices, options?, forgiving}, literals: [sentence]}=

Domain: MUST ANNOTATED + TRANSLATED. VOCALIZED for listen.

Review: per-blank-token + sentence. Correct = SUCCESS token; all
correct = SUCCESS sentence; any wrong = NEUTRAL sentence.

Emitter =/literal=: ={literal, blankIndices, gameplay, options?}=

** Pick — =game/pick/=

No gameplay enum. Schema: ={data: {recall}, literals: [target, ...distractors]}=

Self-serves distractors from =/pick/literal/feed= (3 same-band) when
tactic doesn't provide. Review: correct = SUCCESS target; wrong =
FAILURE target + FAILURE distractor.

Keyboard: 1-4. Closed on mobile.

** Match — =game/match/=

Gameplay: ="translate"= | ="describe"= (cortex-gated, future).

Schema: ={data: {recall, gameplay, descriptions?}, literals: [batch]}=

Failure is sticky: any wrong match = permanent FAILURE on both
literals. Sentences allowed, cap 4-5 candidates (UX).

Emitter =/batch=: ={literals, gameplay, descriptions?}=

** Speed Judge — =game/speed-judge/=

Gameplay: ="visual"= | ="audio"= | ="audio-only"=. Single-item
buffers. =data.distractor= boolean — true means =literals[1]= is wrong
translation. =literals[0]= always target. Component derives shown text
from literals + recall direction.

Schema: ={data: {recall, gameplay, speed, distractor}, literals: [target, distractor?]}=

Emitter =/literal=: single-literal entry. Distractors from seen items
(={memories: {}}=, not feed). Coin-flips correct/wrong. Guards
identical translations. =/feed= calls =ctx.mode.emit.literal()= in a
loop — self-referential.

Speed presets (base + multiplier per char):
- FAST: 1500ms + 80ms/char
- NORMAL: 2500ms + 120ms/char (default)
- SLOW: 3500ms + 180ms/char

Override via =data.speed.{base,multiplier}=. =multiplier: 0= means
base is absolute.

Swipe: left=wrong, right=correct (50px threshold). Keys: left/1=wrong,
right/2=correct. Timer bar at top.

Review: correct = SUCCESS; wrong/timeout = MISTAKE target.

** Listen — =game/listen/=

Gameplay: ="pick"= | ="type"=. Set by memory (UNKNOWN/LEARNING→pick,
KNOWN→type) or tactic.

Schema: ={data: {recall, gameplay, forgiving}, literals: [target, ...distractors?]}=

Direction: LEARNING = hear PT → produce EN; KNOWN = hear PT → type PT
(transcription).

Emitter =/literal=: self-serves distractors for pick (same-band + same
POS + similar length).

Audio REQUIRED. Autoplay on mount. =r= replay. FRAUGHT trait on manifest.

Type: MISTAKE for close answers (levenshtein ≤ 2). Pick: FAILURE on
target + distractor for wrong picks.
