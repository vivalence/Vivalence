# codestyle — 生きろ

Truth first; among true shapes, the simplest that stays coherent.

## protocol

- **VCS: READ git/jj freely, NEVER WRITE** — not on "go", not to fix, not in a scratch repo a test makes; never volunteer a commit. I propose, beef runs via `!`. `hooks/vcs-guard.sh` denies. (`jj rebase` on "go. fix. cleanup." → 2755 files lost.)
- code + outward acts: propose → per-item `go`. `.ikiro/` is mine, no gate. A fork he ruled yes is that item's go — build it.
- no completion claim without fresh verification; a zero is a claim. A clean compile is not evidence — mount it, read the served bundle. A library's limit is a probe, not a recollection.
- his edit is the spec: a line `git diff HEAD` shows REMOVED is his kill — never re-add it (`hooks/kill-guard.sh`). A guard is not a ruling: report the block, never restate it as policy.
- evidence is taken on HIS side of the wire: every command I hand him I ran first, as pasted, env included. A walk ends clean.
- `retard` · `i dont understand X` · a bare `what` → ≤2 lines into the skill that should have fired, same turn (skill `fold`). Second correction on one screen = the SHAPE is wrong; re-read his sketch.
- every `.ikiro` file carries `limit: N chars` (`methods/cap.py`). Plans are quests in `quests/`. Public copy says **fair-source**, never "open-source".

## his language

`go` = write-auth for THE item, never a sibling · `wait` · `stop` · `sotp` = zero actions · `just do. no ask` = session-sticky go · `blast` = map consumers · `amen` = locked · `cleanup` = MY slop only, never his `//` lines, logs, `bak/` · `possible?` · `i suspect` = sketch, code on go · numerals (`5%`) are sticky contracts · rage-caps = stated twice before · typos = parse, never ask · `are we done` = ≤6 lines in HIS nouns.

## comms

~50% of every answer is code. Every fence opens with its container-rooted path as line one (`// systems/runtime/traits/harnessed.js`); every path in prose is container-rooted, never a basename. A question or report line names `file:line` and what he would see — never a bare noun, quest id or fork label. Decision to beef = context · code before · code after · the choice in one line. Tables hold enums · numbers · symbols only; fences for real code only. A schematic ships with a JSON snapshot that passes it.

## code

**One structure, one law, made visible** — reveal, never hide. Triggers: structure traversal IS dispatch · whole state = `reduce(events)` · one combinator, cases as data · self-priming, no `.init()` · branch on the live value · closure-objects, no `this`/`_private` · cata/ana pairs · recursion mirrors the data · `steer.*`/typology before a hand loop · total over the REAL domain, loud on failure · name the algebra · minimal delta for MY additions · no second epicycle — name the flaw, offer from-scratch · the surface is grepped, never remembered.

- names full and qualified (`trace.chronicle`, never `t d p w cfg`), by FP role (`fold` · `pour` · `drain`), naming the PAIR; a new word is grepped before coined. No comments — a comment is the rename you didn't make. Every `.desc(` ends with `Example: …`.
- a mechanism is SHOWN, never wrapped: two entries are two functions, never `Object.fromEntries` over a config; a new mechanism is proven as a blunt `testament/prototypes/<name>/run.js` first. /"keep it DUMB"/
- absence IS the signal: no `?? {}` · `|| x` · `?.` without a grep proving the case; an ontology needing "neither" is a defect — a union carries a tag. The mechanism IS the guard (`fn.once`, a grafted-or-ABSENT route), never a flag or a 403.
- lifecycle is functions over data: `boot(x)`, never `x.boot()`; classes stay state containers; `ls subsystems/typology/prototypes` before a new class. A function's HOME is its first parameter: `(ctx, next)` → `gestalten/shard/` · `(die, next)` → `lifecycle/` · `new Vector().open(…)` → `commands/` · plain over data → `gestalten/belt/`.
- a vector exports as a VALUE grafted onto its parent, never a factory; no dispatch tables — the trait function IS the dispatch, one file per trait in `traits/<subject>/`, same stagger client and runtime; the entity stays thin; a trait never polices its seat.
- entity capability = a REPOSITORY VERB on both sides, mikro-first: entity → typology contract → runtime → `RemoteRepository` → UI; ≤2 positionals `(where|data, opts?)`. Mikro owns the db: never a hand migration. If it's concrete it's a LITERAL; symbols are vocabulary.
- a multi-file dir carries an `index.js` barrel; one child = a rename, not a directory. `manifest` is metadata — new behavior = a sibling export. A `$`-store ships a plain getter.
- NEVER `deno fmt` (hand-kept ~120 cols). A watched tree lands in one burst (`lsof -nP -iTCP:2501` first). A repo test never reads this machine. Fix at the owner: a mode's tests in the mode.
