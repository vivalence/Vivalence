- **newborn · silent gate**: younger than the window → `NEWBORN`, a baseline, never a finding; a silent deny
  gate stays: silence is it working (REJECTED `molt.py:212` `(retire?)`).

- **model-generation** (a new `claude-*` after the stamp): the decay audit — would the bare model keep each rule? Candidates → a table for beef, never cut alone (/"harnesses have to keep getting simpler"/ m69 3.4).

## the passes — agents by the Workflow tool, opus MEDIUM, read-only on `.ikiro/`

1. **sweep** — 8 angles (labs · open harnesses · self-improving agents · forums · context engineering · guards+evals), each claim re-fetched by a skeptic, one synthesis: `the meta re-measured` · `delta vs
   ikiro` (adopt | cut | confirm | contradict, costed).
2. **corpus** — batches ≈180 KB → a reader writes JSONL (`kind · claim · voice · family · owner`) → a second adds misses +
   RETRACTs → `merge.py` dedups, grep-checks against the live files →
   a judge per unlanded cluster (landed · land · drop · hook · known-issue; a misfit → the closest + its sentence, 09-22).
3. **land** — ONE writer per owner (codestyle · skill · shard · known-issues), ≤2 lines per learning, `cap.py`; seen
   ≥3× with no guard → a hook + exercise cases, wiring proposed; `merged.jsonl` · `unlanded.md` · the candidates → `reference/molt/<date>/`.
4. **shed** — `trash them` = THROUGHPUT (compacts · research · stamps); PERSISTENT (map · ledger · codemap · kernel ·
   skills) is rebuilt — ask which (REJECTED 09-23, 23 files → 15%: /"this was a bit too agressive. some files are
   throughput. … some are more static."/). First killed intents (struck titles) → REJECTED-with-why (/"i had 4
   titles defined. what were they?"/), graded cases → evals (10-05), delete only what beef ordered, landings on disk, a refuter per delete
   (default KEEP); a file no commit holds → the stamp dir first, else `git ls-tree -r <commit> <path>`.
