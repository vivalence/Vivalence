# ontology-pass — the name before the mechanism, the way beef actually locks one

Canon: `self/lexicon.md` (`amen` · probes · falsification-driven design) · pre-flight 4 (*"stop fucking coding. start designing."*) · Scoreboard `pin-ontology-before-naming` · `user-intent-drift`. In all 8 measured occurrences the order was: agent proposes a mechanism → beef refuses in one line → the ontology gets named. *"Building the mechanism before the ontology, three times."* This pass runs BEFORE the sketch. Landing a settled noun is [[rename-pass]].

## The procedure — extracted from m15 · variant→instance · m62 · m67 · m68 · #152 · #178

1. **beef opens with the dissatisfaction, not a name.** *"lets globally rename cake. i dont like the name."* · *"we need a word for this … not process or job … don't call it the ledger"*. Read the refusal as the spec of what the word must NOT be.
2. **collision-list from disk FIRST.** `ls subsystems/typology/schematics/prototypes/ subsystems/typology/gestalten/shard/` and a term census: how many THINGS does the word mean today (`output` meant FOUR; `skills` taken twice; `fold` already a catamorphism). A name that collides with its two nearest neighbours is a trap, not a register. State the count you MEASURED, not the count you grepped (75 sites claimed, half real).
3. **count what wants naming, separately.** *"Two things want naming: the UNIT and the ORGAN."* One word per concept across the wire; residence never disambiguates.
4. **propose fifteen** — beef's own number, twice — clustered by REGISTER (machine · body · allowance · authority …), one-line case each, STRUCK candidates kept visible, then a stated **Lean**, never a decision. A coined register dies (*"what is Crib?"* after forty uses; *"nature is a reserved word too"*). Plain technical words; extend the existing family.
5. **survey precedent** — in-repo AND external (an industry standard: *"what does USD call that internally"*; MCP resources, Letta blocks) → say STEAL or INVENT. Textbook assets settle a term a debate cannot: `subcomponent` appeared zero times across three USD asset sets and was struck.
6. **extract the PRINCIPLE that decides**, not just the winner — *"Residence disambiguates; one noun per concept across the wire"* · *"Mask keys are SEMANTIC (role); lookup surfaces are LEXICAL (type)"*. A first draft split on the wrong axis is named inconsistent, not patched.
7. **pin the noun→meaning table**, one row per term, including `DEAD`.
8. **prove the grammar is latent on disk** before landing it — `populate.js:39 accio(mask.module)` verbatim; the naming already live in a test.
9. **the lock** — beef writes the call himself (`const iq = v.thread.trait(row, "INTELLIGENT");`) or says `amen`, PER ITEM, never for a batch. Then [[rename-pass]].

## Rejection shapes to anticipate

- **a union by absent fields** — *"sell me the ontology of node by the absence of component or assembly?? … not clean schema design."* → name the discriminator (`kind: "component" | "assembly"`).
- **an object-with-severity config** — *"I want a functional solution. I want an array of arrays where each array contains two functions."* Three proposals, two rejections, one `amen`.
- **too flat** — *"there should be a ancestor key. schematics."*
- **symbols vs literals** — *"events are not fucking symbols stupid. they are concrete - literal."* Abstract is a symbol; concrete is a literal.
- **his role/ontology rulings are STANDING AXES** — *"inspiration"*, *"concrete = literal"* bind every later design touching the named thing; a second correction on one screen means re-read his sketch, not patch the value (`feedback_second_correction_means_wrong_shape`).

## Design mode

*"ignore the forks. were doing high level design now."* · *"You are going too fast into implementation. I'm still on design."* No countdown framing, no forks, no code; end on the sharpest open tension. A cheap structural check when a tree is proposed: count children per node — a node with exactly one child is a rename, not a structure (`feedback_cluster_by_factor_not_taxonomy`).
