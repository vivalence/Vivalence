# name — "i dont like the name" · "rename X to Y everywhere": lock a noun, then land it

Order: mechanism proposed → beef refuses in one line → the ontology named. BEFORE the sketch.

## lock — the ontology pass

1. **the dissatisfaction is the spec** — /"lets globally rename cake. i dont like the name."/: what it must NOT be.
2. **collision list from disk FIRST** — `ls` typology's `prototypes/` · `gestalten/shard/`; a census: how many THINGS it means today, MEASURED. A collision is a DIFFERENT concept; the word naming the values is the heir (10-10: `bundle` struck against its own `Bundle`).
3. **count what wants naming** — /"Two things want naming: the UNIT and the ORGAN."/
4. **propose fifteen** — by REGISTER, a one-line case each, STRUCK kept, a **Lean**, never a decision. Plain words; extend the family; the name says the MECHANISM (`LOOPING`), never the drama. REJECTED: a coined register (/"what is Crib?"/) · a noun coined as if code: first use says `(mine, 0 hits)` · 10-16 `POSSESSED` (/"so theatrical"/).
5. **precedent** — in-repo AND external → STEAL or INVENT.
6. **the PRINCIPLE that decides**, not the winner — /"Residence disambiguates; one noun per concept across the wire"/.
7. **the noun→meaning table**, a row per term, `DEAD` too.
8. **prove the grammar latent on disk** — the naming live in code, `file:line`.
9. **the lock** — beef writes the call or says `amen`, PER ITEM; terse words map IN ORDER (REJECTED 10-23 /"legend and $chord"/ → /"its the legend???? what?"/), then land.

Rejections:
- a name I CARRY into a sketch is mine — renamed in the same diff. REJECTED 10-12: `enter()` · `door` (third time → hook owed).
- a verb in HIS paste is his: `/chrome` ADDS beside `/repl`; his `repl or chrome` is a list, not a choice — REJECTED 10-15 (/"WHERE IS FUCKING RPLLL"/).
- a union by absent fields → a discriminator `kind` · severity config → /"an array of arrays … two functions"/ · too flat → /"there should be a ancestor key."/

Design mode (/"ignore the forks."/): no forks, no code; end on the sharpest tension.
Interview (/"ask to understand my design"/): `drill-me`'s question shape (REJECTED 10-16: fragments → /"gibberish"/ · /"I don't understand Q8 at all"/). REJECTED 10-15: a cited wall (/"i cant fcking read that"/) · conflating channels · a file summarized, not SHOWN (/"word salad"/). A relation never decides layout; carried words: `drill-me`.

## land — the rename pass

/"entirely. no dual read. replace with instance."/ · /"no fallback window."/ · /"rename files, content and references."/

1. **keep-list** — every place the word SURVIVES meaning else (`font-variant-numeric` · `.ikiro/` history · `.bak`), BEFORE the grep.
2. **term census** — identifiers · `manifest.type` strings · scope keys · `VIVA_*` env vars · route nouns · file/dir names · fixtures · snapshots · docs · bruno · compose · `.mjs`. `/usr/bin/grep -rI`, NO include filters (REJECTED 10-13: shell `grep` reads `.gitignore`), the literal AND its regex-escaped form `grep -rnIF 'a\.b'` (REJECTED 10-24: `vnd\.vivalence` hid in `bundler.js:5` · `sections.js:15` · `mime.js:30`).
3. **radius = the whole machine** — repo + `~/.viva/instances/*` + `~/.viva/registry/*`; a tapped package "owed" is not landed; `~/.viva` has no VCS → capture first (skill `readme`).
4. **relative imports** — `grep -rn '\.\./.*<old>/'`; quest-tangle NEW files; every `file:N` past a dropped line (REJECTED 10-19).
5. **new names exact** — `grep -rn '<new>'` first; a key may be RULED, unlanded: grep `.ikiro/quests` incl. `done/` · `discarded/` (REJECTED 10-21 `VIVA_VAULT_MOUNT`, m79 F2 held it).
6. **the atomic spine** — scope key · env var · `find.type` · manifest `type` · ledger path form in ONE milestone; split, boot is red.
7. **bracket it** — skill `change`; fixtures + snapshots, repo AND registry → ZERO old name.
8. **residue grep against the keep-list** — outside it = a miss.
9. **canon** — `grep -rn '<old>' .ikiro/` → zero outside history; shards re-stamped.

REJECTED: an alias · a dual read · a deprecation window · `// was X` · renaming his `//` lines or `bak/` · `git mv`.
