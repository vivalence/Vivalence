# name — "i dont like the name" · "rename X to Y everywhere": lock a noun, then land it

Order: mechanism proposed → beef refuses in one line → the ontology gets named. BEFORE the sketch.

## lock — the ontology pass

1. **the dissatisfaction is the spec** — /"lets globally rename cake. i dont like the name."/: what the word must NOT be.
2. **collision list from disk FIRST** — `ls` typology's `prototypes/` · `gestalten/shard/`; a census: how many THINGS the word means today, MEASURED. A collision is a DIFFERENT concept; the word naming the values is the heir (10-10: `bundle` struck against its own `Bundle`).
3. **count what wants naming** — /"Two things want naming: the UNIT and the ORGAN."/
4. **propose fifteen** — by REGISTER, one-line case each, STRUCK kept, a **Lean**, never a decision. Plain words; extend the family; the name says the MECHANISM (`LOOPING`), never the drama. REJECTED: a coined register (/"what is Crib?"/) · a noun coined as if code: first use says `(mine, 0 hits)` · 10-16 `POSSESSED` (/"so theatrical"/).
5. **precedent** — in-repo AND external → STEAL or INVENT.
6. **the PRINCIPLE that decides**, not just the winner — /"Residence disambiguates; one noun per concept across the wire"/.
7. **the noun→meaning table**, one row per term, `DEAD` included.
8. **prove the grammar latent on disk** — the naming already live in code, cited `file:line`.
9. **the lock** — beef writes the call or says `amen`, PER ITEM. Then land it (below).

Rejections to anticipate:
- a name I CARRY into a sketch is mine — rename it in the same diff. REJECTED 10-12: `enter()` · `door` (third time → hook owed).
- a verb in HIS paste is his: `/chrome` ADDS beside `/repl`, never replaces it; his `repl or chrome` is the list, not a choice — REJECTED 10-15 (/"WHERE IS FUCKING RPLLL"/).
- a union by absent fields → a discriminator `kind` · severity config → /"an array of arrays … two functions"/ · too flat → /"there should be a ancestor key."/

Design mode (/"ignore the forks."/): no forks, no code; end on the sharpest tension.
Interview (/"ask to understand my design"/): ONE question per turn, two options AS CODE + my lean, plain sentences — compression off (REJECTED 10-16: fragments → /"gibberish"/ · /"I don't understand Q8 at all"/). REJECTED 10-15: a cited wall (/"i cant fcking read that"/) · conflating channels · a file summarized, not SHOWN (/"word salad"/). A relation never decides layout; a carried word (seat · face) is struck.

## land — the rename pass

/"entirely. no dual read. replace with instance."/ · /"no fallback window."/ · /"rename files, content and references."/

1. **keep-list** — every place the word SURVIVES meaning something else (`font-variant-numeric`, `.ikiro/` history, a `.bak`), written BEFORE the grep.
2. **term census** — identifiers · `manifest.type` strings · scope keys · `VIVA_*` env vars · route nouns · file/dir names · fixtures · snapshots · docs · bruno · compose · `.mjs`. `/usr/bin/grep -rI`, NO include filters; REJECTED 10-13: shell `grep` honors `.gitignore`.
3. **radius = the whole machine** — repo + `~/.viva/instances/*` + `~/.viva/registry/*`. A tapped package reported "owed" is not landed. `~/.viva` has no VCS → capture first (skill `readme`).
4. **relative imports** — `grep -rn '\.\./.*<old>/'`; also quest-tangle NEW files and every `file:N` past a dropped line (REJECTED 10-19).
5. **new names exact** — `grep -rn '<new>'` before writing; a key may be RULED, unlanded: grep `.ikiro/quests` incl. `done/` · `discarded/` (REJECTED 10-21 `VIVA_VAULT_MOUNT`, m79 F2 held it).
6. **the atomic spine** — scope key · env var · `find.type` · manifest `type` strings · ledger path form in ONE milestone; a split leaves boot red.
7. **bracket it** — skill `change`; fixtures + snapshots (repo AND registry) → ZERO old name.
8. **residue grep against the keep-list** — anything outside it is a miss.
9. **canon** — `grep -rn '<old>' .ikiro/` to zero outside history; shards re-stamped.

REJECTED: an alias · a dual read · a deprecation window · a `// was X` comment · renaming his `//` lines or `bak/` · `git mv`.
