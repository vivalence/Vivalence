# bird — the wiring derived from its demands; the code is evidence

/"look at a problem holistically and not be confined by whats already in code"/ (11-16). Sibling of skill `connoisseur`: it judges a HUNK against triggers 1–19, the bird the WIRING against its demands — trigger 16 as a process. Its law stays law: triggers · typology · every `amen` — first principles on WIRING, never on idiom.

## primitives — seven nouns, used exactly

- **demand** — what a consumer or his screen needs, said without ONE noun of the implementation; falsifiable: a probe or a `specimen.it` can fail it.
- **invariant** — what must never be observable; it names its owner.
- **premise** — one sentence the is-wiring assumes. RULED (a quest lock, cited) · DERIVED (a demand forces it, `Dn`) · ACCIDENT (history; nothing forces it). Only an accident is free to die; a ruled one is surfaced as a question, never broken silently. A lock the census meets on the SAME mechanism is QUOTED in the reply, `file:line`, even when his new words outrank it (11-20 `one signup, traits gate it` met, never shown).
- **epicycle** — a mechanism compensating for another's shape: a sync · a guard · a flag · a re-derive · a special-case arm · a hand-synced list. Their census = the case for a rewire.
- **zero** — the wiring written as if today's demands had been day-one assumptions.
- **delta** — zero minus is: DIES · MOVES · BORN, counted in files and exports.
- **passage** — the ordered landing of a delta, every step green.

## process

1. **gate** — a rewire, or a `change`? ≥2 epicycles on one mechanism · a demand no owner holds · his word. One epicycle → `change`. Name the subsystem's EDGE: consumers outside it are fixed, everything inside is free.
2. **census — the is** — the chain end to end, `file:line` per step, RUN (a probe prints it), never recalled; every state → its writers; every consumer, the BARE word grepped (`blast`: repo + `~/.viva/registry`; 11-16 3 → 14); a trait WORD = its declarers AND non-declarers + its `bak/` history (11-16 `CONVERSATIONAL` read as voice); the epicycles `E1…En`, each `file:line` + what it compensates for; `grep -rn '<its nouns>' .ikiro/quests` incl. `done/` for the rulings AND the probes, BEFORE a premise is tagged — an "unprobed" · "never ruled" cites its zero-hit grep (REJECTED 11-19: m82 had probed the members). The EDGE widens between passes (a new owner · a second process · a client) → the census re-runs on the new ground before a want is written: the owner's directory READ, his comments in it too; `how do others do it` = a docs-checked survey, each claim sourced, never memory (11-20 /"think again."/).
3. **demands** — read off the CONSUMERS and his turns, never off the internals: 3–9, `D1…Dn`. His design sentence is walked clause by clause FIRST, each clause → the hunk that carries it, or `uncarried`, before any fork of mine (11-21 two leaf forks asked and built under a core never carried). The test of each: could a different wiring satisfy this sentence? No → a premise in disguise; move it to 4.
4. **premises** — every one, `P1…Pn`, tagged. Each ACCIDENT gets a probe whose output would differ were it false; "library limit" · "ordering" = ALWAYS a probe. Two failed fixes share a premise: that premise is tested first.
5. **zero, blind** — written from 3 + 4 ONLY, the is-files closed. Order: the consumer's call site → the data shape (entity · event · trie) → the owners (one writer per state) → the dispatch. TWO zeros, structurally different — another owner or another data shape, never flavors (one zero = the is, remembered). Before any new primitive the surface is grepped (19): `steer.*` · `shape.*` · `belt.*` · the nearest sibling subject, measured. Each zero: the connoisseur's pass (1–14) + `drill-me/red-flags.md` + depth.
6. **delta** — per zero: DIES · MOVES · BORN; which `E` it kills; which `P` it breaks and that P's tag. The deletion test on every BORN: delete it — does complexity concentrate, or only move? A zero that kills no epicycle is a rename: dropped. Zero ≈ is: SAY SO — the defect is local, hand it to `change`.
7. **report — never a template of my nouns**; his /"what should I want?"/ = the knot as ONE table, then N numbered wants, plain (11-19 /"amen."/) (REJECTED 11-16 `## zero A` · `## demands` · `## premises`: /"this was bad form. its not 'zero x'. orient on /drill-me and /show-me"/). The is = `show-me` stops (explanation · code · usage · snapshot, one per turn when >1). The fork = ONE `drill-me` question: plain sentences, what he SEES first, Option A · Option B as whole units with their CALLER, a lean, `A or B?`. `zero` · `premise` · `epicycle` · `delta` · `D1` · `E1` · `P1` are MY worksheet: none reaches the reply.
8. **hand-off** — a fork → `drill-me`, one lock per turn; locked → `quest`. The passage: subtract first (dead exports · zero-reader keys) → the atomic spine in ONE milestone → consumers migrate, THEN the old dies in the same milestone → no dual read, no compat arm; each milestone bracketed by `change`.

## the questions that open a wiring

- Who OWNS this state — and who else writes it (15)?
- What does the mechanism already compute that a second one re-derives (17)?
- Which branch disappears if the data carried a tag · were a trie · were `reduce(events)` (2 · 3 · 11)?
- Which consumer knows an internal rule to call it right (18)?

## rejections

- **an anchored zero** — it keeps the is's file names and step count: step 5 was not blind. Redo.
- **a greenfield fantasy** — breaks a RULED premise unsaid · coins a primitive typology holds · leaves idiom (`Vector` · die · trait · repository-first).
- **a third epicycle "for now"** — the gate fired; the patch is the defect.
- **a zero without its consumer site** — types derive from the call, never the reverse.
- **a worksheet step claimed** — `rewires written, not yet run` over zeros never drawn: an undone step is SAID undone, by name (11-21).
- **a pattern survey** — "event sourcing would fit" ✗; a zero is its code in OUR tree, real cardinality, RUN (11-16).
- **an edit** — this skill writes no product file; `go` on a delta lands the QUEST.
