* fits — which mechanism could host a standard, extensible set of kinds

- 5 trait vocabulary + =claim=: a name looked up in a merged map, throw on unknown, =schema.fill= the data — closest precedent; cost: a vocabulary object per scope + one lookup per =track=.
- 7 =Part= tagged union + =Alien=: the standard set as =v.const= tags, one open member — cost: a central union; the open member is typed only as =unknown=.
- 1 =static coercions=: per-subclass, inherited, casting — cost: casts the address, not the record; would need a second static on Span.
- 4 =fromm.yield= =[[kind, sniff, fill]]= with a declared =kind= override: cost: central table, silent =opaque= fallback (not loud).
- 8 =MACHINE= self-validated at import: cost: closed by construction; fits only the subset the machine reads (7 names).
- 9 =Record= schema: already on the wire; cost: the name is =v.string()=, nothing enforced.
