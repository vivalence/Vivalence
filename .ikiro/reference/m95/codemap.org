* how to read this

One tree per system, =ls= order. A row = path · what it is today · verdict. Verdict words:
- KEEP — stays where it is, the new chrome reads it
- PORT — the logic survives, moves or re-skins (Svelte → Solid, anima-local → shared)
- REWRITE — the slot survives, the body is new
- DROP — dies with the pincer, the SvelteKit shell, or a dead word
