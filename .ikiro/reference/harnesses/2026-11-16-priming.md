## the startup routine — the only source that states one

Anthropic, effective harnesses for long-running agents (11-26-2025): every session opens the same way.

```
pwd                                  "Run `pwd` to see the directory you're working in."
progress file + git log -20          "Read the git logs and progress files to get up to speed."
feature list → ONE item              "choose the highest-priority feature that's not yet done"
init.sh / start the server
smoke test BEFORE new work           "a basic end-to-end test before implementing a new feature"
```

One item at a time is called critical; an item is marked passing only after testing as a user would.

## what to load — up front vs on demand

Anthropic, effective context engineering (09-29-2025):

- hybrid: memory files "naively dropped into context up front", everything else fetched just in time.
- hold identifiers, not content: "lightweight identifiers (file paths, stored queries, web links, etc.)".
- progressive disclosure: agents "incrementally discover relevant context through exploration".
- structure is signal: "Folder hierarchies, naming conventions, and timestamps".
- budget: "the smallest set of high-signal tokens".
- after a reset "the agent reads its own notes and continues".
- exploration in a sub-agent that "returns only a condensed, distilled summary" (1–2k tokens).

HumanLayer, advanced context engineering (08-29-2025):

- "keeping utilization in the 40%-60% range".
- research → plan → implement; research = "Understand the codebase, the files relevant to the issue".
- "Subagents are about context control."
- human review goes to research and plans, the highest-leverage artifacts.
