* §5 probe — the per-context enable (the gravity fix)

A =default: true= mode filter throws on every daemon-WIDE read (=dataset.js= ×16, =stucatch/vivaware/domain/ingress.js= ×8, =education/modes/games/dojo/aperture/index.js:32=). A filter added on the CONTEXT em is the context's alone:

#+BEGIN_SRC js
// probe P1–P7 — the enable
const enable = (ctx, name, cond, entity) => ctx.addFilter({ name, cond, entity, default: true });
#+END_SRC
