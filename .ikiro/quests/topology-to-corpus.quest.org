* Intent

Rename the third kernel type. =topology= (geometric/structural) never described what the kernel actually carries: a vocabulary corpus. Rename throughout.

| current      | new      |
|--------------|----------|
| topology     | corpus   |
| topologies   | corpora  |
| Topology     | Corpus   |
| .topology    | .corpus  |

Symbol semantics, file shapes, dataset contracts, and trait set unchanged. Pure identifier rename + directory move.

* Boundary

In scope:
- 1 runtime class + 2 dispatch sites (kernel.js, population.js, bench.js)
- 1 typology comment (=properties.js:1=)
- 8 =.viva.js= manifests (1 active, 1 vocalized variant, 6 archived under =bak/=)

* Risk model

Pensieve indexes by =manifest.type=, not by filesystem path. This decouples M1 (manifest semantics) from M2 (cosmetic dir name).

| change | breaks if alone? | reason |
|--------|------------------|--------|
| manifest =type: "topology"= → =type: "corpus"= without updating circuitry imports | YES | accio query =@vivalence/topology/english-to-brazilian= no longer resolves; pensieve has it under =corpus= |
| circuitry import strings without updating manifests | YES | accio finds nothing under =@vivalence/corpus/=; daemon boot fails |
| runtime class rename without manifest rename | YES | =find((v) => register.manifest.type === v.type)= finds no match; modes orphaned |
| dir rename without anything else | NO | paladin walks recursively, ingests by content |
| docs sweep alone | NO | docs are descriptive |

→ M1 is atomic. M2 + M3 are independent and reorderable.

* Decision: filter vs find

Current: =die.kernel.topology= is a =filter()= returning array. Daemons with multiple corpora exist conceptually but not in active circuitry — every active =daemon.viva.js= references exactly one corpus.

Two options for the new key:

| option | shape | impact |
|--------|-------|--------|
| =corpus= as filter (array) | =die.kernel.corpus = [...]= | preserves current shape; downstream consumers index =[0]= |
| =corpus= as find (single)  | =die.kernel.corpus = {...}= | matches singular noun; aligns with =domain=; one-shot break |

Recommendation: keep filter (array) for M1. Change shape in a separate quest if desired. Lower blast radius.
