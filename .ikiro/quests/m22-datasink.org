* Meta
** Intent

=DATASET= is anabolic: registry files → daemon entities, once, at install.
This quest builds the katabolic path: daemon entities → registry files,
ongoing.

Enrichment that happens INSIDE the daemon — harvested candidates, agentic
annotation, minted lemma symbols, rank corrections — currently dies in the
sqlite file. Draining it back makes the registry the durable, versioned,
travelling home of the data, and the daemon merely working memory.

Not sync. Two one-way operations at different times:

| operation | truth    | shape                          |
|-----------+----------+--------------------------------|
| install   | registry | idempotent upsert              |
| drain     | daemon   | wholesale scoped projection    |

No reconciliation, ever.

** The shape in one screen

#+begin_example
  registry files ──DATASET(install)──▶ daemon entities
                                            │
                                            │ writes (harvest, agentic, mint)
                                            ▼
                                       twitch /{type}/{op}/after
                                            │ debounce 1500ms
                                            ▼
  registry files ◀──DATASINK(drain)─── project.row → match → shape → write
#+end_example

Both land. =flow/= dies whole. Measured, it was four unrelated things in a
bag, each with an existing home:

| flow module                  | already exists as                                                   | what was actually new |
|------------------------------+---------------------------------------------------------------------+-----------------------|
| =selector.js=                | =belt.object.match= (=gestalten/belt/object.js:55=)                 | the operators         |
| =project.js= =pick/omit/pipe=| =belt.object.pick/omit= — already dotted-path aware                 | nothing               |
| =project.js= =row/refs/lean= | —                                                                   | the sink's row algebra|
| =reader.js=                  | =paladin.source= + =paladin.read.file= + =paladin.find.walk/read=   | =.default= codec, =index.js= skip |
| =writer.canonical=           | —                                                                   | deterministic order   |
| =writer.scribe=              | =paladin.state.text/json=                                           | atomic + write-if-changed |
| =writer.facet=               | —                                                                   | sink partition policy |

=paladin.read.file= (=subsystems/paladin/belt/read.js:37=) already dispatches
a codec by extension, and =paladin.find= (=belt/find.js:11=) already skips
=bak=/=archive=/=slp= — which =reader.dir= did not. The first draft's walker
was a worse copy of a live primitive.

**The seam, stated once**: a carrier holds DECLARATIONS, never loaders.
Nothing under =prototypes/= touches =Deno.*=. This is the =Bundle= shape —
=prototypes/bundle.js= is pure (hash, entries, fetch-by-integrity),
=paladin/belt/bundler.js= does the filesystem, =traits/application.js= wires
them, and a module imports =Bundle= without ever seeing paladin.

So the vocabulary is:

- =Dataset= — carrier ={ schema, intent, ...sources-per-type }= where a source
  is a mount-relative STRING, a directory STRING, or an inline row array.
  Legacy ={ schema, entities }= lifts free (every existing module UNCHANGED).
- =Datasink= — carrier of per-type tuple lists, normalized to
  ={ type, where, match, shape, target }=. Owns =canonical(rows) => string=
  and =strata(rows, target) => Map<path, rows>= — both pure. Neither writes.
- =reader= / =writer= — the nouns SURVIVE, the directory does not. @beef:
  /"i actually like the name reader and writer. they are nicely explicit and
  obvious."/ They are now pure DESCRIPTOR factories, exported beside the
  carrier each one feeds: =reader= from =prototypes/dataset.js=, =writer=
  from =prototypes/datasink.js=. =reader.dir(t)= => ={ walk: t }=,
  =reader.json(t)= => ={ read: t, codec: "json" }=, =writer.json(t)= =>
  ={ write: t, codec: "json" }=, =writer.facet(prefix, into, {rest})= =>
  ={ facet: prefix, into, rest }=. A bare string lifts to the extension's
  descriptor, so declarations stay terse. Nothing here opens a file — the
  trait hands the descriptor to =paladin.find= / =paladin.state=. The
  explicitness @beef wanted is at the declaration face, which is the only
  place it was ever doing work.
- =project= — the row algebra, exported from =prototypes/datasink.js=:
  =row/refs/lean/detail/slug/drop=, plus =pick/omit/pipe= as thin CURRIED
  adapters over =belt.object= (=omit = (...keys) => (row) =>
  object.omit(row, keys)=). Curry at the declaration face, no second
  implementation.
- =belt.object.where(query)= — compiles a MikroORM query object to a row
  predicate; =null= on an operator it cannot compile → conservative
  dirty-all, DB stays authoritative. =object.match(obj, query)= becomes
  =where(query)?.(obj)= — ONE compiler, and the five live =object.match=
  call sites gain operators.
- =belt.object.ordered(value)= — recursive key sort. General, sibling to
  =clone=/=descend=.
- =paladin.state.scribe(path, text)= — atomic tmp+rename, write-if-changed,
  returns whether it wrote.
- =paladin.find.data(dir)= — the codec walk, =index.js= skipped.

Nothing is added to =gestalten/index.js=, =index.client.js=, or =fromm=. On
that last one @beef was right and it is structural: /"SMELL!!! big smell. not
good."/ — every =fromm= member is =fromm.X(thing) => { get view() }=, a lazy
coercion view; =selector(where) => fn= has a different shape, and the
re-export crossed a directory barrel. It is belt.

#+BEGIN_SRC javascript :tangle ../../subsystems/typology/gestalten/flow/selector.js :mkdirp yes
import { is } from "@vivalence/typology";

const like = (pattern) => {
  const source = String(pattern)
    .split("%")
    .map((part) => part.replace(/[.*+?^${}()|[\]\\]/g, "\\$&"))
    .join(".*");
  const rx = new RegExp(`^${source}$`);
  return (value) => is.string(value) && rx.test(value);
};

const slugs = (refs) =>
  [refs ?? []].flat().map((ref) => (is.string(ref) ? ref : ref?.slug)).filter(Boolean);

const scalar = (expected) => {
  if (!is.object(expected)) return (value) => value === expected;
  const tests = [];
  for (const [op, arg] of Object.entries(expected)) {
    switch (op) { //@beef is this the mikroorm set? one to one?
      case "$eq": tests.push((value) => value === arg); break;
      case "$ne": tests.push((value) => value !== arg); break;
      case "$in": tests.push((value) => arg.includes(value)); break;
      case "$nin": tests.push((value) => !arg.includes(value)); break;
      case "$like": tests.push(like(arg)); break;
      case "$nlike": { const test = like(arg); tests.push((value) => !test(value)); break; }
      default: return null;
    }
  }
  return (value) => tests.every((test) => test(value));
};

const refset = (expected) => {
  const spec = is.array(expected) || is.string(expected) ? { $all: [expected].flat() } : expected;
  const tests = [];
  for (const [op, arg] of Object.entries(spec)) {
    const wanted = slugs(arg);
    switch (op) {
      case "$all": tests.push((present) => wanted.every((slug) => present.has(slug))); break;
      case "$in": tests.push((present) => wanted.some((slug) => present.has(slug))); break;
      case "$none": tests.push((present) => !wanted.some((slug) => present.has(slug))); break;
      default: return null;
    }
  }
  return (row, key) => {
    const present = new Set(slugs(row?.[key]));
    return tests.every((test) => test(present));
  };
};

export function selector(where) {
  if (where == null || where === true) return () => true;
  if (is.fn(where)) return where;
  if (is.string(where)) return selector({ symbols: [where] });
  if (is.array(where)) return selector({ symbols: where });
  if (!is.object(where)) return null;

  const tests = [];
  for (const [key, value] of Object.entries(where)) {
    if (key === "$and" || key === "$or") {
      const parts = value.map(selector);
      if (parts.some((part) => part == null)) return null;
      const fold = key === "$and" ? "every" : "some";
      tests.push((row, ctx) => parts[fold]((part) => part(row, ctx)));
    } else if (key === "symbols" || key === "literals") {
      const test = refset(value);
      if (test == null) return null;
      tests.push((row) => test(row, key));
    } else if (key === "traits") {
      const wanted = [value].flat();
      tests.push((row) => wanted.every((name) => (row?.traits ?? []).includes(name)));
    } else {
      const test = scalar(value);
      if (test == null) return null;
      tests.push((row) => test(row?.[key]));
    }
  }
  return (row, ctx) => tests.every((test) => test(row, ctx));
}

        if (!policy) return [item];
        const shaped = policy[1](item);
        return shaped == null ? [] : [shaped];
      })
      .sort(bySlug),
  });
};

  const entries = [];
  for await (const entry of Deno.readDir(base)) entries.push(entry);
  for (const entry of entries.sort((a, b) => (a.name < b.name ? -1 : 1))) {
    const path = `${base}/${entry.name}`;
    if (entry.isDirectory) await walk(path, found);
    else if (entry.isFile && entry.name !== "index.js" && CODECS[ext(entry.name)]) found.push(path);
  }
  return found;
};

  const files = await walk(at(mount, target));
  const loaded = [];
  for (const path of files) loaded.push(await CODECS[ext(path)].load(path));
  return loaded.flat();
};

  const stat = await Deno.stat(path);

  if (!codec) throw new Error(`[reader] no codec for "${path}"`);
  return codec.load(path);
};

export async function scribe(path, text) {
  await Deno.mkdir(dirname(path), { recursive: true }).catch(() => {});
  const existing = await Deno.readTextFile(path).catch(() => null);
  if (existing === text) return false;
  const tmp = `${path}.tmp`;
  await Deno.writeTextFile(tmp, text);
  await Deno.rename(tmp, path);
  return true;
}

export const tee = (...writers) => async (rows, mount) => {

  return results.some((wrote) => wrote !== false);

const facetOf = (r, prefix) => {
  const head = `${prefix}.`;
  return (r.symbols ?? [])
    .map((item) => (is.string(item) ? item : item?.slug))
    .filter((s) => s?.startsWith(head))
    .map((s) => s.slice(head.length))
    .sort();
};

export const facet = (prefix, into, { rest = null } = {}) => async (rows, mount) => {
  const strata = new Map();
  let restless = 0;
  for (const r of rows) {
    const facets = facetOf(r, prefix);
    if (facets.length > 1) console.warn(`[writer.facet] ${r.slug} carries ${facets.length} "${prefix}" facets`);
    const key = facets[0] ?? null;
    if (key == null && rest == null) { restless++; continue; }
    const bucket = key == null ? "" : key;
    (strata.get(bucket) ?? strata.set(bucket, []).get(bucket)).push(r);
  }
  if (restless) console.warn(`[writer.facet] ${restless} rows without "${prefix}" facet skipped`);
  let wrote = false;
  for (const [key, slice] of [...strata.entries()].sort()) {
    const write = lift(key === "" ? rest : into(key));
    wrote = ((await write(slice, mount)) !== false) || wrote;
  }
  return wrote;
};

import * as reader from "../gestalten/flow/reader.js";

export class Dataset {
  schema = null;
  intent = [];
  sources = {};

  constructor(input = {}) {
    if (input instanceof Dataset) return input;
    const { schema = null, intent = [], entities = {}, ...declared } = input ?? {};
    this.schema = schema;
    this.intent = intent;
    for (const [type, sources] of Object.entries(declared))
      this.sources[type] = [sources].flat().map(reader.lift);
    for (const [type, rows] of Object.entries(entities))
      (this.sources[type] ??= []).push(() => rows);
  }

  get types() {
    return Object.keys(this.sources);
  }

  async rows(type, mount) {
    const loaded = [];
    for (const load of this.sources[type] ?? []) loaded.push(await load(mount));
    return loaded.flat();
  }
}

import { is } from "@vivalence/typology";
import { selector } from "../gestalten/flow/selector.js";
import * as writer from "../gestalten/flow/writer.js";

export class Datasink {
  sinks = [];

  constructor(input = {}) {
    if (input instanceof Datasink) return input;
    for (const [type, tuples] of Object.entries(input ?? {}))
      for (const tuple of tuples) {
        const [where, second, third] = tuple;
        const [shape, write] = third === undefined ? [null, second] : [second, third];
        this.sinks.push({
          type,
          where: is.fn(where) || where === true || where == null ? null : where,
          match: selector(where),
          shape,
          write: writer.lift(write),
        });
      }
  }

  get types() {
    return [...new Set(this.sinks.map((sink) => sink.type))];
  }

  of(type) {
    return this.sinks.filter((sink) => sink.type === type);
  }

  concerns(type, row, ctx) {
    return this.of(type).filter((sink) => sink.match?.(row, ctx) ?? true);
  }
}

** M22.4 — the DATASINK trait

NEW =systems/runtime/daemon/traits/datasink.js=. Reads:

1. lift the carrier, hang it on the mode (=mode.datasink=) for the
   resolution-time overlap lint;
2. userspace guard — deny-list plus the user-relation heuristic read off
   stripped metadata (a type with a relation targeting =user= is by
   definition not registry data);
3. one type-level =dirty= set, wholesale rewrite per type;
4. twitch opens =/{type}/{op}/after= per declared type, gated on =armed= —
   which the FINALIZER sets, so the install storm's own twitches never mark
   dirty;
5. =fn.debounce(1500)= settle, single-flight =mode.drain= (shared in-flight,
   cleared on settle).

The drain itself is one pipeline per sink:

#+begin_example
  repo.constrain?.(where)          DB-side, authoritative
    → find(populate: relations)
    → project.row                  strip system keys, normalize refs
    → match(row, {daemon, mode})   memory-side classify
    → claimed.add(slug)            for the orphan census
    → shape ?? lean                the declared projection, or the default
    → drop nulls
    → write(rows, mount)
#+end_example

#+BEGIN_SRC javascript :tangle ../../systems/runtime/daemon/traits/datasink.js :mkdirp yes
import { fn, shard, project, Datasink } from "@vivalence/typology";

const USERSPACE = new Set(["thread", "buffer", "turn", "user"]);
const DEBOUNCE = 1500;

export const DATASINK = (mode, daemon) => {
  const datasink = new Datasink(mode.module.datasink ?? {});
  mode.datasink = datasink;

  const meta = shard.datamap.strip(daemon.datamap.introspect());
  for (const type of datasink.types) {
    const scoped = Object.values(meta[type]?.properties ?? {}).some((relation) => relation.target === "user");
    if (USERSPACE.has(type) || scoped)
      throw new Error(`[DATASINK] ${mode.type}/${mode.slug} declares userspace entity "${type}"`);
    if (!daemon.entities[type])
      console.warn(`[DATASINK] ${mode.type}/${mode.slug} declares unknown entity "${type}"`);
  }

  const dirty = new Set();
  let armed = false;
  let flight = null;

  const drain = async (input = {}) => {
    const types = input.all || !dirty.size ? datasink.types : [...dirty];
    const report = { drained: [], written: 0, orphans: {} };

    for (const type of types) {
      dirty.delete(type);
      const repo = daemon.entities[type];
      if (!repo) continue;

      const relations = Object.keys(meta[type]?.properties ?? {});
      const claimed = new Set();

      for (const sink of datasink.of(type)) {
        const where = repo.constrain ? repo.constrain(sink.where ?? {}) : (sink.where ?? {});
        const found = await repo.find(where, { populate: relations });
        const matched = found
          .map(project.row(relations))
          .filter((row) => sink.match?.(row, { daemon, mode }) ?? true);
        for (const row of matched) claimed.add(row.slug);
        const shaped = matched
          .map(sink.shape ?? project.lean(relations))
          .filter((row) => row != null);
        const wrote = await sink.write(shaped, mode.module.mount);
        if (wrote !== false) report.written++;
      }

      const total = await repo.count({});
      report.orphans[type] = Math.max(0, total - claimed.size);
      report.drained.push(type);
    }

    return report;
  };

  const once = (input) => (flight ??= drain(input).finally(() => (flight = null)));
  const settle = fn.debounce(() => once({}), DEBOUNCE);

  mode.drain = once;

  for (const type of datasink.types)
    for (const op of ["create", "update", "delete"])
      daemon.twitch.open(`/${type}/${op}/after`, () => {
        if (!armed) return;
        dirty.add(type);
        settle();
      });

  return () => {
    armed = true;
  };
};
#+END_SRC

coverage measure: rows in the DB that no declared sink claims will be LOST on
the next install cycle. It rides in the drain report rather than warning,
because on a partial topography a nonzero orphan count is expected.
