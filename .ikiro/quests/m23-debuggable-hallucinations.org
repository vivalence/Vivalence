*ONE DEVTOOL CHANNEL* (I). Every question about what the system did — what went into a provider, what came out, which tools fired, how long, how much, what entered context — is answered by the *span*. No inspector endpoints, no debug leaves, no parallel introspection surface. If a fact is worth seeing it is span-marked; if it is span-marked it reaches the client for free. The =Span=→=Pipe=→=trace.chronicle=→panel g spine is BUILT and UNUSED (beef: *"i dont use them at all rn"*); m23 is where we start using it.

*NOTHING UNBOUNDED ENTERS AT COMPILE TIME* (II). Turns, system and tools are bounded by the request. Everything m23 adds enters as an *index line*, never a body. Bodies are elevated by the agent through a tool and *distilled back to a receipt* at persist time. *Wire filter — the convention*: any mark whose verb ends =/full= is CABINET-ONLY.

#+begin_src javascript
const heavy = (record) => record.verb?.endsWith("/full");

export const cabinet = ({ depth = 20 } = {}) => {
  const shelves = new Map();
  const write = (records) => {
    const root = records.find((r) => !r.trace)?.span;
    if (!root) return;
    shelves.set(root, records.filter((r) => heavy(r) || !r.trace));
    while (shelves.size > depth) shelves.delete(shelves.keys().next().value);
  };
  return { write, read: (span) => shelves.get(span) ?? null, depth };
};
#+end_src
