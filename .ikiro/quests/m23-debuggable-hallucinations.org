* law

Two laws carry the whole quest.

*ONE DEVTOOL CHANNEL.* Every question about what the system did — what went into a provider, what came out, which tools fired, how long, how much, what entered context — is answered by the *span*. No inspector endpoints, no debug leaves, no parallel introspection surface. If a fact is worth seeing, it is span-marked; if it is span-marked it reaches =$telemetry= for free. The existing =Span=→=Pipe=→=trace.chronicle=→panel g spine is built and unused; m23 is the quest where we *start using it*.

*NOTHING UNBOUNDED ENTERS AT COMPILE TIME.* Turns, system, tools are already bounded by the request. Everything m23 adds — notes, memory, skills — enters as an *index line*, never a body. Bodies are elevated by the agent through a tool, and *distilled back to a receipt* at persist time. Three gates: admission (compile) · elevation (loop) · distillation (persist). The context explosion is not the index; it is the recalled body that rides every subsequent request forever.

Corollary to the placement law (m20): the hallucination still compiles only what it is handed. Notes/memory/skills are harness concerns. The provider still translates ONE request; usage, model, and cost are *response* facts and ride =meta=, never the Faculty.
