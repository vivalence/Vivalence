** the style of a belt file

One =export const <member> = (paladin) => { paladin.<member> = { … } }= per file. The leaves are written inline in the member. No helper functions around them, no class, no comments: the 169 comment signals of today's belt go. Ran whole in =.ikiro/reference/paladin-belt/style/belt/=.

#+BEGIN_SRC js
// subsystems/paladin/gestalten/belt/remove.js
export const remove = (paladin) => {
  paladin.remove = {
    file: (path) => Deno.remove(path.absolute ?? path).catch(() => {}),
  };
};
#+END_SRC
