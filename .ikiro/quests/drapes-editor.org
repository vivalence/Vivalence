** the org mode (LANDED — `subsystems/drapes/editor/org.js`)

A `StreamLanguage` with real state, not a regex list: the tokenizer carries `block` · `drawer` · `headline`
across lines, so a `* headline` inside `#+begin_src` is body text and a `:PROPERTIES:` drawer swallows its
own lines until `:END:`. Nothing else in CodeMirror 6 knows org, so every mark below is ours.

| covered                        | mark                          |
|--------------------------------+-------------------------------|
| headlines, levels 1–6          | `heading1`…`heading6`         |
| the whole headline line        | its own level                 |
| TODO · NEXT · STARTED · WAITING · HOLD | `marks.todo`          |
| DONE · CANCELLED · CANCELED    | `marks.done`                  |
| `[#A]` priority                | `marks.priority`              |
| `:tag:tag:` at end of headline | `marks.tag`                   |
| DEADLINE · SCHEDULED · CLOSED  | `annotation`                  |
| `<…>` · `[…]` · ranges         | `marks.stamp`                 |
| `:DRAWER:` … `:END:`           | `marks.drawer` · `marks.property` · `string` |
| `#+begin_x` … `#+end_x`        | `keyword` · `content`         |
| `#+KEYWORD:` directive         | `meta`                        |
| `# ` comment                   | `lineComment`                 |
| `-` `+` `1)` bullets           | `list`                        |
| `[ ]` · `[X]`                  | `marks.checkbox` · `marks.checked` |
| tables and separator rows      | `marks.table`                 |
| `-----` rule                   | `contentSeparator`            |
| `*b* /i/ _u_ +s+ =v= ~c~`      | `strong` · `emphasis` · `link` · `strikethrough` · `marks.verbatim` · `monospace` |
| `[[t][d]]` · `[[t]]`           | `link`                        |
| `[fn:1]` · `<<target>>` · `{{{macro}}}` | `marks.footnote` · `marks.target` · `macroName` |
| `\(…\)` · `\[…\]` · `$…$` · `\alpha` | `special(content)` · `character` |

Three rules that are org's and not markdown's, each with its own test —

- **the keyword only counts in the first slot.** `* TODO file it` marks TODO; `* file the TODO later` does
  not. The sets are the caller's: `org({ todo: ["OPEN"], done: ["SHIPPED"] })`.
- **emphasis has an open and a close rule.** A marker opens only after whitespace or an opening bracket and
  with a non-space after it; it closes only against a word and before whitespace or punctuation. So
  `a * bold * b` is not bold, `2*3*4` is not bold, and `a *bold *` is not bold.
- **only its own `#+end_` closes a block.** `#+end_quote` inside `#+begin_src` is body.

FOLDING rides along as a `foldService`, so it needs no parse tree: a headline folds to the next headline of
its level or shallower (the last one to the end of the document), a block to its own end, a drawer to
`:END:`. This is what the App's outline already does to the text — now the editor does it to the source.

LATER, marked: the language named on `#+begin_src js` does not highlight its body. That is the same call as
the markdown fence — it would pull `lang-javascript` and its neighbours back into the graph.

*** THE ACTUAL CAUSE — =markdown= was never a valid Language (found from his console)

His console, as soon as he typed:

#+begin_src text
Uncaught TypeError: this.parser.hasWrappers is not a function
    get allowsNesting · topNodeAt · languageDataAt · indentOnInput
    filterTransaction · resolveTransaction · update · applyDefaultInsert · applyDOMChange

=languages.js= built markdown as =new LanguageSupport(LRLanguage.define({ parser }))= over
=@lezer/markdown='s parser. That parser is a =MarkdownParser=, NOT an =LRParser=, and
=LRLanguage.allowsNesting= is =return this.parser.hasWrappers()= — a method only an LR parser has. It
throws inside =filterTransaction=, so **every input transaction was aborted**: the browser wrote the
character into the contenteditable, CodeMirror's state never advanced, and the drawn cursor stayed frozen
at the last state it knew. That is the whole symptom, and it had nothing to do with the two defects fixed
in the pass before it.

Only =LRLanguage= calls =hasWrappers=. Base =Language.allowsNesting= returns =true=; =StreamLanguage='s
returns =false=. So **org was always fine and markdown was always broken** — and a JDex note is =.md=, so
it broke on every keystroke he ever typed. Reproduced headless across the whole format list, before and
after:

The fix keeps the bare lezer parser (no =@codemirror/lang-markdown=, no +195 kB) and builds the Language
the way a non-LR parser must be built — base =Language= with its own facet, the top node carrying it:

#+begin_src js
const prose = defineLanguageFacet({ commentTokens: { block: { open: "<!--", close: "-->" } } });

const markdownLanguage = new Language(
  prose,
  parser.configure({ props: [languageDataProp.add((type) => (type.isTop ? prose : undefined))] }),
  [],
  "markdown",
);
#+end_src

WHY THE SUITE MISSED IT: the format test asserted =language(format).language.parser= was defined — a
property read that never touches =allowsNesting=. It now runs a real transaction through =indentOnInput=
for every format plus =txt=, which is exactly the path that threw, and pins
=allowsNesting= true for markdown / false for org.

      if (update.docChanged) text = update.state.doc.toString();

        oncaret?.(update.state.doc.lineAt(update.state.selection.main.head).number);
