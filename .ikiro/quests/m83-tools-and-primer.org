* the law

- a TOOL is any Vector node ={ nature, valence, input }= the model may call; whether its body drives the controller is the body's business. No SKILL tier, no =skills= word in code. A tool and an aperture route differ by AUDIENCE only (model · client).
- a hallucination HAS a =primer=: a =Primer= minted fresh per request by =requesting=, thrown away with it. =system= is the loaded record the cortex and the providers see (H).
- =Primer= is a Vector type beside =Twitch=: =open(pattern, effect)=. An effect is a string, a function returning a string · =null= (absent) · a =Primer=, or a =Primer= itself (grafted at that branch). A pattern is ={ nature, valence?, load? }=; =load= defaults to =eager=; =lazy= on a branch reaches every node under it, the nearest declared wins. Natures are flat paths at the call site (=guides/render=), never a nested =new Primer()=.
- =shape.primer.load= transposes at the harness's effect sites: =eager= → a section keyed by its nature, in graft order; =lazy= → one line =<nature> — <valence>= in ONE index section, and ONE tool =primer_read { nature }=, armed only when a lazy node exists. The transposer is typology-deep, no file system.
- a read lands in the TURNS as a tool result, never edits a primer — the cached prefix (primer · tools) stays byte-equal; a body read once stays on the thread.
- files reach a primer ONLY through =paladin.prime.<verb>(path)=, which returns a =Primer=. Deno never in the runtime or a mode: no raw import, no =Deno.*=. =paladin.read= keeps raw files, =frontmatter= among them.
- =paladin.prime.directory(path)= — one node per file, nature = its path under =path=, sniffed PER FILE: a standard frontmatter (=description=) → ={ valence: description, load: "lazy" }=; our frontmatter → the pattern as written; none → eager. The body is read per call.
- =path= is OUR =Path=: =new Path(import.meta.resolve("./x"))= or =new Path(import.meta.url).branch("../x")=; =Path= strips =file://= and knows =..=; =Pattern= does not.
- =PRIMER= mints =mode.primer = new Primer().graft(mode.module.primer)=; a mode without it has no =mode.primer=. A domain is just another mode.
- =requesting= builds the request's primer: the mode's (when present) · the domain's under its slug · for an AGENTIC mode every sibling's under its slug, lazy. No persistent mode is written.
- the choice round's record is =system= (I); a provider keeps its own word at the boundary.
- REJECTED: =() => TEXT= wrappers with =load: "eager"= at every site (F) · a lazy default (F5) · two strings on an output · lazy by an absent =valence= · a lazy load editing a primer · one tool per lazy node · a tier split by the controller · raw =import … with { type: "text" }= in a mode · =Deno.readTextFile= in a trait · the nested =branch({ load: "lazy" }, new Primer().open(…))= (/"your option A example is kind of weird"/) · =paladin.primer.skills= · a =skills= verb or a =SKILL.md= layout case (Q5) · =leaf= · =signature= for a pattern · =new URL(…)= at a call site · a coercion through =URL= · a =(base, relative)= pair (Q2) · =..= on =Pattern= · the population seat (Q6) · AGENTIC writing foreign primers onto =mode.primer= (Q7 — /"I don't think your mental model here is correct."/) · AGENTIC requiring PRIMER (Q8).
