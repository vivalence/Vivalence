* the law

- a TOOL is any Vector node ={ nature, valence, input }= the model may call. Whether its body drives the controller is the body's business; =valence= says what it costs (=research.js:24= /"It costs a minute and several model calls"/). No SKILL tier, no =skills= word in code.
- a tool and an aperture route differ by AUDIENCE only (model · client), never by capability.
- a hallucination HAS a =primer=: a Vector, or an already-transposed record. A leaf returns a string, sync or async; =null= = absent; anything else throws.
- =Primer= is a Vector type beside =Twitch= (=subsystems/typology/prototypes/primer.js=): =open(signature, leaf)= takes a string or a function, sync or async. It nests. A node's signature is ={ nature, valence?, load? }=; =load= defaults to =eager=; =lazy= set on a branch is inherited by every leaf under it. A record is sections already — what the transposer returns. The short text is the =valence= (known without running the leaf); the long text is the leaf's output. Two levels; a third comes free: a body names deeper natures, read the same way.
- =shape.primer.load= transposes (the harness, at its effect sites, into =system=): =eager= → a section keyed by its nature path, in graft order; =lazy= → one line =<nature> — <valence>= in ONE index section, last of the stable sections, and ONE tool =primer_read { nature }=, armed only when a lazy node exists.
- a read lands in the TURNS as a tool result, never edits the primer — the cached prefix (primer · tools) stays byte-equal; a body read once stays on the thread.
- the transposer is =shape.primer= in =subsystems/typology/gestalten/shape/primer.js=: typology-deep, no file system. A file read is a leaf the trait supplies through paladin.
- the choice faculty's =primer= is the same primer (F2): a =Primer= or a record, lowered by the same transposer; it holds no lazy node (F).
- =PRIMER=: the mode exports =primer=, a =Primer=; the trait grafts it onto the hallucination's primer. =<mode dir>/primer/**/*.md= → one node each, nature = its path under =primer/=, signature = its frontmatter, body read per call — to be re-cut in the work (F named the export, not the files). Another harness loads a mode's primer as a branch under its slug, the way =AGENTIC= branches tools (=systems/runtime/lifecycle/mode/traits/agentic.js:9=).
- a provider keeps its own word at the boundary (Anthropic's param stays =system=).
- REJECTED: =primer.open({ nature, load: "eager" }, () => TEXT)= at every site (F) · a lazy default (F5, reversed by F) · renaming the choice faculty's =primer= (F2) · a tier split by the controller or an Activity (m81 =:241= rejected both) · two strings on the output (the short one would need the long one loaded) · lazy by an absent =valence= · a lazy load editing the primer (breaks the cache) · one tool per lazy node (the tool list grows; the index lives with the text).

// subsystems/typology/gestalten/shape/primer.js
import { is, steer } from "@vivalence/typology";
import { fire } from "../steer/strategy.js";

const key = (steps) => steps.map((step) => step.nature).join("/");

const loading = (steps) => steps.findLast((step) => step.load)?.load ?? "eager";

const leaves = (primer) =>
  steer.trie.rollup(primer, (carry, effect, steps) => effect).map(({ pattern, steps, fn }) => ({
    nature: key(steps),
    valence: pattern.valence,
    load: loading(steps),
    leaf: fn,
  }));

const text = async (leaf, ctx) => (is.fn(leaf) ? await fire(leaf, ctx) : leaf);

export const lazy = (primer) => leaves(primer).filter((node) => node.load === "lazy");

export const keys = (primer) => leaves(primer).filter((node) => node.load === "eager").map((node) => node.nature);

export const index = (primer) =>
  lazy(primer).map((node) => `${node.nature}${node.valence ? ` — ${node.valence}` : ""}`).join("\n");

export async function load(primer, ctx = {}) {
  const sections = {};
  const deferred = `Read on demand with primer_read { nature }:\n${index(primer)}`;
  for (const node of leaves(primer)) {
    if (node.load === "lazy") {
      sections.primer = deferred;
      continue;
    }
    const body = await text(node.leaf, ctx);
    if (body != null) sections[node.nature] = body;
  }
  return sections;
}

export async function read(primer, nature, ctx = {}) {
  const node = leaves(primer).find((node) => node.nature === nature.replace(/^\/+/, ""));
  if (!node) throw new Error(`[primer] no node at '${nature}'`);
  return await text(node.leaf, ctx);
}
