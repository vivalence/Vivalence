* the law

- one schema, one table per kind, FIXED at the kernel; a daemon is a COLUMN and a REPOSITORY, never a class, a file, a namespace or a second ORM. The schema's only authority is the libsql =Migrator=; nothing calls =schema.update= at runtime. REJECTED 10-07: STI / TPT (strand Z).
- customisation has two directions and no third: the REPOSITORY (per daemon, per kind — scope + verbs) and the TRAIT (schematic + verbs, payload under =row.trait[NAME]=). A trait never adds a column or a row method; a sort over a payload field is =json_extract= with an expression index.
- a domain brings traits, schematics, aperture routes, tools, a twitch — never a table, never a class, never a subscriber. Education's retention code (bayesian · boolean · counter) is education's and stays there.
- a row has a trait by CLAIM (=traits[]=); a trait verb on a row without the claim throws through =v.<kind>.trait= (=subsystems/typology/schematics/v.js:123=).
- the instance file is paladin's; the runtime reads it at boot, diffs against its rows, installs what is missing, prunes on =--prune=, and writes composition changes back through =paladin.state.scribe= from =Daemon.mask= over the RAW file — a =${KEY}= never expands into the file. Rows win running, JSON wins at boot. (V Z)
- the runtime publishes the registry it supplied (=/metadata/registry=) and mutates it only through paladin's ledger verbs (=registry.tap= · =untap=). (J)
- the lighthouse authenticates on the protected BRANCHES (=/daemon/*= · =/userspace= · =/registry= · =/instance=), never the root; =ctx.user= is bound behind each; =/attached/*= · =/metadata= · =/status= · =/lighthouse/*= are open; no route verifies a token by calling itself. (F N Z)
- a query from inside a daemon runs through the daemon's REPOSITORY (=daemon.entities.<kind>=), which scopes =daemon= — never through the kernel repository (=em.getRepository(Literal)= sees every daemon). Mode · Activity · the userspace kinds carry no daemon scope: a lifecycle query over them names =daemon= or =user= explicitly.
- ONE subscriber exists (=shape.subscriber= on the runtime datamap); it feeds the runtime twitch; a daemon's branch filters by =entity.daemon=; a domain or a mode hears the KIND's name — =/after/literal/create= — never a daemon's. (Q Z)
- the domain is a trait SOURCE like any kernel entry, never a class, a layer or a table. /"The domain does not play in here. The domain might configure stuff, but so might any other mode."/ REJECTED 10-07: an abstract class per domain — my probe's invention, void.
- =traits= on Literal · Symbol · Note is a JSON string array; the vocabulary is the daemon's composed trait set; the ORM enum dies for these kinds.
- no data crosses: every db on every shelf is dropped; a user signs up again. (Z)

#+begin_src javascript
// subsystems/paladin/belt/expand.js — replaces belt/hydrate.js: no thunks fire, no Proxy watches; a "${KEY}" is read through the strata and RECORDED
const REFERENCE = /^\$\{([A-Z0-9_]+)\}$/;
const INLINE = /\$\{([A-Z0-9_]+)\}/g;

export default function expand(paladin) {
  const read = (key) => (key.startsWith("SECRET_") ? paladin.secret.get(key) : paladin.env.get(key));
  const blank = (value) => value === undefined || value === null || value === "";
  // a whole-string reference keeps the value's TYPE (a number stays a number, a blank secret stays null);
  // a reference inside a string interpolates as text — "${VIVA_RUNTIME_ORIGIN}/" the way Env already reads a .env default
  const walk = (node, record, at) => {
    if (typeof node === "string") {
      const whole = REFERENCE.exec(node);
      if (whole) {
        const value = read(whole[1]);
        record?.push({ at, read: [whole[1]], unset: blank(value) ? [whole[1]] : [] });
        return value;
      }
      const keys = [...node.matchAll(INLINE)].map((match) => match[1]);
      if (!keys.length) return node;
      const values = Object.fromEntries(keys.map((key) => [key, read(key)]));
      record?.push({ at, read: keys, unset: keys.filter((key) => blank(values[key])) });
      return node.replace(INLINE, (_, key) => values[key] ?? "");
    }
    if (Array.isArray(node)) return node.map((value, index) => walk(value, record, `${at}[${index}]`));
    if (node?.constructor === Object)
      return Object.fromEntries(Object.entries(node).map(([key, value]) => [key, walk(value, record, at ? `${at}.${key}` : key)]));
    return node;
  };
  paladin.expand = (node, record = null, at = "") => walk(node, record, at);
  // the doctor's scan: every "${KEY}" in a recipe, by path, before anything is read
  paladin.expand.scan = (node, at = "", found = []) => {
    if (typeof node === "string") {
      const match = REFERENCE.exec(node);
      if (match) found.push({ at, key: match[1] });
    } else if (Array.isArray(node)) node.forEach((value, index) => paladin.expand.scan(value, `${at}[${index}]`, found));
    else if (node?.constructor === Object) Object.entries(node).forEach(([key, value]) => paladin.expand.scan(value, at ? `${at}.${key}` : key, found));
    return found;
  };
}

// repository verbs that read or write it. a row HAS the trait by claim (row.traits includes name); v.<kind>.trait gates.
export function defineTrait(name, { schematic = null, verbs = {} } = {}) {
  return { name, schematic, verbs };
}

export function applyVerbs(Repository, traits) {
  for (const held of traits)
    for (const [key, verb] of Object.entries(held.verbs))
      Object.defineProperty(Repository.prototype, key, { value: verb, writable: true, configurable: true });

  return traits;
}
