* nomenclature

| word       | is                                                                     |
|------------+------------------------------------------------------------------------|
| run        | one lifecycle vector per process type, =run.daemon=                    |
| lifecycle  | a middleware on a run, =(die, next)=                                   |
| die        | =mask= + =runtime= · =service= · =daemon= · =mode= + what the run owns; a process's with its =controller= |
| birth      | population: the parent creates the process with its controller; IDLE   |
| boot       | resolution: the parent executes the child's run; RUNNING               |

|----------------------+------------------------------------------------------+--------------------------|
