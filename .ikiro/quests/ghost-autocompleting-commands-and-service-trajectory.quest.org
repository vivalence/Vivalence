* Intent

Restore the *walking autocomplete* command UX and *service trajectory tree*
that lived in the ghost-era predecessors (=system/clients/shell/= 2025-08,
=packages/clients/cli/= 2025-05). User types a partial signal (=viva services=);
the walker advances as far as it can; at each fork it prompts a =Select= built
from that node's child docs; resolves to an effect. Services and runtimes
contribute their own subtrees declaratively — no central command registry.

** Trajectory core

#+begin_src ts
// subsystems/shared/src/trajectory/core/trajectory.ts
open(patterns, effect) {
  patterns = this.parse(patterns);
  this.branch(() => patterns.slice(0, -1))
      .effects.set(patterns[patterns.length - 1], effect);
  return this;
}
branch(patterns) {
  patterns = this.parse(patterns);
  if (patterns.length === 0) return this;
  let descendant = [...this.descendants.entries()]
      .find(([p]) => p.hash === patterns[0].hash)?.[1];
  if (!descendant) {
    descendant = new Trajectory(this.parsers);
    this.descendants.set(patterns[0], descendant);
  }
  return patterns.length > 1 ? descendant.branch(() => patterns.slice(1)) : descendant;
}
match(signal) {
  for (const [pattern, effect] of this.effects.entries()) {
    const match = pattern.match(signal);
    if (match !== null) return { signal, pattern, match, effect };
  }
  for (const [pattern, descendant] of this.descendants.entries()) {
    const match = pattern.match(signal);
    if (match !== null) return { signal, pattern, match, descendant };
  }
  return null;
}
#+end_src

* Nifty bit 2 — walking autocomplete (Walker + Prompt.Select)

The headline UX. Partial signal → walker advances → at fork, asks user to pick
from available branch docs → repeats until an effect resolves.

** Entry

#+begin_src js
// system/clients/shell/lib/run.js (2025-08)
import { parsers, Walker, Deferred } from "@vivalence/shared/trajectory";
import { Prompt } from "@vivalence/interface/shell";

export default async (client) => {
  const signal = parsers.sig.signal(Deno.args.join("/"));
  const deferred = new Deferred();
  const walker = new Walker(client.trajectory, deferred);

  await walker.walk(signal, async (docs) => {
    const selection = await Prompt.Select.prompt({
      message: "",
      options: docs.map((d) => d.segment),
    });
    return parsers.sig.signal(selection);
  });

  const handler = await deferred.handler;
  const result = await handler({}, { locals: client.tools, tools: client.tools });
  return client;
};
#+end_src

** Walker loop — async drain with prompt callback when signals run out

#+begin_src ts
// controllers/walker.ts
async walk(signals = [], getSignal) {
  let maxSteps = 20;
  while (!this.resolved) {
    if (0 > maxSteps--) throw new TraversalError(null, "MAX_STEPS_REACHED");
    if (signals.length > 0) {
      steps.push(await this.traverse(signals.shift()));
    } else {
      signals.push(...(await getSignal(this.trajectory.docs)));   // ← AUTOCOMPLETE HOOK
    }
  }
}

async traverse(signal) {
  this.stack = [...this.stack, ...this.trajectory.middlewares];
  const match = this.trajectory.match(signal);
  if (!match) {
    throw new TraversalError(signal,
      this.trajectory.types.includes(signal.type)
        ? "NO_PATTERN_MATCHED" : "PATTERN_TYPE_NOT_FOUND");
  }
  if (match.effect)          this.resolve(match.effect);
  else if (match.descendant) this.trajectory = match.descendant;
  return match;
}
#+end_src

** UX shape

Type =viva services= → walker fills =services=, then prompts =Select= listing
every child segment. Pick one → next prompt. Until effect resolves. Tab/return
flow native because each fork is a real prompt.

* Steal recommendations (for ghost today)

- *Walking autocomplete* — partial-signal → Walker + sheets =Select= (drop
  =@cliffy/prompt=). Mechanism is library-free; only the prompt is.
- *Trajectory tree* — already relates to existing patterns/Signal grammar.
  =branch=/=open=/=match= triad + walker = one of the cleanest dispatch
  designs you had. Reuse it for ghost command surface.
- *Variadic flag builder* — pattern for any external CLI (ffmpeg, docker, jj).
  Drop straight into ghost's tool layer.
