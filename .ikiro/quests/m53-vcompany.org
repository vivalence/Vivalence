** laws — what held

- the house mechanism: an ontology IS the one TOPOGRAPHICAL symbol on a literal (the subscriber throws on two); traits carry payload shape; symbols classify. A domain extends the runtime literal with its trait enum and repository verbs.
- FOUR ontologies on one literal: =vdex= (a file on the mount) · =message= (a message on a channel; channel = a symbol dimension, =MAIL= · =CHAT= carry the channel-shaped fields) · =event= (a span on a calendar) · =transaction= (empty). Trait nouns, never participles: =DOCUMENT= · =MESSAGE= · =MAIL= · =CHAT= · =EVENT= · =TRANSACTION=.
- the vdex slug = deepest JD coordinate · folded stem · extension (=22.04.re24-05277.pdf= · =12.notes.md= · =readme.org=). Directories never enter the slug; =DOCUMENT.asset.path= is the truth on disk. A JD id is a SYMBOL (=vdex.id.22.04=), a file is a LITERAL. A =NN.00= index file's title labels its coordinate (Johnny.Decimal's rule = the docs site's =jdex.js= rule).
- the vdex is a dataset SOURCE: typology =reader.load= (=load(mode) → rows=, =stamp(mode) → string=), =load.js= = two loaders over ONE scan, DATASET installs, BOOTED prunes inline through the em and WATCHES (=Deno.watchFs= → =sync(paths)= → per-path rows → the twitch). No fingerprint comparison: an unchanged file is an =assign= with no diff.
- the vdex speaks SLUGS, never paths: eight verbs (=index find read write file move delete open=) implemented ONCE in the aperture, the tools an application over =ctx.mode.call.<verb>=; =open= is an EMITTER (=/emit/open= → the App buffer). Three faces, one body.
- the harness index is ROWS: every coordinate, every document as =slug · title=, no fold, no budget.
- the mode boundary: nothing under a mode imports outside its directory; package fixtures live at the package root (=tests/scenarios.js=); the domain reaches modes at runtime, never by path.
- the ignore doctrine: ONE glob list (=paladin.belt.ignore.IGNORE=, =*.bak= as data), =skip(globs)= compiled once; the walker's head takes the list beside the pattern (=find.walk(pattern, ignore)(root, depth)=); a caller's list is the WHOLE list (no union); =describe= is a stat; index-ignore ≠ vcs-ignore.
- masking is PALADIN's: the kernel entry ={manifest, module, mountpoint, statics, secrets}= is hydrated at the pinhole, =dress= converts a declared ABSOLUTE mountpoint (relative THROWS, blank stays REQUIRED, none stays none — nothing minted), =integrate= creates declared dirs at init, =accioOne= folds statics AND manifest module-under-instance and VALIDATES the manifest (=v.primitives.Manifest=); the runtime only READS.
- manifest is the ONE identity record: =mode.manifest.{type,slug,name,traits}= everywhere on the citizen; =mode.module.manifest= = the registry identity; the DB ROW stays flat (=(slug, type)= unique, the FK from literal/symbol) — the citizen carries a manifest, the row stays flat.
- mode OWNS rows, single owner: =Literal.mode= · =Symbol.mode= are m:1 nullable, unique =(slug, mode)=; the declared scheme (=dataset/symbols.js=: the ontology marker, formats, slots) is SHARED and unowned; what a mount COMPUTES (=load=) is owned. Every vdex read is scoped by MODE, never by ontology. The prune keep-set reads the MOUNTING's slug (=typeSlug(mode)=), never =manifest.slug= of the module.
- FRAUGHT vs MOUNTED: a mode that ships files declares =FRAUGHT= + =Freight(<subdir>)= (root = =module.mount.dirname=); one that serves an operator's tree declares =MOUNTED= and no freight (root = =mode.mountpoint.absolute=). The three cargo sites ask either.
- a path is not a url: =URL.pathname= escapes — decode on the way out, encode PER SEGMENT on the way in (=freight.js= minting + =resolve()=; =paladin.skills.resolve=). Found twice.
- the provider seam: an office mode names its provider in ONE static (=provider: "dummy/mail"=) and resolves it at call time through =daemon.flatmodes()= (=provider.js=, one refusal); the routes are the contract, not the module. A dummy is the vendor called "none": it owns BOTH directions — a demo DATASET in, a recording aperture out, a DATASINK round-tripping the file its dataset reads (the disk file IS the mailbox). Statics live at mask level; a dummy declares none and refuses by name.
- the held send: an officer's =reply= HOLDS (=MESSAGE.hold {by, at}= + =message.status.held=); =/key= is the ONLY route that clears it and is NOT armed as a tool. Officer writes, human sends. Same asymmetry on the calendar: =create= · =move= armed, =delete= not.
- a series is a MASTER with its RFC 5545 =rrule=, expanded in memory for the asked range (=occurrences.js=); an occurrence's slug is =master@YYYY-MM-DD=; =/move= refuses a series.
- =MESSAGE.external= = ={account, id, thread, etag}=; =external.thread= is the VENDOR's grouping and never the threading edge — threading is the literal's own =uses=/=in=; a mail thread is MESSAGES (the walker filters =ontology === "message"=; events that reference a mail are the calendar's view of it).
- coordinates cross ontologies: mail and events take =vdex.category.*= / =vdex.id.*= symbols — one coordinate groups documents, mail and the calendar.
- an App's keys live on its root (=role="presentation" tabindex="-1"=), never =svelte:window=; ⌥ reads =event.code=; rows are =$state.raw=; every wire call lands in the status bar, a refusal in danger ink; the twitch replaces the row in place, never a refetch; drafts survive a switch; sections are cut from TEXT (line ranges), never the AST; every overlay takes dapper =skeleton-4= (there is no zone 5); the tool envelope is m26's ={condition?, output:{message?, object?, literal?:[], buffer?:[]}}=, entity keys SINGULAR.
- a design-phase App is READ AGAINST THE ROWS SNAPSHOT before landing (the READY draft had =symbol.vdex.id= wrong — it is ={cat: id}=, a string-leaf fold).
- =stable()= blanks uuid VALUES, never drops a KEY named =id=.
- the installer's own source seeds EVERY dataset stamp — editing =traits/dataset.js= reinstalls every mode once on every instance, then silence.
- the literal↔symbol m:n cascades REMOVE both ways: every boot pass rides an em FORK; the fold is an UPDATE fact (fresh rows are touched once); =row()= refs carry no traits (mint from =coordinates(path).symbols=).
