* Intent

The C panel is the host (=app/panels/c/c.svelte=) that splits into D · E · F.
Rebuild all three as the terminal control surface, driven by the active
=terminal= (=$thread= · =$buffer=) and the daemon/mode metadata.

- *D* — daemon→mode tree (§1) + threads-per-daemon (§2) + intents-per-daemon (§3).
- *E* — active info (§1: reactive mode label + the *mode's* traits) + trait bar (§2: the controllable *thread* traits, each with its widget) + intent management (§3, dummy).
- *F* — factory (§1: create/emit/start) + active buffer (§2: =terminal.$buffer=) + buffer list (§3: =thread.$buffers=).
- *A* — renders =terminal.$buffer= via drapes =Frame= (=import(buffer.mode.view.url)=).

Underneath: a unified *=/metadata/<topic>=* self-description surface replaces the
scattered =/manifest= =/cargo= =/datamap= =/buffered= routes, and the
masked·aimed·queueing traits consume the schema topics (=view=, =emitter=) it serves.

* Terminology

| term | definition |
|------+------------|
| terminal | client workspace; owns =$thread= + =$buffer= (active buffer) + =stall=. Active buffer is *terminal-owned*, not thread-owned. |
| thread | live session on a mode. Atoms: =$mode= =$traits= =$trait= =$label= =$buffers=. Mode is *replaceable* on a live thread. |
| thread traits | LABELED · MASKED · AIMED · QUEUEING — the *controllable* set (the E trait bar). LABELED+MASKED always-on; AIMED+QUEUEING opt-in toggles. |
| mode traits | VIEWABLE · EMITTER · FRAUGHT · HARNESSED · … — the mode's *capability* set (shown in E §1 "traits"). |
| Mask (capital) | the *schema* a form renders from. =thread.trait.MASKED= = the *data* the form produces. |
| factory | F §1 — create (direct buffer from MASKED) / create·emit (aimed pull) / start·stop (queueing Stall). |
| /metadata | the aggregated self-description surface. =/metadata/<topic>=, topics trait-contributed, no index/sitemap route (system-level wiring knows the topics). |

* Trait model & the E trait bar

LABELED+MASKED auto-added in =thread/dossier.js= when mode is VIEWABLE.
AIMED available iff =mode.emitter.leaves.length > 0=; QUEUEING available iff AIMED active.
Toggle via =TraitTagIcon= (=+= / =×=) → =thread.updateOne({traits})=. Deactivating AIMED also strips QUEUEING.

Each tag's *body* toggles its widget open (a *Set* — multiple widgets stack, not either/or).
Every widget carries a *head* (trait name + hint) so it self-identifies.

| trait | widget | writes |
|-------+--------+--------|
| LABELED | label input (debounced 5s) | =trait.LABELED.name= + =$label= |
| MASKED | =FormFromSchema= (schema-driven) | =trait.MASKED= |
| AIMED | emitter-mount picker (from =mode.emitter.leaves=) | =trait.AIMED.mount= |
| QUEUEING | depth slider | =trait.QUEUEING.depth= |

** Masked — the two complexities (both solved & verified)
1. *reactive schema switch* — =maskSchema(mode, traits, trait)= in =skins/form/schema.js=: aimed → emitter leaf =input= at =AIMED.mount=; else → view mask's =data=. Picking the aimed mount live-switches the form (view =recall= → emitter =limit/recall/where=).
2. *reactive form from schema* — =FormFromSchema.svelte= + =fields()= (handles intersect/allOf, =anyOf=→enum, integer/number/boolean/string; digs =properties.data= for the view mask).
