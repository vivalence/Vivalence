* law

One law places every responsibility: *a provider translates ONE request; the system folds everything that spans requests.* Loop, retry, transcript, persistence, cache marks, session vocabulary, span records → system (=shard.hallucinate= + =soma.transcript=). Block dialect, cache_control placement, wire parse, fault normalization → provider (=translate.js=, pure).
