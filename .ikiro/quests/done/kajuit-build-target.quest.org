#+AUTHOR: Vivalence

* Intent

Serve the kajuit SPA from the runtime in production without coupling client
to runtime. The seam is a shared paladin declaration, not a direct reference:

#+begin_src
paladin.variant.clients.kajuit.statics.mount.absolute
#+end_src

Both ghost (build side) and runtime (serve side) read this path from paladin.
Neither imports the other. The variant manifest is the single source of truth
for where the built bundle lives.

** Why not couple them

Tying runtime to client (runtime imports/builds/knows kajuit) is a nifty trick
but wrong. Decouple via paladin: the variant declares a =mount= for the kajuit
client; ghost builds the SPA *to* that path; runtime serves *from* that path if
declared and prod. Shared declaration, zero cross-import.

** Production model

- Kajuit is a Svelte/vite SPA → build-time, not run-time. No client process in
  prod.
- =vite build= → static =dist/= written to the client mount.
- Runtime's aperture serves =dist/= as a root catch-all fallback (API routes win
  by router precedence; unmatched paths → SPA / =index.html=).
- One process (runtime) serves API + client. One listener.
- Dev unchanged: kajuit stays a separate =vite dev= watch (HMR); runtime skips
  the static step via =paladin.is.dev=.

* Mount location

Mountpoint, per-client subdir — mirrors the daemon/service mask convention:

#+begin_src
<variant>/mountpoint/client_kajuit/
e.g. /Users/finn/vivalence/code/vivalence/testament/variant/mountpoint/client_kajuit
#+end_src

The variant declares it (explicit in marker), else paladin autocompletes the
default. =mount= must be a =Path= (=.branch= / =.absolute=).

* The serve route (decided)

Runtime aperture, prod-only, inserted LAST (insertion-order = fallback):

#+begin_src js
runtimeDie.good.aperture.open("/(.*)", async (input, ctx) => {
  const rel = fromm.params(ctx.params).path.absolute;
  const file = (await exists(join(dist, rel))) ? join(dist, rel) : join(dist, "index.html");
  ctx.response.type = contentType(extname(file)); // @std/media-types
  return await Deno.readFile(file);
});
#+end_src

Router precedence (verified in =steer/navigate.js= + =match.js=):
- Multi-segment API (=/daemon/x=, =/attached/y=) → =feed= prefers trajectory on
  =signal.heir= → API branch wins.
- Leaf API (=/status=) → literal effect beats =(.*)= remainder by insertion order.
- Unmatched (=/assets/app.js=, =/learn/verbs=, =/=) → root =(.*)= → serve dist.

Precedent: runtime already serves static via aperture —
=/attached/view/*= (mode JS) and =/attached/cargo/*= (=Deno.readFile= + =ctx.response.type=,
=systems/runtime/lifecycle/resolve.js:26,54=). =shape.http= =respond()= already wraps
=Uint8Array= into a =Response= (=http.js:67=). This route is the same move.

* Build tasks (a–d)

** a. autocomplete mount if missing — =subsystems/paladin/prototypes/variant.js=

In =resolve()=, after =hydrate(cake.clients)=. Clients are plain objects (not
masked), so default-fill + coerce to =Path=:

#+begin_src js
variant.clients = hydrate(cake.clients ?? {});
for (const [slug, client] of Object.entries(variant.clients)) {
  client.statics ??= {};
  client.statics.mount = new Path(
    client.statics.mount ?? variant.paladin.scope.mountpoint.branch(`/client_${slug}`),
  );
}
#+end_src

=??= so explicit marker declarations win. =new Path()= coerces an explicit string
into a Path (=.branch=/=.absolute= safe). Same =scope.mountpoint.branch= pattern as
the daemon/service mask.

** b. build to that path — =vite build --outDir <mount>=

- *docker*: fixed bake path baked into image (e.g. =/viva/mountpoint/client_kajuit=);
  =vite build= at image-build time; runtime reads same mount at runtime.
- *instance/init*: =deno run -A npm:vite build --outDir <mount.absolute>=, cwd
  =systems/kajuit=. Only if kajuit declared + =!paladin.is.dev=.

** c. runtime lifecycle fn — =systems/runtime/lifecycle/= (resolve.js family)

#+begin_src js
export async function client(runtimeDie) {
  const mount = paladin.variant.clients?.kajuit?.statics?.mount;
  if (!mount || paladin.is.dev) return; // dev → vite owns it
  const dist = mount.absolute;
  runtimeDie.good.aperture.open("/(.*)", async (input, ctx) => {
    const rel = fromm.params(ctx.params).path.absolute;
    const file = (await exists(join(dist, rel))) ? join(dist, rel) : join(dist, "index.html");
    ctx.response.type = contentType(extname(file));
    return await Deno.readFile(file);
  });
}
#+end_src

Wire LAST in the lifecycle sequence.

** d. ghost instance/init change — =systems/ghost/trajectories/instance/init.js=

After env/user scaffold, add client build step:

#+begin_src js
const kajuit = ctx.variant?.clients?.kajuit;
if (kajuit?.statics?.mount && !paladin.is.dev) {
  await paladin.state.dir(kajuit.statics.mount.absolute);
  await new Deno.Command("deno", {
    args: ["run", "-A", "npm:vite", "build", "--outDir", kajuit.statics.mount.absolute],
    cwd: paladin.scope.repository.branch("systems/kajuit").absolute,
  }).output();
}
#+end_src

instance/init = create user · scaffold env · *build client → mount*.
instance/run just serves it.

#+begin_src

#+end_src
