- =client = { mask, controller, runtime, modes, $active, $dock, repl, dispatch }= — =mask= is paladin's =clients[ghost]= row after =wire()=; =runtime = { manifest, reference, remote, connection, lighthouse, entities, daemon, $status }=; terminals are =runtime.entities.terminal= rows; =$active= is the cursor.
- a mode on the client carries =mode.repl = new Vector()= — REMOTE (a row of a host's =entities.mode=, class =prototypes/mode.js=) and HOSTED (a citizen of the client's own =modes=, typology's =Mode=) alike. Traits fill it: =HARNESSED= opens =*= (a turn), =REPLING= grafts the mode's =repling= export (hosted). The composer reads it; nothing else does. A mode without a filled =repl= contributes an empty graft.
- a line that matches no verb is =NotFound= → =track.fault= → a =fault= record on the line's span. So a bare line on a mode without =HARNESSED= answers /"no such verb"/ in the dock, by the mechanism, not a check.
- =terminal.controller = client.controller.branch(`terminal/<id>`)=, branched once where the terminal is met; =thread.controller = terminal.controller.branch(`thread/<id>`)= on seat. Records flow through the ONE root pipe with =path=; =Span.tail(...verbs)= is the filter at a level: the records under THIS span with those verbs, as a store. A message's =data= is what the verb returned — a string (prose) or data; the dock paints a string as a line, a =fault= record as =✕=, a =turn= record as a turn, anything else as a tree. Three HOLY one-liners: =Span.message=, =Span.tail=, =shard.track.message=.
- boot = a Vector of =(clientDie, next)= over =clientDie = { controller, mask, surface, client, register }=, the runtime's grammar; every beat that changes what beef sees marks a message on the span it owns: lighthouse · signed in · runtime mounted · daemon healthy · terminal · home seated · mode seated · application opened.
- HOME this stretch names a HOST mode (runtime or daemon). The terminal lifecycle's =home= beat seats it: no thread + a reference → the owning host awaited =mounted= → =thread.create({ mode })= → =terminal.seat(thread)= → a message. A hosted (client) HOME = a threadless terminal with a client mode = DEFERRED (his r4).
