One sentence: *the environment schema stops being a hand-rolled map of prose and becomes a =v=
schema — the same grammar aperture inputs and entities speak — so the doctor validates VALUES, the
wizard and the scaffold read one object, optionality is =.optional()= and nothing else, and a key
outside the VIVA law is refused the moment the file is imported.*

* the law

* the decision trail

1. *Why a schema and not a fourth field.* The =required: Boolean= marker (landed earlier this session)
   was the right semantics in the wrong vehicle — beef: /"nah. just required: Boolean."/ then, on the
   =v= proposal, /"perfect. brilliant! this is our new meta!"/. Today's format is a strict subset of
   what =v.object= already encodes: =describe= → =.desc()=, =default= → =.default()=, =group= → a
   keyword, =required: false= → =.optional()=. The marker collapses into the grammar.
2. *Values, not just presence.* =hydrate='s =usable()= (instance.js:30) is a heuristic on the PRODUCT
   (=new Url(unset).href === "NaN"=). A declared type lets the doctor cast the RESOLVED value and say
   =INVALID: expected string to match format url= — the third thing that can be wrong, named. m45's
   "only two things are ever wrong" becomes three, honestly.
3. *Observation stops deciding optionality.* m45 II.1 ("required-ness is derived") was a bet that
   the thunk's tolerance is the truth. It was: the ternary =hallucinators= thunk still exists and still
   matters AT RUNTIME (no dead faculty registered). But "is this key owed" is now DECLARED, and
   declared wins outright — =usable= retires from the record. The one thing lost is the drift check
   (declared optional, site dies without it) — the site that lies will fail at boot, loudly, and the
   ternary idiom is the documented way to cope. Accepted.
4. *Key law at import time.* =v.environment()= refuses keys outside the VIVA prefixes. Today a stray
   key is =UNDOCUMENTED= at the doctor, at best. Now the file does not import.
5. *No =v.secret()=.* Secrecy is decided by the KEY (m45's one ingress). A type that duplicated that
   law would be the second reader.
6. *=${VAR}= defaults are never validated.* The default is a raw string on the schema; =Env.get=
   expands on read; the doctor validates the expanded value. Scaffold writes the raw form. Same
   as today, and it is why =v.url().default("${VIVA_RUNTIME_ORIGIN}/")= is legal.
7. *Rows keep their field names.* =describe · group · default · verdict · value · stratum · at= —
   ghost's =Init.jsx= and =Doctor= render rows, not schemas. The schema's =description= is mapped to
   =describe= inside =check=. One consumer-facing surface moves (the declaration); the CLI surfaces
   don't.
8. *One wrong-list.* Three places restate =["UNDOCUMENTED", "REQUIRED"]= today (check.js:96,
   init.js fill, doctor.js WRONG). It becomes =paladin.check.wrong=, read by all three — the =INVALID=
   addition lands once.
9. *Flag-day, no dual read.* beef's standing law (release skill: /"entirely. no dual read."/).
   paladin throws at =mount= if =module.environment= is not a =v= object schema. One recipe on disk,
   one ledger const, two test fixtures — the whole migration.
10. *TypeBox 1.3 facts, measured* (=node_modules/.deno/typebox@1.3.0=): =Format.Reset()= runs at
    import and registers =url= (=IsUrl=); an UNREGISTERED format passes silently (=Format.Test= →
    =true=). =Type.Optional= marks a =~optional= key — a NON-ENUMERABLE string key beside =~kind=
    (=Reflect.ownKeys= sees them, =Object.keys= and =JSON.stringify= do not); =IsOptional= is exported
    from the =typebox= main entry. =Type.String(options)= spreads options onto the schema, so =group=
    rides as a keyword. =Type.Object= computes the object-level =required= array from the
    non-optional properties. CORRECTED at pass 2: the sentence "so =v.url= must use the registered
    name =url=" was wrong — see 11.
11. *=v.url()= is the RFC 3986 grammar, not TypeBox's =url= format and not our schemes.* Measured at
    pass 2: =IsUrl("http://localhost:2501/")= → =false=, =127.0.0.1= → =false=, =ws://= → =false=; the
    registered format wants a TLD. The first replacement, =^(https?|wss?)://\S+$=, was parochial —
    beef: /"rethink the address pattern, build something that is not for our case, but coherently
    universally true."/ What is universally true is RFC 3986 Appendix A; the trap we hit
    (=localhost:2501= parses as scheme =localhost=) is not a defect of the grammar, it IS the
    grammar. So the scalar is one production narrower: *a URI whose hier-part is a network path*
    — =scheme "://" authority path-abempty [query] [fragment]=, every character class from the
    RFC (=unreserved · sub-delims · pct-encoded · pchar=), IPv6 literal collapsed to hex/colon/dot,
    IPvFuture kept, =reg-name= may be empty (§3.2.2, so =file:///x= passes). Scheme-agnostic:
    =libsql:// postgres:// redis:// ws://= pass; =localhost:2501= (no =//=), =${VIVA_RUNTIME_ORIGIN}/=
    and =http://host/${X}= (braces are outside the URI character set), =NaN=, ="", IRIs
    (=münchen=), a second =#= all fail. 35-item corpus, 0 mismatches. Lives in
    =schematics/scalars/url.js= beside =slug= — the scalars family is where pattern-constrained
    strings live — and =v.url = scalars.url=. Considered and dropped: registering the house =Url=
    predicate under TypeBox's =Format.Set("url")= — a global override of a library's meaning,
    hidden from every reader of =format: "url"=.
12. *=v.environment()= unwraps every property to a plain schema.* =enhance= (=v.js:15-23=) gives
    =.default= / =.$id= two roles: getter when the keyword is set, SETTER otherwise — so
    =v.string().default= is a =function=, and so is =v.object({ B: v.string() }).properties.B.default=
    (measured). Every reader in this quest does =held.default ?? ""= (=envfile.scaffold=,
    =init.owed=) or =held.group ?? "other"= — each would have received the setter and printed
    =(val) => enhance(...)= into =.env=. The Proxy is the chain's vehicle and a property inside a
    finished =v.environment= is never chained again, so =environment()= strips it:
    =Object.defineProperties({}, Object.getOwnPropertyDescriptors(held))= — descriptors carry the
    non-enumerable =~optional= / =~kind= across (measured: =IsOptional(plain)= holds, =Type.Object=
    of plain properties still computes =required=). =.group()= joins =enhance= with the same dual
    role, on purpose — symmetry with =.default=, safe because nothing reads a proxied property after
    construction.
13. *Convert before Check; never Default.* A =.env= holds strings. =Value.Check(Type.Integer(),
    "8080")= is =false=; =Value.Convert= makes it =8080= (measured). Without the conversion every
    =v.integer()= / =v.boolean()= key would be =INVALID= forever, and the deferred =v.port()= would be
    born dead. =v.cast= as it stands discards a scalar's converted value (it returns the original
    =value=), so the surface gains =v.convert(schema, value)= and the doctor casts per key with it.
    =Value.Default= is NOT applied at the doctor: it would fill a blank key with its raw
    =${...}= default, turning the bare-recipe picture from =REQUIRED= into =INVALID= — the
    default belongs to the scaffold, which writes it into =.env= where it is a value like any other.
14. *Per-key validation, not one whole-object cast.* The tempting form — build the resolved map,
    =environment.errors(map)= once, let =required= / =additionalProperties= / the type errors fall
    out of the grammar — was measured: TypeBox reports =required= and =additionalProperties= at
    =instancePath ""= with the key only inside the message text. Rows need the key. So =REQUIRED=
    and =UNDOCUMENTED= stay computed from =isOptional= and schema membership, and only the type
    check is TypeBox's, per property. =additionalProperties: false= stays on the object as the
    schema's own statement that it is closed — nothing at the doctor reads it.
15. *No brand on the environment schema.* A =$id= / kind marker was considered so paladin could
    tell "an environment" from "some =v.object=". The flag-day guard needs only =properties= to
    refuse the old map, and the key law already ran at construction; a brand would be a second
    reader of a fact the shape carries.
16. *A pattern failure names the scalar, not the regex.* Found at the live walk: the doctor's
    =reason= column read =must match pattern "^[A-Za-z][A-Za-z0-9+.\-]*://(?:…"= — 400 characters.
    JSON Schema has the keyword for a short human name: =title=. =v.url()= carries
    =title: "RFC 3986 URI with an authority (scheme://…)"= (=description= stays the recipe's prose,
    =.desc()= never touches =title=), and =check.environment= says =must be <title>= when the
    failing keyword is =pattern= and the schema has one. Every other keyword keeps TypeBox's
    message (=must not have fewer than 24 characters=).

#+BEGIN_SRC js :tangle ../../subsystems/typology/schematics/scalars/url.js :mkdirp yes
import { v } from "../v.js";

const PERCENT = "%[0-9A-Fa-f]{2}";
const UNRESERVED = "A-Za-z0-9\\-._~";
const SUBDELIMS = "!$&'()*+,;=";
const PCHAR = `(?:[${UNRESERVED}${SUBDELIMS}:@]|${PERCENT})`;
const SCHEME = "[A-Za-z][A-Za-z0-9+.\\-]*";
const USERINFO = `(?:(?:[${UNRESERVED}${SUBDELIMS}:]|${PERCENT})*@)?`;
const IPLITERAL = `\\[(?:[0-9A-Fa-f:.]+|v[0-9A-Fa-f]+\\.[${UNRESERVED}${SUBDELIMS}:]+)\\]`;
const REGNAME = `(?:[${UNRESERVED}${SUBDELIMS}]|${PERCENT})*`;
const HOST = `(?:${IPLITERAL}|${REGNAME})`;
const PORT = "(?::[0-9]*)?";
const PATH = `(?:/${PCHAR}*)*`;
const QUERY = `(?:\\?(?:${PCHAR}|[/?])*)?`;
const FRAGMENT = `(?:#(?:${PCHAR}|[/?])*)?`;

export const PATTERN = `^${SCHEME}://${USERINFO}${HOST}${PORT}${PATH}${QUERY}${FRAGMENT}$`;

export const url = (opts) =>
  v.string({ pattern: PATTERN, title: "RFC 3986 URI with an authority (scheme://…)", ...opts });
#+END_SRC

#+BEGIN_SRC js :tangle ../../subsystems/typology/schematics/primitives/environment.js :mkdirp yes
import { v } from "../v.js";

export const KEY = /^(VIVA|PUBLIC_VIVA|SECRET_VIVA)_[A-Z0-9_]+$/;

const plain = (schema) => Object.defineProperties({}, Object.getOwnPropertyDescriptors(schema));

export const environment = (properties = {}) => {
  const stray = Object.keys(properties).filter((key) => !KEY.test(key));
  if (stray.length)
    throw new Error(
      `[environment] keys outside VIVA_ / PUBLIC_VIVA_ / SECRET_VIVA_: ${stray.join(" ")}`,
    );
  return v.object(
    Object.fromEntries(Object.entries(properties).map(([key, held]) => [key, plain(held)])),
    { additionalProperties: false },
  );
};
#+END_SRC
