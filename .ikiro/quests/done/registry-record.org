* the law

- the key is the owner the package declares; =slug= is its slug; key + =package= + slug is the identifier =@chess/package/chess=.
- =mount= is absolute, or relative to the record file (inline record: the ledger home) — the ledger parts' rule. Tap writes =./…= when the package sits under the record's dir, absolute otherwise.
- a tap ARGUMENT keeps its frame: a bare name is a folder in =scope.registry=, an absolute path is taken whole (=Registry.stored=).
- =remote= is written only by a tap that cloned; a local tap records none.
- one owner, one mount: tapping an owner already tapped elsewhere throws; a root with two package declarations throws.
- a record its package contradicts throws at mount, naming both identifiers — never mounts a lie.
- the list shape throws on read ("not a registry record: / must be object") — no dual read.
