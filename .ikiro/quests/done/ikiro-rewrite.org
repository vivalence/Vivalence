* the law — the new shape in one line each

1. **a self is small enough to hold whole**: every live `.ikiro` file carries `limit: N chars`; a write past it is refused, never compacted away.
2. **history is data, not prose**: `corpus/` is sealed — read by `methods/corpus.py` (FTS5), never loaded, never hand-edited; nothing is summarized into a second place.
3. **a correction lands where it should have fired**: `retard` · `i dont understand X` → ≤2 lines into the skill or `self.md`, same turn, one line appended to `corpus/callouts.md`. Twice broken → a hook (beef wires). No families · rungs · scoreboard · flywheel · reflection.
4. **a fold is a handoff**: `world/frontier.md` rewritten by hand (≤2000) + each live quest's `* handoff`; no compact file. The transcript under `~/.claude/projects/` is the raw record.
5. **skills are verbs, recipes are nouns**: process skills by verb (change · debug · name · quest · fold), recipe skills by thing (mode · domain · package · topography · design · readme · ops).
