* the law

#+BEGIN_EXAMPLE
Every ikiro file declares a KIND. PERSISTENT files are rebuilt, never trashed: an authored half
(traps, laws, rulings — what the code cannot show) and a generated half (re-derived from the
territory by a script at stamp time). THROUGHPUT files idle at 15% of their cap and drain to an
owner. LEDGERS are append-only.

What loads first primes what comes out: persistent files are CODE and DATA — snippets with their
paths, JSON probes, snapshots, before/after — never prose about code. Prose in the prefix, prose
in the reply.

A file matters only through the channel that loads it. Each persistent file names its channel,
and the channel census measures whether it arrives.

A rule that can be checked is a hook or an instrument. A rule that cannot be checked is a line
in a table of contents, or it is deleted. Compliance is scripted, never begged.

A change to the harness is proven by the eval, never by resembling a better harness: the same
tasks, the same model, pass^k before and after, transcripts read. Deltas under the noise floor
are not results.
#+END_EXAMPLE

*** 1.2 the channel census

*** 1.3 the eval set

- =verified:= stamps name the check that ran (=codemap.py= exit, trap sources resolved).
- Gate: =codemap.py --check= finds no drift between the generated half and the tree; every trap resolves to a source.

*** 2.3 map, ledger, connoisseur
- =world/map.md=: generated from the workspace probe (=deno.jsonc= members, tasks, run surfaces) + an authored line per container.
- =world/ledger.md=: generated from =viva instance/doctor --json= and the ghost trajectories' verb table + the authored traps (the ten kept on 09-23).

- Gate: census relevance ratio up on all three; the eval's code-shape tasks (=imperative-js-reflex=, =fit-existing-trees=) do not regress.

*** 2.4 memory, folded and versioned
- Per F3: memory under =.ikiro/memory/=, version-controlled.
- The index as a table of contents: =project_*= facts that describe the code move to their codemap's traps or their quest; =MEMORY.md= keeps user · feedback · reference and live project pointers.
- Target from the research, not from the hook: the index is read at every wake, so every line is paid every session.
- Gate: =MEMORY.md= ≤ 10 KB; no memory body lost (count before = moved + kept + deleted-with-reason); the eval does not regress.

** step 3 — WIRE the loop: throughput, backpressure, reset, decay

*** 3.1 throughput vectors, formalized
- Each throughput file declares its DRAIN (frontier → quests and known-issues · loop-backlog → quests · =## Open= → quests or trash · MARKERS → the compact that consumes it).
- =hooks/compact-gate.sh= refuses a fold while a throughput file sits above baseline, and prints which drain it owes.
- Gate: the rig exercises the gate against a throughput file above baseline (deny) and a persistent one above 15% (allow).

*** 3.2 the compact as a handoff
- /"reset beats summarize"/: a compact ends in a structured handoff block — =goal · done · next · never · owed=. The next session reads the latest one first; =world/frontier.md= is derived from the live handoffs, not hand-written.
- =methods/compact.md= and =skills/compact-walk= gain the block; =methods/handoff.py= derives the frontier.
- Gate: the frontier regenerates byte-identical from the handoffs; a fresh session given only the handoff lands its next step (one eval task per handoff shape).

*** 3.3 backpressure over prose
- Every rule in the kernel and the skills is sorted: CHECKABLE → a hook, an instrument or a grader in the eval set; UNCHECKABLE → a routing line or deleted.
- Guards emit errors only (/"Backpressure should surface errors only"/).
- Owed rungs from the scoreboard land here as proposals for beef's wiring call: the yap meter warns in-turn · watch-guard → deny · vcs-guard skips heredoc bodies · a narrowed claim-guard.
- Gate: each kernel rule carries its enforcer or its routing role in the table of contents; =hooks/exercise.sh= covers every wired guard.

*** 3.4 the decay audit
- The reflection pass becomes an ABLATION: remove one component (a kernel line, a skill, a shard's authored half, a hook), re-run the step-1 eval subset, keep only what moves pass^k beyond the noise floor.
- Re-run whenever the model generation changes (Opus 5.5 today, Fable 5.1 next) — /"harnesses have to keep getting simpler as models are post-trained on agent trajectories"/.
- Results land as Scoreboard rows, so the harness has a numerator that does not route through beef's attention.
- Gate: one full ablation round recorded; at least one component deleted or kept on the evidence, with the numbers.
