* Intent

Harvest curated Brazilian Portuguese sentence audio from Tatoeba at scale. Replace ad-hoc one-off ingestion with a repeatable, polite, idempotent pipeline. Goal: grow `english-to-brazilian` corpus sentence collection from 270 entries (90 with audio) to ≥1000 with ≥800 audio-attached, all native-BR-verified.

* Boundary

- in: `registry/kernels/@vivalence/corpus/english-to-brazilian/.tatoeba-harvest.ts` + `.harvest/` staging dir + Tatoeba CSV exports + ffmpeg
- out: `.harvest/sentences/<slug>.mp3` (loudnorm-normalized, 96kbps, 22kHz mono mp3)
- state: `.harvest/state.json` (downloaded SIDs + per-day count + failure log)

* Didactic rubric

Sentences valued by their teaching utility, not just availability.

** Tier 0 — survival functional

Greetings (Oi/Tchau/Bom dia), politeness (Por favor/Obrigado/Desculpa/Com licença), yes/no/maybe (Sim/Não/Talvez), self-ID (Eu sou X / Meu nome é X), numbers/quantity (0-100), direction/location (Onde fica X? / Aqui/Ali/Direita/Esquerda), help/emergency (Ajuda! / Cuidado! / Você pode me ajudar?), request clarification (Não entendo / Mais devagar / Repete). Pre-A1 transactional layer.

** Tier 1 — A1 grammar pivots (20 detected)

The construction the sentence visibly demonstrates. Sentences pivoting on exactly one are pedagogically cleanest. Multi-pivot sentences are richer but noisier — used to fill remainder, not lead.

** Tier 2 — A1 functional outcomes (CEFR can-do)

Self-introduction (nationality/origin/age/profession/family), daily routine, preferences (gostar), plans (vou + inf), past actions (preterite), time/date/weather, shopping (price/quantity), food/drink (order/describe), travel (directions/transport), health (doctor/body parts/symptoms). Mapped onto Tier 1 pivots; achieved via curated combinations.

* Selection algorithm

Round-robin across pivots — target 25-30 sentences per pivot for balance. Within each pivot bucket, rank by:

1. fewest total pivots per sentence (cleaner pedagogy)
2. length closest to 22 chars (A1 sweet spot — observed median in confirmed tier)
3. 100% vocab coverage (every token already in corpus = annotation-feasible without new word entries)

After per-pivot quota fills, remainder taken from full pool ranked by same key.

Filters applied to candidate pool before scoring:

- contributor in {Voz, Ricardo14, alexmarcelo, bill, MathKay, GustaBR, brauliobezerra}
- not duplicate of existing 313 sentences (270 in english-to-brazilian + 232 in vocalized, deduped)
- length 12-60 chars
- 0 PT markers, 0 "tu + Vs" patterns
- 100% vocab coverage

Pool size at each gate: 7,214 raw → 6,170 after gates → 1,235 with 100% coverage → 500 after pivot round-robin.

* Tooling

** .tatoeba-harvest.ts

Single Deno script. Args:
- `--input <tsv>` — input TSV (default `.harvest/top500.tsv`)
- `--out <dir>` — output mp3 dir (default `.harvest/sentences`)
- `--state <file>` — state JSON (default `.harvest/state.json`)
- `--quota <n>` — daily limit (default 500)
- `--rate <s>` — seconds between fetches (default 2.0)
- `--dry-run` — log only, no fetch
- `--no-normalize` — skip ffmpeg, save raw

Pipeline per row:

1. Skip if SID in state.downloaded or output mp3 exists (>1KB)
2. Fetch `https://tatoeba.org/audio/download/<audio_id>`
3. ffmpeg loudnorm I=-16 TP=-1.5 LRA=11 → libmp3lame 96kbps 22050Hz mono
4. Write `<slug>.mp3` to output dir; slug = NFD-fold + lowercase + hyphenate + strip non-alnum
5. Update state.json (rewrite every 25 successes)
6. Sleep `rate` seconds before next fetch

** daily quota convention

`state.daily.<YYYY-MM-DD>` counter. Default 500/day. Default rate 2s = 17 min sleep budget per 500. State persists across runs — safe to interrupt and resume. Re-running the same input is idempotent.

* First 500

Initial harvest 2026-04-29. ETA ~21 min for 500 at 2s rate (sleep budget + ~0.5s ffmpeg per item).

*** select_didactic.py — Tier-1 pivot round-robin

Output: `top500.tsv` with cols `sid audio_id contrib len n_pivots pivots text`.

#+BEGIN_SRC python
import re, json
from collections import defaultdict, Counter

with open("/tmp/tatoeba/known_words.txt") as f:
    known = set(w.strip() for w in f if w.strip())
with open("/tmp/tatoeba/existing_sentences.txt") as f:
    existing = set(s.strip() for s in f if s.strip())

pt_pat = re.compile(r'\b(autocarro|comboio|telemóvel|frigorífico|ananás|gelado|pequeno-almoço)\b|(?:está|estou|estás|estamos)\s+a\s+[a-záàâãçéêíõóôú]+r\b', re.I)
tu_pat = re.compile(r'\btu\s+[a-záàâãçéêíõóôú]+s\b', re.I)
CONFIRMED_BR = {"Voz", "Ricardo14", "alexmarcelo", "bill", "MathKay", "GustaBR", "brauliobezerra"}
TARGET_PER_PIVOT = 30

def tokenize(text):
    text = text.lower()
    return [re.sub(r'[.,!?;:¿¡"\'()…—–\-]', '', t) for t in text.split() if t]

def pivots(text):
    t = text.lower()
    p = set()
    if re.search(r'\b(sou|é|somos|são|és)\b', t): p.add("ser")
    if re.search(r'\b(estou|está|estamos|estão|estás)\b', t): p.add("estar")
    if "ser" in p and "estar" in p: p.add("ser-vs-estar")
    if re.search(r'\b(tenho|tem|temos|têm|tens)\b', t): p.add("ter")
    if re.search(r'\b(vou|vai|vamos|vão|vais)\s+\w+(ar|er|ir|or)\b', t): p.add("ir+inf")
    if re.search(r'\b(estou|está|estamos|estão|estás)\s+\w+ndo\b', t): p.add("estar+ndo")
    if re.search(r'\b(fui|foi|fomos|foram|teve|tive|tivemos|tiveram|fez|fizemos|fizeram|pôde|pude|pudemos|puderam|quis|quisemos|quiseram|soube|soubemos|souberam|disse|dissemos|disseram)\b', t): p.add("preterite-irreg")
    if re.search(r'\b(gosto|gosta|gostamos|gostam|gostei|gostou)\s+de\b', t): p.add("gostar-de")
    if re.search(r'\b(quero|quer|queremos|querem|queres)\s+\w+(ar|er|ir|or)\b', t): p.add("querer+inf")
    if re.search(r'\b(preciso|precisa|precisamos|precisam|precisas)\s+\w+(ar|er|ir|or)\b', t): p.add("precisar+inf")
    if re.search(r'\b(posso|pode|podemos|podem|podes|poderia|podia)\s+\w+(ar|er|ir|or)\b', t): p.add("poder+inf")
    if re.search(r'\b(sei|sabe|sabemos|sabem|sabes)\s+\w+(ar|er|ir|or)\b', t): p.add("saber+inf")
    if re.search(r'\b(não|nada|nunca|ninguém|nenhum|nenhuma|nem)\b', t): p.add("negation")
    if re.search(r'\?', t) and re.search(r'\b(onde|quem|quando|como|por que|o que|que|qual|quais|quanto|quanta|quantos|quantas)\b', t): p.add("wh-question")
    if re.search(r'\b(mais|menos)\s+\w+\s+(que|do que)\b', t): p.add("comparative")
    if re.search(r'\b(tão|tanto)\s+\w+\s+(quanto|como)\b', t): p.add("comparative")
    if re.search(r'\b(meu|minha|meus|minhas|seu|sua|seus|suas|nosso|nossa|nossos|nossas|dele|dela|deles|delas)\b', t): p.add("possessive")
    if re.search(r'\b(este|esta|estes|estas|esse|essa|esses|essas|aquele|aquela|aqueles|aquelas|isto|isso|aquilo)\b', t): p.add("demonstrative")
    if re.search(r'\b(em|no|na|nos|nas|sobre|embaixo|atrás|dentro|fora|perto|longe)\b', t): p.add("prep-place-or-time")
    if re.search(r'\b(porque|porém|mas|ou|se|quando|então|mesmo que|embora)\b', t): p.add("conjunction")
    if re.search(r'^(faça|faz|veja|vê|vai|venha|coma|abra|fecha|me|te)\b', t): p.add("imperative")
    return p

with open("/tmp/tatoeba/audios_por.csv") as f:
    for line in f:
        parts = line.rstrip("\n").split("\t")
        if len(parts) >= 3: aid_by_sid[parts[0]] = parts[1]

with open("/tmp/tatoeba/all_audio_sentences.tsv") as f:
    for line in f:
        parts = line.rstrip("\n").split("\t")
        if len(parts) < 3: continue
        sid, contrib, text = parts[0], parts[1], parts[2]
        if contrib not in CONFIRMED_BR: continue
        norm = re.sub(r'[.,!?;:¿¡"]', '', text.lower()).strip()
        if norm in existing: continue
        if len(text) < 12 or len(text) > 60: continue
        if pt_pat.search(text) or tu_pat.search(text): continue

        if not toks: continue
        cov = sum(1 for t in toks if t in known) / len(toks)
        if cov < 1.0: continue
        candidates.append({

            "pivots": pivots(text), "audio_id": aid_by_sid.get(sid, ""),

def quality_key(c):
    return (len(c["pivots"]), abs(c["len"]-22), c["sid"])

buckets = defaultdict(list)
for c in candidates:
    for p in c["pivots"]: buckets[p].append(c)
for p in buckets:
    buckets[p].sort(key=quality_key)

selected = {}
pivot_filled = Counter()
pivot_order = sorted(buckets.keys(), key=lambda p: len(buckets[p]))  # rare first
while len(selected) < 500:
    progress = False
    for p in pivot_order:
        if pivot_filled[p] >= TARGET_PER_PIVOT: continue
        for c in buckets[p]:
            if c["sid"] in selected: continue
            selected[c["sid"]] = c
            for pp in c["pivots"]: pivot_filled[pp] += 1
            progress = True
            break
        if len(selected) >= 500: break
    if not progress: break

# fill remainder
remaining = [c for c in candidates if c["sid"] not in selected]
remaining.sort(key=lambda c: (len(c["pivots"]), abs(c["len"]-22)))
for c in remaining:
    if len(selected) >= 500: break
    selected[c["sid"]] = c

with open("/tmp/tatoeba/top500.tsv", "w") as f:
    f.write("sid\taudio_id\tcontrib\tlen\tn_pivots\tpivots\ttext\n")
    for c in selected.values():
        f.write(f"{c['sid']}\t{c['audio_id']}\t{c['contrib']}\t{c['len']}\t{len(c['pivots'])}\t{','.join(sorted(c['pivots']))}\t{c['text']}\n")

prior = "/Users/finn/vivalence/code/vivalence/registry/kernels/@vivalence/corpus/english-to-brazilian/.harvest/state.json"

candidates = []
with open("/tmp/tatoeba/all_audio_sentences.tsv") as f:
    for line in f:
        parts = line.rstrip("\n").split("\t")
        if len(parts) < 3: continue
        sid, contrib, text = parts[0], parts[1], parts[2]
        if sid in already: continue
        if contrib not in CONFIRMED_BR: continue
        norm = re.sub(r'[.,!?;:¿¡"]', '', text.lower()).strip()
        if norm in existing: continue
        if len(text) < 8 or len(text) > 35: continue
        if pt_pat.search(text) or tu_pat.search(text): continue
        toks = tokenize(text)
        if not toks: continue
        verb_hits = [t for t in toks if t in paradigm_forms]
        if not verb_hits: continue
        cov = sum(1 for t in toks if t in known) / len(toks)
        if cov < 1.0: continue
        lemmas_in = set()
        for v in verb_hits: lemmas_in.update(form_lemmas[v])
        candidates.append({
            "sid": sid, "contrib": contrib, "text": text, "len": len(text),
            "verb_hits": len(verb_hits), "verbs": verb_hits, "lemmas": lemmas_in,
            "audio_id": aid_by_sid.get(sid, ""),
        })

def rank_key(c):
    return (abs(c["len"]-18), -c["verb_hits"], c["sid"])

buckets = defaultdict(list)
for c in candidates:
    for l in c["lemmas"]: buckets[l].append(c)
for l in buckets: buckets[l].sort(key=rank_key)

selected = {}
lemma_counts = Counter()
while len(selected) < 500:
    pivot_order = sorted(paradigm_lemmas, key=lambda l: lemma_counts[l])
    progress = False
    for l in pivot_order:
        if lemma_counts[l] >= TARGET_PER_LEMMA: continue
        for c in buckets.get(l, []):
            if c["sid"] in selected: continue
            selected[c["sid"]] = c
            for ll in c["lemmas"]: lemma_counts[ll] += 1
            progress = True
            break
        if len(selected) >= 500: break
    if not progress: break

remaining = sorted([c for c in candidates if c["sid"] not in selected], key=rank_key)
for c in remaining:
    if len(selected) >= 500: break
    selected[c["sid"]] = c

with open("/tmp/tatoeba/top500-verbs.tsv", "w") as f:
    f.write("sid\taudio_id\tcontrib\tlen\tverb_hits\tverbs\tlemmas\ttext\n")
    for c in selected.values():
