* Intent

Migrate the Conjugation virtual entity to a first-class ontology.
Conjugation becomes the third ontology alongside word and sentence.
Conjugation literals are learnable entities with their own Memory,
connected to their form literals via the uses/in M:N self-relation.

The virtual entity (100-line SQL pivot over symbol_literals x5) is
dead. Conjugation lookup is a simple literal.feed() with populated
uses. No more lemma hacks.

* Design Decisions

| Decision | Choice | Rationale |
|----------+--------+-----------|
| Ontology count | 3: word, sentence, conjugation | Conjugation is structurally distinct |
| Shape | Literal with CONJUGATED trait | Reuses entity infra, learnable via Memory |
| Trait structure | { infinitive: slug, paradigm: { slot: slug } } | Infinitive at root, person slots in paradigm object |
| Strength tracking | Conjugation has its own Memory | Reviewed as a unit, tracks independently |
| Traits | RANKED, CONJUGATED | No TRANSLATED, EXEMPLIFIED, ANNOTATED, VOCALIZED |
| Ontology enforcement | Callers pass ontology in where | No repo-level enforcement. Flexible, explicit |
| Lemma encoding | None. Feed pipeline handles it. | Symbol-based queries + rank + blacklist replace lemma lists |
| Brazilian slots | 4: 1sg, 3sg, 1pl, 3pl | tu/vós not used in standard Brazilian speech |

* Conjugation Literal Shape

}
