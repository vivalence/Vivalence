* nomenclature

| word       | is                                                                     |
|------------+------------------------------------------------------------------------|
| execution  | one lifecycle vector per process type, =lifecycle.daemon.execution=    |
| lifecycle  | a middleware on an execution, =(die, next)=                            |
| die        | =mask= + =runtime= · =service= · =daemon= · =mode= + what the execution owns; a process's with its =controller= |
