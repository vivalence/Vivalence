* Design

*tap = materialize + record. Mount is runtime's.* (beef: /"Mount is at runtime.
It happens automatically because of the way that our system is architectured.
So the tap has to do materialize and record. Very clean."/)

#+begin_src text
tap(src)    remote? → materialize: jj git clone --colocate (git fallback) → rel ref
            guard: target declares manifest.type "package" or THROW
            registry.add(ref)                 ← pensieve NEVER touched
untap(ref)  registry.remove(ref)              ← record only
supply()    read() ?? seed() → fold registry.resolve → mount each   ← boot, the only mount
#+end_src

  s3/… future arm). The record never learns URLs — provenance = the clone's own
  =.jj=/=.git=.

  ="rel"=≡="./rel"= store-relative · identifier kind PARKED (fork A).
- ghost is the cwd-aware skin: a shell =./x= / =../x= resolves against
  =INIT_CWD= to an absolute BEFORE vip — registry grammar stays pure
  (recording a shell =./= as store-relative would be a lying surface).
- =Pensieve.evict= DISSOLVED — Pensieve extends Map; =pensieve.delete(owner)=
  IS eviction. No new method.
- resolution is REGISTRY-owned (base = store root), never =paladin.source= (cwd).
- 14 locked laws stand (manifest identity · authored owner · package-blind
  pensieve · two-throw · record rules …) — table + verbatims in HISTORY, pinned

    "$(printf '=%.0s' {1..76})" "$rev" "$date" "$path" \

Two traps, both hit while verifying this:

- =git= resolves as a shell function here, so it is NOT on =PATH= inside a
  =while read= loop — the loop reports =command not found= (exit 127) for every
  entry and reads as /"0 of 12 reachable"/. Use =GIT=$(command -v git)= and call
  ="$GIT"=. A reachability sweep that returns all-zero is a broken harness until
  proven otherwise.
- =4c5a1e2d~1= is deliberate: those four documents were DELETED by =4c5a1e2d=
  (/"added italian"/), so they exist only at its parent.
