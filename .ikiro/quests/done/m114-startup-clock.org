* the law

- the runtime BINDS at its fourth beat; =/status= answers =IDLE= through the boot, =RUNNING= after =keepalive=; a twin dies at bind, before any db
- readiness = the =start= track of a two-segment path (=[runtime/<slug>] start=); =listen= is liveness
- a client that finds =IDLE= waits; =null= spawns; any other code is not its to start
- one stamp, one notion: the CONTENT of every source a mode installs — dataset files, the fileset, the installer — folded by =paladin.stamp.fold= over =[path, digest]= pairs, paths relative to their root; =installed= is set for every mode after its traits
- a trait that installs rows gates on =mode.entity.installed= (DATASET · FILESET); a changed source changes the stamp, the lifecycle clears =installed=, the trait re-records
- a bundle's identity is its import graph; a compiled artifact is found by the graph's stamp before any compile
- =registry.supply= evaluates in parallel; a malformed package still faults at boot
