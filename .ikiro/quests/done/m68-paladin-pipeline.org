* the law

- *Supply is the runtime's moment; the verb is paladin's.* =registry.supply()= runs at runtime boot (and in ghost verbs that need the pensieve), never inside =lifecycle.mount= — the doctor keeps mounting an instance without touching the registry. But what =supply= and =accio= RETURN is finished: manifest folded, statics folded, secrets carried, seat carried. The runtime reads fields; it never writes =??=.
- *One fold per mask, one rule.* mask ⊕ module folds ONCE, in the registry's accio: =manifest= key-wise (mask wins) — =traits= ACCUMULATE, a mask adds and never strips, because settle's cast fills =traits: []= on every =Service= and =Client= mask manifest and a fill is not a word — =statics= key-wise (mask wins), =secrets= mask whole, =mountpoint= mask (seated upstream by =resolve.ground=). - *A schema rule is a fault, not a runtime throw.* What typology can state, =integrate.settle= reports and the doctor prints; the runtime asserts nothing it was handed.
- *Integrity is a fold, the span is its only log, a throw is its only stop.* A rule is a pair =[applies(module), apply(module, span) → module]=. =probe(rules)(module, span)= is =reduce=: the module threads through every applicable rule, in authored order. Two kinds of rule and no more (beef: /"cut out all the logic rules"/): a TYPE validates against its schematic (=Manifest= for all, =Domain= for a domain — so "a domain has entities" is the schematic's sentence); a TRAIT names the export it travels with (=TRAITS= in paladin's =integrity.js= for now, trait → prototype; the keys are the known traits). A rule says what is wrong with =span.fault= — the fold continues, every fault is known; a rule THROWS only for a file unfit to register (no slug); that file alone stays out, its path carries the throw. No return code, no severity field, no =integrity= field on the module: the registry's span pipes its faults into a =Map= (path → sentences), the doctor reads the map, and every road out of the registry — =lookup=, a path read, the folded citizen — passes =assert=, which throws the joined faults of what it hands back. The consumer that names a broken module pays; the registry never does.
- *One registry.* =paladin.ledger.registry= is the record (=registry.json=: list · add · remove · resolve · discover · seed · reconcile) AND the pensieve (mount · supply · tap · untap · accio · list). =paladin.vip= is gone.
