* the law

#+BEGIN_EXAMPLE
1. Composition ≠ process. resolve(rows, part) never sees a step. A step names placements by SLUG,
   never by row id, never by nesting.
2. A guide orders steps; a step belongs to exactly the guides that name it. Order is
   SEQUENCED.sections.flatMap(steps). A section is guide content, not a symbol.
3. PREPARED is derived, never stored: tools = the step's tool.* symbols; parts = bom(upto n) − bom(upto n−1).
4. The repository is the only writer. Natures are repository verbs; tools and both modes ride them
   through daemon.call. A mode never imports outside its own directory.
5. Every slug a step holds (ASSEMBLED, at.literals, built) follows a rename / move. No dangling slug
   survives a writer verb.
6. All screen state lives in buffer.data — down to the selection, the open inspector tab and the
   unsaved draft. The editor saves the draft into the literal it came from, debounced 700 ms.
7. The comp is ported verbatim in geometry and behaviour; every colour is a theme token; every datum is
   re-sourced from the daemon.
8. The package has no VCS and sits under runtime/watch: built in a scratch copy, captured to
   ~/.viva/bak/, landed in ONE rsync.
9. Reading is bounded (feedback_read_budget): a milestone reads the files it edits, when it edits them.
   Hunks are authored at the milestone, not ahead of it.
#+END_EXAMPLE

* the ontology

=~/.viva/registry/assembly/domain/assembly/schematics.js= — =ONTOLOGIES= after (=stack= gone, =SEQUENCED= moves part → guide):

#+begin_src js
part:      { traits: ["LABELED","SOURCED","MODELED","PARAMETRIC","COUNTED"],   layer: true  }
placement: { traits: ["LABELED","PLACED","JOINED"],                             layer: false } // JOINED { joins } — torque OUT
step:      { traits: ["LABELED","ASSEMBLED","INSTRUCTED","ANNOTATED","STAGED"], layer: false }
guide:     { traits: ["LABELED","SEQUENCED","INSTRUCTED","ANNOTATED","STAGED"], layer: false }

ASSEMBLED  { placements: [{ literal: "<placement slug>", active: boolean }] }
SEQUENCED  { subject?: "<part slug>", sections: [{ name, steps: ["<guide>.01", …] }] }
INSTRUCTED { lines: [{ text, at? }], images: ["manual/<id>.webp"] }
ANNOTATED  { notes: [{ text, symbols: ["note.tip" | "note.warning" | "warn.*"], images?, at? }] }
STAGED     { camera?: { target: VEC3, position: VEC3 }, explode?: 0..1, ghost?: boolean,
             built?: { steps: [slug], placements: [slug] },   // absent = every earlier step
             tints?: { "<placement slug>": TINT } }          // blue green orange red violet grey
ANCHOR at  { literals?: [slug], offset?: VEC3, position?: VEC3 } // position wins · literals(+offset) · none = the panel
PREPARED   derived — never stored
#+end_src
