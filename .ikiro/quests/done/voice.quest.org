* Aim

Single-tier orchestration: STT → LLM → TTS streamed end-to-end with token-level
pipelining and barge-in cancellation. New BOX deck owns mic + speaker. New
VOCALIZED trait gates server fanout. Existing CONVERSATIONAL trait already

* Distilled rules

1. Single tier. No fast/slow split. Two-tier rejected (appendix).
2. *Decks are pure.* No deck takes another deck (beyond pre-existing
   =Top(quarters, lighthouse)=). No deck knows entities or audio. Each deck
   owns its concern: =Box= (mic+speaker), =Quarters= (terminals), =Top= (active
   terminal/thread), =Bridge= (layout), =Lighthouse= (auth/daemons). Cross-deck
   orchestration lives in =traits/thread/vocalized.js= — a free function wired
   once at +layout init.
3. Use typology primitives — =Pipe=, =Queue=, =Conversation.subscribe=, =soma.tee=.
4. Trait gates: =mode.traits.includes("VOCALIZED")= server gate;
   =thread.trait.INSITU.audio.enabled= per-thread runtime gate.
5. Pipeline by default. Stream packet-by-packet.
6. Cancellation propagates. Barge-in reaches LLM, TTS, AND speaker buffer
   atomically. Idempotent.
7. Hallucinator namespace — =@vivalence/hallucinator/{deepgram,elevenlabs,anthropic,groq}=.
8. Faculty types — =dialogue=, =speech=, =verbatim=.
9. Trait colocation. =vocalized.js= owns guard server-side + engagement
   client-side.
10. PCM 16kHz int16 end-to-end. Mic worklet downsamples 48→16. ElevenLabs
    =output_format=pcm_16000=. No mp3 chunking.
11. Vanilla getters where natural; =.get()= fine where natural. No rigid rule.
12. Inflight promise memoization for =claim()=.
13. Server-authoritative barge-in. Client speaker stops on =/speech/abort= packet.
14. Standard typology barrel pattern. Multi-file directories carry =index.js=
    barrels.
15. Voice tier mandates Groq for sub-1s. Anthropic for non-voice.

* Codec

| Direction              | Format                    | Notes                                                |
|------------------------+---------------------------+------------------------------------------------------|
| Browser → server       | int16 PCM 16kHz mono      | Worklet downsamples 48→16. 20ms frames. ~50fps WS    |
| Server → ElevenLabs    | text chunks               | =soma.textFromPackets= over audioBranch              |
| ElevenLabs → server    | int16 PCM 16kHz mono      | =output_format=pcm_16000=                            |
| Server → browser       | int16 PCM 16kHz mono      | Pass-through                                          |
| Browser → speaker      | AudioBuffer chain         | =createBuffer + start()= per chunk; no decodeAudioData |

Backpressure: =socket.bufferedAmount= watch at mic tap site.

** =systems/runtime/daemon/traits/conversational.helpers.js= [NEW — server]

#+begin_src js :tangle ../../systems/runtime/daemon/traits/conversational.helpers.js :mkdirp yes
import { soma } from "@vivalence/typology";

let counter = 0;
const nextTurnId = () => `turn-${Date.now()}-${++counter}`;

export async function fanoutDialogue({ daemon, mode, state, parts, thread, tune }) {
  const conversation = state.conversation;
  const turn = nextTurnId();
  const controller = new AbortController();
  state.inflight ??= new Map();
  state.inflight.set(turn, controller);

  try {
    const stream = await mode.harness.dialogue.stream({ parts, thread, tune });
    const vocalized = mode.traits.includes("VOCALIZED");

    if (!vocalized) {
      for await (const packet of stream) {
        if (controller.signal.aborted) break;
        conversation.send.dialogue.packet({ ...packet, turn });
      }
      conversation.send.dialogue.close({ turn });
      return;
    }

    const [textBranch, audioBranch] = soma.tee(stream);

    const dialoguePath = (async () => {
      for await (const packet of textBranch) {
        if (controller.signal.aborted) break;
        conversation.send.dialogue.packet({ ...packet, turn });
      }
      conversation.send.dialogue.close({ turn });
    })();

    const speechPath = (async () => {
      const speech = daemon.cortex.resolve("speech", { tune: tune ?? "eager", via: "stream" });
      if (!speech) return;
      const textChunks = soma.textFromPackets(audioBranch);
      for await (const packet of speech.via.stream(textChunks, {})) {
        if (controller.signal.aborted) break;
        conversation.send.speech.packet({ ...packet, turn });
      }
      conversation.send.speech.close({ turn });
    })();

    await Promise.all([
      dialoguePath.catch((error) =>
        conversation.send.dialogue.error({ message: error.message, turn })
      ),
      speechPath.catch((error) =>
        conversation.send.speech.error({ message: error.message, turn })
      ),
    ]);
  } finally {
    state.inflight.delete(turn);
  }
}
#+end_src

** =systems/kajuit/src/typology/decks/box/box.js= [NEW — pure deck]

WHY: BOX deck owns mic + speaker. Pure. Zero dependencies on other decks. Doesn't
know terminals, threads, conversations. Exposes =mic: Pipe=, =speaker: Queue=,
atoms, =claim()/release()=. Inflight-memoized claim per
=feedback_inflight_promise_guard=.

#+begin_src js :tangle ../../systems/kajuit/src/typology/decks/box/box.js :mkdirp yes
import { atom } from "nanostores";
import { Pipe, Queue } from "@vivalence/typology";
import workletURL from "./worklet.js?url";

const PROMPT = "prompt";
const GRANTED = "granted";
const DENIED = "denied";

export class Box {
  $claimed = atom(false);
  $permission = atom(PROMPT);
  $error = atom(null);
  $inputLevel = atom(0);
  $playing = atom(false);

  mic = new Pipe();
  speaker = new Queue();

  audioContext = null;
  micStream = null;
  micNode = null;
  activeSource = null;
  drainController = null;
  claimInflight = null;

  get claimed() { return this.$claimed.get(); }
  get permission() { return this.$permission.get(); }
  get error() { return this.$error.get(); }
  get inputLevel() { return this.$inputLevel.get(); }
  get playing() { return this.$playing.get(); }
  get queueDepth() { return this.speaker.depth; }

  claim() {
    if (this.claimInflight) return this.claimInflight;
    if (this.$claimed.get()) return Promise.resolve();
    this.claimInflight = this.openAudio().finally(() => { this.claimInflight = null; });
    return this.claimInflight;
  }

  async openAudio() {
    try {
      this.audioContext = new (window.AudioContext || window.webkitAudioContext)({
        sampleRate: 48000,
      });
      if (this.audioContext.state === "suspended") await this.audioContext.resume();
      await this.audioContext.audioWorklet.addModule(workletURL);
      this.micStream = await navigator.mediaDevices.getUserMedia({
        audio: {
          channelCount: 1,
          echoCancellation: true,
          noiseSuppression: true,
          autoGainControl: true,
        },
      });
      this.$permission.set(GRANTED);
      const source = this.audioContext.createMediaStreamSource(this.micStream);
      this.micNode = new AudioWorkletNode(this.audioContext, "box-input-processor");
      this.micNode.port.onmessage = (event) => this.handleMicFrame(event.data);
      source.connect(this.micNode);
      this.$claimed.set(true);
      this.startSpeakerDrain();
    } catch (error) {
      this.$error.set(error.message ?? String(error));
      if (error?.name === "NotAllowedError") this.$permission.set(DENIED);
      this.teardownAudio();
      throw error;
    }
  }

  release() {
    if (!this.$claimed.get()) return;
    this.teardownAudio();
    this.$claimed.set(false);
  }

  teardownAudio() {
    this.drainController?.abort();
    this.drainController = null;
    this.speaker.flush();
    if (this.activeSource) {
      try { this.activeSource.stop(); } catch {}
      this.activeSource = null;
    }
    this.$playing.set(false);
    if (this.micNode) {
      this.micNode.port.onmessage = null;
      this.micNode.disconnect();
      this.micNode = null;
    }
    if (this.micStream) {
      for (const track of this.micStream.getTracks()) track.stop();
      this.micStream = null;
    }
    if (this.audioContext) {
      this.audioContext.close().catch(() => {});
      this.audioContext = null;
    }
    this.$inputLevel.set(0);
  }

  handleMicFrame({ pcm16, rms }) {
    this.$inputLevel.set(rms);
    this.mic.send({ audio: pcm16, rms });
  }

  startSpeakerDrain() {
    this.drainController = new AbortController();
    (async () => {
      try {
        for await (const packet of this.speaker.drain(this.drainController.signal)) {
          await this.playPacket(packet);
        }
      } catch {} finally {
        this.$playing.set(false);
      }
    })();
  }

  async playPacket(packet) {
    if (!this.audioContext) return;
    const buffer = this.toAudioBuffer(packet);
    if (!buffer) return;
    const source = this.audioContext.createBufferSource();
    source.buffer = buffer;
    source.connect(this.audioContext.destination);
    this.$playing.set(true);
    this.activeSource = source;
    await new Promise((resolve) => {
      source.onended = () => resolve();
      try { source.start(); } catch { resolve(); }
    });
    if (this.activeSource === source) this.activeSource = null;
    if (this.speaker.depth === 0) this.$playing.set(false);
  }

  toAudioBuffer(packet) {
    if (!this.audioContext) return null;
    const audio = packet?.audio ?? packet;
    const bytes = audio instanceof ArrayBuffer
      ? new Int16Array(audio)
      : ArrayBuffer.isView(audio)
        ? new Int16Array(audio.buffer, audio.byteOffset, audio.byteLength / 2)
        : null;
    if (!bytes) return null;
    const buffer = this.audioContext.createBuffer(1, bytes.length, 16000);
    const channel = buffer.getChannelData(0);
    for (let i = 0; i < bytes.length; i++) channel[i] = bytes[i] / 0x8000;
    return buffer;
  }

#+begin_src js :tangle ../../systems/kajuit/src/typology/decks/box/worklet.js :mkdirp yes
class BoxInputProcessor extends AudioWorkletProcessor {
  constructor() {
    super();
    this.buffer = [];
    this.targetSampleRate = 16000;
    this.ratio = sampleRate / this.targetSampleRate;
    this.frameSize = (this.targetSampleRate * 20) / 1000;
  }
  process(inputs) {
    const input = inputs[0];
    if (!input || !input[0]) return true;
    const channel = input[0];
    let sumSquares = 0;
    for (let i = 0; i < channel.length; i++) sumSquares += channel[i] * channel[i];
    const rms = Math.sqrt(sumSquares / channel.length);
    for (let i = 0; i < channel.length; i += this.ratio) {
      this.buffer.push(channel[Math.floor(i)]);
    }
    while (this.buffer.length >= this.frameSize) {
      const frame = this.buffer.splice(0, this.frameSize);
      const pcm16 = new Int16Array(frame.length);
      for (let i = 0; i < frame.length; i++) {
        const sample = Math.max(-1, Math.min(1, frame[i]));
        pcm16[i] = sample < 0 ? sample * 0x8000 : sample * 0x7FFF;
      }
      this.port.postMessage({ pcm16: pcm16.buffer, rms }, [pcm16.buffer]);
    }
    return true;
  }
}
registerProcessor("box-input-processor", BoxInputProcessor);

export const VOCALIZED = (thread, _ctx) => {
  const conversation = thread.conversation;
  if (!conversation) return;
  conversation.inbound.branch("speech").open("packet", () => {});
  conversation.inbound.branch("speech").open("abort", () => {});
  conversation.inbound.branch("speech").open("close", () => {});
  conversation.inbound.branch("speech").open("error", () => {});
  conversation.inbound.branch("verbatim").open("packet", () => {});
  conversation.inbound.branch("verbatim").open("error", () => {});
};

export function wireVoiceEngagement({ box, top }) {
  let engagement = null;
  let threadSubs = null;

  const reconcile = () => {
    engagement?.controller.abort();
    engagement = null;
    const thread = top.$current.get();
    if (!thread) return;
    if (!thread.traits?.includes("VOCALIZED")) return;
    if (thread.trait?.INSITU?.audio?.enabled !== true) return;
    engagement = engage(box, thread);
  };

  const offCurrent = top.$current.subscribe((thread) => {
    threadSubs?.();
    threadSubs = null;
    if (thread) {
      const offTrait = thread.$trait?.subscribe?.(reconcile);
      const offTraits = thread.$traits?.subscribe?.(reconcile);
      threadSubs = () => { offTrait?.(); offTraits?.(); };
    }
    reconcile();
  });

  return () => {
    engagement?.controller.abort();
    engagement = null;
    threadSubs?.();
    offCurrent();
  };
}

function engage(box, thread) {
  const controller = new AbortController();
  const conversation = thread.conversation;

  (async () => {
    try {
      await box.claim();
    } catch {
      const trait = thread.trait ?? {};
      const insitu = { ...(trait.INSITU ?? {}), audio: { enabled: false } };
      thread.trait = { ...trait, INSITU: insitu };
      return;
    }
    if (controller.signal.aborted || !conversation) {
      box.release();
      return;
    }

    const releaseTap = box.mic.tap(({ audio }) => {
      conversation.send.verbatim.packet({ audio });
    });
    const offSpeechPacket = conversation.subscribe("/speech/packet", (packet) => {
      box.speaker.enqueue(packet);
    });
    const offSpeechAbort = conversation.subscribe("/speech/abort", () => {
      box.speaker.flush();
    });
    const offSpeechClose = conversation.subscribe("/speech/close", () => {});

    controller.signal.addEventListener("abort", () => {
      releaseTap();
      offSpeechPacket();
      offSpeechAbort();
      offSpeechClose();
      conversation.send.verbatim?.close?.();
      box.release();
    });
  })();

  return { controller };
}

* Lessons (session 2026-05-06)

Carry forward into next session. These are general — not voice-specific.

1. *Read the wider convention before extrapolating local notes.* The
   typology-rotation quest has a narrow rule "no single-export =index.js=
   barrels" — it applies to the degenerate dir-with-one-file case only. I
   extrapolated it into a universal anti-barrel stance and argued for flat
   =decks/box.js= when typology-wide convention is barrel-per-directory
   (=gestalten/belt/=, =gestalten/shape/=, =decks/bridge/=, =entities/thread/=).
   Cost: quest rewrite. The standing ikiro directive — "read
   =subsystems/typology/.ikiro/CLAUDE.md= greedily before working in any
   subsystem" — exists for this exact failure.

2. *Decks are pure.* No cross-deck constructor injection. =Quarters= takes
   nothing audio/voice-related. =Box= takes nothing. The pre-existing
   =Top(quarters, lighthouse)= is the exception, not a precedent. Cross-deck
   orchestration is a *separate concern* — lives in trait files as free
   functions (=wireVoiceEngagement=) called once at +layout init. Same lesson
   as typology-rotation =$dock= relocation: "this is dirty as FUCK. belongs
   into traits".

3. *Vanilla getters are a preference, not a hard rule.* =$field.get()= is fine
   where natural. =feedback_transparent_accessors= is "prefer", not "ban".

4. *When the session's output is a quest, the quest IS the compact.*
   Don't write date-specific =.ikiro/compacts/<date>.<topic>.org= when a single
   quest owns the session's substance. Fold arc into Changelog, lessons
   into Lessons section, quote ledger if useful. Date-specific compacts are
   for sessions without a single quest anchor.

5. *Structure docs by what they describe, not by build order.* Files-as-the-
   thing is the spec; milestones are a separate document about execution order.
   "What changes in conversational.js" lives in conversational.js's section,
   not scattered across M2.5 + M3 + M4.

6. *Inline @beef annotations in the quest are authoritative.* When user
   edits the file mid-conversation, that's the new spec — don't argue with it,
   propagate it.

7. *Service category vs faculty type are different layers.* All hallucinator-
   class services declare =manifest.type: "hallucinator"=. The faculty TYPE
   (=dialogue= / =speech= / =verbatim=) lives on the faculty object emitted by
   =provider(mask)=. Cortex.resolve reads faculty.type, never service.manifest.
   type. Existing files declaring =manifest.type: "speech"= / =manifest.type:
   "verbatim"= were misnamed; corrected.

8. *Hallucinator slot is uniform — collapse per-faculty slots.* Don't have
   parallel daemon-manifest slots =hallucinator: {...}, speech: {...},
   verbatim: {...}=. One array =hallucinators: [{module, statics, secrets},
   ...]= per daemon. Each provider returns faculties of any type; cortex
   accumulates them. Adding a new faculty class (e.g. embedding) is a new
   service module + a new array entry — no daemon-manifest schema change, no
   population.js change.

9. *Paladin pairs object queries with their mask.* When a registry slot's
   query is an object with =.module=, =accioMany= returns ={ service: <module>,
   mask: <query> }=. String queries return bare module (back-compat).
   Consumers iterate paired entries and call =service.provider(mask)= with
   no parallel-array bookkeeping.

10. *VOCALIZED is dead. Voice capability is cortex-driven.* No separate
    VOCALIZED trait at runtime, mode, or thread layer. Server's
    CONVERSATIONAL trait branches on =daemon.cortex.has("speech")= +
    =daemon.cortex.has("verbatim")=. Mode authors don't declare voice as a
    flag; they declare it by giving the daemon speech/verbatim hallucinators
    in its manifest. =VOCALIZED= survives only as a corpus literal-trait
    (audio-quality marker on dictionary words), an unrelated concern.

11. *BOX deck owns devices, panels and docks consume.* =new Microphone()=
    inside a panel/dock is the wrong pattern — every other kajuit deck
    (Bridge, Top, Quarters, Lighthouse) is constructed once in =+layout.
    svelte= and consumed via =getContext=. Panels are consumers, not
    instantiators. "Divorced from X" never means "skip the deck" — only
    "skip cross-deck wiring". Hardware singletons especially demand deck
    ownership: browser limits one mic stream + one AudioContext per page.

12. *Audio engagement belongs inside the trait, not in +layout.* The
    conversational trait's per-thread =wire(thread)= + =open(thread)= already
    own conversation lifecycle. Audio engagement (mic claim, speech
    subscription, transcript routing) is part of that lifecycle. Layout's
    only obligation is =provide({box, top})= once at construction — an
    explicit dependency-injection handoff, not a subscription loop.

13. *Mode-level config is a sibling export, not a manifest field.* Manifest
    is metadata (type, slug, traits). Configurable behavior (autoVoice,
    language, voice preference) is an export sibling like =harness=,
    =dataset=, =tools= — assigned to mode instance via =Object.assign(this,
    cake)=. Faculty objects emitted by service providers stay uniform; mode-
    specific resolution preferences are read by the consumer (server
    =conversational.js=) at =cortex.resolve= time.

14. *"retard" is the self-improve codeword, not just an insult.* Each
    occurrence in a session = log a callout in =.ikiro/zettelkasten.md= with
    Finn-verbatim quote + root cause + corrective rule. Three callouts
    landed this session (panel-as-owner, service-vs-faculty type, manifest-
    hardcoding + faculty-discriminator). All preventable by reading
    surrounding code before proposing.
