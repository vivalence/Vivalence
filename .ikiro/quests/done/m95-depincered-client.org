4. A buffer's component receives ={ terminal, buffer, surface }=; =surface.place ∈ cell · frame=.
5. One dispatch: =terminal.dispatch(line)=; every row write a chrome makes is a line; a pane never calls a repository.
6. The keymap is its own tree (m92), mapped onto the repl by =chord:= and line effects; its list on =ctrl-v ctrl-v= is the =catalog=; =palette= is the colours.
7. =DOCKED= resolves terminal → user → client mask → =DEFAULT_DOCK=; =THEMED= client mask → user → the OS.
8. The database mirrors; keystrokes, chords, focus, a drag's pixels stay in the client.
9. Client modes are bundled when a client is built; client · runtime · daemon modes are wholly independent.
10. No pincer: no bones, gesture, radial, throw, spine. =/face= · =/design= are dead.
11. ONE client factory, =factories.client(surface)= on a browser-clean =@vivalence/ghost=; a door builds the die as =run.js= does.
12. Paladin is any system's interface with its environment — os or browser; imported, never on a die; =instance= comes from paladin onto the die.
13. ONE =paladin.vault= (=held · store= by origin), its backend resolved: Deno → =paladin.scope.credentials=; a browser → =localStorage=.
14. A command has one of three owners by need: client · terminal · runtime mode.

16. A View owns its File rows (=file.view=, =view.entry=); no upstream.
