* the law — 10-26 (v4 · Q20–Q36 · 33B–33I)

1. a factory MAKES the thing, never a die, never an effect; an execution runs over what was made (10-25 ruling · 23′).
2. the client is a state machine its factory kicks off (mint · dispatch · hand back RUNNING); nobody awaits its run (22A).
3. the App is the trunk — client · surface · controller · box · bridge · telemetry; the client never knows its surface (Q20 · Q21).
4. the shell's =/chrome= mints the client, the App onto it, and executes the App; the App's execution: open · client · bundle · mount · hold (S1–S3 · Q28 · 33D).
5. teardown lives on the App: the client settling aborts the app, the app ending aborts the client (22A).
6. the client's dataspace holds the terminals; the runtime keeps every user holding one; =app.bridge= remembers the pick, the Layout shows it when the store holds it, else the first (Q28 · 33D).
7. a command reaches the App through =ctx.client.app=; the app's commands and keymap are present only with an app (Q27 · Q31).
8. entities do not run: a terminal is data, its controller cast at hydration, its stall a watch; a thread holds nothing (Q29 · Q30).
9. ambients are TOOLING (=gestalten/ambient.js=); the chrome gets ONE Provider, =ambient.app=, and one per window, =ambient.terminal= (Q26 · S4).
10. the surface is ={ bundle, mount }=; =mount.jsx= is the bundle's entry and holds the cover: booting → signin → layout (S2 · S4 · Q24).
11. the Dataspace is minted with the Runtime and walks its declaration — =daemon · mode · thread · buffer · turn · activity · terminal · view=, every =find= then every =subscribe=; it is the only reader; another user's sign-in drops it and walks again (33B · 33G · 33H · 33I).
12. one theme name, no dark/light: the mask's =THEMED=, else the user's (the cast defaults ="northsea"=); before sign-in ="porcelain"= (Q35 · Q35A).
13. an entity's invariant lives in its twitch, never a boot beat — the Terminal twitch keeps every user holding one (33D · Q34).

class Buffer {}

};

  const opened = new Set();
  const connection = {
    branch: (path) => ({
      url: { absolute: path },
      call: async (route) => (route === "/find" ? ROWS[path] : null),
      subscribe: () => {
        opened.add(path);
        return () => opened.delete(path);
      },
    }),
  };
  const ENTITIES = {
    thread: { repository: (dataspace) => new RemoteRepository(Thread).connect(dataspace.runtime.connection.branch("/userspace/entities/thread")), hydration: new Vector() },

  return { dataspace, opened };
};

  });
});
