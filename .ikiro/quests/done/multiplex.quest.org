#+title: multiplex — the daemon session: Socket exchanges frames
#+status: LANDED (typology + runtime green; live Phase-B + Phase-C pending)

* the problem

Browser 6-per-host HTTP/1.1 pool. SSE subscriptions hold sockets; two daemons break
it. The tunnel (earlier prototype, 32/32) proved one-socket muxing but was HTTP
cosplay — frames re-synthesized web Requests server-side, re-entered shape.http.
Every follow-up patch (retry capability smuggling, carrier leases, Duct ws-shim, ALS
carry hack) was adapter code. Connoisseur verdict: the tunnel reinvented four things
the system already owned — Queue, Socket's dispatch, the packet grammar, the channel
family. Structure wrong.

* the concept — one grammar

The daemon surface is a Vector dispatching Signals. Put signals on the wire.

- SOCKET GREW. echo (unary correlation) → FRAME (multi-reply correlation). One
  dispatcher both sides (the one Socket already had). One correlation scheme.
- Every living exchange is a frame: call (first frame), flow (stream), subscribe
  (durable). push() stays frame-less. Server-side iterable outputs consumed INSIDE
  the middleware carry — the ALS/RequestContext bug class dies structurally.
- multiplex = a KEEPER combinator (shard.transmitter), NOT a class: address (Url+token), lazy establish, waiter
  backoff, Socket recreation on drop, transport() shim for Connection compat. ~130 lines.
- Queue IS the frame inbox (buffer/waiter/close/drain). Failure is DATA (an error
  frame in the stream), never channel poison — Queue untouched, matches /dialogue/error.

* frame grammar (Socket)

  → { frame, signal, input?, verb?, token?, stream? }   open
  → { frame, input } / { frame, done }                upstream chunk / end
  → { frame, close }                                    cancel
  ← { frame, open }                                     attach ACK (leaf ran)
  ← { frame, output }                                   reply / stream item
  ← { frame, close } / { frame, error }               end / failure
  (frame-less { signal, input } = push, unchanged)
