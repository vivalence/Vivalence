* what jev is — measured from the sources, 09-23

TypeSafe AI's "System One model" (released 2026-09-15): a =state= (text or JSON) and typed questions in, a probability distribution per question out, never prose. Three question types on their wire: =noul= (P(yes)), =choice= (≤255 options, argmax + probabilities + confidence), =score= (2–10 ordered levels, probability-weighted mean). ~100 ms, $0.042/M input tokens, output free, 32k context, text only. OpenRouter serves it as =typesafe/jev-1.13= at =POST /api/alpha/decisions=.

The mechanism, from =nobodywho.ai/posts/jev-in-25-lines= and =ekzhang/openjev-sglang=: prefill the prompt, read the logprobs of the answer-label tokens at the FIRST output position, softmax. No decode. Confidence = =1 − H(p)/log(n)=. That is the whole trick, and it runs on any model that exposes logprobs, including a 0.6B GGUF on a laptop.

* rulings

1. *choice is a faculty, not object with sugar.* Test: derivability. =object= derives from =dialogue= (=cortex.js:103=); a distribution cannot be derived from one sampled value, and Anthropic exposes no logprobs at all. What cannot be derived is its own type.
2. *viva is self-contained; Jev's types die.* beef: /"fuck jev's types. viva is self contained. choice. yes no?"/ =noul= is =choice(["yes","no"])=; =score= is choice over ordered options plus =expect()=. One primitive.
3. *the three types are provider details, not native kinds.* The provider only ever produces a distribution over a closed label set; the one semantic bit (ordered or not) is a property of the option array the caller authored. Jev's =noul · choice · score= live in a Jev provider's =translate.js=, exactly where =response.choices[0]= lives for OpenAI today. Taken on my lean; beef's go was on the code that assumes it — QUESTIONED until he says the word.
4. *options are strings; the surface lifts.* beef asked /"can i only pass strings of text into the choice space? what about function signatures? what about objects with properties?"/ — the first landing answered with =Option{value, label: Label}= + a =lift= in the shard that knew tool declarations. beef, on =v.union([v.string(), Tool, Option])=: /"no. i am against this. thats bad abstraction. the core faculty knwos nothing of the implemntation details of its surface. any processing of tools has already happened at that point. we know our constraints are strings. thats good enough."/ =options: v.array(v.string())=; a mode maps its tools, rows or tiers to strings before the call and back by name after. =Option= · =Label= · =Tool= · =lift= left the faculty the same day.
5. *the distribution is over things, in option order.* =Verdict = [{option, probability}]=. =pick · confidence · expect · probability= are pure belt readings over it, the way =belt.verbatim= holds =harmonize · fold · transcript=.
6. *no lift in the core.* Superseded by ruling 4 — the shard renders =A. <option>= per line and nothing else. Whatever knows a Tool from a row lives at the surface (a mode, later the harness wrapper under deferred).
7. *no derivation.* When no choice faculty is registered the avenue throws =[hallucination] no 'choice' faculty resolves a 'render' avenue= (=hallucinate.js:19=, unchanged). A fallback through =object= would return ={pick: 1}= and call it a probability. Taken on my lean; beef has not ruled.

* the law

#+BEGIN_EXAMPLE
A faculty is a kind of hallucination the cortex cannot derive from another.
choice reads a distribution over a closed set; dialogue samples one value from an open one.
An option is a string. The core faculty knows nothing of what the string stood for; the surface lifted it and takes it back by name.
The verdict is over things, in option order. Readings are belt; kinds are not minted for readings.
A provider that returns no logprobs registers no choice faculty. Absence throws; it never derives.
#+END_EXAMPLE

export const pick = (verdict) =>
  verdict.reduce((best, row) => (row.probability > best.probability ? row : best)).option;

export const probability = (verdict, value) => verdict.find((row) => row.option === value)?.probability ?? 0;

export const expect = (verdict) => verdict.reduce((sum, row, index) => sum + index * row.probability, 0);

export const confidence = (verdict) => {
  const present = verdict.map((row) => row.probability).filter((probability) => probability > 0);
  const entropy = -present.reduce((sum, probability) => sum + probability * Math.log(probability), 0);
  return verdict.length < 2 ? 1 : 1 - entropy / Math.log(verdict.length);
};
#+end_src

  const content = `${typeof state === "string" ? state : JSON.stringify(state)}\n\n${question}\n\n${text}`;
  return {

      { role: "user", content },

    logprobs: true,
    top_logprobs: 20,
    reasoning: { enabled: false },

export function readChoice(response, labels) {
  const top = response.choices[0]?.logprobs?.content?.[0]?.top_logprobs ?? [];
  if (!top.length) throw new Error(`[openrouter] ${response.model} returned no logprobs — it cannot serve choice`);
  const logits = labels.map((label) => top.find((entry) => entry.token.trim() === label)?.logprob ?? -Infinity);
  const peak = Math.max(...logits);
  const weights = logits.map((logit) => Math.exp(logit - peak));
  const mass = weights.reduce((sum, weight) => sum + weight, 0);
  return weights.map((weight) => weight / mass);
}
