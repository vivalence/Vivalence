* the law

1. A view DECLARES where it shows: View traits =FRAME= · =CELL=; no traits is =FRAME= (Q0 · Q1).
2. A buffer PICKS a view per place: =trait.RENDERED.frame= · =.cell=, a slug; =data= is the buffer's internals only (data · Q2).
3. A chrome lists what it RUNS, then what the place allows: =framed= · =cells=; a =CELL=-only view never enters the frame (filter · Q7).
4. An empty or stale pick reads as the first listed (Q4; design =ring.js:993=); nothing is written until a click.
5. The act starts at the place: =/frame/set <slug>= · =/cell/set <slug> <name>= (Q3A); a gesture dispatches through the repl (Q8A).
6. A cell takes clicks only, =focused: () => false= (Q5); a view is told nothing about where it shows (Q6).
7. No cell view → the card: its head alone; a click is =/buffer/full <name>= (Q8A).
8. Markdown in the journal is a dock setting, =DOCKED.markdown= =pretty= · =plain=, per terminal, default =pretty= (Q9).

});

export const cell = new Vector().open(
  { nature: "/cell/set", valence: "which view a buffer shows as its cell in the journal. Example: /cell/set board play #1", input: Celled },
  async (ctx) => {
    const { slug, name } = belt.input.cast(Celled, labeled(ctx.signal));
    const found = ctx.terminal.thread.$buffers.get().find((candidate) => named(candidate) === name);
    if (found === undefined) throw new Error(`no buffer ${name} on thread #${ctx.terminal.thread.id} — its buffers: ${ctx.terminal.thread.$buffers.get().map(named).join(" · ") || "none"}`);
    const slugs = (await belt.view.candidates(found, ctx.client.runtime.attach)).filter((view) => view.traits.includes("CELL")).map((view) => view.slug);
    if (!slugs.includes(slug)) throw new Error(`${name} cells ${slugs.join(" · ") || "none"}`);
    await ctx.client.runtime.entities.buffer.updateOne({ id: found.id }, traits.patch(found, { RENDERED: { cell: slug } }));
    return `${name} · cell ${slug}`;
  },
);
