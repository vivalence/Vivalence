Two deliverables: (1) the checker treats =I'm= ≡ =I am= (and friends) as one answer; (2) ONE home for the table, designed so the next per-language static (beef's promised pronoun statics, the survival tactic themes) lands in the same slot instead of reopening the question.

* the concept, pinned

Today's forgiveness is UNIVERSAL: =string.fold= (=subsystems/typology/gestalten/belt/string.js:9=) kills case · diacritics · punctuation (incl. the apostrophe) · =/= alternatives via =separate= · parentheticals via dojo =bare()=. It knows no language.

A contraction equivalence is the first LANGUAGE-DEPENDENT forgiveness: =I'm= ≡ =I am= holds in english, =dov'è= ≡ =dove è= holds in italian, =pra= ≡ =para= holds in brazilian, and =del= ≢ =di il= in italian/spanish (mandatory contraction — accepting the expansion would teach an error). So the checker gains a LANGUAGE AXIS, and a language — today only =daemon.statics.language.{known,learning} = {slug, name}= — grows its first piece of static linguistic knowledge. That is the real design object: *per-language statics*, contractions being entry one.

Naming: =contractions= is already the in-repo word — brazilian literal slugs =*.contraction= (54, every one ANNOTATED with its decomposition =do = de + o=), symbol =word.compound.contraction=, italian =*.contraction= (30 preposizioni articolate). Keep it. No coined register.

Recommendation: *C*. Reasoning, ranked:
1. A language's contractions are a property of the language → the pair module that surveys that language owns them; the domain stays language-agnostic; a packaged topography ships whole.
2. =statics.language.{known,learning}= already IS the language object on both sides of the wire — the only code motion is the fold; zero new client wiring; the checker reads what the label code already reads.
3. "derive by default, lock to override": the variant keeps authoring ={slug, name}= only; the topography supplies the linguistic half; a variant MAY override a key inline (mask wins in the merge) for the one-off.
4. Pronoun statics land in the same slot next (=statics.language.learning.pronouns=) — the question never reopens.

The honest cost: the english table (~40 entries) lives 3× (italian/brazilian/spanish topographies). Mitigation path if it grows: the domain owns the KNOWN language's table (fork 2) — but only once a second known language exists or the table stops being tiny.

** the hybrid (second cut, same session)

beef, on the 51-entry english dump: /"those are very specific. is it feasable to be more .... abstract? but true? maybe nto"/ → /"can we do a hybrid. makes sense to have scalability + accuracy."/

- =LANGUAGE= grew =elision: boolean=; =contractions= keys are now two kinds: a key starting with ='= or =n'= is a SUFFIX RULE riding any host word (='re= → =are=: =you're=, =there're=, =the cats're= all free), any other key is a literal pair (=won't= → =will not=).
- =string.contract=: literal pairs first, then suffix rules, longest =long= first within a kind — so =will not= → =won't= lands before =n't= could make =willnt=. Suffix regex =(^|\s)(\S+) <long>(?=\s|$)= → =$1$2<short>=.
- =string.elided(expected)= builds =^chunk[aeiou]? ?chunk…$= from the answer's apostrophes; =matches({ elision: true })= accepts it. Directional — only fires where the ANSWER elides, so =la casa è= never collapses; fusions (=del=/=di il=) stay rejected because no apostrophe. Cost accepted: =lo amico= ≡ =l'amico= (the optional/mandatory line lives in no list now).
- Tables: english 10 (7 rules + 3 irregulars) ×3 · italian ={ elision: true, contractions: { "po'": ["poco"] } }= (truncation, not elision) · brazilian 16 colloquial (not rule-derivable — the honest list) · spanish ={}=.
- =judge.evaluate({ language })= now takes the whole side (=contractions= + =elision=); Rep passes =side(recall)=; cloze passes =language.learning=.
- Live through bruno: =testament/_bruno/variants/education-language/domain/aperture/language.bru= (login → =/language=; 5 asserts + 1 test green); payload: known = the 10 + =elision:false=, learning = italian =elision:true= + =po'=.
