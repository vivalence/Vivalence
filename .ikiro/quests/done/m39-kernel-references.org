* intent
One sentence: *a daemon =kernel[]= entry stops being only a bare package specifier, and a mode's app stops needing a file on disk.*

Four kernel forms, one array:
#+begin_src js
kernel: [
  "@playground/playground/spawner",   // bare specifier  → pensieve.revelio            (unchanged)
  "/abs/path/x.viva.js",              // absolute path   → paladin.read.viva            NEW
  "./greeter/greeter.viva.js",        // relative        → resolved vs the VARIANT FILE  NEW
  hello,                              // inline module   → passed through verbatim       NEW
]
#+end_src

Plus the app seam: =svelte`…`= returns ={source}=, =App= carries it, =APPLICATION= bundles from source. A whole mode can now live inside the variant file with no directory at all.

Why it matters: the variant file becomes self-sufficient. A playground, a test rig, a one-file demo, an LLM-emitted mode (simmering strand #3, /"ad-hoc svelte buffer renderer … would be INSANE"/) all stop needing a package published into the pensieve first.

* findings — REVISED by the critical pass (initial read struck through where the run disproved it)
1. *kernel skips =hydrate= — DOWNGRADED defect → intended asymmetry.* PROVEN live (probe: =staticsProbe: "function"= survives resolve) — but file modules never hydrate either (no registry mode carries a thunk; =read.viva= returns raw exports; =aperture/metadata.js:28= serves =mode.statics= raw). Kernel entries are MODULE-shaped, not declaration-shaped; thunks fire only in variant declarations. Consistent. Worth ONE sentence of doc, zero code. (A thunk in an inline module's statics silently stays a function at =/metadata/statics= — the only trap.)
2. *resolver family, now four members* — =belt/source.js= (CLI: =./= = cwd-relative, bare = repo-root) · =ledger/registry.js normalize= · =read.js resolved= · patch's =reference= (=./= = variant-file-relative, bare = pensieve specifier). Variant-file-relative is CORRECT here — a daemon boots from any cwd; a variant file's =./= must mean itself. The flag is the FAMILY: same string shapes, four local grammars, none named. Not a blocker; a candidate consolidation (widen =paladin.source= to take a =Path= home) when it next itches.
3. *inline =mount= = the variant FILE — RESOLVED, correct by precedent.* =vip.mount:17= stamps every pensieve module the same way: ={...module, mount: new Path(path)}= — module-layer =mount= IS the file path (=APPLICATION='s =mode.module.mount.dirname + app.mount.nature= depends on it). =entry.mount ?? home= says: an inline module's file is the variant file. Coherent; the mixed case (inline module, file-based =app.mount=) even resolves the app relative to the variant's dir — right on purpose, not by accident.
4. (new) *missing-file error is raw* — =accioOne("/nowhere/nothing.viva.js")= → =Module not found "file:///nowhere/nothing.viva.js"= — legible but not =[VIP]=-prefixed like its sibling errors. Pennies.
