** the jj equivalents (when git is not the tool at hand)

jj has no =show <rev>:<path>= — =jj show= takes a REVSET, not a path, and errors
on one. The two forms that do work:

#+begin_src sh
jj log -r 'files("<path>")' --no-graph \
   -T 'commit_id.short() ++ "  " ++ committer.timestamp().format("%Y-%m-%d") ++ "  " ++ description.first_line() ++ "\n"'

jj diff --from 'root()' --to <sha> <path> | sed -E '1d; s/^ *[0-9]+: //'
#+end_src

The second renders the whole file as one big addition, then strips jj's
=NNNN: = line-number gutter. Two gotchas, both hit and confirmed:

- =jj log -r 'files(p)'= lists the DELETING commit too (it touches the path by
  removing it). The last-alive revision is the *second* row.
- glob revsets (=files("glob:.ikiro/compacts/**registry**")=) returned empty for
  paths that exact-match fine. *Use exact paths*; for discovery use
  =jj diff -r <sha> --stat | grep=.

** the seed ⚠ long form

=Registry.seed= is a raw =Deno.readDir= loop that pushes *every child directory*
of =scope.registry= as a location — it never reads a manifest, so it cannot know
whether a child is a package:

#+begin_src js
  async seed(scope) {
    const locations = [];
    for await (const entry of Deno.readDir(scope.absolute)) {
      if (entry.isDirectory) locations.push(`${scope.absolute}/${entry.name}`);
    }
    await this.write(locations);
    return locations;
  }
#+end_src

It survives today only because the monorepo =registry/= happens to be one flat
level of packages. Point =VIVA_REGISTRY_MOUNT= at any directory with a stray
child and it seeds garbage. This is *literally the shape fork 11 rejected*
surviving one layer down from where it was killed — the imperative-walk
recidivism family (pre-flight check 1). =paladin.find= is not a drop-in: it
yields FILES by pattern, so the fix is =find(/\.viva\.js$/)= → read → keep
=manifest.type === "package"= → dirname, which is what fork 11 asked for anyway.
