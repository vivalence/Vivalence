* the convention

#+BEGIN_EXAMPLE
~/.viva/                 scope.ledger — machine state, NEVER git-managed
  registry.json          record: package locations (absolute = pinned checkouts
                         incl. the repo's own packages; relative = store children)
  instances.json  locks/  logs/
  registry/              package STORE — scope.registry, unconditional default;
    <slug>/              remote taps clone here; each child = its own git clone
  variants/              variant shelf — NO scope, NO env var; pure convention;
    <slug>/              each child git-manageable; holds variant + environment/ (+ mountpoint/ at runtime)
#+END_EXAMPLE

* decision trail (locked)

1. *Convention = defaults only.* No new env var, no new scope for =variants/=. The ledger mount is the single knob that moves the whole home.
2. *variant ≠ variants* (beef). Runtime renders ONE; =scope.variant= singular forever; the plural is a shelf.
3. *Explicit location wins wholesale*: clone with target puts variant + =environment/= (+ runtime-derived =mountpoint/=) there — already structurally true (=scope.environment=/=mountpoint= branch off =scope.variant=). Only the no-target fallback changes.
4. *=VIVA_VARIANT_MOUNT= learns slugs*: bare token (no =/=, no leading =.=) → =<ledger>/variants/<slug>=; everything else rides =paladin.source= (absolute / =./=cwd / bare-segment-repo-relative).
5. *The store is the ledger's, UNCONDITIONALLY* — =scope.registry= = env ?? =<ledger>/registry=, no citizen branch (recon: citizen cannot discriminate repo-dev from installed). The repo's standard packages are NOT the store's business: they enter =registry.json= as ABSOLUTE refs via seed over =scope.repository.branch("registry")=. This completes the m11 sentence "monorepo registry/ demoted to tapped absolute refs" — and existing ledgers already hold exactly that shape, so nothing migrates.
6. *Seed source moves to the repository registry* (=vip.supply= + =/ledger/install=) — the store starts empty and fills by tap; discovery fills the standard packages.
7. *seed = union* — discovery adds, never erases.
8. *Education emigrates*; monorepo registry = =fixtures/playground/viva= (testing, dev, std). All four education-material runtime test files emigrate WITH it (F2 firmed — scenarios are exported, the harness travels by specifier).
9. *Naming collision accepted* (beef: "fine") — =registry.json= record beside =registry/= store, the brew duality.

describe("scope conventions — the ledger is the home", () => {
  it("registry store defaults to <ledger>/registry", async () => {
    const paladin = await mkPaladin();
    expect(paladin.scope.registry.absolute).toBe(paladin.scope.ledger.branch("registry").absolute);
  });

  it("VIVA_REGISTRY_MOUNT from paladin.env wins over the convention", async () => {
    const paladin = await mkPaladin();
    const explicit = await Deno.makeTempDir({ prefix: "paladin-store-" });
    paladin.env.set("VIVA_REGISTRY_MOUNT", explicit);
    expect(paladin.scope.registry.absolute).toBe(explicit);
  });

  it("VIVA_VARIANT_MOUNT bare slug shelves under <ledger>/variants/", async () => {
    const paladin = await mkPaladin();
    paladin.env.set("VIVA_VARIANT_MOUNT", "localhost");
    expect(paladin.scope.variant.absolute).toBe(paladin.scope.ledger.branch("variants/localhost").absolute);
  });

  it("VIVA_VARIANT_MOUNT absolute path stays verbatim", async () => {
    const paladin = await mkPaladin();
    const home = await Deno.makeTempDir({ prefix: "paladin-variant-" });
    paladin.env.set("VIVA_VARIANT_MOUNT", home);
    expect(paladin.scope.variant.absolute).toBe(home);
  });

  it("seed unions with held taps instead of erasing them", async () => {
    const paladin = await mkPaladin();
    await paladin.ledger.registry.add("/external/checkout");
    const registryRoot = await Deno.makeTempDir({ prefix: "paladin-registry-" });
    await Deno.mkdir(`${registryRoot}/alpha`);
    await Deno.writeTextFile(
      `${registryRoot}/alpha/alpha.viva.js`,
      `export const manifest = { owner: "@alpha", type: "package", slug: "alpha", version: "0.0.1" };`,
    );
    const seeded = await paladin.ledger.registry.seed({ absolute: registryRoot });
    expect(seeded.sort()).toEqual(["/external/checkout", `${registryRoot}/alpha`].sort());
  });
});
#+END_SRC
