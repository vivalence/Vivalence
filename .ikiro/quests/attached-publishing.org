* intent

/"Okay, I have an idea. I would like to move my blogging from or into Vivalence. I think there's a way to do this via attachments. The key question is, can we, as a mode, expose specific endpoints as an attachment outside of authentication to serve bundles of rendered pages, and probably serve whole bundles so that we can break it up into multiple subpoints, so multiple files and a whole bundle, something for the engine and then something per article or something like that. And so that when that attachment point is running, we can use traffic or whatever routing to just look at that specific endpoint. So can we serve as attachments whole bundles? That would probably be a mode, and the same mode inside of the system could be used to, for example, write articles into that bundle. Maybe we create a whole ontology where we have a buffer per article and then a bundling step. So it's like split out.
