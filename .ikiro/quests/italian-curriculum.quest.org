* the decision trail (locked)

1. *Three-tier rank scheme.* T0 social core → T1 food/ordering/payment → T1b everyday transactional (shopping/transport/directions/hotel/health) → T2 = everything else, sorted by =(-anchorZipf, anchorLemma, tokenCount)= where anchor = the rarest content word looked up in the word datasets (articles/preps/names free). T2 gives both wants for free: sentences unlock in vocab order (a sentence never outranks its own vocabulary — the /"vicab and sentences ranking is coherent"/ requirement) AND same-lemma drills cluster (the grammar highlighting). Tier membership = explicit slug lists in =rerank.js=; taste edits happen there.
2. *Additions with elegant redundancy* (45 new, no freight). Three structural patterns, not padding: adjacency pairs (=Grazie mille= → =Prego=/=Di niente=; =Buon appetito= → =Grazie, altrettanto=), minimal pairs on a frame (=Non capisco=/=Ho capito=/=Non ho capito=; =Scusi=/=Scusa=; =Sono di=/=Abito a=; =per due=→=per uno=), register ladder (=Certo che sì → Sì, volentieri → Può darsi → Purtroppo no → Un attimo=). 3. *No single-word sentences.* beef: /"I don't like single word sentences. 4. *Chopping block outcome:* almost nothing choppable — 31/32 Tom sentences are vocalized freight; sole free kill =tom-mi-ha-dato-una-penna=. Freighted junk sinks to wherever its vocab puts it instead.
5. *"After you" ×2* (beef: /"i have 'afyer you' twice and its confusing"/): =dopo-di-te= / =dopo-di-voi=, both vocalized → Italian frozen, glosses disambiguated to =(informal)= / =(plural)=. Gloss edits on freighted entities are lawful.
6. *Words: ingredients before contractions.* beef: /"before I touch a single of the concatenations, I have all of the ingredients from which the concatenations are constructed."/ The whole set = =contraction.js= (30, the full {di,a,da,in,su} × {il,lo,la,i,gli,le} grid — no con/per forms exist, no =l'= entry, so 11 ingredients cover all 30). Fix = minimal permutation over the 41 occupied rank slots: 11 ingredients first (relative order kept), 30 contractions after (relative order kept) → ingredients max 23 < contractions min 27. zipf/fpm untouched (corpus facts). Homograph clitics (=lo.pronoun= et al.) deliberately NOT moved — different lexemes, not ingredients; the same-form-same-rank invariant is knowingly broken, rank is curriculum now.
7. *Audio: band the sources.* beef: /"i need to hear the sentences"/ + /"band the search beyond this singular source"/. const tier = (s) => {
  const i0 = T0.indexOf(s.slug)
  if (i0 >= 0) return [0, i0]
  const i1 = T1.indexOf(s.slug)
  if (i1 >= 0) return [1, i1]
  const i1b = T1b.indexOf(s.slug)
  if (i1b >= 0) return [1.5, i1b]
  const a = anchor(s)
  return [2, -a.zipf, a.lemma, toks(s.trait.TRANSLATED.learning).length]
}

const cmp = (a, b) => {
  const [ta, tb] = [tier(a), tier(b)]
  for (let i = 0; i < Math.max(ta.length, tb.length); i++) {
    const [x, y] = [ta[i], tb[i]]
    if (x === y) continue
    if (x === undefined) return -1
    if (y === undefined) return 1
    return x < y ? -1 : 1
  }
  return 0
}

const reranked = sentences.toSorted(cmp).map((s, i) => ({
  ...s,
  trait: { ...s.trait, RANKED: { rank: i + 1 } },
}))

const byOriginal = new Map(sentences.map((s, i) => [s.slug, i]))
const output = sentences.map((s) => {
  const r = reranked.findIndex((x) => x.slug === s.slug) + 1
  return { ...s, trait: { ...s.trait, RANKED: { rank: r } } }
})
