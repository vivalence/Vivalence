Mine, said in one line each:

- =take= · =give= stand beside his =match= · =lower=: =take= faults on what comes in, =give= on what comes out.
- An =alien= part passes both ways: it is the provider's own block.
- =thinking= is always in a dialogue faculty's =in= (both translators carry it), in =out= only when the model thinks.
- =object= is in =out= on =render= only: both providers build it there, never on =stream=.
- =bytes= is in the grammar and held; no faculty declares one yet. =count= is declared once, from openrouter's =limits.references=; its hand check dies.
- Anthropic's image list is read off its vision guide: jpeg · png · gif · webp.
- A packet is held as the part it is: ={ type: "audio", mime, data }= through =take= coming in (=transcribe= · =converse=) and =give= going out (=gated=, now around =synthesize= too). The meter reads the rate off the mime; a packet that names no rate is not timed.
- A fixture packet of made-up bytes says =audio/pcm= with no rate: it passes a pcm channel and stays untimed, as before.
- A render of any faculty runs the one loop =respond=: =verbatim.render= and =speech.render= lose their own executors. Speech out on =render= was never held before 7 (=vocalize= called no =give=).
- A render transcribes every audio part of the request, one text part each; a speech render speaks every text part, one audio part each. No =count=.
- A transcript's turn has =role: "user"=: it is what the user said, as the stream's turns are.
- =soma.drain= opens a part with its =mime=: the out gate reads a part when it opens.
- A filed part is lowered to a text line only for a faculty that takes text; else the fault names the part's own media type.
- The two turns a tool round adds are lowered before the next round, as the request's turns are: =turns = [...turns, ...lowered(faculty, streamOrRender, [turn, answered])]=. A tool result is a JSON =product=, never media.

    mime: v.array(media()).optional(),
    bytes: v.integer({ minimum: 1 }).optional(),
    count: v.integer({ minimum: 0 }).optional(),

const Sides = v.object(
  { in: v.array(Channel), out: v.array(Channel), via: v.unknown() },
  { additionalProperties: false },

);
