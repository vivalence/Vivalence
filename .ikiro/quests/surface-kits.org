* the law

- A package where code is shared, a subpath where a compiler forces it. Medium is the package (the sheet · the cells), a second framework the subpath.
- A model moves to dapper when BOTH media paint it and the screens stay equal. A DOM-only part keeps its tables; =sheets/text.js= · =gesture.js= · =pointer.js= · =drapes/hold.js= have one consumer each and stay.
- Dapper carries no framework and no medium. Its build tooling rides its own subpaths, never the barrel.
- A member is built from the =node_modules= the view was built from; a view names its members, a client maps them.
- A member is an EXACT specifier in =MEMBERS=; a runtime subpath outside it fails the bundle, loud. A member holds no alias.
- Arcade is a subsystem of its own: never in dapper, never under a kit's framework.
