# geometry

A part's mesh is one GLB on a topography's freight; `MODELED.file` names it, relative to that freight.

- unit: metres.
- axes: Y up, right-handed, as glTF has them.
- origin: the part's own. A placement's `translation` is where that origin sits in its layer.
- `MODELED.tris` and `MODELED.bbox` are measured off the file, never typed.
- a part without a file is PARAMETRIC (a generator builds it) or COUNTED only (the kit ships it, nothing draws it).
#+END_SRC

    cancelAnimationFrame(frameId);

    controls.removeEventListener("change", touch);
    controls.removeEventListener("end", rest);

    renderer.forceContextLoss();
    renderer.domElement.remove();

    palette,

    bounds,
    centre,

    get alive() {

    pose,
    go,
    orbit,
    zoom,
    fit,
    snapshot,
    local,
    struck,
    dispose,
  };
