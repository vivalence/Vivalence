* Desired end state (plain language)

Open the dojo: the drawer is down. One field finds symbols (slug or LABELED name) and literal
traits; a chip clicked lands in the aimed bin — MUST HAVE ALL OF · ANY ONE OF · NEVER — and
the rows below re-resolve as Italian at once, with a count. Take = the domain repository's
own streams. Cap = one typeable number, 10 by default in the drawer, 200 the ceiling. Add clause → a card in THE SET with a live count
and five previewed rows. Presets, recents and saved sets load a whole set. Axes on the right.
Start materializes and closes the drawer; the rep is what remains; the handle over it reads
"N in the set · TYPE ×2". Esc pulls the drawer back. Same thing on a phone, one space at a
time with four stubs. Nothing under the buffer changes: =data.set= clauses in the
repositories' grammar, one resolver, =/resolve /setup /commission=.

* The query engine — exactly what the repositories provide

| repository (level)                     | grammar exposed                                                                 | drawer surface                                   |
|----------------------------------------+---------------------------------------------------------------------------------+--------------------------------------------------|
| Literal (runtime, base)                | =symbols: [..]= AND · ={$all,$in,$none}= · =search= (slug + translations)         | bins ∧ ∨ ∅ take symbol chips · TEXT contains       |
| Data (runtime, base of both)           | =traits: string | [] | {$contains,$overlap,$none}=                              | trait chips drop into the SAME bins              |
| Literal entity fields                  | =ontology= · =rank=                                                             | ontology = TOPOGRAPHICAL symbol chips · RANK window |
| Literal (domain)                       | =feed · due · novel · byStrength · byLastSignal(signals) · sample({status})= · =card= | TAKE row; byLastSignal opens signal toggles, sample opens status toggles; rows carry =status= |
| Symbol (runtime = domain)              | =slug= · =trait.LABELED.name= · =traits {$contains,$overlap,$none}= (ONTOLOGICAL/STRUCTURAL/TOPOGRAPHICAL) · =findByIdentifiers= | =/symbols {search, traits, limit}= — server typeahead, kind filter, trait-dot colour |
| Retention (domain)                     | status · strength · lastSignal · nextAt                                          | through the streams only — no invented filters   |

Clause = ={pick, where?, limit?, signals?, status?, literals?, knowables?}=. =limit= unset = =types.CAP= 200 (emitters); the drawer writes 10 unless told otherwise.
=data.omit= DIES (no surface, no consumer).
