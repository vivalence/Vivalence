* ontologies

** the law — one entity, three ontologies

House mechanism, unchanged (education): an ontology IS the one TOPOGRAPHICAL symbol on a
literal (=Literal.ontology=, subscriber throws on two); traits carry payload shape
(=traits[]= + =trait{}=); symbols classify (ONTOLOGICAL = subject matter, STRUCTURAL =
sets). A domain extends the runtime literal with its trait enum and repository verbs.

#+begin_example
literal
├── vdex         a file on the mount        DOCUMENT  {asset:{path}, title, format, readable, bytes, mtime, hash}   body NOT in row
├── message      a message on a channel     MESSAGE   {channel, direction, from, to[], at, body, external:{id}}     body IN row
│                                           MAILED    {subject, cc[], messageId, inReplyTo, references[], attachments[]}
│                                           CHATTED   {platform, chat, sender:{id,name}, replyTo}
└── transaction  (T4, empty)                POSTED    {at, memo, entries:[{account, amount, currency}]}  Σ amount = 0
#+end_example

** vdex — a document

*** slug — lean, JD-smart

The JD id already encodes area (=22= ⇒ =20-29=) and category (=22=). The slug is the deepest
coordinate present + the ASCII-folded file stem, dotted:

#+begin_example
20-29_koerperschaft/22_finance/22.04_accounting/Rechnungen/Notariat/RE24-05277.pdf   →  22.04.re24-05277
10-19_viva/12_goals/12.04 Ubiquity and a Thin Slice.md                                →  12.04.ubiquity-and-a-thin-slice
30-39_architecture/30.00_architecture.mdx                                             →  30.00.architecture
10-19_viva/12_goals/notes.md            (category-level file)                          →  12.notes
00.00 Index.org                          (root, id in the name)                        →  00.00.index
readme.org                               (root, no coordinate)                         →  readme
#+end_example

- directories never enter the slug; =DOCUMENT.asset.path= (mount-relative) is the truth on disk
- collision inside one coordinate (=a/x.md= · =b/x.md=) → sorted by path, second gets =-2=
- the JD id itself is a SYMBOL (=vdex.id.22.04=), never a literal; a file is the literal
- the parser tolerates both grammars on disk: =NN-NN[_ ]area= · =NN[_ ]category= · =NN.NN[_ ]id= (=jd.js= below)

** message — email and chat, one ontology

/"is email a type of message?"/ — yes. =message= is the TOPOGRAPHICAL symbol; the channel is
a symbol dimension; the channel-shaped fields ride a trait. Same shape as =word= +
TRANSLATED/VOCALIZED/CONJUGATED. Two ontologies would fork every read tool ("what did X say"
must cross channels), and the subscriber allows exactly one TOPOGRAPHICAL symbol anyway.
={symbols: ["message.channel.email"]}= = all mail; =implements("MAILED")= = has headers.

** ownership — mode ↔ literal · symbol (typology + runtime, GATED)

Today a dataset row has no owner: =Mode.installed= is a content hash, =Literal= knows its
symbols and its =uses=, nothing knows which mode put it there. Prune is therefore impossible
everywhere. The relationship:

#+begin_src javascript
// subsystems/typology/schematics/entities/mode.js  (mirror of buffer.js:12-13)
literals: () => v.array(v.literal()).optional(),
symbols:  () => v.array(v.symbol()).optional(),
// literal.js / symbol.js — the inverse
modes: () => v.array(v.mode()).optional(),
#+end_src

#+begin_src typescript
// systems/runtime/daemon/entities/daemon/Mode.ts — owner side, pivots mode_literals · mode_symbols
literals = new Collection<LiteralEntity>(this);
symbols  = new Collection<SymbolEntity>(this);
// properties: { literals: { kind: "m:n", entity: () => LiteralEntity, owner: true }, symbols: { … } }
#+end_src

- =systems/runtime/daemon/traits/dataset.js= — the install links every upserted row to
  =mode.entity= in the link phase (same =INSERT OR IGNORE= pivot mechanism it already uses
  for =symbol_literals=). Education's rows gain owners; its boot is otherwise byte-identical.
- =install(mode, daemon, dataset)= is FACTORED OUT of the =DATASET= trait so a BOOTED mode can
  install a dataset it computed from the world (=reader.rows= already exists in
  =subsystems/typology/prototypes/dataset.js=). No =installed= stamp for boot installs.
- =prune(mode, keep)= on the domain repository: =delete literal where modes ∋ mode and slug ∉ keep=;
  same for minted symbols. Scheme symbols (dataset-declared) are never pruned — they re-install
  on stamp change. A symbol declared by two modes (=message=) is multi-owned; m:n carries it.
- typology is HOLY: the =mode.js/literal.js/symbol.js= touch lands only on an explicit go, under
  the blast-bracket (education boot + runtime suites before/after).

#+begin_src javascript
// modes/office/vdex/jd.js — both grammars on disk; coordinates → symbols, deepest coordinate → slug prefix
const AREA = /^(\d\d)-(\d\d)[ _](.+)$/;       // 20-29_koerperschaft · 10-19 Business administration
const CATEGORY = /^(\d\d)[ _](.+)$/;          // 22_finance · 11 The business & its people
const ID = /^(\d\d)\.(\d\d)[ _](.+?)(\.[^.]+)?$/;   // 22.04_accounting · 12.04 Ubiquity and a Thin Slice.md
const SLOT = { "00": "index", "01": "inbox", "02": "tasks", "03": "templates", "04": "links", "08": "someday", "09": "archive" };

const fold = (text) =>
  text.normalize("NFKD").replace(/[̀-ͯ]/g, "").toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-|-$/g, "");

export function coordinates(path) {
  const symbols = [];
  let prefix = "";
  for (const segment of path.split("/")) {
    let match;
    if ((match = segment.match(ID))) {
      symbols.push(structural(`vdex.id.${match[1]}.${match[2]}`, match[3], path));
      if (SLOT[match[2]]) symbols.push({ slug: `vdex.slot.${SLOT[match[2]]}` });
      prefix = `${match[1]}.${match[2]}`;
    } else if ((match = segment.match(AREA))) {
      symbols.push(structural(`vdex.area.${match[1]}-${match[2]}`, match[3], path));
      prefix = `${match[1]}-${match[2]}`;
    } else if ((match = segment.match(CATEGORY))) {
      symbols.push(structural(`vdex.category.${match[1]}`, match[2], path));
      prefix = match[1];
    }
  }
  return { symbols, prefix };
}

const structural = (slug, name, path) => ({
  slug, traits: ["STRUCTURAL", "LABELED"],

export const slugOf = ({ prefix }, file, seen) => {
  const stem = fold(file.path.split("/").pop().replace(/\.[^.]+$/, ""));
  const base = prefix ? `${prefix}.${stem}` : stem;
  let slug = base;
  for (let n = 2; seen.has(slug); n++) slug = `${base}-${n}`;
  seen.add(slug);
  return slug;
};

export async function boot(daemon, mode) {
  const root = mode.mountpoint.absolute;
  const files = await paladin.find.index(root, { ignore: mode.statics.ignore });   // T2.b: [{path, format, bytes, mtime, hash}], sorted
  const seen = new Set();

    });
