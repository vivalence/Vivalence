* the design — shape only

Three owners, one shared organ, drafted from beef's rulings:

#+BEGIN_EXAMPLE
provider    HARD LIMITS per call        max_tokens · timeout · the SDK fetch takes { signal }        anthropic/openrouter provider/index.js
hallucination  THE LOOP                 rounds · tokens (Σ turn.meta.usage) · repeated identical tool call → stop (name+input hash seen twice)
                                        checks policy.signal between rounds; deliver() forwards it     shard/hallucinate.js
tool        gated + viewed              dispatch() opens a span branch already; it joins the same organ (count · elapsed · condition)
aperture    the same I/O                a request is an activity too — optional, same organ; stop/activity verbs live here
cortex      MEDIATES                    resolves faculties; hands the organ's signal + span into policy; never owns a budget
THE ORGAN   daemon-level, shared, modes never touch it
            reach(thread)               join the live one or mint; a child thread joins its parent's signal (AbortSignal.any)
            budgets that SUM            per thread · per user · per mode · per daemon — a tree of counters, the leaf adds up
            rate                        calls per minute at any node of the tree (beef: "per thread. Maybe per daemon even. or per user")
            control                     stop(node) → abort every signal below; the provider fetch dies NOW, not at the next yield
            view                        the span pipe as a nano-atom: per hallucination — path · opened · rounds · usage Σ · calls (name · input · condition) · faults · thinking deltas
#+END_EXAMPLE

Where it attaches (beef: /"Maybe the control doesn't flow through the span"/ — held as a fork): control = AbortSignal down the tree; telemetry = Span up the tree. Two directions, two mechanisms, one organ holding both handles per node. The span is the VIEW, never the control.

Thread + buffer awareness (beef: repository vs trait, unsure): neither row needs a column — the organ is keyed by thread id in memory on the daemon; the F-panel reads the organ, not the row. A trait would persist a live thing; a repository verb would make the daemon's memory a table. Lean: the organ is a prototype on the daemon (`daemon.<noun>`), reached by id, not persisted; the fork stays his.

kajuit: F panel, live list per thread (and daemon-wide, for the operator): elapsed · tokens · calls · the last tool · faults; thinking unfolds inline from the same stream; the existing stop button calls `stop` and is finally honest.

* the noun

beef: /"we need a word for this … propose me a couple of words … not process or job … don't call it the ledger"/. `process` is taken by m49 (Process/Die on Wafer), `line` by multiplex, `effort` by INTELLIGENT, `session` by the lighthouse. Two things want naming: the UNIT (one bounded run of a hallucination/tool) and the ORGAN (the daemon-level shared instance).

#+BEGIN_EXAMPLE
the organ (daemon-level, shared, controls + counts + views)
  governor     the engine part that caps speed — rate limit, budget, stop, in one plain word; universal, no coinage. daemon.governor.reach(thread)
  metabolism   what the body burns and at what rate — extends the cortex/soma/hallucination family; the F panel shows the metabolism
  warden       holds the keys, counts the inmates, can halt; slightly carceral

the unit (one bounded run under the organ)
  stint        a bounded period of work — the budget is IN the word; a hallucination opens a stint, tools run inside it
  bout         one round of exertion with an end; reads well nested (a bout inside a bout)
  errand       one sent-out task with a return — fits tools better than hallucinations
#+END_EXAMPLE

Lean: `governor` + `stint` — both standard English, both say the constraint, neither collides. `metabolism` if the bio register should win.
