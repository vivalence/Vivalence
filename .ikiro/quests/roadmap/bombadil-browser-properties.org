* what it is
Bombadil (Antithesis, github.com/antithesishq/bombadil, manual v0.7.10). A CLI: =bombadil browser test · fuzz · shrink · inspect=, plus a terminal track. A spec is a TypeScript file that imports =@antithesishq/bombadil= and re-exports the browser defaults. Properties use temporal operators =now · always · extract=.

The marked example (3.7.2), from the manual:

#+begin_src ts
import { extract, always, now, time } from "@antithesishq/bombadil";
export * from "@antithesishq/bombadil/browser/defaults";

const notificationCount = extract((state) =>
  state.document.body.querySelectorAll(".notification").length,
);

export const constantNotificationCount = now(() => {
  const initial = notificationCount.current;
  return always(() =>
    notificationCount.current === initial,
  );
});
#+end_src
