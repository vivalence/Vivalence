Leak paths: history · Referer · server logs · screenshots. Mitigations: one use · short TTL · POST redeem · =history.replaceState= · after =#= so it never reaches a server.

* the coherent shape — a URL is REPL lines

m95 settles everything through the repl; the demo's "try it" already replays lines (=~/Downloads/vivalence-client-v1/build/src/design.js:236= =lines.forEach((l) => R.dispatch(w, l))=). So the query is lines, the fragment is the credential:

#+begin_src text
http://localhost:1794/?do=/terminal%20<id>&do=/mode%20<daemon>/<type>/<slug>#code=<one-use>
#+end_src
#+begin_src js
// systems/anima/src/surface/arrival.js (sketch)
export const arrival = async (client, location) => {
  const lines = new URL(location).searchParams.getAll("do");
  const code = new URLSearchParams(location.hash.slice(1)).get("code");
  history.replaceState(null, "", location.pathname);
  if (code !== null) await client.dispatch(`/lighthouse/redeem ${code}`);
  for (const line of lines) await client.dispatch(line);
};
#+end_src

* two designs for the credential

A. the refresh token itself in =#refresh==, stripped on read, boot's refresh step mints access.
#+begin_src js
const refresh = new URLSearchParams(location.hash.slice(1)).get("refresh");
history.replaceState(null, "", location.pathname);
client.lighthouse.authority = { refresh };
#+end_src
Cost: zero server code; a reusable 180-day credential sits in history and screenshots — the user's ONLY session.

B. a one-use code: the lighthouse mints, the client redeems.
#+begin_src ts
// systems/runtime/entities/User.ts (sketch) — repository verbs, mikro-first
async admit(user) { const code = crypto.randomUUID(); await this.assign(user, { admission: { code, expires: Date.now() + 120_000 } }); return code; }
async redeem(code) { const user = await this.findOneOrFail({ admission: { code } }); if (user.admission.expires < Date.now()) throw new Expired(); return this.assign(user, { admission: null }); }
#+end_src
#+begin_src sh
viva /lighthouse/admit --terminal <id> --mode <daemon>/<type>/<slug>   # prints the URL
#+end_src
Cost: ~30 server lines + ~10 client; INVITATIONAL's empty function is its natural owner.

Lean B. Catch either way: redeeming writes the one session slot, so the =viva= that minted the link is logged out on its next refresh — three answers: accept it (=/login= does it today) · =/redeem= hands back the existing refresh (shared session) · a session entity (over-engineered now).
