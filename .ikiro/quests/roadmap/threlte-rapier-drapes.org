* laws measured today (droneaid)

- Deno import maps CANNOT prefix-map into npm: — ="three/": "npm:three@x/"= fails with /"could not be URL-parsed relative to the URL prefix"/. Addons are exact entries or =npm:three@x/addons/...= inline.
- =three/addons= (the =Addons.js= barrel) imports an =https:= module → Deno's ESM loader refuses (=ERR_UNSUPPORTED_ESM_URL_SCHEME=). Never import the barrel server-side.
- The browser bundler never reads the import map for bare specifiers: =gestalten/bundle/svelte.js= resolves from =nodePaths=[<repo>/node_modules]= with =conditions: ["svelte","browser"]= and =mainFields: ["svelte",…]= — exactly what threlte's =.svelte= sources need. An out-of-tree package's buffer importing =three= or =@threlte/core= compiles without the package owning a node_modules.
- The drapes law from the editor quest stands: a heavy engine is a SUBPATH (=@vivalence/drapes/<x>/index.js=, entry always =.js=), never re-exported from =mod.js=. =stage/= is in the barrel today, so echarts already rides every buffer; three (≈600 kB min) must not join it there.
