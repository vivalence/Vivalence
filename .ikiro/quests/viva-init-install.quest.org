* arc

A fresh clone cannot boot. =testament/= is gitignored wholesale (=.gitignore:1=); the only
committed bootstrap artifact is repo-root =.env.example=. So a new developer has no ledger, no
variant manifest, no =environment/= jsoncs — nothing to run.

Close the gap with two ghost trajectories + a self-contained =localhost= registry variant.
=ledger install= scaffolds the per-machine run surface and mounts the standard packages;
=variant clone <source> <target>= resolves a variant (by identifier OR filepath) and
recursive-copies it into place. The =localhost= variant carries its own =.env.example= so it is
turnkey — clone it, fill five secrets, boot.

This is the frontier's =viva-init/install= thread.

* command specs

** ledger install [dest]

Takes ONLY a destination path (default =testament/ledger=). Every ledger install features the
standard packages in =/repo/registry=.

#+begin_src text
scaffold   dest/{locks,logs}                        (mkdir -p; from system/init)
seed       dest/instances.json = {}
seed       dest/registry.json  = [ /repo/registry/* ]   the standard packages, always
→ the ledger now KNOWS the registry; vip.supply() resolves variants from registry.json
#+end_src

** variant clone <source> <target>

=<source>= is a known format — a filepath OR a pensieve identifier. =<target>= is the destination
dir (default =testament/variant=). Recursive dir-copy from the resolved mount; overwrites what is
there.

#+begin_src text
source.startsWith("@")  → paladin.vip.accio(source)   → module.mount    identifier
else                    → paladin.source(source)      → Path            filepath: ../ · ./ · /abs · bare-segment
cloneDir(mount, resolve(INIT_CWD, target))            recursive copy      (clone.js already has cloneDir)
#+end_src

Ordering: =ledger install= must run first — =variant clone <identifier>= resolves =<source>=
against the ledger's mounted packages (=vip.supply()= reads =registry.json=).

* resolution primitives (pensieve / paladin — never hand-roll)

The identifier is =@owner/type/slug[@version]=. Parse lives in =cast.lookup= (typology
=gestalten/cast/primitives.js:24=, =is.string= branch):

#+begin_src js
const [owner, type, ...rest] = thing.split("/");
const [slug, version] = rest[0].split("@");
return { owner, type, slug, version };
// "@viva/variant/localhost"  → { owner:"@viva", type:"variant", slug:"localhost" }
#+end_src

- =Manifest.identifier= (=paladin/prototypes/manifest.js=) = =`${owner}/${type}/${slug}`=.
- =Pensieve= (=pensieve.js=) = nested Map owner→type→slug→version; =revelio= pure descent, =latest= semver fold.
- =Vip.accio(query)= (=vip.js:55=) = =cast.lookup(query)= → =pensieve.revelio= → module (carries =.mount= Path). Two-throw: "not supplied" ≠ "Module 404".
- =Vip.supply()= (=vip.js:43=) = =ledger.mount()= (fn.once) → =ledger.registry.read() ?? seed(scope.registry)= → =mount= per location.
- =paladin.source(location)= = 4 styles: absolute · ./cwd · {file,source} · bare-repo-segment. THE filepath resolver.
- owner DERIVES from mount dirname (=@${last-segment}=); an authored =package.viva.js manifest.owner= LOCKS it.
