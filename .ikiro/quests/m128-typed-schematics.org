- In plain JS a parameter is typed only where its function sits inline in a typed call. Outside one it needs a =@type= row or a =.ts= file (ruling 6).
- A declaration file types a file's importers, never its own body. Nothing checks it against the JS until the type check.
- =decode= changes the object in place only because =Instance= is a class. On a plain object it returns a new one and the given keeps its strings (=probes/held.probe.js= · =probes/held.instance.probe.js=).
