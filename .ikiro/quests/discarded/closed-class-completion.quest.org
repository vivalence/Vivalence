* Tier 1 — Zero-fill (highest leverage)

** Contractions (T1.A)

Strict UD: contraction is NOT a UPOS. UD handles contractions via multi-word token splitting — component PoS only. The 14 existing entries already follow this (compound =ADP + DET= or =ADP + PRON=); no retag needed.

Add the 41 missing forms with compound PoS per their components.

Clinic queries contractions via PoS-intersection (=adposition= AND =determiner|pronoun|adverb=); slug suffix =.contraction= is naming convention only, not an ontology marker.
