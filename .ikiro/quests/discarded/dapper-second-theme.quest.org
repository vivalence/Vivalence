* Intent

Dapper ships one theme today (=themes/dark.js=). This quest adds a *second*
theme — a warm dark red/wine palette sampled from the =flap= video asset — as a
peer theme function, and persists the palette as the single source of colour
truth consumed by BOTH the web zones (kajuit) AND the ghost TUI ascii field
(the =instance/init= background). One palette, two renderers.

* Why

@beef wants the =instance/init= wizard to play the flap clip as a warm-red ascii
field background. Rather than hardcode a red ramp in the TUI, the colour theme
belongs in dapper — the theming subsystem — as a real second theme. The TUI
=Field= and the web =Zone= then both read the same =ember= palette. Persisting
it here also seeds eventual runtime theme switching (see decorum dependency).

Theme character: warm dark *red → wine → magenta*, low-lum bulk, magenta-pink

Grounded 4-level ramp (the TUI field consumes this directly; the web ramp
interpolates a full 0–950 scale around these anchors):

#+begin_example
  L0  #1a0606   space / black
  L1  #330000   dark red (bulk)
  L2  #803349   brick ↔ wine
  L3  #cc6679   mauve / salmon highlight
#+end_example

* Architecture — extend dapper, don't special-case

** colors.js — add the warm ramps
=subsystems/dapper/primitives/colors.js= holds named ramps (=gray=, =aqua=,
=indigo=, =rust=, =pink=, =amber= …) keyed 0–950. Add a =wine= (or =ember=) ramp
interpolated from the seed anchors above (L1→L3 across 300→700, deepening to 950
at =#1a0606=). The existing =rust=/=pink=/=amber= warm ramps may cover roles;
=wine=/=ember= is the new surface/boundary identity ramp.

** themes/ember.js — the second theme fn (mirror dark.js)
A peer of =dark.js=. Same shape:
#+begin_example
  export default async function (ds) {
    const { ember, wine, rust, pink, amber, moss, indigo } = ds.colors.roots;
    ds.themes.ember = { ...ds.tokens };
    const roles = { primary: {ramp: ember, anchor: 300}, accent: {ramp: pink, …}, … };
    const zone0 = skeleton({ surface: ember[900], contrast: ember[200], boundary: wine[400], roles, error, font });
    … zone1..N …
  }
#+end_example
surface = dark maroon (=#1a0606=/=#330000= band), contrast = mauve/salmon
(=#cc6679=), boundary = wine. Zones step the surface like dark.js steps =iron=.

** themes/index.js — register
=[dark, ember].reduce(...)= so both themes build into =ds.themes=.

** TUI consumption — the ascii Field reads ember
The =instance/init= =Field.jsx= (ascii video bg) imports the =ember= L0–L3 ramp
(not a hand-written red). Single palette → web zones + terminal field stay in
lockstep. (Bridge: a tiny export of the 4 anchors from dapper that the TUI can
import without the web/postcss machinery.)
