* intent

beef, verbatim: /"i think i detected an issue in ledger. we store a slug in instances.json and
then another in ledger/instances/*/*.vivajs. no?"/ · /"instances.json is the identity authority:
{ slug: { mount } }. Manifest slug is template-only and never consulted for instance identity.
amen!"/ · /"dir name as slug??!! suuggest that again i get grok"/ · /"as is not flag. is second
optional param"/ → revised → /"--slug maybe makes sense"/ · flags ruled property-specific over
semantic: /"amen"/ to =--slug=.

One sentence: *instance identity has exactly one store — the ledger record* — =manifest.slug=
names the RECIPE (what a registry reference resolves to), =instances.json= names the INSTANCE
(slug → mount), and every reader (locks, logs, sessions, specs, doctor) resolves through the
record; nothing ever derives identity from a directory name or a manifest again.

* the law

                 a MAP — the key IS the slug; uniqueness is structural, never a runtime check

        instance/tap <path> --slug=<slug>                        adopt a hand-placed dir

        mount-by-slug  = the record row the picker already read  (use takes row.mount)

never   manifest.slug for identity — template-only
never   basename(mount) for identity — display fallback only, never written
never   a slug in VIVA_INSTANCE_MOUNT — MOUNT MEANS PATH, populate's throw is PERMANENT

Two shelved copies of one recipe now hold two record entries with the same =manifest.slug= —
the README promise ("two shelved copies, not two moods of one") becomes true at the
locks/record layer, not just on disk.

* the decision trail

- *Array-of-paths record, slug = basename* — proposed, KILLED by beef (/"dir name as
  slug??!!"/). Path is identity's *anchor*, not its *name*.
- *Manifest as instance identity* — killed jointly: every copy needs a file edit or collides;
  "iffy cause hard to set".
- *Heuristic precedence* (=manifest.slug ?? basename=, target.js:11) — this IS the bug: two
  readers, silent loser. (The manifest preference was itself m41 work — deliberate
  supersession, not drift.)
- *=--as= vs =--slug=* — property-specific ruled: flags name the record field they set. /"amen"/.
- *[target] param stays a path* — beef corrected himself; slug is never positional.
- *List of objects, slug inlined* — beef floated (/"what do you think about implementing this
  as a list of objects instead iwht slug inlined}"/), then ruled /"keep."/ the map: rows are a
  projection every reader folds in one line; the authority file's job is uniqueness, and a map
  makes slug collision impossible BY CONSTRUCTION.
- *Bare slug in VIVA_INSTANCE_MOUNT* (the old M4: record lookup + shelf fallback in populate)
  — KILLED: /"can only every be a path. mount is a path type. non negotiatable. always."/
  populate's m41 throw is permanent; slugs enter ONLY through =instance/use=, which resolves
  them via the record and stores the path. M4 recast accordingly.
- *register on unknown mount* — throws; =use=/=init= CATCH and print the tap line. /"amen."/
- *Log identity on rename* — beef floated session-keyed logs (/"if we 'ALWAYS' set session, we
  could merge those?!"/) — killed: sessions are shell-pid-keyed and reaped, wrong lifetime for
  instance history. Ruling: /"move on rename. obviously."/ Locks AND logs move with the key.

#+BEGIN_SRC js
import paladin from "@vivalence/paladin";
import { path } from "../../belt/index.js";

export async function tap(ctx) {
  const [input] = ctx.signal.params ?? [];
  const slug = ctx.signal.flags?.slug;
  if (!input || !slug) {
    return (ctx.effect = { error: "usage: /instance/tap <path> --slug=<slug>" });
  }
  if (!input.includes("/") && !input.startsWith(".")) {
    return (ctx.effect = { error: `'${input}' is a slug-shaped token — a tap takes a PATH; try ./${input}` });
  }
  const mount = path.pin(input);
  const stat = await Deno.stat(mount).catch(() => null);
  if (!stat?.isDirectory) return (ctx.effect = { error: `no directory at ${mount}` });
  if (await paladin.ledger.instances.read(slug)) {
    return (ctx.effect = { error: `instance '${slug}' exists` });
  }
  await paladin.ledger.instances.write(slug, { mount });
  ctx.effect = { tapped: slug, mount };
}
#+END_SRC
