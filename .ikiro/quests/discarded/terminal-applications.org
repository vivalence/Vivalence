* the shape in English — a draft, not a ruling

The browser already does this. A mode with =APPLICATION= ships a svelte app; the runtime bundles it through paladin's bundler and serves it by hash; anima =import()=s it and renders each buffer's =data= through it. =GENERATIVE= does the same with source a hallucinator wrote.

The terminal twin is the same pipe with a third bundler kind. A =jsx= kind compiles an ink component with =react= · =ink= · =@vivalence/sheets= external; ghost imports it by URL (Deno imports a URL) and renders the buffer in the stage, where F17's parked (d) put a mode's face. Generative: =SOURCE= gains an ink twin, so a hallucinator can write a terminal face. Procedural: a face built from the buffer's schema with no authored component (Blender draws its panels from RNA) — the floor every buffer gets for free.
