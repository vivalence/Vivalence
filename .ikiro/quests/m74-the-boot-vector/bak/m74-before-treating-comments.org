* nomenclature

| word       | is                                                                     |
|------------+------------------------------------------------------------------------|
| run        | one lifecycle vector per process type, =run.daemon=                    |
| lifecycle  | a middleware on a run, =(die, next)=                                   |
| die        | =controller · mask · subject= + what the run owns                      |
| subject    | =die.runtime · die.service · die.daemon · die.mode=, born with the die |
| birth      | population: the parent mints controller, subject, row; row IDLE        |
| boot       | resolution: the parent executes the child's run; row RUNNING           |
| execution  | the promise of a started run                                           |
| process    | a row of =entities.process=                                            |
| controlled | the wait for a status on a controller                                  |
| ctx        | the request context, never at boot                                     |

| holder               | holds                                                | reached by               |
|----------------------+------------------------------------------------------+--------------------------|
| the die              | =controller · mask · <subject>=                      | the run                  |
| a daemon's die, more | =register · instance · connection=                   | the run, never a request |
| a mode's die, more   | =daemon · traits=                                    | the run                  |
| the subject          | =aperture · entities · datamap · modes · cortex · …= | =ctx.daemon=             |
| the parent's subject | =runtime.daemons= · =daemon.modes=                   | the parent's lifecycles  |
| the row              | =type · slug · manifest · status= + three handles    | =entities.process=       |

      bind: (name, resolve) => async (ctx, next) => {

        await next();
      },
      carry: () => {
        const context = RequestContext.currentRequestContext();
        return (task) => (context ? RequestContext.storage.run(context, task) : task());
      },
    };
  }

    return this.orm.getMetadata();
  }

    this.orm.em.getEventManager().registerSubscriber(subscriber);
  }

    return this.orm.close();
  }
