* nomenclature

| word       | is                                                                     |
|------------+------------------------------------------------------------------------|
| run        | one lifecycle vector per process type, =run.daemon=                    |
| lifecycle  | a middleware on a run, =(die, next)=                                   |
| die        | =mask= + =runtime= · =service= · =daemon= · =mode= + what the run owns; a process's with its =controller= |
| birth      | population: the parent creates the process with its controller; IDLE   |
| boot       | resolution: the parent executes the child's run; RUNNING               |
| execution  | the promise of a started run                                           |
| process    | a =Service= or a =Daemon=, an entity of =runtime.processes.<type>=     |
| controlled | the wait for a status on a controller                                  |
| ctx        | the request context, never at boot                                     |

| holder               | holds                                                | reached by               |
|----------------------+------------------------------------------------------+--------------------------|
| a process's die      | =controller · mask= + =runtime= · =service= · =daemon= | the run                |
| a daemon's die, more | =register · instance · connection=                   | the run, never a request |
| a mode's die         | =mask · mode · daemon · traits=, no controller       | the run                  |
| the daemon           | =aperture · entities · datamap · modes · cortex · …= | =ctx.daemon=             |
| the runtime          | =runtime.processes.{service,daemon}=                 | the runtime's lifecycles |
