* the problem — measured 10-01

=Vector.slurp= copied the source's *edge table* one level deep and shared the subtrees. The runtime builds its served aperture by slurping every service, daemon and mode aperture, so:

- a top-level =open()= on a service aperture after resolution never reached the served root
- a grandchild =open()= did reach it, because those nodes were shared
- a nature colliding across two slurps was forked one level deep — children dead, grandchildren live

Liveness depended on depth. That is the smell.

* the law

#+BEGIN_EXAMPLE
a vector has no identity of its own. it is reached only through an edge. so:

  copy      is a NODE operation — pour another node's contents into mine.      graft(vector)
  reference is an EDGE operation — point an edge at another node.              branch(sig, vector)

the grid  {copy, reference} × {self, path}  has three cells and one structural hole:
  path × reference   branch(p, v)
  path × copy        branch(p).graft(v)      (the two primitives composed, not a third op)
  self × copy        graft(v)
  self × reference   —    a node cannot point at itself; only the edge above it can be re-pointed,
                          and re-pointing it orphans the node. not a missing method.

a vector holds NO record of what it was built from. no sources list, no composed producer,
no previously-slurped slot. the trie IS the structure.

attach is always live, at every depth, in both directions: open() on the mounted node writes
into the source, because they are one node. middleware and sibling routes that used to hang on a
mount node hang on the source instead.

graft is a deep copy, frozen at graft time, at every depth. on collision the later effect and the
later pattern win; an earlier effect survives a later side that has none. self-graft is a no-op.

branch(sig, v) on an OCCUPIED edge degrades to graft into the existing node — never a silent get.
on a multi-segment path the vector lands on the leaf; intermediates are minted.
#+END_EXAMPLE

* the change

** =subsystems/typology/prototypes/vector.js=

#+BEGIN_SRC js
  branch(signature, trajectory) {
    const pattern = new this.signature(signature);

    if (pattern.nature == null && !pattern.heir) return this;

    let edge = this.trie.get(pattern.nature);
    if (!edge) {
      edge = { pattern, trajectory: (!pattern.heir && trajectory) || new this.constructor(this, this.signature) };
      this.trie.set(pattern.nature, edge);
    } else if (trajectory && !pattern.heir) {
      edge.trajectory.graft(trajectory);
    }

    if (pattern.heir) {
      return edge.trajectory.branch(pattern.heir, trajectory);
    }
    return edge.trajectory;
  }

  graft(vector) {
    if (vector === this) return this;
    if (vector.effect) this.effect = vector.effect;

    for (const [nature, edge] of vector.trie) {
      const existing = this.trie.get(nature);
      const branch = existing?.trajectory ?? new this.constructor(this, this.signature);
      branch.graft(edge.trajectory);
      if (existing) existing.pattern = edge.pattern;
      else this.trie.set(nature, { pattern: edge.pattern, trajectory: branch });
    }

    this.carry.push(...vector.carry);

    return this;
  }
#+END_SRC

Deleted: =set()=, =slurp()= and its comment. =swallow= renamed =graft=. Two lines =graft= gained over =swallow=, both forced by tests: the self-guard (=swallow(this)= recursed the whole tree and doubled =carry=) and =existing.pattern = edge.pattern= (slurp's "later wins on the edge" — the valence/input overrides the harnessed tool tests pin).
