* patch
A buffer renders from its OWN attached view first, the mode's app as the
fallback. Three sentences carry the design: CONTENT on the row, LOCATION in
live metadata, ARTIFACT in the store.

| where    | what                                              |
|----------+---------------------------------------------------|
| row      | =view = { kind, hash, output, bytes, source }=    |
| metadata | =app.spawned= — the live serve base               |
| store    | =<hash16>.<ext>= source, =<hash16>.<kind>.mjs=    |

=hash= addresses the source, =output= is what the client verifies before
executing. No location persists — the client derives
=<station>/<hash16>.<kind>.mjs=, so rows never carry stale origins. The store
(under the mountpoint: boot-persistent, in-repo so esbuild resolves workspace
imports) is the seam's ONLY state — no keeper, no cache to invalidate. Spawn
is idempotent because the artifact exists; serve reads it back; restarts
change nothing by construction. Serve names are regex-guarded (no store
traversal); creation flows only through emitters — there is no spawn
aperture. Frame fetches, digests, compares, executes via blob import,
memoizes by =output=; an unverifiable view faults, never runs.

Verified out-of-tree against the exact esbuild-svelte config (svelte pinned
5.39.6): 12/12 compile+integrity (wall, diagnostics, determinism, tamper),
12/12 store semantics (mtime-proven artifact reuse, traversal refusal, html
contract), jsdom mount driving a spawned component's controls.

Open forks, deliberately NOT taken: the =view= column needs a schema
migration; store growth is unbounded (content-addressing makes GC safe
whenever wanted); =@playground/chaosmonkey/reader= wants testament
registration.

      return this;
    },
  };

  static from(pojo, app) {
    const buffer = Object.assign(new Buffer(), pojo);
    buffer.app = app;
    return buffer;
  }

  mount() {
    for (const hook of this.hooks.mount) hook(this);
  }
  unmount() {
    for (const hook of this.hooks.unmount) hook(this);
  }
  // render(...a) {for (const hook of this.hooks.render) hook(this, ...a);}
  release(...a) {
    for (const hook of this.hooks.release) hook(this, ...a);
  }
}
