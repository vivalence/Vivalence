#+AUTHOR: Vivalence
#+DATE: 2026-04-20
#+STATUS: DESIGN

* Intent

Tactic emitters today mix four layers in one function body: data fetching, domain-predicate filtering, pedagogical policy, and buffer composition. Twenty-one emitters (5 survival + 12 clinic scopes + 4 clinic sub-emitters) each re-derive the same paradigm-unpacking, weakness-filtering, and pool-composition patterns.

Split the reusable machinery onto =ctx= as two middlewares, analogous to =ctx.pool= and =ctx.daemon=:

- =ctx.analysis= — surveys, repo-method wrappers, pure decoders, phase derivation
- =ctx.routine= — named buffer-sequence emitters, encapsulating isParadigm branching + pool.section/apply plumbing

Each emitter shrinks to ~5–10 lines of pure domain policy.

* Desired end state

- Two middlewares attached by the EMITTER trait, available wherever a tactic/game emitter runs.
- Every tactic emitter file is under 30 lines and reads as intent, not implementation.
- =extractParadigm=, =assess=, =weakest=, =weightedPick=, =failedTokenIndices=, =pickWeakForms= live in one place, not duplicated between =clinic/emitter/tools.js= and inlined copies in survival/clinic effects.
- Per-game emit patterns (exhibit + flashcard, pick-from-pool, match-batch, cloze-on-indices, shadow-or-write, listen-type, conjugation-drill) live on =ctx.routine=, not in effect bodies.
- Clinic scopes express as =ctx.routine[phase](items)=; survival phases express as sequenced routine calls.

* Principles currently violated

** Principle 1 — Use repo methods, don't reimplement queries in JS
- =matchPool.sort((a,b) => a.memory.strength - b.memory.strength).slice(0, 6)= is =byStrength(..., {limit: 6})=.
- =forms.filter((f) => !f.memory || f.memory.is.weak)= is a WHERE clause or a status-scoped repo method.
- =sentence.uses.getItems().filter(word => word.memory?.is?.failed)= is =byLastSignal(["MISTAKE","FAILURE"], ...)= on a scoped subset.

** Principle 2 — Emergence over workarounds (no duplication of named patterns)
- =extractParadigm= exists in =tactic/clinic/emitter/tools.js=; survival's =buildup.js= and =warmup.js= inline the identical unpacking (bySlug → infinitive → forms → tenseSymbol → moodSymbol).

** Principle 4 — No intermediate aliases without purpose
- =distractorPool=, =matchPool=, =weak=, =dueVerbs= in buildup. =virgin=, =failedSlugs=, =blankIndices= in exercise. Each is a staging ground for a single downstream expression. Absorb into named functions or inline.

** Principle 5 — Architecture over expedience
- Refactoring 21 emitter files one-by-one is expedient. Extracting the shared layer once is architecture. This WP favors the latter.

* Middleware surface

** =ctx.analysis=

*Query wrappers* (named, ontology-scoped — thin over =ctx.daemon.entities.literal=):
- =analysis.sentences({ where?, limit, blacklist?, populate? })=
- =analysis.words({ where?, limit, blacklist?, populate? })=
- =analysis.conjugations({ where?, limit, blacklist?, populate? })=
- =analysis.verbs({ where?, limit, blacklist? })=
- =analysis.weakest(ontology, { where?, limit, blacklist? })=
- =analysis.novel(ontology, { where?, limit, blacklist? })=
- =analysis.due(ontology, { where?, limit, blacklist? })=
- =analysis.errors(ontology, { where?, limit, blacklist? })= — wraps =byLastSignal(["MISTAKE","FAILURE"], ...)=

*Decoders* (pure, no IO):
- =analysis.paradigm(conjugation) → { infinitive, forms, tenseSymbol, moodSymbol, lemmaSymbol, bySlug }=
- =analysis.failedTokenIndices(sentence) → number[]=
- =analysis.pickWeakForms(conjugation, forms, count) → LiteralEntity[]=
- =analysis.assess(items) → { total, avgStrength, errorRate, unseenRatio, phase, forms }=
- =analysis.weakest(items, n)=
- =analysis.weightedPick(entries, weightFn)=
- =analysis.shuffle(array)=

*Phase derivation* (pedagogical):
- =analysis.phase(items) → "FAMILIARIZE" | "EXPAND" | "CONSOLIDATE"=

** =ctx.routine=

*Primitive emitters* (one game, one gameplay):
- =routine.exhibit({ literals, layout?, title?, subtitle? })=
- =routine.exhibitNew({ sentences })= — filters virgin internally, no-op if none
- =routine.flashcardPass(literals, { recall? })=
- =routine.pick({ literal, distractors, recall? })=
- =routine.pickFromPool(items, distractors, { recall? })= — section + shuffle built in
- =routine.match({ literals, gameplay?, recall? })=
- =routine.paradigm({ conjugation, recall?, feedback?, order? })=
- =routine.shadowSentence(sentence, { rate? })=
- =routine.writeSentence(sentence)=
- =routine.listenWord(word, { gameplay? })=
- =routine.clozeOnIndices(sentence, blankIndices, { gameplay? })=
- =routine.conjugationDrill(literals)=
- =routine.judgeFast(items, distractors)=

*Compound pedagogical routines*:
- =routine.familiarize(items, { title?, subtitle?, layout? })= — exhibit + flashcards
- =routine.produce(items, { distractors? })= — pick + cloze + write
- =routine.reinforce(items)= — cloze-in-context + write
- =routine.stress(items, { distractors? })= — write + judge-FAST
- =routine.contextualize(forms, companions)= — the virgin→shadow / weak→write / vocalized→listen dispatch
- =routine.errorCloze(sentences)= — cloze on failed-token blanks for each

Compound routines absorb the =isParadigm= branching (forms vs paradigm.forms) and =pool.section(...).apply(shuffle)= plumbing.

* How emitters look after

** clinic scope (ser-estar)

#+begin_src js
export default async (ctx) => {
  const paradigms = [
    ...(await ctx.analysis.conjugations({ where: { symbols: ["word.lemma.ser"] } })),
    ...(await ctx.analysis.conjugations({ where: { symbols: ["word.lemma.estar"] } })),
  ];
  if (!paradigms.length) return;
  const phase = ctx.analysis.phase(paradigms);
  ctx.routine[phase.toLowerCase()](paradigms);
};
#+end_src

** survival buildup

#+begin_src js
export default async (ctx) => {
  const [conjugation] = await ctx.analysis.conjugations({ limit: 1 });
  if (!conjugation) return;
  const paradigm = ctx.analysis.paradigm(conjugation);
  if (!paradigm.forms.length) return;

  const companions = await ctx.analysis.verbs({
    limit: 4,
    blacklist: { literals: [...paradigm.forms.map((f) => f.id), paradigm.infinitive?.id] },
  });
  const weakForms = ctx.analysis.pickWeakForms(conjugation, paradigm.forms, 2);

  ctx.routine.exhibit({ literals: paradigm.forms, layout: "TABLE", title: paradigm.infinitive?.trait?.TRANSLATED?.learning, subtitle: [paradigm.tenseSymbol?.trait?.LABELED?.name, paradigm.moodSymbol?.trait?.LABELED?.name].filter(Boolean).join(" ") });
  ctx.routine.pickFromPool([...weakForms, ...companions], [...paradigm.forms, ...companions]);
  ctx.routine.match({ literals: [...weakForms, ...companions] });
  ctx.routine.paradigm({ conjugation });
  ctx.routine.contextualize(paradigm.forms, companions);
  ctx.routine.conjugationDrill([...companions, ...weakForms]);
};
#+end_src

** survival exercise

#+begin_src js
export default async (ctx) => {
  const sentences = await ctx.analysis.sentences({ limit: ctx.input.limit ?? 3 });
  if (!sentences.length) return;
  const errors = await ctx.analysis.errors("sentence", { limit: 3 });

  ctx.routine.exhibitNew({ sentences });
  for (const sentence of sentences) ctx.routine.contextualize.sentence(sentence);
  ctx.routine.errorCloze(errors);
};
#+end_src

* Implementation plan

** M1 — Promote shared decoders into =ctx.analysis= (no new middleware yet)
Move =extractParadigm=, =assess=, =weakest=, =weightedPick=, =shuffle=, =failedTokenIndices=, =pickWeakForms= into a new module =registry/modes/@vivalence/tactic/shared/analysis.js=. Import from both tactics. Kill =tactic/clinic/emitter/tools.js= inlined duplicates. Zero API change to effects.

** M2 — EMITTER trait attaches =ctx.analysis=
Runtime trait =systems/runtime/daemon/traits/emitter.js= populates =ctx.analysis= with the module above + repo-wrapper methods scoped to =ctx.daemon.entities.literal= + ambient user filter. Each emitter can call =ctx.analysis.*= without import.

** M3 — Routine primitives on =ctx.routine=
Implement single-game emitters first (one per game × variant). Tests: pool output shape. No compound routines yet.

** M4 — Compound pedagogical routines
=familiarize=, =produce=, =reinforce=, =stress=, =contextualize=, =errorCloze=. Absorb =isParadigm= branching.

** M5 — Migrate survival (5 files)
buildup ✓ (current version close), exercise ✓, warmup, drill, cooldown. Gate: each emitter under 30 lines.

** M6 — Migrate clinic scopes (12 files) + sub-emitters (4 files)
Scopes become =phase-dispatch= one-liners. Sub-emitters disappear — their bodies become compound routines.

* Gates before M1

1. Naming: =ctx.analysis= vs =ctx.study= vs =ctx.look=? =ctx.routine= vs =ctx.recipe= vs =ctx.teach=?
2. Location: =tactic/shared/= (co-located with consumers) vs =subsystems/typology/= (proper shared library)?
3. Scope of =ctx.analysis.phase= — does phase derivation belong in analysis, or is it a routine-layer concern?
4. Compound routines — inventory correct? What's missing for the A2 dataset work?
5. Does the EMITTER trait wire both middlewares, or do only tactic modes get them?

* Testing

- =mountMode= scenario gains a fake =ctx.routine= that records pool calls for inspection.
- =bench= scenario uses real routines; assertions on pool.drain() shape.
- Unit tests for analysis decoders (pure functions, easy).

* Emitter trace overlay (nice-to-have)

Panel D inside-tab extension: for the active thread, show which routine methods fired, what literals went in, what buffers came out. Without this, calibrating tactics stays opaque. Build once M3 lands so there's something meaningful to observe.

* Open questions

1. Should =analysis.phase= read from a Memory-scoped virtual entity (user × symbol progress) rather than re-derive on each call?
2. Do routines write span entries to telemetry (so the trace overlay picks them up for free)?
3. Do we support =ctx.routine.from(items).exhibit().pickFromPool()= fluent chaining, or stay positional?

* Principles respected

- *Emergence over workarounds.* Shared helpers live once. Duplication dies.
- *Architecture over expedience.* One middleware refactor eliminates 21 file rewrites.
- *Use repo methods.* Analysis wraps them; no tactic ever writes =em.find= or JS sorts again.
- *Design and implementation separate.* This document is design; M1–M6 are the implementation gates.
