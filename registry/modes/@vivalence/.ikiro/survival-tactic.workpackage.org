#+AUTHOR: Vivalence
#+DATE: 2026-03-25
#+STATUS: IMPLEMENTATION

* Intent

One tactic. Five phases. One session structure that covers everything
needed to conquer survival Brazilian Portuguese.

The session structure is universal — warmup, buildup, exercise, drill,
cooldown. Each phase has a dedicated emitter that composes buffers from
the existing game mode library. Each phase has a dedicated intent that
configures what content the emitter seeks.

No hallucinator. No cortex. Pure emitter architecture — seek literals
by symbol coordinates, compose game mode buffers, emit coherent
learning sequences.

* Session Phases

| Phase | Purpose | Energy | Buffer Count |
|-------+---------+--------+--------------|
| Warmup | Easy recall, get in the mood | Low | ~12-16 |
| Build Up | Conjugation paradigms, agreement chains | Rising | ~15-20 |
| Exercise | Deep sentence work, token decomposition | Peak | ~20-30 |
| Drill | Isolated verb form reps, high volume | Sustained | ~25-35 |
| Cool Down | Relaxed listening, reinforcement | Falling | ~10-16 |

** Warmup

Seek: words at survival proficiency.
Flow: exhibit new → flash all (easy direction) → judge all (slow) → listen vocalized (pick).
No typing. No production. Just recognition and audio exposure.

** Build Up

Seek: verb forms by lemma + tense + proficiency.
Flow: exhibit untouched paradigm → pick forms (paradigm siblings as distractors) → match person↔form → judge all.
Introduces conjugation patterns then tests recognition.

** Exercise

Seek: sentences at survival proficiency.
Flow: exhibit untouched sentences → exhibit untouched words → shadow sentences (slow) →
cloze untouched/unknown tokens → judge unknown (normal) + learning (fast) →
write sentences → listen(type) sentences → listen(pick) untouched/unknown words →
listen(type) learning words.

Memory-driven: groups tokens by status, not by sentence order.
The heaviest phase — resolves ANNOTATED tokens and their memory states.

** Drill

Seek: verb forms by tense + proficiency (broader than buildup — all survival verbs).
Flow: exhibit untouched → flash all (hard direction) → write all → judge all (fast).
Pure volume. Speed-based conditioning.

** Cool Down

Seek: any survival-proficiency literals with audio.
Flow: listen(pick) all (easy direction) → flash all (easy direction).
No typing. Relaxed audio exposure to end the session.

* Design Decisions

1. *One tactic, five emitters.* Not five tactics. The session structure
   is a single unit. Intents select content per phase.

2. *Memory-driven composition.* Exhibit only shows for UNTOUCHED content.
   Judge speed varies by memory status. Listen gameplay varies (pick for
   new, type for learned). The emitter reads memory and adapts.

3. *No reorder yet.* Reorder mode exists conceptually but the Svelte
   component needs drag interaction work. Exercise phase can add it later.

4. *Exercise resolves tokens.* The most complex emitter. It fetches
   sentences, resolves their ANNOTATED tokens via findOne + memory
   populate, then groups by memory status. This is the only emitter
   that does cross-entity resolution.

5. *Phases don't share state.* Each intent invocation is independent.
   No session-level tracking of "words seen in warmup, skip in drill."
   That's a future concern (session blacklist accumulation).

6. *Judge renamed from speed-judge.* The mode directory is =game/judge/=.
