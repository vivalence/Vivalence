* Stanza NLP Service

Docker: =docker compose up -d= from =server/=
Port: =localhost:5555=
Health: =GET /status=

** Connect

#+begin_src bash
curl -X POST http://localhost:5555/tokenize \
  -H "Content-Type: application/json" \
  -d '{"language":"es","text":"María se mira","processors":"tokenize,mwt,pos,lemma,depparse"}'
#+end_src

#+begin_src javascript
import { Connection, Url } from "@vivalence/typology";
const nlp = new Connection(new Url("http://localhost:5555"));
const result = await nlp.call("/tokenize", {
  language: "es",
  text: "María se mira",
  processors: "tokenize,mwt,pos,lemma,depparse",
});
#+end_src

** Processors

=tokenize,mwt,pos,lemma,depparse=

| processor | fields |
|-----------+------------------------------|
| tokenize  | index, token, start/end_char |
| pos       | upos, xpos, feats            |
| lemma     | lemma                        |
| depparse  | head, deprel                 |
